GitHub官方规则：未认证REST请求按来源IP每小时60次，通常认证用户每小时5000次。代理若共用出口，未认证额度可能共享；本次没有测量其他用户流量。primary超限通常403/429且remaining=0，按reset等待；secondary按Retry-After或退避。GET /rate_limit不计primary配额，但不应高频轮询；实际请求的响应头优先。
