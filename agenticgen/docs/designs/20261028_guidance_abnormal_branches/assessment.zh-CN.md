# 进一步的异常行动分支：研究、代码核查与第三轮访谈

日期：2026-10-28，Asia/Shanghai。核查已提交基线 `f08cc928`，原 skills 1.3.0。本轮没有运行新分子实验；下列情景是风险分析或明确标注的模拟，不是新增测量。

## 主要发现

“动作合法”和“行动值得做”是两个不同问题。当前验证器能检查身份、整数步长、分支方向、边界和重复，但并不证明候选有改善价值、具有独立信息或适用于另一锚点。仅增加“谨慎”“充分思考”之类措辞不足以填补这些分支。

| 异常分支 | 可能出现的错误行动 | 本轮增加的指引或提出的决策 |
| --- | --- | --- |
| 每个方向强制选一个，但其中一个缺乏实验价值 | 为满足格式捏造收益理由，浪费一次生成 | 用户已选择该方向可以暂不行动；须增加执行器状态，不能仅凭 skills 实现 |
| `feasible_examples` 被当成完整候选集或推荐排序 | 始终选择固定顺序靠前的锚点、区间和步长，形成不必要的搜索偏置 | 明确它是合法示例，不保证完整，也不是效能排序；综合器的精确候选键集合仍必须遵守 |
| 常数权重标定被误解为四维组合验证 | 任意组合经验上下限，并据此宣布稳定 | 区分坐标范围与已测组合；合法的混合窗口仍需要实测和绝对位移证据 |
| 请求失败、执行中断和分子结果差被混为一类 | 从空输出推出引导过强；从评价异常推出零误差或分子失败 | 先按实际证据区分请求/格式、执行、评价缺失和有效差结果；保留部分可用观察，缺失不补写 |
| 同一区间的效应随其他区间变化 | 用全局口号覆盖相反记录，或删除不合预期的证据 | 保留锚点和背景；询问是否优先做联动对照、局部单步、联合性能搜索或分背景规则 |
| 均值好，但种子表现不一致 | 把总体平均改善称为每类样本都改善；暗中改变目标排序 | 询问一致性、均值、较差情形或暂存双方案的取舍；未获得逐种子数据时不能作该判断 |
| 反复在相同随机样本上搜索 | 把搜索面板上的最优称为独立验证或普遍改进 | 明确结论范围；询问未来是否预留未参与搜索的最终验证样本 |
| 多个角色给出一致解释 | 把同源意见重复当独立证据，选择看似自信的答案 | 一致意见不能替代新的测量或独立核查；综合器仍需核对原始证据 |

上一轮尚未回答的“暂时退化的辨因实验”“新锚点选择”“长历史工作上下文”保持原状态。新问题没有替代或默认回答这些问题。

## 原始研究依据

1. [KnowNo，CoRL 2023，第 3 节](https://proceedings.mlr.press/v229/ren23a/ren23a.pdf)：显式构造不确定性与求助状态。其共形预测依赖校准数据和适用假设；本项目只借鉴接口与证据边界，不声称获得其统计保证。
2. [Why Do Multi-Agent LLM Systems Fail?，arXiv v3](https://arxiv.org/html/2503.13657v3)：区分任务/角色规范、协作及验证问题，包含重复步骤、推理与行动不符、验证不充分等模式。本项目的“请求失败不等于分子失败”是据此作出的领域适配。
3. [TuRBO，NeurIPS 2019，第 2 节及第 3.6 节](https://proceedings.neurips.cc/paper/2019/file/6c990b7aca7bc7058f5e98ea909e924b-Paper.pdf)：不同局部区域可以有不同响应规律；不能把局部响应无条件外推。这里没有实现其高斯过程或信赖域算法。
4. [NIST/SEMATECH 实验设计指南，5.2.1.2](https://www.itl.nist.gov/div898/handbook/pri/section2/pri212.htm)：仅逐个改变因素无法识别交互。相反响应可能与其他区间背景有关，但不凭现有稀疏数据认定已证实交互。
5. [Bayesian Optimization of Risk Measures，NeurIPS 2020，第 2.2 节](https://papers.nips.cc/paper/2020/file/e8f2779682fd11fa2067beffc27a9192-Paper.pdf)：均值、尾部风险与最坏情形对应不同优化目标。本轮询问偏好，不擅自新增风险目标或计算没有数据支持的尾部概率。
6. [Cawley 与 Talbot，JMLR 2010](https://www.jmlr.org/papers/volume11/cawley10a/cawley10a.pdf)：有限评价准则也可能被优化过程过拟合，从而产生选择偏差。固定分子随机面板是适用性类比，不是已经测得本项目过拟合。

来源基于本次实际阅读的原文/官方指南；未将综述、媒体或第三方解读当作原始证据。

## 代码定位与实施边界

以下以 `git show f08cc928:<path>` 的已提交内容为准。工作区存在其他任务的采样代码改动，本次未修改或提交那些文件。

- `geometry_protocol.py::legal_options(..., limit=2)` 按历史聚合误差排序，遍历步长和窗口，达到数量即返回。它是合法动作示例生成器，不是效能推荐器，也不是穷举结果。
- `geometry_protocol.py::derive_domain` 从完整的常数权重组提取标定范围，再形成各窗口的范围约束；返回值也明确 `stability_guarantee=False`。这不能证明四窗口任意组合稳定。
- `geometry_council.py::advise` 在非最终模式中，每分支 `proposals` 数量固定为两个；综合 `selected` 要求每分支一个候选。合法候选不足时直接报错；没有“合法但缺乏价值”的弃选状态。
- `geometry_council.py::history_view` 主要提供配置级指标和区间诊断，未提供完整逐种子结果。因此种子一致性偏好必须有输入构造支持，不能让 Agent 从均值反推。
- `geometry_protocol.py::choose` 仍按全部约束原子对聚合误差排序。本轮不会把某种风险偏好伪装成已有自动排名。

若实现弃选，需要同时处理提案、综合选择、执行调度、尝试账本和完成判定。弃选不是生成失败，也不是一次成功评测；其计数需协议明确。当前本轮只写入已确认的指引及这项能力缺口。

## 已确认与待确认

用户已确认 `branch-evidence-abstention-v1`：某方向没有支持的改善或有辨别价值的实验时，可以暂不行动，并说明缺失证据，其他有价值方向继续选择。新候选尚未测过不等于没有价值；弃选不是默认放弃所有不确定实验。

区间交互的实验取舍、均值与种子一致性的偏好，以及未见验证样本安排仍待答。原始问题、选项、答案和来源保存在 `interview.json`。选择某项未来策略不自动授权启动试验、改变冻结版本或新增预算。

## 手工反例复核

以下只核对规则含义，不是 LLM 行为测试：

- 空正文、输出截断：保留请求失败证据，不把它记为“该权重导致分子崩坏”。
- 评价程序异常但结构已保存：该评价未知；已有有效指标保留，不能全部归零。
- 示例动作只列了最靠前窗口：这不能证明其他合法窗口没有价值。
- 同一调整在不同锚点效果相反：两份测量都保留，学习附带背景的规则，不凭叙述消除矛盾。
- 新配置没有历史成绩但有可检验假设：不能仅因“未测”而弃选。
- 没有独立评价集：可以报告固定随机面板内的结果，不能称作泛化验证。
