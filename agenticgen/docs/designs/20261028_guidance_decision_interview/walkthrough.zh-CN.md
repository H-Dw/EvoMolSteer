2026-10-28，Asia/Shanghai。本文配合标准技能包 `guidance-experiment-optimizer` 1.2.0。用户已回答四项访谈，确认“条件几何优先、停滞后关注邻域设计、自适应局部搜索、风险先诊断”。原始答案与解释分开保存在 `interview.json`；未提供的数值界限保持未定。

## 先区分协议与证据

当前仓库同时保存旧坐标引导和新内部距离引导。旧结果中的控制原子坐标均方根偏差，不能冒充新协议的分子内原子对距离均方根偏差。新内部距离实现的数值验收也不是完整生成效果实验。

下面的数值模拟采用已提交 `da1b535ad0f71fb9e37e37773d6d0c58234dff4e` 的内部距离动作契约，仅用于说明决策。Agent 只返回锚点以及区间和整数步长 `updates`，执行器计算完整归一化权重和实际强度。通用技能包的旧实际权重 `schedule` 接口和新接口不能直接交换；本文中的权重数组是执行器计算后的解释，不是要求新 Agent 输出数组。

## 一次完整决策如何运行

| 步骤 | Guidance Agent 或控制器做什么 | 可检查的产物 |
| --- | --- | --- |
| 绑定问题 | 控制器提供教师、条件、原子对应、完整指标名称、合法动作、随机状态、预算与当前模式 | 明确本次优化什么、可改什么；禁止根据文字猜测指标定义 |
| 整理历史 | 读取所有已提供的兼容历史，按科学配置身份识别重复；失败与缺失另列 | 可比较记录、复用记录、不可比较证据和历史覆盖限制 |
| 回看预测 | 把先前提案与实际执行配置、原锚点和实测结果对应 | 支持、反驳、尚不确定；不事后改写原预测 |
| 形成假设 | 从匹配对照中识别哪个区间可能控制不足、干预过强或受前序状态影响 | 观测、机制假设、待区分的其他解释分别说明 |
| 选择锚点 | 选择已测且允许执行的权重配置；比较对象可另选 | 实际锚点标识、原权重；不把父配置误作物理初态 |
| 私有建议 | 增大、减小、重新分配三个角色，在各自约束下给出合法候选 | 每个候选的目的、改变区间、历史依据、预测和反证 |
| 综合选择 | 在已有候选中选择；同时看集合是否重复或只检验同一解释 | 选中候选键，以及相对未选候选的理由；不重新编造权重 |
| 执行前校验 | 控制器检查身份、刻度、边界、分支、配置指纹和预算 | 不合规行动被拒绝；重复成功配置复用原记录 |
| 实际评价 | 仅在外部授权的实验中运行采样与诊断；保留失败、缺失及极端值 | 原始结果、全量基础指标、指定子集诊断及覆盖范围 |
| 更新下一次选择 | 用新增结果修改假设和下一步权重分配；外部决定是否继续 | 可追溯的分配结论，而非重复上一轮叙述 |

例如，“降低某区间强度能改善邻域距离”是可检验假设；“权重越大越好”没有适用背景，也没有反证条件。若只看终态误差，不能判定过程中发生了振荡；若同时改两个区间，不能分别归因。

## 输入与输出如何保持固定、简短

输入分成五类：冻结的任务与动作契约、当前教师的标定和边界、兼容历史及复用身份、已执行提案与实测反馈、当前角色和适用的已确认偏好。历史的测量值保留精度、类型与失败信息；可共享重复对象，但执行标识与可执行锚点列表要明确展示。研究文献和全部访谈记录由主 GPT 管理，不在每次私有调用中重复拼接。

| 输出角色 | 固定顶层模块 | 模块内必须交代的内容 |
| --- | --- | --- |
| 私有建议 | `analysis`、`mechanism_uncertainty`、`proposals` | 决定性历史比较与更新后的假设；尚未排除的解释；符合当前 schema 数量要求的提案 |
| 每个内部距离提案 | `id`、`branch`、`anchor_id`、`anchor_reason`、`updates`、`evidence`、`prediction`、`falsifier` | 精确身份；选择锚点的原因；整数区间更新；实测依据；相对锚点的预期变化；什么观测会反驳它 |
| 综合选择 | `analysis`、`choice_evidence`、`selected` | 候选之间的价值差异；选择与未选的理由；原候选键，不能生成新权重 |

最终分析模式以外部 schema 为准，可要求空提案并不返回选择。一个回答只含一个完整 JSON 对象，禁止额外 Markdown、重复字段、非有限值或追加对象。长历史不要求长叙述：用最多两项决定性比较支持当前选择，保留反证与不确定性；这不会保证模型内部 reasoning 不再截断。

## 数值情景：三个角色会如何提出不同实验

**本节所有数值均为假设，不是真实教师结果。** 固定同一个模拟教师、相同原子映射、初态和随机样本。四个位置依次对应第 10–25、26–50、51–75、76–90 步。

| 假设已测配置 | 归一化权重刻度 | 控制原子间距离均方根偏差 | 控制原子与邻域原子距离均方根偏差 |
| --- | --- | --- | --- |
| 基准 | `[0,0,0,0]` | 0.34 Å | 0.14 Å |
| 第二区间更强 | `[0,2,0,0]` | 0.30 Å | 0.18 Å |
| 第二区间更弱 | `[0,-2,0,0]` | 0.38 Å | 0.10 Å |

归一化零值表示本教师的标定基准强度，负值表示较弱，不表示反向力；具体倍率仍来自该教师真实标定。本模拟使用倍率 1 和区间 [-2,2] 作为机械校验夹具，不提供任何教师的推荐倍率或允许范围。

可提出的假设为：“在这个背景上，第二区间增强能改善控制集合内部距离，但可能损害其与邻域的几何关系。”这些数据尚不能说明其他区间的效果，也不能决定两种误差的取舍。

| 角色 | 两个示例合法候选 | 主要用途与未解决的问题 |
| --- | --- | --- |
| 增大 | `[1,0,0,0]`；`[0,0,1,0]` | 探索其他区间是否提供不同的收益/退化关系；尚无匹配证据保证有效 |
| 减小 | `[0,-1,0,0]`；`[0,0,0,-1]` | 前者测试第二区间的较小回退；后者区分末段干预是否相关 |
| 重新分配 | `[0,-1,1,0]`；`[0,-1,0,1]` | 测试减弱第二区间并在其他区间补充干预；属于联合变化，不能拆成单区间因果 |

例如，第二个区间的一步回退对应 `anchor_id="simulated/baseline"` 和 `updates=[{"window_id":1,"step":-1}]`。窗口标识从零计数；实际强度减半，而不是减去固定物理强度。同一候选改两个区间时使用相同绝对整数步长；重新分配要求符号相反。完整提案仍须包含既定的证据、预测和反证字段。

综合 Agent 不能仅凭这张表宣称某个候选最优。根据用户已确认的条件几何优先原则，应先寻找改善控制原子间距离且邻域退化可接受的候选。不能仅因减小角色预计改善邻域距离，就认定其整体优于其他分支；减小动作还需有条件几何收益、风险诊断或已成立的阶段转换依据。缺少明确退化限度时，方向偏好和已通过验收仍是两件事。`simulation.json` 保留访谈前的离线快照，没有实际选择或执行任何组合。

同名或改名重复 `[0,2,0,0]` 都不会提供新独立证据。使用共享标签 `r80` 作为锚点、把增大的动作放到减小分支、超出标定区间也会被拒绝。离线脚本直接使用固定提交的纯动作校验函数，检查 **6 个合法候选和 4 个非法示例**；没有调用模型或采样。

## 模拟一次预测与实测回看

假设外部选择了 `[0,-1,0,0]`。注册的预测是：相对基准，控制原子与邻域原子距离均方根偏差减小，控制原子间距离均方根偏差可能小幅增大。可反驳它的结果是邻域距离没有改善，或实际退化超过事先规定的容差；没有给出容差时，不能自行认定“足够小”。

**继续假设** 下一次得到 0.36 Å 和 0.11 Å：该批样本的变化方向与假设一致，但未提供跨种子不确定性，不能宣布普遍规律。Agent 更新为“第二区间回退具有局部折中作用”，再依据用户偏好决定优先验证邻域收益、保留基准，还是测试重新分配。它不能把预测事后改成“两个指标都会改善”。

按照本次用户答复，这个结果支持原折中假设，却不自动成为优先采用的配置：控制原子间距离从 0.34 Å 变差到 0.36 Å，邻域改善不能自行抵消条件几何退化。在尚未成立的停滞状态或未给出保护容差时，应保留这一限制。预测准确与决策目标达成需要分别判断。

如果反而得到 0.40 Å 和 0.17 Å，原局部收益假设被这批结果反驳。下一步应更换解释或比较背景，而不是继续套用“减弱就会改善”的理由。两条都是教学分支，没有真实生成这些分子。

## 如何把回答写回 skills

记录用户原话和理由，随后提炼“适用条件—优先行动—取舍原因—改变判断的证据”。区分用户确实选择的内容、主 Agent 的解释和仍然缺失的参数。一个教师上的具体偏好，不自动推广为其他教师的数值阈值。

只将已确认且不改变执行契约的偏好用于相应提示。需要改变排序、硬约束、动作集合或预算的选择，标明需要执行器集成，不能只改提示便宣称已生效。推荐项、待回答问题和模拟数字均不写成默认已接受策略。

用户答复已记入 `interview.json`，1.2.0 把已确认原则写入通用技能包、内部距离 Guidance Agent 的三个角色和负责复盘的主 GPT 技能。未恢复任何暂停实验，也未修改科学损失、执行器排序或采样代码。

## 用户确认后的决策规则与实际边界

| 情况 | 已确认原则 | 不能从回答中推断的内容 |
| --- | --- | --- |

| 兼容历史持续缺少明显的条件距离改善 | 将更多实验注意力转向条件区域与其他配体原子的关系，保护已经取得的条件几何效果 | 没有固定轮次数、最小改善幅度、噪声界限或保护容差；不能以重复配置或 API 失败判断科学停滞 |
| 局部实验有收益或无收益 | 有收益沿局部改进，无收益收小合法干预，信息耗尽后换已测锚点 | 不改变合法整数步长或教师标定范围，不自动添加实验预算 |
