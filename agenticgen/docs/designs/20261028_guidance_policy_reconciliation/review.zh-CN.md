# Guidance Agent skills 1.5.0：六项决策落实与逻辑冲突审查

记录时间：2026-10-28T19:15:14.362405+08:00（Asia/Shanghai）。本次只修改标准skills、渲染包与决策/审查文档；没有发起模型请求、分子采样、远端部署、重启或自动化变更。此前实验的暂停状态不因本次工作改变。

## 已采用的六项决定

| 用户回答 | 写入的规则 |
| --- | --- |
| 1B及括号补充 | 允许有价值的探索实验变差；连续两轮退化后，回到最优兼容checkpoint的策略基础，利用后续失败提出新策略。以明确补充为准，不采用旧B选项“禁止预期退化”的含义 |
| 2A | 局部耗尽后，结合条件几何及风险，选择能检验不同分配假设的已测锚点 |
| 3A | 工作上下文采用全局覆盖概览、当前锚点关键对照、反例与风险记录，并保留源文追溯；完整账本不删减 |
| 4C | 优先联合配置的实测性能，不要求先拆清每个窗口的独立作用 |
| 5B | 优先总体平均改善，受明确退化界限约束；不额外要求所有种子一致改善 |
| 6B | 继续固定样本，结论限定于该样本集合，不默认增加留出验证 |

这些规则以`history-adaptive-search-v2`统一记录，并保留先前的条件几何优先、先广筛后集中验证、无价值方向可弃选三项选择。直接答案与实现解释分开，未替用户补写选择理由。

## 已消除的指引冲突

| 原有或潜在冲突 | 本次处理 |
| --- | --- |
| 1B字母与用户补充文字相反 | 明确补充优先；原选项仍留在历史问卷，新的答案标记为自定义修订 |
| 保护条件几何与允许实验变差 | 区分探索候选与最佳结果接受；探索可以失利，最佳记录不随之降级，外部硬约束仍有效 |
| 不在skills固定总轮次与“两轮退化” | 把2记入外部决策参数记录，运行指引引用供给的触发条件；不规定实验总轮数 |
| 每次失败缩小局部搜索与强制回滚 | 已核实回滚触发优先于普通局部继续；极端结构风险诊断仍优先处理 |
| 回滚旧checkpoint与保留最新经验/指引 | 只回到策略基础，保留全部后续失败和最新用户政策；不倒退账本、预算、科学绑定或合法动作校验 |
| 最优锚点耗尽与必须从最优处重启 | 以最优作为恢复基准，允许选支持新假设的兼容已测锚点；不重跑最佳结果 |
| 全历史学习与紧凑上下文 | 完整账本、推理工作上下文和主GPT全版本复盘分层；选择后的输入不能宣称完整 |
| 优先辨因/单窗口分析与4C | 有用的联合改善可以先推进；隔离变量仅在影响下一决策或风险定位时采用 |
| 平均收益与种子一致性/极端风险 | 一致性不再成为额外目标，但实际结构失效和外部界限不能被均值掩盖 |
| 主指标优先与平台期转向邻域 | 平台期允许在条件保护限度内改善邻域均值，不再要求每次次目标改善也降低主指标 |
| 文献建议独立验证与6B | 固定样本结论明确限域；不将论文中的建议视为用户已选择的验证计划 |
| 多个角色重复书写研究与完整固定输出 | 保留原角色JSON模块、字段和字符上限；只写关键证据、更新假设、行动、预测和否定条件 |

## 仍需执行层接入，不能宣称已由skills实现

本次检查的源码版本见`decisions.json`与`validation.json`中的哈希。下列缺口已经写进主GPT维护skills，属于代码/参数接入问题，不再作为未回答的偏好问题。

| 边界 | 当前代码证据 | 采用前需要的工作 |
| --- | --- | --- |
| 分支弃选 | `geometry_council.py`私有schema固定两个提案；综合结果必须三方向；`geometry_runtime.py`要求三提案且检查固定总组数 | 扩展schema、分发、预算与完成回执；不能用非法空数组或虚构skip伪装 |
| 连续退化回滚 | 当前`geometry_council.py`/`geometry_runtime.py`没有消费本次策略参数或实施相应回滚流程 | 绑定轮次单位、代表结果、退化比较基准与容差、缺失/中间状态的计数规则、兼容checkpoint；再实现审计回滚 |
| 条件几何优先的数值排名 | `geometry_protocol.py::choose`仍按全部约束原子对的聚合距离误差排序 | 不覆盖旧排名；另行实现和校验明确的条件几何优先排序及接受界限 |
| 精选工作上下文 | `geometry_council.py::advise`仍将全部兼容history行放入上下文 | 实现有覆盖元数据和来源追溯的选择机制；全局去重不能只依赖选入上下文 |
| 均值、种子和退化边界 | `history_view`未包含完整逐种子结果；本次未指定均值分母/缺失处理、条件保护/邻域容差 | 保留实际分母和失败，不从均值捏造逐种子结果，不自定通用阈值 |
| 广筛后验证 | 现有正式组仍固定总体规模；偏好本身不改变调度 | 如采用分阶段正式评价，需显式预算和群体身份，复用已测槽位 |

其中只有`consecutive_regression_limit=2`是本次明确新增的数字。不能把“两个候选差”“两轮没进步”“两次API失败”当作“连续两轮已测退化”。全程最优值也不能直接作为会下降的轮次序列。缺少定义时应报告实施缺口，不能凭skills自动恢复正在暂停的实验。
