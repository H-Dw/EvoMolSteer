# 默认化学信息inpainting，坐标继续gradient guidance

本次在`777bfa36`模板距离实现及其后续运维提交上集成化学状态注入。使用现有化学投影实现的语义，接入当前的单组、预实验、正式Agent以及混合候选批执行入口。历史冻结目录和旧失败产物不迁移或覆盖。

## 配置和执行范围

```json
{
  "protocol": "template-relative-distance-guidance-v5-chemical-state-inpainting",
  "output_policy": "raw999",
  "chemical_inpainting": {"enabled": true},
  "maximum_single_atom_guidance_increment_angstrom": 3.0
}
```

`chemical_inpainting`省略时默认开启，运行配置会将默认值显式写入冻结文件。对照实验可以显式设为false；不接受坐标覆盖、额外通道或终态强制替换选项。

化学来源为当前条件对象中已优化分子的完整原子/键图，而非原始复合物坐标或历史教师SDF。将完整图交给RDKit确定控制原子的杂化状态，并按实际FLOWR词表编码元素、形式电荷、可用时的杂化状态及控制原子之间的诱导键类型（含无键）。原生模型要求去芳香化时按其配置进行Kekulé转换。

仅注入`controlled_atom_ids`及它们之间的键，使用冻结的`atom_to_generated_slot`。邻域和其他原子的化学通道、控制—外部原子之间的键、对角键、mask和自条件均不覆盖。化学映射不调用Hungarian匹配，不依赖运行中的距离配对顺序。

每步先执行原生化学随机转移及坐标更新，再按原公式施加完整坐标VJP引导与逐候选3 Å上限，最后在第10–99步更新后投影化学状态。化学投影不调用模型或随机数，不修改任何坐标张量。化学状态会影响下一次模型预测，这是条件生成的预期作用，不能要求整个后续坐标轨迹与无inpainting对照相同。

raw999维持100个积分区间、0–0.999网格，最终返回第99循环中的未覆盖预测；不添加终态前向或终态化学/坐标覆盖。因此采样状态被注入不等于最终返回分子的化学身份得到硬保证。第99步状态注入及坐标更新不再影响已捕获的返回预测；最后影响返回值的状态更新为第98步。

## 绑定和记录

`CHEMICAL_CONDITION.json`保存输入条件哈希、控制原子ID、生成槽位、实际原生化学编码、RDKit版本及投影语义。其哈希写入`OUTPUT_POLICY.json`，完整绑定写入checkpoint。轨迹保存投影后的化学类别，逐候选记录投影前后的匹配率及是否执行；混合批拆分和人口合并按原seed/slot保留这些字段。

开启状态、实现和条件进入采样兼容性指纹。恢复拒绝不同化学配置或映射，旧无inpainting的λ、缓存、验收回执不能复用为新协议结果。Agent上下文明确说明化学注入范围与最终未覆盖输出的区别；不修改已有不可变skills 2.2.0文件。
