## 采样配置

`agenticgen/configs/uniguide_geometry.json`：

```json
{
  "protocol": "normalized-internal-distance-guidance-v3-raw999-limited",
  "output_policy": "raw999",
  "steps": 100,
  "windows": [[10,25],[26,50],[51,75],[76,99]],
  "maximum_single_atom_guidance_increment_angstrom": 3.0
}
```

100个积分区间覆盖0–0.999，步宽0.00999；返回第99次循环中的未覆盖预测，其网络时间约0.98901。没有额外终态前向、坐标覆盖或化学inpainting。第99步更新仍执行并保留最终状态，但不会影响已经读取的返回预测；最后影响返回值的引导更新为第98步。

第四窗口由76–90延长至76–99，其余三个窗口不变。预实验与Agent推理共用相同采样实现和限幅规则，混合方向candidate batch也使用相同规则。

## 大增量如何约束

先按原完整坐标反传和积分公式计算每个候选的原始引导增量。对于候选分子b，令最大有效原子向量范数为d_b，单位Å；配置上限为L。执行器计算：

`candidate_scale_factor = min(1, L / d_b)`

然后用这一个系数等比例缩放该分子的所有有效原子引导向量。若d_b为0则系数为1。实际实现对触发限幅的行额外留极小浮点舍入余量，确保转换回采样精度后的向量范数不超过L；未触发候选按位保留。

例如一个分子的最大原子增量为12 Å，上限为3 Å，它的整个引导向量缩到约四分之一；同批最大增量为1 Å的另一分子完全不变。采用每分子统一缩放，保留该分子引导方向及各原子相对权重，避免逐坐标截断扭曲方向。限幅后继续当前轨迹，不丢弃候选、不重采、不关掉整个batch或整个gradient guidance，不修改Agent提出的窗口强度。

限制的是单次**gradient guidance贡献**，不是原生漂移、随机噪声或总坐标变化。原生更新本身仍可能很大，3 Å上限不是整体数值稳定性或分子质量保证。NaN/Inf不能通过有限半径修复，继续明确记录原有非有限失败，不冒充有限限幅成功。

阈值必须在config中显式提供正有限数；代码内没有3 Å常量。范围可按新的实验配置调整。单位转换使用模型的coord_scale；范数和缩放计算用float64，避免大但有限的float32向量仅因平方求和溢出而被误判。

## 审计、Agent反馈与恢复

保留原始和实际引导向量、逐候选原始最大位移、缩放系数及触发标记。组统计同时报告限幅候选数、限幅候选步数、最小缩放系数和未限幅最大位移，窗口诊断扩展到99步。批结果拆分与人口合并保持这些字段的seed/slot身份。

Agent历史输入明确区分未约束与实际位移。高强度频繁触发限幅仍是风险证据；不能仅因实际位移被限制就断言强度安全。标定原有绝对增长审计继续读取未限幅位移，避免限幅掩盖原始梯度失稳。

采样网格、输出策略、窗口、限幅方法和阈值进入兼容性指纹与checkpoint绑定。恢复时任一变化都拒绝；末状态checkpoint保留最后未覆盖预测，末状态恢复无需再做终态前向。旧native输出/10–90/无限幅的λ和测量不得混入新协议，后续需在新协议下取得真实预实验结果。
