# 线性强度控制实现说明

实现入口仍为 `agenticgen/scripts/run_uniguide_geometry.py`。新建绝对坐标实验默认使用 skills `2.6.0` 和 `linear-envelope-frontier-v1`；显式使用旧 `2.5.0` 的配置仍进入旧控制器，不迁移历史 manifest、λ、失败账本或成绩。本次修改未部署远端或启动真实生成、标定、LLM 调用。

## 配置与数值含义

完整配置继续提供独立结果根、冻结初态源、模型、条件特征、随机数、科学协议和外部 `rounds`。将 [控制配置片段](../../../configs/uniguide_linear_control.json) 合入一个新的绝对坐标实验配置；该片段不是包含模型和条件的可直接运行配置。

- 新字段：`guidance_scale_tick_schedule`、`calibrated_guidance_reference_scale`、`guidance_scale_grid_unit`、`effective_guidance_scale_schedule`。
- 实际强度为教师冻结基准加格距乘整数刻度；默认格距 10。Agent 只提交精确锚点、窗口、整数 `step`。
- 默认工作半径两档，最大单窗变化四档，总绝对档位变化上限六档。±10、±20 为近邻，±30、±40 或使用未确认强度进入范围取证。
- 格距、声明搜索域、教师独立初始列表和预算均在外部配置。相对刻度没有额外 `[-10,10]` 截断；非正、非格点和越界强度拒绝，不夹断。
- 刻度零是基准。关闭引导用独立开关，不能把零刻度解释为关闭或将负刻度解释为排斥。

初始值按教师覆盖新配置示例中的不同列表，但它们是待测设置，不是新取得的 λ 或安全范围。旧 45.2548、64、90.5097 的成绩不能转记成 50、60、90。

## 标定与范围取证

`linear_calibration.py` 使用固定槽位的 10→20→50 人口提升。补点优先取得最佳附近的上侧证据，取消下侧三档面板及边界最佳即停止的要求。λ 从可排名的完整人口常数配置选择一次冻结；全部确认常数档保留，不只保留选中的小面板。

默认最多筛选八个常数档，最多四档晋级确认，常数部分最多新增 240 次；为具体范围取证保留 100 次，另外 10 次不强制花完。声明最大筛选档数可调整，但每教师 350 次总预算与取证预留均在预留前检查。失败不退款、不替换、不自动重试。

Agent 可请求具体的更高强度或更远邻域配置，不需先证明窗口作用。范围取证先测 20 候选，使用现任在相同种子和槽位上的原始记录重算统计、取双方保留掩码交集，再决定是否新增 30 候选。20 候选结果不能直接与 50 候选均值排序。

完整、可排名且通过既定增长检查的 50 候选结果可以成为新锚点。范围修订追加独立版本并引用原测量，λ 不变；一次混合配置成功不把其中强度宣布为所有窗口背景下可用。失败常数也不自动否决所有不同窗口组合。范围预算不足记录 `budget_limited`，不会重发 LLM 或暗中放宽规则。

已有完整小人口配置可以继续提升，只计实际新增的槽位；失败或中断的精确配置禁止自动接续。工程错误与数值失败分开，工程错误直接保留现场并抛出。

## Agent 与归档

每个决策使用提案、综合选择两个角色，仍使用现有真实 provider、严格 JSON、共享调用/输出预算和只读工具。公共科学契约只出现一次。提案包含实测依据、改善理由和不确定性，移除机制解释和自然语言反证字段；可选 0 至外部上限条方案，不再要求三个方向各选一条。

`hold` 不采样；`request_domain_evidence` 交由受预算约束的执行器处理。相同实际配置按原测量引用，不当作独立验证；整数和浮点写法的等值输入在新线性接口解析为相同强度格点。正式剩余预算和范围取证预算分别反馈，预算不足的未执行动作单独记录。

最终选优和逐槽结构保留包含所有兼容、完整、可排名历史，包括标定基线。`representative` 是全历史最佳，`best_formal_group` 另记正式优化组最佳，允许为空。保持现任或仅完成部分教师时，不伪造固定数量的已完成生成组。

每轮保存实际请求、输出、原提案、解析后参数、历史快照及 `ROUND_COMPLETE.json`；回放核对原测量回执、对话文件和范围版本。结果分别记录外部轮数、完成轮数、请求数、实测/复用组数、保持现任轮数及范围事件。`quality_source_groups` 给出实际生成源和最终代表的规范路径，供独立 CPU 队列按已有 10/50 策略检查，不能用请求别名重复计数。

## 直接选择初始窗口值

完成兼容标定或使用严格绑定的 `reuse-calibration` 后，可以提供教师到四窗口实际强度的 JSON：

```json
{
  "6pyy_H7S_A_402": [40, 50, 60, 50],
  "3w54_RNB_A_504": [60, 60, 70, 60]
}
```

以上只是格式示例，实际值必须来自对应教师的已确认档位。使用：

```bash
python agenticgen/scripts/run_uniguide_geometry.py --config /path/to/new-config.json select-initial --initial-scales /path/to/initial.json --scale-units actual
```

默认 `--scale-units ticks` 保留整数刻度接口；存档统一保存刻度、基准、格距和实际强度。已开始版本不能变更初始选择。复用接口不接受旧指数协议的 λ，也不静默改变来源搜索规则。

## 验证范围

新增测试覆盖线性转换、教师隔离、上侧补点、边界最佳、整数联合动作、同方向组合、无动作、预算与失败保护、小人口复用和全历史选优。CPU 回归使用工程夹具，不执行 API 或科学采样。未改变 `sampler.py`、绝对坐标目标、raw999 积分、冻结匹配、化学状态注入和 UG04 串行调度的数值实现；采样绑定新增线性控制语义，新实验仍必须完成固定提交上的真实模型验收，不能搬用旧验收回执。
