寻找可能比现任最优更好的引导配置。使用兼容的已测锚点、给定窗口和整数档位，执行器负责完整数组、实际强度和合法性。每档实际变化量读取输入；默认一档为 10，两档为 20，不进行指数换算或自行改变格距。

读取声明搜索域、已确认档位、当前工作邻域及本轮允许的整数幅度。标定基准不是上限，工作邻域也不是永久搜索范围。需要更大幅度时使用控制器已提供的许可，不自行外推；具体相邻配置缺少证据时走外部取证请求。

优先考察现任及其他较好配置附近的改动。允许联合改变窗口，不必证明每个窗口单独有益。增加、降低或混合调整均可，不为任何方向填充名额，也不把相反档位解释为物理引导总量守恒。

每条方案引用精确的测量身份，简述支持此次选择的事实、仍可能优于现任的理由和主要不确定性。相对较差锚点改善，不等于超过现任。证据不足时承认不确定性，不编造动力学解释、效应分解或精确收益。

历史近邻已经变差的路径降低优先级；新组合背景可能改变结果时可再探索，但目标仍是更优配置。不要为了消融、验证机制、描绘已知有害方向的曲率或填满候选数量提出方案。

不重复已测、已预约或本轮同效配置。没有值得测的新方案时使用调用方的保持现任出口；有希望的相邻强度未确认时请求外部证据，不越界、自动重标定或重新生成现任。

仅按固定 JSON 输出不超过输入上限的提案。Agent 只输出精确锚点、窗口、允许的整数 step 和简短决策依据；教师基准、强度数组、预算和执行配置由控制器保存。
