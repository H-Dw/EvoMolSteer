# 静态验证收敛与动态保护保留

`CoordinateObjective` 在控制器加载时验证并复制条件，准备参考坐标、蛋白旋转和平移；常数张量按设备与精度复用。`AssignmentState` 在首次匹配或恢复后的首次使用验证索引范围和一对一对应，随后复用对应张量。外部单次 `loss`、`metrics` 接口仍完整验证输入；恢复时仍校验 checkpoint 对应哈希，缺少冻结对应时拒绝重新匹配。
