# 双教师三策略五轮 Guidance Agent 重测计划

2026-10-31（Asia/Shanghai）根据本对话历史及用户最新授权重建。最新要求是：说明文字上限由原先 300–700 字符统一提高到 3000 字符；提交并推送新代码，远端使用新固定提交重新测评；每教师 Guidance Agent 改为五轮。本计划取代本次执行所依据的八轮计划，不改写八轮实验的失败、取消、claims 或账本。

## 历史与本次边界

原八轮 baseline 的真实失败包括综合角色 reason 超过 700 字符，以及另一教师后续修正引用不存在的证据 ID。提高文字长度只修复前一类契约限制；证据 ID、动作、数值与预算校验保持严格。原联合前缀合并、五窗口标定的工程缺陷已在 e0c3a384 修复，本次继续保留。

SSH 恢复后原三策略结果根、修复根和固定执行目录在当前文件系统中不可见；此前已按用户要求终止原任务并删除其巡检。本次为新授权、新计划、新结果根，不声称恢复了不可见终态，不导入旧 λ、排名、回执或预算，不复用旧验收。保留本地已归档的实际 prompt、回执与旧账本。相同随机初态的重测属于配对复现，不计独立验证；历史消耗与本次消耗分开报告。

仅在 codex/uniguide-flowr-agent 修改、提交、推送，不动归档分支。原 uniguide-flowr 保持 PAUSED、35 分钟配置不变，不修改其他自动化，不向其他聊天发消息。

## 六个串行任务

教师固定为 6pyy_H7S_A_402 / single_b004_final_015、3w54_RNB_A_504 / single_b000_final_003，各原九个 PLIP 直接互作配体重原子作为单一条件区域，沿用已冻结教师结构、蛋白锚点、模型及随机初态。部署前核对当前可见输入、初态和模型的实际哈希。

| 顺序 | 实验 | 条件策略 | Agent 窗口（闭区间索引） |
|---|---|---|---|
| 1–2 | baseline，两教师 | 每步及终态动态 Hungarian；坐标 gradient guidance、10–99 化学状态 inpainting | 10–25 / 26–50 / 51–75 / 76–99 |
| 3–4 | prefix_joint，两教师 | baseline 加索引 0–9 原生 FLOWR fragment 坐标和化学 inpainting、条件原子网络时间 1；索引 10 起撤去坐标覆盖及固定位置/条件时间标记 | 同 baseline |
| 5–6 | five_windows，两教师 | baseline 条件策略，不启用联合前缀 | 10–20 / 21–30 / 31–40 / 41–50 / 51–99 |

“0–10”保持半开区间 [0,10)，避免与索引 10 开始禁止坐标覆盖重叠。化学状态注入和坐标损失共用当步匹配；不覆盖自条件预测或最终输出。分别报告动态匹配几何覆盖和初始对应误差。

三策略均为 raw999、100 区间、0–0.999、索引 10–99 引导，返回最后循环中未覆盖预测，第 99 步更新不进入返回端点。单一逐候选损失为条件绝对坐标平方误差和除以 2K，完整预测终态 VJP，只有蛋白参与测量变换。无 affinity/相对距离项、3 Å 限幅、向量缩放或 RMSD 梯度掩码。

仅组级汇总与排名使用 Q3+max(3×IQR,1 Å) 的单侧高值排除，至少 10 观测、最多 10%，低 RMSD 全部保留。原始/排名 RMSD、loss、阈值、排除身份与真实分母分开保存；NaN/Inf、缺测和工程错误不能过滤成成功。

## 文字契约、控制与五轮学习

为新的指引版本统一 proposal/synthesis 的 reason，以及动作的 improvement_reason、uncertainty 为最多 3000 个字符。标识符、证据引用与数组长度保持原约束；边界测试覆盖 700 以上、3000 和 3001 字符。字符限制不等于 token 限制，不提高模型输出 token 或调用预算。旧指引发布目录保持原样，新的运行配置绑定新发布及哈希。

保留线性格距 10、整数改动、focused/expanded/jump 三种探索幅度、proposal/synthesis 两个实际角色。Agent 只探索潜在更优完整路径，不承担机制证明、消融或反证任务。每教师五轮，每轮最多六条提案、最多三条选择，允许少选、保持或请求合法范围证据；轮次由外部配置控制。

每轮 performance 使用本轮新完成、可排名完整 50 人口配置的最佳值，不使用单调累计最佳代替。连续两次相邻下降后，下一轮从最佳兼容 checkpoint 出发，实际 prompt 列出失败路径及效果，提示另寻优化方向；不重采最佳。无新完整测量时如实记录，不制造下降。五轮结束不额外增加轮次。

真实 DeepSeek deepseek-flash、thinking/high、单响应 16384 token、既有网络重试和一次格式修正保持不变；每教师每轮共享 30 调用、491520 输出 token。保存真实 provider 请求/回执、claims、工具回执和解析后动作。配置存在不代表已调用。

## 预算、验收与结果保存

每个教师/策略独立执行 prepare→本提交完整 acceptance→新标定→真实 GD01 五轮→独立 CPU 诊断。标定每任务最多 350 次（含至多 100 次范围证据），正式每任务最多 5×3×50=750 次；六任务上限为标定 2100、正式 4500。10→20→50 复用同协议已测槽位，失败计费不退款、不补样，精确重复配置引用实际源测量。

UG04 串行调度保持：逻辑组 50，网络前向/VJP 固定 10 行、默认 stream 依次执行，CPU 算子线程 8；无专用 GPU 工作进程、GPU 线程池、额外 stream、OOM 降档或自动接续。完整双教师真实模型验收不能由单测或旧回执代替；nonfinite_isolation 为预期夹具，不能据此宣布全链失败。

当前 /workspace 为 overlay，而 /root/private_data 为持久挂载。本次部署优先将执行代码、配置、结果、审计及必要输入快照置于确认可写且空间足够的持久路径；实际目录、提交、配置 SHA、模型/输入绑定和全局锁位置写入 launch_audit.json 和机器 PLAN。若有输入仍引用 /workspace，必须明确记录并保留足够恢复材料，不能声称已经持久保存。原目录只读保留，不部署纯文档提交到固定执行目录。

实际容量核查后，持久挂载剩余约 4.2 GiB，不足以保证六任务所有 HDF5 轨迹。采用持久执行目录、配置、冻结初态/教师/条件/原生 FLOWR 源码快照；全量结果保存在独立 /workspace 新根，每两分钟及阶段结束将安全 JSON、结构、压缩张量终态/检查点和阶段日志复制到持久快照。MIRROR_STATE 逐文件记录哈希，复制中变化的文件留待下次；镜像错误显式记录但不触发重采。HDF5 原文不在该镜像内，保留在结果根并在巡检时下载已完成产物；不能将该镜像称为完整轨迹备份。交互 launcher.log 和 core 不进入镜像或下载。

独立 CPU 队列每个实际源组 attempts=50、checked_attempts=10、not_selected=40、coverage=0.2，固定五种子各 logical_slot 0、1。构建失败占抽查分母，不替换，其余 40 不追加慢查；复用组仅引用原源组质量回执。构建失败、真实不通过、无法评价和工程错误分别报告，PoseB 内部几何、蛋白冲突、能量分别报告，不将 10/50 外推全人口。

## 失败处理、后台巡检与收尾

按表顺序串行执行六任务；单任务失败保存日志、源码/配置哈希、账本、阶段进度、请求/claim 后跳过，剩余任务继续。对明确接口不齐、遗漏导入、维度或代码逻辑缺失，沿用用户授权本地修复、测试、推送、新固定目录和新任务尝试；原失败和累计消耗不删除、不清零。采样已保存只补后处理。数值发散、资源故障、真实截断或无效证据引用不通过弱化、提额或盲目重发绕过。

后台启动后设置本次专属一小时巡检。每次核对真实命令、进程/锁、PLAN/配置/提交哈希、保护源文件、STATUS/HEARTBEAT、steps/progress、attempts、验收/标定/轮次标记、实际 LLM 回执和质量队列，保存 Asia/Shanghai 快照。健康、排队或无实质变化保持 DONT_NOTIFY，仅通知完成、实质异常、工程修复或需用户处理的问题。连接中断不等于实验失败，不据旧 PID 重启。

全部任务完成或保留终态失败后，实际读取所有教师的标定、五轮 checkpoint、prompt/参数/选择/回执、原始及排名 RMSD、化学保持、构建/连通/唯一性和 10/50 诊断；按教师配对比较三策略，明确不完整任务和历史与本次消耗。下载安全结果/审计，完成真实主 GPT 复盘并提交推送，FINALIZED 绑定实际复盘和源哈希。仅在队列空闲、路径与进程归属确认后停止本次 CPU worker，再删除本次专属巡检；不动其他自动化。

凭据和 API 密钥不打印、不写入仓库/自动化；交互环境 launcher.log 仅留远端。中文 UTF-8，自动化读回以 JSON ensure_ascii=true 验证无 Unicode 替换字符。GitHub 异常依次直连、ghfast.top、gh-proxy.com、ghproxy.net、gh.llkk.cc，均不可用才用已验证且仅含已推送提交的 Git bundle。
