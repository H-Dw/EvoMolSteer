用户于 2026-10-31 授权新增可选接口、依次后台完成三组实验，每组两教师、每教师八轮，并每小时巡检。代码仅在 `codex/uniguide-flowr-agent` 修改、提交、推送，远端使用独立固定提交目录；不恢复 UG05，不修改旧实验、归档分支或其他自动化。

## 实验、输入与边界

教师为 `6pyy_H7S_A_402 / single_b004_final_015`、`3w54_RNB_A_504 / single_b000_final_003`，各原九个 PLIP 直接互作配体重原子作为单一条件区域，沿用已冻结教师身份、结构、蛋白锚点及随机初态。

| 顺序 | 实验 | 坐标与化学条件策略 | Agent 窗口（闭区间索引） |
|---|---|---|---|
| 1 | baseline | 最新逐步及终态 Hungarian；坐标 gradient guidance、10–99 化学状态 inpainting | 10–25 / 26–50 / 51–75 / 76–99 |
| 2 | prefix_joint | baseline 上增加前十积分区间的 FLOWR 原生 fragment inpainting，坐标与化学同时注入；索引 10 起取消坐标 inpainting | 与 baseline 相同四窗口 |
| 3 | five_windows | baseline 的条件策略，不启用前缀坐标 inpainting | 10–20 / 21–30 / 31–40 / 41–50 / 51–99 |

“0–10”按半开区间 `[0,10)`、即索引 0–9 定义，避免与后续 `[10,99]` 的禁止坐标覆盖要求冲突。prefix_joint 同时采用 FLOWR 原生条件原子的网络时间配置、原生 builder 的坐标/化学覆盖与键对称化；自条件覆盖遵循原生默认关闭，末端不做坐标/化学覆盖。前缀以首个初态匹配初始化条件，之后每步使用当步预测匹配；退出前缀时移除条件网络时间/固定位置标记。原生初态和 categorical RNG 消耗保留，状态条件化不生成新的随机数。

三组均使用 raw999：100 区间、0–0.999，返回最后循环内未覆盖预测；第 99 步更新不进入输出。单一损失为每候选绝对坐标平方误差和除以 `2K`，完整预测 VJP，蛋白单独确定测量变换；没有 affinity 梯度、相对距离损失、3 Å 限幅或高偏差梯度掩码。单侧高 RMSD 仅用于组级汇总与排序，保留全部原始低值和失败记录。

## 控制接口与八轮学习

新增可选 `prefix_inpainting`、配置化引导 `windows`、`checkpoint_learning`；默认不启用前缀坐标覆盖，默认仍为四窗口。skills 接受外部窗口列表及整数档位，三种分支只代表跳跃幅度，不承担机制证明、消融或反证任务。线性格距默认 10，教师独立参考强度，动作由执行器计算和校验。

每教师八轮，每轮最多六条提案、最多三条选择，允许少选、保持当前配置或请求范围证据；迭代轮数只由外部参数控制。真实调用 DeepSeek `deepseek-flash`，thinking/high、单响应 16384 和既有重试/一次格式修正不变；每教师每轮共享 30 调用、491520 输出 token。实际请求、回执、claims 和解析后的动作全部保存。

每轮 checkpoint 的 performance 定义为该轮新完成且可排名的完整 50 人口配置中的最低排名条件区域坐标均方根偏差。无新完整测量时记录未测/保持，不伪造下降；累计历史最佳单独保存。连续两次相邻 checkpoint 比前一个更差时，下一轮以同实验、同教师的历史最佳 checkpoint 为优化锚点，并在实际 LLM prompt 中列出下降配置、窗口改动、测量误差与“先前这些优化方向效果不佳，基于最佳配置寻找新路径”的指引。保留全部历史，不重跑最佳组或替换源测量。

## 标定、预算与调度

每组、每教师单独结果根和完整固定提交验收；重新进行线性强度预实验。条件策略或窗口划分变化后不得沿用旧 λ/参考强度、测量排名或验收回执。沿用 10→20→50 槽位提升、每教师最多 350 标定尝试（包括最多 100 范围取证尝试）、正式最多 `8×3×50=1200` 新尝试。六个教师任务合计最多 2100 标定、7200 正式尝试；失败计费、精确重复引用、不补样。工程验收夹具不计科学尝试。

使用 UG04 串行策略：逻辑组 50，前向/VJP 固定 10 行在默认 stream 依次执行，CPU 算子线程 8，无 GPU 并发池、额外 stream、OOM 降档接续。按 baseline 两教师→prefix_joint 两教师→five_windows 两教师顺序执行六个独立任务。单任务失败保存证据并跳过，不能阻断剩余教师或实验。

独立 CPU 诊断每个实际源组 attempts=50、checked_attempts=10、not_selected=40、coverage=0.2，固定五种子各 logical_slot=0、1；构建失败占抽样分母，不替换，其余 40 不补查。复用组追溯原质量回执。PLIP/PoseB 构建失败、测量不通过、无法评价与工程错误分别报告；抽样通过率不外推为全人口通过率。
