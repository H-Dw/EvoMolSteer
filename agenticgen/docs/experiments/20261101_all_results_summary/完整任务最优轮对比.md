# 已完成五轮任务：最优轮结果对比

只保留完整完成五轮的六项任务；从主表排除原测中止的联合前缀6pyy（1/5）与五窗口3w54（0/5），由各自已完成五轮的严格工具重测结果进入比较。排除仅改变展示范围，原失败文件、600次历史消耗和完整账本保留。

选轮规则：以每轮新形成的完整50候选配置中最低的排名条件RMSD为轮成绩，再取成绩最低的一轮；主表只展示该轮最佳配置，统一每实验50候选。三个指标均在这同一配置上计算，不能分别选不同轮。最优轮全部分支另列，避免误称整个轮次总是50候选。

## 为什么先前各实验的总生成数量不同

五轮是五次决策，不是固定生成5×3×50。每轮最多三个动作，允许少选或hold；范围取证与正式采样分账，未晋级范围只形成20候选视图，预算不足的动作不采样。此前又汇总了所有轮次，并包含两项中止任务，所以总样本数不同。下表为六项完整任务的实际动作核对。

## 统计与文件

- RMSD：原九个PLIP条件重原子的终态几何Hungarian覆盖误差；pIC50为保存的终态affinity.pic50预测，未重新推理或重评分。
- SA使用既有标准RDKit评分，低值更易合成；只对构建成功分子计数，不以0填缺，也不作为三维构象分数。
- 前10%在原始有限值中独立取最优，向上取整。主表RMSD/pIC50各50观测，SA可能49或48；各指标均取5个。
- 沿用原统计过滤：完整配置至少10观测；RMSD仅高侧Q3+max(3IQR,1Å)，pIC50/SA双侧3IQR；异常超过10%不输出过滤均值，不将构建失败或缺测算成统计异常。
- 六个最佳配置的现有PoseB均为10/10通过，内部几何、蛋白接触/冲突、内部能量分项也各10/10；只检查固定10/50，不外推其余40。
- 此次只做已有数据筛选、复算和展示，没有采样、模型前向、LLM调用或删除实验。
