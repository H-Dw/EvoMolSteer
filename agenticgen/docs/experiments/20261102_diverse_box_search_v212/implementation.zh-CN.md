# 多样化五分支搜索：代码与技能 2.12.0

本次将新的搜索协议作为显式配置加入代码。每轮最多提出五个完整 scale 假设，所有通过准入的提案均在当轮执行；综合角色审计参数、证据和累计预算，不再从五个方向缩选三个。迭代仍为五轮，每个方向为完整 50 候选，因此正式预算为每教师最多 1250，预实验仍为每教师最多 500。两个教师新运行的总上限为 3500，不改写历史运行的预算或账本。

## 搜索域与早段剂量

新配置为 `agenticgen/configs/uniguide_diverse_box_search.json`，使用 `negative-box-exclusion-v2` 和不可变 skills 2.12.0。默认声明上限从 200 扩展到 400；这是有限的可执行边界，不能将到达 400 或用完预算称为收敛。可按新实验配置进一步扩展，但必须同时声明网格和足以覆盖网格的跳跃范围，并重新绑定验收与标定。

六窗口保持 0–10、11–20、21–30、31–40、41–50、51–99。首窗实际操作 1–10，默认网格为 0、1、2、5、10、20……400，后五窗为 0、10、20……400。整数序列化单位为 1，并不表示后窗允许任意整数；客户端逐位置校验每窗网格。`teacher_window_grids` 可显式设置教师专属网格，必需预实验配置不在网格内时在配置检查阶段报错，不进入采样后才发现。

距离改为六窗各自网格索引差的总和。默认全域最大总距离为 243、单窗为 43，取消旧 12 档局部球；focused 为 1–2，expanded 为 3–8，bold 为 9–243。新的分档描述探索跨度，不给未经测量的组合附加收益或稳定性保证。候选建议包括薄弱覆盖窗口、首窗弱剂量、远端边界、两窗联合跳跃及递增、递减、交错等完整形状；建议不是已测证据，也不是参数白名单。

默认首窗为 constant。可叠加 `uniguide_diverse_box_search_ramp.json` 显式改用 linear_ramp：首窗参数表示第 10 步的终值，第 1–10 步用 `floor(scale × step / 10 + 0.5)` 得到实际整数剂量。该形状在新任务中冻结，进入兼容摘要、domain、恢复绑定与验收；Agent 不能逐提案暗改形状。渐增模式需要自己的完整 GPU 验收和新预实验，不能套用 constant 模式的旧测量。

两种形状均保留原生端点 0/99；实际额外操作阶段为 1–98。允许 box 的 scale=0 仅关闭额外坐标引导，化学阶段仍保留；NativeOff 同时关闭梯度与化学覆盖。完整绝对坐标 VJP、动态 Hungarian、原生漂移/噪声、raw999、100 区间及串行 50 逻辑人口/10 行网络与 VJP 保持；没有梯度限幅、归一化、亲和力或相对距离梯度。

## 五分支指引与执行证明

五个新版技能按读取历史与覆盖、设计完整落点、整组审计、显式提交的顺序引导 Agent。要求简短可核验的理由和不确定性摘要，不要求私有逐步思维、窗口机制解释、消融或反证任务。重点包括：

- 区分任意背景的已测剂量和当前其他五窗背景下的已测剂量；最佳路径未改变某窗不能证明该窗已充分探索。
- 优先考虑不同组合区域和跨窗口重分配。足额且有合法新落点时优先提出五个方向；至少一个真实多窗 bold，有三个以上方向时覆盖至少三个不同改变窗口集合。允许合法的同背景剂量括界，不靠无意义改动伪装多样性。
- `WINDOW_EVIDENCE.json` 提供逐窗覆盖、当前背景未测剂量和已核验终态轨迹的更新幅度摘要。大更新只是观察，不能直接判有害；小更新不能判无效。均匀配置较差不能推广为某窗同剂量不可用。
- 每个提案绑定真实标定根、当前 global best 与父链摘要。回滚复盘最优节点及前置路径和近期坏旁支，从兼容最佳节点转向新的组合，不重采最佳。
- proposal 与 synthesis 使用原生 strict 工具提交完整控制数组。`audit_action_batch` 自动审计新协议的整组累计成本，不增加不存在的工具参数；synthesis 必须显式选择全部 proposal ID。

HTTP/token 预算、3000 字符、证据 ID、唯一一次格式纠正等原契约不放宽。`ROUND_COMPLETE.hypothesis_execution` 记录请求方向、完整源组及失败 ID。数值失败保留原失败、实际已计费消耗且不补样，让其余已准入方向继续；存在失败时本教师/版本不标为完整成功。工程或设备异常仍按异常策略停止，不用重试掩盖。

## 配置与验证范围

在新任务中将基础 `uniguide_absolute_coordinate.json` 与 `uniguide_diverse_box_search.json` 合并，设置新的 root、冻结输入路径、教师和模型配置，然后调用 `absolute_runtime.validate_config`。若需要渐增，仅更新合并后 `box_search.early_guidance_shape`；保留已有显式网格。旧 2.11.0 及更早技能文件、历史 fixed checkout、结果与自动化均不修改。

`validation.json` 保存本地回归、五项技能校验、包资源核验和独立 Agent 的离线前向检查结果。严格接口测试使用 HTTP MockTransport；五轮执行测试使用写入真实磁盘账本的合成执行器；渐增验收测试使用受控张量夹具。它们验证程序契约，不能称作真实 GPU acceptance、真实 DeepSeek 回执或科学效果证明。本次未启动远端科学运行或定时任务。
