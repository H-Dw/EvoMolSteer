# 七窗口实验配置

配置文件：`agenticgen/configs/uniguide_diverse_seven_box_search.json`。它是叠加在 `uniguide_absolute_coordinate.json` 上的实验配置；需为实际运行设置新结果根、冻结输入和模型路径，再调用 `absolute_runtime.validate_config`。技能版本为 2.13.0，旧六窗口配置和 2.12.0 发布文件保留。

第0步和第99步仍原生更新；第99循环输出不覆盖。两个新增独立维度可设置不同scale，也可分别由Selection关闭；关闭同时停止对应box的额外VJP/坐标梯度和化学inpainting。允许box的scale=0仅关闭额外坐标引导，化学阶段保留。

默认上限仍为400，首窗网格0/1/2/5/10/20……400，后六窗0/10/20……400；首窗默认constant，可用已有ramp叠加配置在新实验中显式设置linear_ramp。总网格索引距离更新为283（单窗43），防止新增维度意外缩小可探索范围。

每轮最多五个假设全部执行，仍为五轮、50候选/组，正式最多1250/教师，预实验最多500/教师；双教师新运行总上限3500。原始完整VJP、动态Hungarian、raw999、串行50逻辑人口/10行网络、CPU8线程、原损失和统计契约保持。

历史六窗末段采用较高scale只是拆分探索的动机，不能证明拆分后两段各自存在甜点。新背景仅复制原第六个参数到两段，全部重新测量，不导入旧的六维测量、标定、排名或验收：

Guidance可以探索后两窗一高一低、同时提高或与前窗联合重分配；默认最佳仍为新门控下最优完整50标定节点，严格更好才替换。

七窗初筛为33配置各10，两个背景10→20→50增量80，共410次。500上限内先计算完整负面确认成本：确认一个可疑box需双背景各补40，共80；确认两个还需联合门控50，合计130，因此七窗正常预算默认最多确认一个可疑box。没有足够完整证据的窗保留，不沿用六窗的整体结论。剩余预算才做首窗弱剂量及后段联合边界探测；无可疑窗时410+90=500，有一可疑窗时410+80+10=500。失败计费且不补样，可能实际少于上限。

新验收入口包括两个后段box分别NativeOff的完整轨迹检查。`validation.json`记录本地CPU、严格HTTP模拟、七维五轮执行及资源打包检查；这些不等于真实GPU验收或真实DeepSeek运行。本次配置变更未启动远端实验。
