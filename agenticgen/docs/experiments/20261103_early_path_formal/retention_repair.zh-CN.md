# 2.14 终态结构留存修复

2026-11-04 巡检发现，6pyy 已保存五轮、25 组正式测量，标定消耗 500、正式消耗 1250。最终 `retain` 对每个 seed/slot 选择结构时调用了总体 `choose`，单个候选缺少完整 50 候选统计，因此触发排名资格错误，最终汇总尚未生成。此前五轮模拟测试替换了 retainer，遗漏了这个真实入口。

修复后的留存函数使用候选自身的 `condition_aligned_rmsd_angstrom`，并检查评价标识及有限性。完整总体仍通过严格的 50 候选均值接口排名。新增测试调用实际 retainer，覆盖位姿误差与对齐误差排序相反、缺失候选测量，以及总体接口继续拒绝单个候选。

`scripts/recover_guidance_214_retention.py` 校验原测量和五轮回执、预算、原始最佳 checkpoint，使用已保存坐标测量恢复留存及报告。输出位于结果根的 `postprocessing_recovery/<repair_commit>/<job_id>`，保存原运行提交和修复提交、原错误回执哈希、候选与总体评分、零新增采样和模型调用记录。原实验及失败回执继续保留。

恢复仅适用于上述明确的留存错误，尚在运行的教师由原流程继续执行。两位教师的原始运行状态和恢复后交付状态分别记录。
