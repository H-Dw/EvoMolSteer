# V6–V30逐版问题、改动与实测效果

这里把版本迭代与版内采样轮区分。V6–V30共25版，每版固定skills/协议运行R1–R5；版内只改变四共享调度，不在每一轮修改代码或skills。下表的“改动”发生在复盘版完成后、下一版真实部署前；“效果”来自下一版完成结果，不能倒置成已执行于复盘版的原因。

本次只整理已有有限复盘与锁定聚合数据，不新增全量会话审阅。V7旧全量复盘在32条终止；未检查的其他轮次只提供聚合表现和动作，不编造其内部判断。每版获胜轮的直接问题均能在原复盘定位；完整来源hash在iteration_ledger.json。

ΔMean按下一版减前版，正值表示本任务范围内更接近较高teacher；ΔC为模板区域RMSD变化，负值更好；Δ等权gap负值更好。所有版本分别用自己的全池最小C锚定0.02Å主带。它们是观察到的变化，不是随机消融确定的因果效果。R5提案只归档，不能将其错误记成后续采样损失。
