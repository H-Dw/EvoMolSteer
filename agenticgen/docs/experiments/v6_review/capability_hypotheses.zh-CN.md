# V6→V7：三个通用能力改进假设

依据正式52会话及作废尝试11上下文的完整复盘，修改两份通用运行skills。主要问题是如何解释已有事实并配置探索预算，而不是计算工具普遍缺失。现有 `response_edge` 已提供精确方向、候选贡献、有效性和指导位移，本次不再添加功能重复的计算工具，不修改奖励、模型、采样、幅度域或token上限。

以下是待V7验证的策略假设。离线逻辑检查和软件回归只证明规则与接口兼容；未执行新的LLM离线回放，不能声称模型已按新策略行动，更不能宣称亲和力已改善。

## H1：按具体边和背景，分维度学习响应

**盲区与探索损失。** 正式Top2后期把功能代价平台外推为条件斜率平台；作废Top2 R1G4已有25个候选同向条件改善，却把它们写成正负抵消，因候选间分布宽度和排序带否定已测总效应。多个会话把大残差、大指导位移或较长窗口直接当作更高终态可控性，提前关掉未测方向。

**通用策略。** 以确切A→B边、未变背景和实际步编号为单位，分别更新实际传递、条件斜率、功能代价和机制。小的有符号结果保留；比例传递加小终态效应属于该边终态灵敏度弱，不能称控制未生效。机制未知或集中贡献不取消总效应，正负探测同号允许局部曲率解释。全局幅度域、局部合法域、历史已测点分别记录。

**预期行为与反证。** V7复盘逐条检查关键方向判断是否有匹配边、是否区分条件与功能、是否因未经校准阈值或集中贡献放弃方向。统计只以Agent确实可见且相关的边为分母。若仍从带宽/残差直接宣布整个幅度轴耗尽，或修正数字后下一动作毫无变化，则该能力改进不成立。允许基于明确预算价值放弃微小收益，不要求无限追逐每个数值变化。

## H2：先闭合预测与实测，再发布任务记忆

**盲区与探索损失。** 正式Top1 R5实际已回答某些后段迁移与中段幅度问题，公共记忆仍称未知；Top2多轮则能匹配实测、撤销旧未知并改变方向，是保留的正面反例，不能宣称所有Agent都没有学习。

**通用策略。** 私有分析先将上一预测映射到本组实际数组与背景，更新原belief_id，分别标记支持、反驳、未解决及适用范围。汇总再合并同轮事实，先撤销已回答的未知，再选择新试验。私有Agent看不到同波兄弟，其合理未知不计失误；未执行提案不能生成实测结论。

**预期行为与反证。** 逐轮核查“可匹配的旧问题→实测→知识修订→后续选择”链条，记录仍以未知流传的已答问题、已反驳仍作为事实的判断及修订是否影响行动。不因文字中出现learning_update便认定学习成功。若仅增加记忆长度而旧错误继续主导动作，下一版应改变检索/发布流程或提供更明确的事实视图。

## H3：按条件、功能和决策信息配置四个试验

**盲区与探索损失。** 正式Top1后期大多追逐微小条件收益，带内功能代表仍来自R2；作废Top2 R1G1的双目标改善因集中贡献被轻易否定。另一方面，正式Top2后期确实利用功能档案改善最终选择，证明目标导向配置可发生，不能把结果总体弱全部归因于没有策略。

**通用策略。** 两私有提案及汇总四槽分别说明其价值是推进条件前沿、改善排序带内功能，还是解决能改变剩余决策的问题，不设置固定比例。已有有效边要考虑合法延伸或精细邻点；反向证据支持括号/缩步；新背景复试说明反证为何不直接转移。临近末轮的诊断必须能改变剩余实际选择，舍弃匹配臂时承认失去的可识别性。没有新增幅度、预算或自动代写数组。

**预期行为与反证。** V7记录每个被选试验的预期决策用途、实际产生的新边/知识、利用时机、重复与失败成本；同时报告同预算条件前沿及带内功能代表随试验数/GPU/LLM开销的轨迹。不要把逐链TOP1单调性当作分布改善。若选择结构改变但未带来更有用信息或目标进展，假设仍未得到支持；若仅文案更规范、动作仍无信息重复，则应判为无效改进。两版连续退步的既有回滚规则保持。

## 不调用模型的策略一致性检查

| 输入情形 | 新规则应导向的判断与行动 | 检查结论的边界 |
|---|---|---|
| 实际位移随幅度增加，终态只轻微变化 | 保留局部方向，区分终态灵敏度与传递；再比较延伸或传播诊断价值 | 不是已证明LLM会遵守 |
| 条件改善、功能差扩大，仍在排序带 | 记录真实冲突，比较带内功能机会，不自动继续强化 | 不是新增成功阈值 |
| 少数候选贡献大于净Mean改善 | 正常计总效应，查看抵消与迁移，不要求多数同步改善 | 不保证跨背景收益 |
| 两个相反方向均变差 | 允许局部峰值/曲率，考虑缩步或其他背景 | 不证明全轴无效 |
| 私有记忆未知，但汇总可见同波匹配实测 | 私有未知可保留，汇总发布时必须更新 | 隔离规则保持 |
| 最后一轮只剩归档建议 | 归档未执行假设，不假造后续收益或启动R6 | 每版本仍5轮 |

任务特异的数组、原子、教师和分子解释只出现在本审阅和任务记忆中。通用skills只给出上述方法与证据条件，不传递V6最优数组。V7还需V30追加协议、原生验收及严格review-check；本文件不是启动批准。
