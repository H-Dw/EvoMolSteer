## 目标与判读

Guidance Agent 是自适应条件学习控制器。在 FLOWR、DeepSeek 权重、奖励定义和预算固定时，通过试验学习怎样调节幅度，让推理过程吸收输入 Condition。当前 Condition 是教师指定局部区域在蛋白固定坐标系中的三维坐标；只有这些坐标进入奖励，原子类型、键、电荷及亲和力不直接求导。

1. **条件恢复**：逐候选计算最终状态到教师指导区域的几何 Hungarian 对应 RMSD、平均原子距离、最大原子偏差和 pseudo-Huber；不进行配体刚体对齐。报告整组均值、中位数、分位数、全分布，原 PLIP 核心和核心加一跳区域分开。全部尝试的张量坐标误差与有效分子子集结果并列；低误差但无效的分子不能冒充成功。
2. **功能保持**：报告整组有效分子的 Mean pIC50、教师 pIC50、带符号差值与绝对差值，以及有效数、共同有效起点的配对变化。Mean 提高但条件恢复变差，不直接判为优胜；条件改善但亲和力远离教师，也必须记录功能代价。
3. **额外收益**：Best pIC50 与教师的差值、超越比例、Top10%均值和 Top10均值。Best 超越教师且条件/质量得到保留是更好的结果；仅最高分不能证明整组重构成功。

不设 RMSD、亲和力差或 PLIP 恢复率硬门槛，不用隐含加权分数将两个目标混成一个数字。报告连续的条件误差—亲和力差 Pareto 比较；条件是首要关注方向，Agent 在选案时必须解释对功能目标的预期影响和取舍。未同时达到理想状态时明确报告未解决冲突，不声称“保证接近”或二元验收成功。Best 是加分项，不覆盖条件误差与群体功能缺陷。

## RMSD容忍扰动与对齐：冻结的比较协议

不要求RMSD为零，也不把逐位相同当作重构成功条件。采用 **0.02 Å整组平均局部RMSD排序容差**：对同一教师的全部已测试、未经逐链择优的共享调度组，先找到最低均值Cmin，仅在C≤Cmin+0.02 Å的组内按Mean pIC50到教师的绝对偏差选优；其后按更低原始RMSD、更高Best、稳定记录ID打破并列。每次以完整比较池的最小值为锚，禁止逐对容差累积漂移。R0和逐链TOP1不进入每版本20组的代表调度选取。

该容差只是决策分辨尺度，不是原子允许偏差、奖励死区、统计显著性阈值、采样噪声估计或生物学等价声明。完整保存原始差异，另离线报告0.01/0.05 Å敏感性排序；不因结果不利更换主尺度，也不新增采样。仍报告连续分布，不设重构成功的硬门槛。

选择依据是历史幅度调节的局部差异常远小于0.01 Å，而严格追逐极小差异会忽略功能目标：已核验V2部分记录中，Top1第91节点endpoint平均局部RMSD的比较差约0.000379/0.003475 Å，Top2第75节点部分候选current比较差约0.000149 Å。它们是不同状态/子集的干预响应，**不是最终重构误差的噪声估计**。旧100样本、原核心区域R0终态均值约0.805/2.012 Å，也不能直接当作新25样本、2/8原子区域的标准。这使0.02 Å适合作为待敏感性检验的初始排序尺度，而非已由新任务证明的最优阈值。

计算约定：

- 主指标先逐候选计算指导区域RMSD，再对25次尝试取算术平均；不把所有候选残差合并后开平方。报告无效分子的张量误差及有效子集，不能通过删失败样本改善指标。
- 当前共用同一prepared protein，撤销模型中心化和coord_scale后直接在世界坐标Å中比较，变换为恒等。主指标禁止独立平移/旋转配体，否则可把离开口袋或翻转朝向的结果误判为恢复成功。
- 仅在来源确属不同刚体坐标系时，用事先对应的蛋白骨架重原子N/CA/C/O求一次Kabsch正旋转，保存原子映射、旋转矩阵、平移和残差；同一变换应用于整个蛋白—配体复合物。禁止镜像反射。对应不明或存在非刚体蛋白差异时标记不可直接比较，不用配体拟合掩盖差异。
- 主指标称“条件位点几何RMSD”，使用真实终态与固定教师指导区域的几何Hungarian一对一匹配及活动原子mask。终态重新匹配；原核心只取扩展指导区域对应中的子集，不能另行挑选更有利对应。几何对应不能证明元素、共价图或立体化学一致。
- 次级“化学合法局部pose RMSD”使用完整同图或预定义教师局部子图的元素、电荷、键及适用立体关系约束映射，并处理合法对称对应；没有映射记N/A，不临时缩小成有利MCS。SDF与终态先核对坐标、元素、电荷和图，再以终态全精度坐标计算，不优化构象。
- 可另列配体刚体对齐后的shape RMSD用于诊断；它不参与主排序。少于三个非共线对应原子无法唯一确定空间朝向，因此Top1的两个指导原子不计算单独的shape拟合指标。
- 主指标只读取`state_kind=actual_terminal`的100节点，禁止以中间endpoint head预测替代。所有来源、对应及坐标系均进入分析记录。

0.025 Å每步指导位移上限保持独立。已有新R0在λ=0.5时两教师均未触发裁剪，最大实际单步指导位移约0.00728/0.00340 Å；这不支持把当前低响应归咎于位移上限。扩大幅度后必须重新观察真实位移和裁剪，不能自动放宽位移上限。

## 样本和预算

- 两位教师仍为 5nn4_SC2_A_1017 原 Top1 / Top2；原 node ID 分别为 single_b002_final_005 / single_b004_final_009。
- **每假设25个候选，5个原种子各取5个固定起点**。种子42、100045、200048、300051、400054；各历史批次固定选择原槽位0–4，不依据得分选起点。25是种子数量5的整数倍，不要求是原batch20的整数倍，也不要求被种子的数值整除。
- 物理推理为四假设×25＝**batch100**；每组共用一组四段幅度。原生随机调用仍按每种子的20槽位形状产生，取前5槽位，未使用行不计候选；不同假设对应起点共享随机流。此实现须通过原生抽样与RNG验收，不能只更改配置中的数值。
- 两教师共享同一25个随机起点，50条教师条件链不是50个独立起点。
- 新R0仅50条；每版2教师×5轮×4假设×25＝1,000条优化结果；V6–V30共25版，最多25,000条优化结果，加新R0共**25,050条**。本次增加的是5个外层版本（V26–V30），每版本内部仍为5轮；失败重跑与诊断消耗单独记录，不计为新增有效科学结果。
- 每组25次尝试不补抽。Top10%固定取最高ceil(25×10%)＝3个有效分子的均值，并标明这是离散近似；不足3个记为不可计算。最高10个的均值另列，不混称Top10%。小样本下Best和尾部波动更大，不能与旧100样本Best当作等预算比较。

## 控制器学习与探索

每轮必须更新带证据及适用条件的响应认识：教师条件含义、时间区间可控性、幅度响应、区间配合、几何恢复与功能关系、群体差异以及尚未识别的关系。输出结构化 learning_update，包含先前判断、干预、实测、支持/反驳/未解决状态、知识修订、下一步行动与来源；不要求冗长内部思维过程。

先区分幅度未传递、实际位移弱/裁剪、后期覆盖、局部恢复与亲和力冲突和群体异质性。保留竞争解释；如果位移没有改变，不能仅凭分数变化宣称控制因果。局部几何改善但功能差扩大时应设计区分性试验，而非机械增加幅度。

幅度上限、粗探索尺度、精细分辨率分别管理。V6–V10幅度0–1；初始局部步长0.2，局部步长允许0.1–0.3且每案最多改两个区间。精细分辨率始终0.1。0.3需两次可比较的同向响应支持，条件误差改善且功能差不恶化；负面/局部峰值证据优先缩小步长或反向。早期使用能区分方向的试验；发现有效分支后及时利用。覆盖全部区间不是独立目标，未测方向只有能改变剩余决定时才占用诊断预算。条件与功能冲突时，可在已有时段响应支持下设计合法两区间补偿，缺匹配对照只解释联合效果。最后采样优先可信改进。联合修改缺匹配比较只能解释为联合效果。重复数组先查询缓存，由Agent提出新方案，执行器不编造科学决策。

局部搜索和探索/利用设计借鉴 [TuRBO](https://arxiv.org/abs/1910.01739) 与 [PBT](https://arxiv.org/abs/1711.09846) 的思路。本工程没有实现其完整算法，也不据此声称收敛保证或优于这些优化器。

## 多尺度幅度探索与版本回滚

上限U、粗探索尺度s、精细分辨率q是独立参数。q固定0.1，tick=5始终代表λ=0.5。初始U=1、局部步长0.2；完成V10最优轮策略复盘后，最早V11允许GPT基于边界响应、实际位移/裁剪和未解决假设批准扩展，顺序1→5→10→15→20…，每版最多升一级，同版两教师共用且冻结。扩展后粗尺度默认s=U/10，允许记录并说明其他在0.1网格内的尺度，不能把整个网格改为整数。

扩展版每轮最终四案最多一个`range_probe`，可在批准范围内选择任意0.1网格值、最多修改两区间；应写明实际跳幅、参考背景、与粗尺度的关系、条件/功能预测和反证。其余为局部探索：0.1/0.2；0.3仍需两次同背景可比较的同方向改善授权。私有Agent须提供局部替代方案，汇总程序校验最终大跨度名额。未扩展时不允许range probe。扩大范围不改变奖励、位移上限、样本数或随机流。

连续两轮内部迭代未改善最佳条件或连续负向时，控制器须改变方向、尺度、区间、背景或待区分的问题；若只改解释文字，应在主Agent复盘中认定学习不足。无需把已明确反驳的方向反复当作验证。

每版本每教师从20个未择优共享调度组按上述容差选择代表，版本指标为两教师等权的条件误差C及绝对亲和力差F。相邻完整版本：ΔC>0.02 Å为退步；ΔC<−0.02 Å为条件改善，同时披露功能代价；|ΔC|≤0.02 Å时按F增减判定。Best单独下降不触发回滚。缺指标/未完成只记不完整，不当正常性能退步。

连续两次相邻版本退步，下一版必须用新的Git提交恢复新协议V6以来历史最佳状态：按同一锚定容差对完整版本选择，恢复通用skills、幅度/粗尺度及兼容的控制行为，必要非科学修复保留并说明。保留全部历史、失败和版本号，不删除或改写旧结果；新版本仍使用共享R0、空动态记忆和相同预算，不传入教师最优数组。回滚版完成后清零连续退步计数，总终点仍为V30。

## Agent组织与知识隔离

每组25个候选统一分析。四个私有Agent并行，只读本组、其历史和上一轮已发布记忆，各提出两个方案；第五汇总Agent比较八个方案，选四个不同数组并排序。第五轮完成分析、记忆和清理后不执行第六轮。

静态教师档案保存区域、互作、坐标、共价关系和来源。动态任务记忆按教师/版本隔离：私有更新留在本组，汇总后才发布给下一轮。后续版本复用静态档案和新R0，清空动态搜索答案。通用skills不写教师、靶点、原子编号、固定分子特征或最佳调度表。

## GPT主Agent职责

主Agent负责训练策略设计与能力改进，**禁止全量审阅**。每版本只对每教师最优轮做一次策略检查，按冻结组级条件带选出共享调度代表，读取获胜私有Agent假设和该轮汇总。所有轮次只看程序汇总的真实performance，不再逐请求、逐字段、逐工具检查，不补审所有失败上下文。只有实际运行故障才定点排查所需证据。

从第一性原理判断：幅度如何改变模型轨迹；假设是否针对可控制的时段和条件；局部恢复与功能冲突如何处理；有效方向是否及时利用；剩余试验是否可能改进目标。保留合理竞争解释。重点改进方向选择，而非整理长篇错误清单。计算交给现有工具，只有确有缺口才补事实工具。

每版写一份短报告和1–3项可检验能力假设：视角盲区→探索损失→通用策略→预期行为→下一版实测。skills不写教师答案，科学配置不因简化复盘而变化。只报告实际有限审阅范围，`mode=best_round_strategy`、`full_review_completed=false`；不伪造52条覆盖。review-check核验最优轮来源、完成结果、真实提交、技能与控制政策，不要求全量覆盖。全部原始prompt/工具/失败记录继续归档，归档不等于人工审阅。

已具备资料的策略复盘在一次连续工作中完成，不等待下个定时触发。35分钟是运行巡检间隔。版本间改动直接检查差异、提交推送，不运行本地测试；可执行代码的必要相关验证在远端固定部署后完成，再通过门槛启动。奖励、动作维度或预算变化仍遵循既有授权边界。
