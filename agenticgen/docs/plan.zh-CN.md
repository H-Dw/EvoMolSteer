# agenticgen：自适应条件重构实验

2026-10-22 修订。本文采用用户最新确认：**Condition 重构优先；Mean predicted affinity 接近教师为功能目标；Best 超越教师为额外收益。暂不设置硬阈值，只报告连续误差。** 本文替代旧计划中的“Mean 优先、每组100、batch400”，旧结果和审计保留。

## 目标与判读

Guidance Agent 是自适应条件学习控制器。在 FLOWR、DeepSeek 权重、奖励定义和预算固定时，通过试验学习怎样调节幅度，让推理过程吸收输入 Condition。当前 Condition 是教师指定局部区域在蛋白固定坐标系中的三维坐标；只有这些坐标进入奖励，原子类型、键、电荷及亲和力不直接求导。

1. **条件恢复**：逐候选计算最终状态到教师指导区域的几何 Hungarian 对应 RMSD、平均原子距离、最大原子偏差和 pseudo-Huber；不进行配体刚体对齐。报告整组均值、中位数、分位数、全分布，原 PLIP 核心和核心加一跳区域分开。全部尝试的张量坐标误差与有效分子子集结果并列；低误差但无效的分子不能冒充成功。
2. **功能保持**：报告整组有效分子的 Mean pIC50、教师 pIC50、带符号差值与绝对差值，以及有效数、共同有效起点的配对变化。Mean 提高但条件恢复变差，不直接判为优胜；条件改善但亲和力远离教师，也必须记录功能代价。
3. **额外收益**：Best pIC50 与教师的差值、超越比例、Top10%均值和 Top10均值。Best 超越教师且条件/质量得到保留是更好的结果；仅最高分不能证明整组重构成功。

不设 RMSD、亲和力差或 PLIP 恢复率硬门槛，不用隐含加权分数将两个目标混成一个数字。报告连续的条件误差—亲和力差 Pareto 比较；条件是首要关注方向，Agent 在选案时必须解释对功能目标的预期影响和取舍。未同时达到理想状态时明确报告未解决冲突，不声称“保证接近”或二元验收成功。Best 是加分项，不覆盖条件误差与群体功能缺陷。

## 样本和预算

- 两位教师仍为 5nn4_SC2_A_1017 原 Top1 / Top2；原 node ID 分别为 single_b002_final_005 / single_b004_final_009。
- **每假设25个候选，5个原种子各取5个固定起点**。种子42、100045、200048、300051、400054；各历史批次固定选择原槽位0–4，不依据得分选起点。25是种子数量5的整数倍，不要求是原batch20的整数倍，也不要求被种子的数值整除。
- 物理推理为四假设×25＝**batch100**；每组共用一组四段幅度。原生随机调用仍按每种子的20槽位形状产生，取前5槽位，未使用行不计候选；不同假设对应起点共享随机流。此实现须通过原生抽样与RNG验收，不能只更改配置中的数值。
- 两教师共享同一25个随机起点，50条教师条件链不是50个独立起点。
- 新R0仅50条；每版2教师×5轮×4假设×25＝1,000条优化结果；V6–V20共15版，最多15,000条优化结果，加新R0共**15,050条**。
- 每组25次尝试不补抽。Top10%固定取最高ceil(25×10%)＝3个有效分子的均值，并标明这是离散近似；不足3个记为不可计算。最高10个的均值另列，不混称Top10%。小样本下Best和尾部波动更大，不能与旧100样本Best当作等预算比较。

## 条件、采样和恢复

统一指导核心加一跳邻居。扩展仅从原 PLIP 核心进行一次；Top1为2/10重原子，Top2为8/10，明确较大覆盖范围。原核心、共价邻接、元素/电荷标签和来源单独保存，原模板不覆盖。

原模型、100步积分、SDE、类别转移、Endpoint坐标pseudo-Huber（delta=1Å）、几何Hungarian、蛋白固定坐标系、每步最大原子指导位移0.025Å保持不变。指导区间为10–25、26–50、51–75、76–90，共81步；R0四段均0.5，区间外0。

全部方案均从**新R0第10步更新前固定状态**恢复，重算至100；逐链TOP1不作为父状态。新R0在与正式四假设相同的物理batch100中生成，对重复组验证后只保留25个原始起点的完整状态，重复行不视为新增独立样本。保存0、10、25、26、50、51、75、76、90、91、100的状态、RNG、自条件缓存、预测头、漂移、噪声和指导增量。

## 控制器学习与探索

每轮必须更新带证据及适用条件的响应认识：教师条件含义、时间区间可控性、幅度响应、区间配合、几何恢复与功能关系、群体差异以及尚未识别的关系。输出结构化 learning_update，包含先前判断、干预、实测、支持/反驳/未解决状态、知识修订、下一步行动与来源；不要求冗长内部思维过程。

先区分幅度未传递、实际位移弱/裁剪、后期覆盖、局部恢复与亲和力冲突和群体异质性。保留竞争解释；如果位移没有改变，不能仅凭分数变化宣称控制因果。局部几何改善但功能差扩大时应设计区分性试验，而非机械增加幅度。

幅度0–1、分辨率0.1，初始步长0.2，允许0.1–0.3且每案最多改两个区间。0.3需两次可比较的同向响应支持，条件误差改善且功能差不恶化；负面/局部峰值证据优先缩小步长或反向。前两轮争取覆盖四区间，未覆盖的方向进入清单；后期优先利用得到支持的方向。联合修改缺匹配比较只能解释为联合效果。重复数组先查询缓存，由Agent提出新方案，执行器不编造科学决策。

局部搜索和探索/利用设计借鉴 [TuRBO](https://arxiv.org/abs/1910.01739) 与 [PBT](https://arxiv.org/abs/1711.09846) 的思路。本工程没有实现其完整算法，也不据此声称收敛保证或优于这些优化器。

## Agent组织与知识隔离

每组25个候选统一分析。四个私有Agent并行，只读本组、其历史和上一轮已发布记忆，各提出两个方案；第五汇总Agent比较八个方案，选四个不同数组并排序。第五轮完成分析、记忆和清理后不执行第六轮。

静态教师档案保存区域、互作、坐标、共价关系和来源。动态任务记忆按教师/版本隔离：私有更新留在本组，汇总后才发布给下一轮。后续版本复用静态档案和新R0，清空动态搜索答案。通用skills不写教师、靶点、原子编号、固定分子特征或最佳调度表。

## GPT主Agent职责

主Agent负责训练策略设计与能力改进。全量审阅每版52个逻辑会话及真实去重prompt、工具、未选方案、失败和结果；不能用下载/哈希核验或少数案例替代实质复盘。重点检查：控制器是否识别了关键时间传播、是否理解条件—功能冲突、反证是否改变行动、是否及时利用有效方向、是否浪费预算重复无信息试验。

每次技能修订形成“视角盲区→探索损失→通用策略→预期行为变化→下一版检验”的能力改进假设，优先少量关键策略。可补充计算工具提供事实，不返回教师最优答案。数值纠错是基础，文本更规范不能代表能力或重构效果改善。新增奖励、动作维度、预算仍需用户授权。
