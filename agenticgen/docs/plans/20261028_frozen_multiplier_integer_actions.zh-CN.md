# 冻结教师标定倍率与整数动作协议

本次是独立内部距离协议 v2 的工程优化。原 UG05 保持暂停；不启动完整标定、正式生成或新 inpainting 实验。输出仍为原生终态前向，不改 raw999。

## 标定键与冻结

标定键为教师标识、冻结条件哈希和采样协议哈希的联合哈希。条件包含参考构象、原子对及槽位对应；采样绑定包含模型、原生配置、积分设置、窗口、噪声、五组初始状态、随机流、输出策略、数值软件版本和采样实现。角色提示、skills、LLM 设置、外部循环轮数不进入采样键。

每个键只生成一份冻结倍率。再次调用标定入口会校验原测量回执并直接返回，不加载模型。正式执行在加载模型前验证倍率与原证据；条件、映射或采样协议变化后拒绝沿用。工程验收的完整源码绑定仍然包含 Agent 代码，提示改动不意味着可以跳过部署验收。

## 逐步筛选与预算集中

预声明每教师搜索中心，配置默认均为 1，仅用于定位搜索网格，既非测得倍率也非跨教师平均。可在新实验准备前逐教师设置，不从旧坐标损失结果推导。正式归一化零点来自新的完整人口距离测量。

1. 粗筛：中心乘以二的 -12、-10、…、12 次幂，共 13 个常数强度，每个 10 次完整积分。
2. 复筛：在有限性和位移增长检查允许的粗筛最优点周围，取其 1/4、1/2、1、2、4 倍，共 5 个强度，各扩充至 20 次。
3. 确认：上述完整、可继续的 5 个强度各扩充至 50 次。在连续、通过位移增长审计的常数强度中，选择分子内部原子对距离均方根偏差最小者作为倍率；完全并列取较小强度。确认阶段最优点在有效边界时不冻结倍率，记录证据不足。

每个十次采样单元对应五个固定种子各两个逻辑槽位。人口从 10 晋级 20、50 时，分别追加新槽位，既有终态、轨迹、分子构建结果和失败均不重算。复筛中的三个强度已有十次粗筛测量，因此通常新增尝试为 130 + 70 + 150 = **350/教师，700/两教师**，仍受原 5000 次标定硬上限约束。失败消耗已预留预算，不替换；晋级后的累计测量不是独立验证。

该预算分配借鉴逐步筛选与集中资源的思路，并不承诺找到全局最优。粗筛存在噪声及选点偏差；未晋级候选的原始证据仍可见。最优点落在边界、有限性/位移增长检查后没有足够连续点时停止，不自动扩界、削弱强度或重试。当前实现未增加单位梯度定位预实验，也未新增昂贵的窗口组合标定。

## Agent 与执行器分工

Agent 的动作只有精确 `anchor_id`、`updates` 中的窗口编号和整数 `step`，以及证据、预期改善、反证条件等固定文本模块。四个窗口编号为 0–3。步长只能为 -2、-1、1、2；不接受小数（包括 JSON 的 1.0）、零档、重复窗口或越界动作。

一步改变实际强度两倍，两步改变四倍。每次改一个或两个窗口；两个窗口使用相同绝对档位。increase 全部增加，decrease 全部减小，redistribute 两窗口等量反向。**不要求归一化值为偶数**，所有允许的整数值均可用。

执行器从已测锚点复制数组，展开整数动作，检查方向、实测范围和重复配置，保存：

- `agent_action.json`：Agent 原始动作。
- `proposal.json`：动作、完整 `normalized_guidance_scale_schedule`、`calibrated_guidance_multiplier`、`effective_guidance_scale_schedule`、标定键和来源哈希。
- 测量回执：条件、实际强度、随机槽位和复用来源。

实际强度仍等于倍率乘以二的归一化刻度次幂。归一化零表示倍率，关闭使用独立开关。Agent 不计算物理强度或提交最终数组。固定 schema 拒绝旧数组字段；应用校验进一步拒绝整数外观的小数与布尔值。

三份运行 skills 继续使用完整距离指标名称和历史预测反证。历史中的展开数组只保留一份，提案摘要不重复这些数组；综合角色只接收一次候选集合，私有分析不再次嵌入候选。循环次数仍由外部参数控制。

## 工程验收

远端固定提交测试逐教师冻结、采样绑定变化拒绝、整数动作展开、边界、失败保留、10→20→50 去重与预算、跨正式入口复用、非默认轮数和提示契约。两教师真实模型额外比较原生前缀与新增逻辑槽位的状态及随机流，并检查槽位恢复一致性。工程检查只运行短积分；测试倍率是夹具，不是新的实测倍率。所有完整预实验必须另行启动。
