# Guidance Agent 计算工具与多次调用实现

本更新只接入内部距离 Guidance Agent 的证据计算与多次模型调用。计算工具不采样分子、不修改梯度、条件映射、教师标定倍率、积分策略或既定科学排名。真实模型验收采用明确标注的合成接口数据，不能据此声称分子结果改善。

## 调用与预算

`geometry_council.advise` 仍执行 increase、decrease、redistribute 和 synthesis 四个原角色。每个教师的一轮内，四个角色共用 `model_budget`；默认 `max_model_calls_per_round=30`。最终回顾调用也有独立的同额上限。每次 HTTP 尝试占一次额度，包括工具续调、格式修正和网络重试；读取成功缓存不占额度。每次输出上限仍为16384，轮次输出 token 总上限为491520。两项轮次限制都来自配置，skills 不固定实验轮数。

模型可以先返回原生 `tool_calls`，执行器运行登记函数、保存结果，按 `tool_call_id` 回传，然后继续调用模型。保留工具协议所需的完整 assistant 消息。工具阶段允许空正文；终答必须为完整角色 JSON。最后一个可用请求禁用工具；预算耗尽、输出截断、超过修正额度或不确定的中断请求都会停止并保留账本，不伪造成功或循环重试。

格式修正同时提供 JSON schema 错误和可检查的应用错误，例如证据引用错误。每个角色保留原字段、字符上限、锚点枚举、整数动作及重复配置校验。回执 ID 必须完整复制，不能缩成不可追溯别名。引用校验确认 ID 与已读取回执一致；它不等同于对任意自然语言因果判断的自动事实证明。

人工复核曾发现合成测试回答把归一化0误称“零引导”、把种子簇均值误述成单样本变化。最终输入额外列出每个已测配置的实际强度，动作工具也返回实际强度；skills明确归一化0与负值均不是关闭引导。种子统计及异常样本回执标明聚合层级。未测量的定量预测仍是待验证假设，不能升级为实测事实或接受阈值。

## 已注册工具

| 工具 | 确定性计算 | 不提供的能力 |
| --- | --- | --- |
| `summarize_population` | 完整人口的均值、中位数、双侧各10%截尾均值、中位绝对偏差、90/95百分位、最大值、最差5个均值、构建与缺失覆盖 | 重新生成分子、把质量抽查外推全体 |
| `compare_paired_runs` | 相同教师、条件、采样协议及seed/slot上的配对差、种子分组、探索性配对种子簇bootstrap区间 | 把重复配置当独立验证、把不同样本规模直接排名 |
| `inspect_interval_evidence` | 已测窗口、异常样本身份及时间步骤；明确关联不等于因果 | 由终态反推出未经测量的时序收益 |
| `audit_action_batch` | 原行动约束、输入历史与批内重复检查，返回完整解析配置 | 采样、预测未测实绩、替代执行器全局预约检查 |

先读取已有统计回执。只有缺少会影响决策的证据时才调工具；后续角色可读取本轮已确认计算，重复计算使用缓存。所有来源绑定原完成回执、记录、聚合、manifest和步骤文件的哈希；来源损坏或变化会终止会话，不能当作可继续修正的模型参数错误。计算回执持久化于本轮 `task_memory/calculations`，保留工具名、参数、统计策略、来源绑定及结果哈希；不写入固定skills。

稳健统计以每个分子为观测单位，不能把原子对数当独立样本数。截尾仅用于描述稳健中心，源样本和严重失稳仍完整保留。缺失值和非有限值不算零；未完整测量的统计明确标记范围。配对bootstrap同时重采两侧同一随机种子簇，在固定、反复使用的少量种子上仅作探索性诊断，不宣称显著性或独立泛化证据。

## Skills与冻结边界

独立发布目录为 `resources/skill_releases/guidance/2.1.0`：分析、提案、综合模块版本2.1.0，新增共享 `guidance-evidence-computation` 版本1.0.0。每个角色加载分析、对应角色、计算三个模块。六条用户直接指引写入计算技能；外部 RSI 技能保留，但不载入运行角色。

新的 `GUIDANCE_AGENT_BINDING.json` 在实验范围内冻结全部角色与计算技能，覆盖所有教师及内部版本。实验内复盘只能记录结果和选择，禁止通过 `patches` 修改技能；外部RSI在实验完成后建立新版本。历史已冻结且没有工具配置的实验不会被自动迁移；应继续使用其原固定执行目录。

标准格式检查覆盖五个SKILL文件；运行时副本与标准源文件绑定哈希。发行包包含版本化技能。旧2.0.0文件保留原字节。

## 验收与实际限制

离线测试覆盖空正文工具阶段、多工具及依赖续调、非法工具、格式修正、共享30次上限、网络重试计数、缓存回放、中断请求不重发、证据来源校验、配对与尾部计算、原动作校验、实验级技能冻结和打包。

`scripts/validate_guidance_tools.py --live --output <新目录> --rounds 2` 是显式付费接口验收入口，必须从进程环境读取密钥。每轮执行全部四个真实角色，再做不新增HTTP的缓存回放。它只使用合成接口夹具，不加载生成模型。失败目录不可用该入口自动重启；新工程验收必须使用新目录并保留旧失败。

具体回执、调用计数、修正记录、源码绑定和验收时间见同日期证据JSON。本次不部署覆盖已有远端执行目录，不恢复暂停的UG实验，也不触发分子采样。
