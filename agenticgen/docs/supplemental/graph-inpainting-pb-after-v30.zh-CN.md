## 1. 已确认的目标

用户授权在原方向结束后，使用FLOWR原本的Graph inpainting能力保留teacher的目标condition子图，探索几何约束与周围生成区域之间的平缓适应。Guidance Agent每个主版本仍迭代5轮；GPT主Agent在外部从策略角度改进其skills，额外最多20个主版本，独立编号`I01–I20`，不称为V31–V50。

| 项目 | 用户明确确认 |
|---|---|
| 对象与规模 | 沿用当前两位5nn4 teacher、core+一跳条件区域、每组25候选和四组并行 |
| 图条件 | 条件子图原子/键身份在整个生成过程中保持；先不探索中间改变子图化学身份 |
| 坐标自由度 | inference中条件区域允许放松、移动；最终姿态也允许适当改变，不要求坐标回到原值 |
| interaction condition | 仅输入声明时保留同一蛋白位点/残基及指定相互作用类型，按该条件规定的距离/角度范围验收；未声明则不额外强加 |
| 首要评价 | 整体分子的PoseBusters合理性；逐分子PB通过后才比较condition结构恢复，组级优先提高PB通过率 |
| PB不通过时 | 用结构应力和PB失败反馈指导连续优化，减少条件约束对周围结构生成的干扰 |
| 生效时间 | V30完成后先commit保存原方向，再读取本计划并激活；现在只保存计划 |

本计划中的“反向gradient guidance”指对可微结构代价反向求导并沿降低代价方向干预生成；不是把旧condition奖励简单乘负号，也不是把PB布尔结果直接反传。

## 2. 接口边界与机制假设

当前独立包的[FLOWR适配器](../../src/agenticgen/adaptive_schedule/flowr.py)明确拒绝`inpainting_mode`及`graph_inpainting`。该保护继续用于原方向；后续建立独立适配路径及协议，不删除保护来强行复用原实验。

作者当前实现区分Graph inpainting和fragment坐标固定：图模式的固定身份不等于位置固定。官方说明也指出条件生成的固定部分可能有变化。因此需要在激活后核对**远端现有固定FLOWR源码和原v2 checkpoint**的真实语义、mask、图标签覆盖及最终解码，不把最新main的行为当成当前已验证能力，不升级模型或环境。[作者源码](https://github.com/jule-c/flowr_root/blob/main/flowr/models/fm_pocket.py)、[官方生成说明](https://github.com/jule-c/flowr_root#generating-molecules-from-pdbcif)

第一项可检验假设：保留条件子图身份、允许其坐标与邻域共同调整，比从早期始终锁定参考坐标更容易形成合理的跨边界几何。第二项假设：根据PB失败类型调节结构代价、作用区域和时间强度，能提高最终合格率，而非仅降低中间能量。二者均需实际结果验证。

固定子图只覆盖输入声明的原子及其内部图特征，不默认固定整枚teacher分子的图。固定—自由区域的连接约束按输入的attachment定义保持；其余外部图由原生生成器产生。元素、键阶、电荷、芳香性/立体等具体字段在激活时按输入和原生表示列入契约，未支持的字段明确记录。

坐标控制分为条件区域、邻近可生成区域、远处可生成区域；空间权重可随距边界的距离平滑衰减，避免在mask边缘施加突变力。条件坐标可以移动，其身份不改变。若有interaction condition，软引导维持指定site/type的允许几何，末态独立验收；不把全部条件坐标强行贴回teacher姿态。

## 3. 新评价契约

PB在**最终生成、最终条件处理和解码之后的实际保存结构**上运行。整体化学有效性、分子内部几何和蛋白环境冲突均报告；不能只检查condition局部，也不能靠过滤失败候选提高通过率。PB包含多类几何和化学检查，单个应力指标不能替代它。[PB官方检查说明](https://posebusters.readthedocs.io/en/latest/checks.html)

激活时冻结PB版本、适用check列表、蛋白/辅因子输入和氢处理方式；沿用当前环境优先，不用整枚teacher分子作为必须完全相同的参考配体去否决合法的新生外部图。PB不适用/求值失败单列原因，计入全尝试分母，不当作通过。

每组25个尝试全部记账，评价顺序为：

1. **主要目标：整体PB通过数/全部尝试数。** 各teacher分别报告，跨teacher等权汇总；不能用更多低质量样本或选优子集掩盖失败。
2. PB通过样本中，报告条件子图一致性，以及声明的interaction site/type保持率。PB通过但条件契约不满足，不能称为最终成功。同步报告`PB且条件满足`的联合产率及其分母。
3. 在PB与条件契约满足的样本上，比较目标区域的结构恢复程度：同一蛋白框架中的映射RMSD、原子最大偏差及分布。坐标变化允许，RMSD是次级恢复指标，不沿用旧0.02Å条件排序带作为新主门槛；独立拟合后的shape仅作诊断。
4. PB全失败或通过率相同时，对未通过样本使用冻结的连续违反/应力指标帮助判断下一步，不能以低应力替代PB合格。无可评分样本时条件恢复为不可用，不填零、不伪造最优。

正式组排序在`I01`前写入新协议：PB通过率优先，其后联合条件满足率，再比较合格子集结构恢复；失败严重度作为没有合格结构时的搜索反馈及剩余并列项。合格子集数量与组成必须同时显示，不能只报筛后的低RMSD。图条件被破坏属于约束失败，即便PB通过也不得宣称完成目标。

亲和力Mean/Best可以保留为描述性结果，本方向不再用它们取代PB优先目标，也不加亲和力梯度。原方向的指标与新方向分别报告，不拼接成同一排序历史。

## 4. 连续结构代价与梯度路径

从PB反馈选择少量可微代理项：键长/键角超限、非键原子重叠、蛋白碰撞、平面性/扭转畸变，以及有定义的结构应力。跨固定身份—自由图区域的键和非键相互作用必须参与计算，不能因为mask而被删除。按物理单位/容差归一化，并记录总量、均值及局部最严重违反。

结构应力可采用同一生成图上的构象应变能与几何违反。若使用力场，冻结参数化、参考松弛方式和单位；参考松弛仅用于定义应变，不替换实际生成结构。参数化失败、缺失原子类型、非法图及求值失败都单列，不能视为低能量。离散价态或拓扑错误不能指望坐标梯度自动修复，应反馈给原生图生成/条件接口的定点问题处理。

PB是终态判定器；内部Guidance使用可微代理，在有意义的clean/endpoint预测上求导并经正确的采样器映射施加。先选择一条清晰、已验证的梯度路径，不同时铺开所有梯度路线。方向、归一化、裁剪、时间步换算和实际交付位移分别核对；若后续有代理改善无法传到终态的证据，再由主Agent决定是否研究经模型反传等兼容扩展。

软过渡同时允许两类调控：空间上由条件边界向外围平滑变化；时间上避免早期不合理几何强压，按证据调整适应、维持和释放。interaction存在时保持相应约束，缺省则不强制整体返回原姿态。不能把“晚期必然强、早期必然弱”写成固定答案。

初始工程实现优先保留100步及现有四窗口作为比较基础；把结构代价强度、条件几何软约束及空间过渡范围形成小规模、可解释的动作域。系数与旧RMSD奖励的U不具有自动可比性，新上下界、单位及改变段数在I01前冻结。梯度直接位移初始采用现有0.025Å上限作为保守起点；任何原生投影/条件操作造成的额外移动单独记录，不能隐藏在梯度裁剪之外。

## 5. 两层自适应循环与预算

外层最多20个主Agent版本`I01–I20`；每版两teacher各5轮，每轮4组，每组25候选，共1000优化终态/主版本，正式优化上限20000。沿用五个原种子、每种子五槽和相应组共同随机流；不同候选策略从新方向自己的条件初始化/恢复状态公平比较。**原方向R0不可直接当作已通过inpainting验收的新R0。**

在激活准备阶段设置一次共享的原生inpainting-only参考，每teacher25条，共50条，作为解释新增Guidance作用的对照，不作为额外主Agent版本或重复的零引导搜索组。因此计划上限为20000优化终态+50参考终态；工程验收及失败重跑的成本另记，不混入正式分数。没有新增大规模消融或独立搜索任务。

四个私有Guidance Agent各提两案，第五个汇总选择四案；同轮私有隔离。每轮接收整个分子的PB逐项反馈、连续应力/违反分布、条件身份与已声明interaction保持、合格样本的恢复情况，以及必要的真实干预统计。下一版本清空动态历史，保留通用skills和静态任务条件；第五轮只反思归档，不生成第六轮。

GPT主Agent每完成一个主版本，只检查按新PB优先协议选出的每teacher最优轮私有分析和同轮汇总，共四上下文，结合40组聚合结果；仍禁止全量会话/字段审计。主要判断：失败来源是否可由当前自由度修复，软过渡是否提高最终PB合格率，条件位点是否仍满足，探索是否解决能改变后续决策的问题。每次仅形成1–3个通用能力假设，选择性吸收经验文档，不写teacher答案进skills。

新方向建立自己的历史最佳和退步计数；若继续采用连续两次退步的恢复机制，其比较必须使用新PB优先协议，不能使用旧Mean-gap。原方向最佳策略可作设计经验，不能直接当新方向最佳。状态/评价/skills需以新campaign命名空间绑定，旧版本门槛不予复用。
