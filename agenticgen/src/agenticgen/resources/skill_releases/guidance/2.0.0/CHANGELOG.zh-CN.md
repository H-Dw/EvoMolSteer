# 2.0.0：实验内路径选择与实验后 RSI 分离

本版本由 2026-10-28 用户对 R1–R6 的明确答复形成，是设计期规则更新，不是完成某次实验后得到的科学改进结论。父版本为 1.6.1；外部 RSI 技能为独立的 1.0.0。原文件和运行目录均未覆盖。

- R1：实验经验始终留在当前任务经验库，不升级为固定 skills。固定技能只规定分析、检索和选择方法。
- R2：冲突经验先匹配当前锚点、其余窗口和状态背景；相似程度相近时选取相对当前状态最近的有效更新时间。反例保留，未来信息和文件更新时间伪刷新不能参与历史决策。
- R3：实验内不修改任何 skills；旧的逐版主 GPT 修改要求不再是 Guidance Agent 指引。只有外部 Agent 在声明实验范围的全部 target 和所需工作完成后才能开展 RSI。
- R4：外部 RSI 一次围绕一个有证据支持的主要问题，必要时改变一至三个模块，共用预期行为与否定标准。不是每次必须修改的配额。
- R5：经实际检验的流程改进可以在后续授权实验中采用；不替换分子最佳 checkpoint、不宣称几何收益、不重置退化计数。仅创建和格式检查尚未证明流程改善。
- R6：外部 RSI 可迁移抽象的待验证思路。具体对象、数值和来源留在更新日志/证据中；固定技能不携带对象身份或其特有最优权重。具体分配假设作为新任务先验上下文，使用接收教师自己的标定/锚点/合法动作检验，直接反证优先。

来源：本对话六项直接答复；完整答复与解释边界见 agenticgen/docs/designs/20261028_guidance_rsi_separation/decisions.json。此前研究出处保留在 20261028_guidance_reflection_policy/research.json，未声称本次新做论文或模型实验。

更新日志不进入 runtime bundle。新版本不是自动部署：旧 geometry_runtime.skill_assets 仍读取旧路径，accept_review 仍要求逐版技能修改。接入新实验前必须显式选择新版本并分离完成审查与 RSI 门禁；禁止拿文字修订冒充执行器已更新。本次不恢复、停止或改动其他实验。
