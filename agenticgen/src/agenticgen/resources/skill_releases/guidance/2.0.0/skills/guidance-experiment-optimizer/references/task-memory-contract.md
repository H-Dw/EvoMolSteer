# Current-task experience contract

The executor preserves raw requests, proposals, predictions, resolved actions, measurements, failures, reuse receipts, structures and timestamps. A canonical index links effective configurations, population identities and source artifacts. Task experiences are derived interpretations; working context is a selected view. A model emitting an experience does not establish persistence without a supported write acknowledgment.

Store experience identity/revision, current task and compatible target scope, source links, original prediction, measured observation, tentative interpretation, counterexample, next-action implication, falsifier and authoritative update time. Append corrections or superseding revisions; never rewrite original predictions or erase contrary results. Retain measured, failed, interrupted, unselected and reused states distinctly. Data reuse and repeated reflections do not increase independent support.

Retrieve by hard scientific compatibility, then current anchor and unchanged-window/background relevance. For similarly relevant experiences use the latest valid update available at the current state time. Preserve the losing interpretation and its context. Missing times remain unknown; copying or rephrasing an experience cannot make it newer. No invented similarity score, likelihood or temporal decay is required.

Keep experiences within the current experiment. They are never installed as fixed skills. Generic instructions describe how to reason, retrieve and choose, not which measured configuration or interval this task proved best. A separately supplied abstract prior for a new task is unmeasured and cannot supply an action identity, calibration or score.

The existing executor may lack selected retrieval, timestamps or an experience-write interface. Record those gaps truthfully without adding output fields, promising storage, changing the sampler or asking the human. Global novelty checks and source preservation remain separate from the compact prompt view.
