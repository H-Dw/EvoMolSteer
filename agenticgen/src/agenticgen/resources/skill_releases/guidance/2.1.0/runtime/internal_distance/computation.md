# 基于计算回执分析与选择

以下指引适用于提案角色及综合角色；工具只提供证据，不替 Agent 设定优化目标。

1. 先读取已有统计回执；只有缺少会影响决策的证据时才调用工具。
2. 判断改善幅度时做配对比较；均值与稳健中心矛盾时检查尾部；出现极端位移时定位样本及时间区间。
3. 只引用工具确认的数值和来源，不自行补造缺失结果。已验证历史原始测量也是证据；新增统计计算必须有计算回执。
4. 没有注册的工具不能假装调用；缺少关键计算时明确记录证据不足。使用现有不确定性字段和机器失败处理，不询问用户。
5. 最终仍使用原角色输出模块，在现有证据字段中引用回执、提出假设、预测及否定标准。综合角色只选择已有候选，不新增动作或输出字段。
6. 计算结果进入当前任务经验库；不据此修改实验内冻结的 skills。由执行器保存回执与来源，Agent 不冒称已经保存无回执的经验。

## 选择计算与解释结果

先核对当前 context 提供的 registered_computation_tools、统计策略和数据范围。summarize_population 读取完整统计与尾部身份；compare_paired_runs 按相同教师、条件、采样协议和随机槽位比较；inspect_interval_evidence 同时定位几何误差最大与引导增量最大的样本、步骤，若有约束前增量也需检查，不能只看终态误差；audit_action_batch 检查原整数动作及当前历史重复，执行器还会检查全局预约账本。这些工具都不能产生新的分子、预测未测实绩或修改预算。

需要时只提供已登记的原始 run_id、anchor_id 和合法参数。压缩标签、证据回执 ID 不可代替执行锚点。背景匹配优先于经验更新时间，保留反例；缺少可辨识对照时，不把多窗口相关变化当成单窗口因果效应。只查看自己当前教师可兼容的记录。

核对scale_reference和动作回执中的实际强度：归一化scale为0仍是该教师的正基线引导，负值表示更弱的正引导，均不是关闭引导。先辨别统计层级：总体均值、种子簇均值、单分子观测不能互换；seed_mean_changes不是某个异常分子的变化，异常样本数值从对应node_id的回执读取。模型可提出待验证的定量预测，但不能把预测、否定标准或临时诊断界限说成已测结果或已批准的接受阈值。

条件原子间距离均方根偏差仍是主要设计关注点；条件原子与邻域原子距离均方根偏差按已确认保护规则解释。使用完整指标名称。稳健中心、普通均值、尾部风险和失败覆盖分开解释；统计工具不改变原梯度损失或自动排名。构建失败但几何可测时保留几何数据；缺失或非有限值不能当成零、成功或完整人口。10/50慢质量诊断不能外推其余40个。截尾计算不删除源样本、不隐瞒严重失稳。

## 工具中间阶段与最终输出

使用原生 function tool calls 请求中间计算，不输出伪造工具调用文本，也不要求中间工具调用符合 proposals/selected 终答 schema。读取每个工具返回的 status、evidence_id、结果与限制；工具错误不是分子测量失败。只有确认的计算结果才能支持相应数值结论。

获得所需证据后，输出原角色的一个完整 JSON；证据字段逐字复制工具给出的完整 evidence_id（ev_ 后的20位字符也必须完整），禁止截短、改写或自编别名。说明假设、预测和否定标准，避免重复数组、整表和日志。每个文字字段均需留出长度余量，不为引用重复抄写同一组数值；单个最终观测不能定位收益发生的时间，更不能把增量异常出现的区间当成收益的因果来源。没有关键证据的结论仍然未知，不为了完成固定输出而伪造数值。执行器保留原科学动作校验。

叙述字段优先使用简洁中文和完整中文指标名称，JSON字段名及来源ID保持原样；不要为了引用长英文指标名而在每个字段重抄同一结论。每个提案聚焦一个假设，prediction与falsifier各用一个短句，均留在schema字符上限内。假设不是实测结论；未知机制不得通过数值补写变成事实。

模型调用次数、工具次数、总 token、超时和修正预算由外部参数控制。工具续调不需要用户参与。缓存匹配的计算不重复调用；预算耗尽或输出截断由执行器终止并保留账本，不自动循环重试，不删除 claim，不修改技能。
