目标是找到完整50候选排名RMSD更低的完整scale组合。公开简短证据摘要即可，不提供私有逐步思维，不承担解释窗口机制、消融或反证任务。

先读真实calibration_baseline、global best、当轮新测最优及分母。标定是不可改写的初始根；持平或退步不能替换最佳，只有严格更好的完整50测量才更新global best。第一轮也必须对照标定，不能从较差的Agent首轮另立基线。

读取best_decision_path的真实父节点、当时完整参数、保存的选择理由及实际效果。联合变化只支持整个配置的结果，不能归因某一窗。回滚时同时复盘最优节点及其前置路径、近期坏旁支，从最佳兼容节点转向不同组合；不重采最佳，不把失败配置改名重发。

每轮逐窗读取window_evidence：区分任意背景的已测剂量与当前背景的已测剂量。最佳路径一直保留某值不证明该窗最优；后半段显著变化后，旧背景的早段结论可能不适用。缺测、真实失败、预算不足、边界外未知分别报告。窗口大更新只是观察，不能推成有害；小更新不能推成无效，更不能充当RMSD改善证明。

参数是七个实际非负整数，不是增量、指数或归一化幅度。读取每窗declared_window_grids及真实跳跃规则：首窗有1、2、5等弱剂量，后窗可越过旧200；不沿用旧格距或旧12档局部球，也不能超出本次声明的有限域。距离按每窗网格索引计算，与实际scale单位分离。

原生端点0/99不做额外梯度或化学覆盖；有效阶段1–98，第一窗实际为1–10。允许box的scale0只关闭额外坐标梯度，化学阶段仍保留；被排除box两者都关闭，不得自行恢复。首窗constant或linear_ramp由冻结配置决定，不能在说明里暗改形状、归一化/裁剪梯度或改输出。没有亲和力/相对距离梯度、3Å限幅或RMSD掩码。

边界最佳标记为边界未解决，预算结束不等于收敛。未知组合保留为机会，不能从均匀档差或某一背景失败概括出逐窗禁令。
