## Template-relative component control

The bound objective has three separately averaged template-distance losses: condition_intra_loss, condition_outer_loss and interact_loss. Default binary weights are one, zero, zero; explicit interaction atom correspondences change the initial interaction weight to one. Distance means separation between atom identities, not absolute coordinate error, shrinking all distances, or an affinity score. The outer component compares every condition atom with every other template-mapped ligand atom, beyond the old two-bond neighborhood. Unmapped generated atoms have no template target and are not assigned invented distances. Interaction pairs compare each declared ligand atom to its specific fixed target atom in the shared template/generation frame. Empty interact_atoms means zero interaction loss. Pair-distance agreement alone does not guarantee chirality, chemistry, or a unique pose.

The primary recorded configuration ranking now uses controlled-atom pair distance root mean square deviation; all-pair root mean square deviation is diagnostic. When internal pairs do not exist, primary preservation is unmeasured, not perfect; the explicit executor fallback uses available intramolecular distances. Component weights are distinct from four temporal guidance scales: only component weights accept binary zero or one; a temporal normalized zero remains positive guidance. The normalization policy is experiment-frozen. Inspect original Angstrom errors, denominator, raw versus applied increments and component losses together. A smaller normalized loss caused only by a larger denominator is not a geometric improvement.

When paired history suggests no clear primary progress, consider activating the outer constraint as a testable intervention while preserving internal condition geometry. Prefer the same measured anchor and unchanged temporal scales for the first diagnostic contrast. An exploratory activation does not certify a plateau or acceptance tolerance. Record absent thresholds and evidence limits instead of inventing them. Request the registered set_guidance_loss_weights tool with the exact anchor, binary values, observed comparison receipt IDs and the hypothesis. Its receipt prepares a candidate-local control; it does not execute or change global state. Put the returned loss_control_id in a proposal only when using that control; omission inherits that proposal's anchor weights. Keep condition_intra_weight enabled when testing outer activation unless evidence supports an explicitly stated diagnostic ablation. Read the next measured paired outcomes before retaining or undoing the intervention.
