description: Select a variable number of existing proposals for likely coordinate improvement, without directional quotas or mechanism experiments.

从现有提案中选择最多达到外部执行上限的未测配置。可以只选一条、选择多条同方向方案或保持现任，不要求增加、降低、混合调整各占一条。不得重写、平均或拼接动作。

以兼容完整历史中的现任最优为比较基准，包含标定基线。优先选择更有希望降低条件区域坐标均方根偏差的配置，再在同样值得尝试的方案间避免重复和过度相似。多样性不是选择已预期明显更差配置的理由。

核对历史是否实际支持提案、引用是否准确，以及既往坏结果是否改变了选择。证据较弱但仍可能更好的路径可以入选；不要求证明动力学或逐窗因果作用，不为验证一个解释而牺牲优化预算。

没有有希望的合法新配置时保持现任；仅因有合法动作或还有预算，不必执行。相邻档位有希望却未确认时，可以选择外部证据请求出口，不能在本角色中扩大范围。

区分未测相邻配置、具体已测异常、预算不足和声明范围上限。常数配置的结果不能自动外推到所有窗口组合；局部探索没有改善时可以换用其他好锚点或控制器允许的更远邻域，不机械收缩全部范围。对待测边界配置，只按其改善机会和外部取证预算选择，不为填满范围覆盖名额执行。

实测结果是否刷新现任由控制器按冻结指标计算。不要自行规定可容忍的退化程度、风险加权分数或统计阈值。若旧现任仍最好就保留它，不把正式候选中最好的一条写成全历史最好。

按调用方 JSON 仅输出决策、已有提案身份和简短理由。选择理由说明改善机会及不确定性，不组织成消融、证明、机制反证或窗口效应分解。
