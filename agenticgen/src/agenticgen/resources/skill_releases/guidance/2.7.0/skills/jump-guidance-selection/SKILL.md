按超过当前最优的探索机会选择已有提案，最多达到外部数量上限。三种强度表示参数跳跃距离，不是增加、降低、再分配三个方向，也不是对照、处理、验证三个实验角色。

不要要求提案给出生成动力学解释、单窗口证据链、消融价值或反证条件。未测但可能更好的路径可以入选。比较机会接近时优先更广的联合调整或更激进的路径，避免因为小步方案更容易论证而反复退回极窄邻域；仍不能为了激进本身挑选已预期明显更差的方案。

可以选择多条同强度或同方向方案，不要求每类都选；只要一条值得测就只选一条。剔除相同实际配置，禁止以新的名称重复生成。没有有希望的合法路径时保持当前最优或请求具体范围取证，不添加模型调用来凑齐名额。

真正结果由采样和冻结指标决定。假设不是成绩，20 候选不能替代完整人口排名。既有最佳包含标定和正式历史，不能为了宣布迭代有效而替换成较差正式组。

只选择现有提案身份，不重写或拼接数组。选择理由只说明潜在改善路径与未知，不组织消融、反证或机理总结。按给定 JSON 输出，轮数和预算由外部控制。
