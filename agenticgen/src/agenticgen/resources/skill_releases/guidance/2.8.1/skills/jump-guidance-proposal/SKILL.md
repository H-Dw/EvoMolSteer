name: jump-guidance-proposal
description: Propose potential improvements as focused, expanded or bold parameter jumps rather than directional ablations.
metadata:
  version: "2.8.1"
---

提出可能超过当前最优的未测完整配置。三种分支假设只是探索激进程度：focused 为相对稳健的跳跃，expanded 为更宽的组合跳跃，bold 为更激进的跨邻域跳跃。具体整数变化范围读取输入。增加、降低、混合方向在三种分支中都可出现，不是三个分支的定义。

优先提出有潜力的联合窗口或跨锚点路径。机会相近时优先 expanded、bold，不因为 focused 更容易解释就长期停留在微调。保守分支同样为了优化结果，不承担对照组或单因素消融任务；不为填满分支名额提出预期明显更差的配置。

每条方案只需提供精确已测锚点、exploration_tier、窗口及整数 step、原测量或已读回执身份、探索落点及可能更优的简短理由、主要不确定性。理由是搜索机会，不是 inference 机制假说。可以说尚无直接改善证据，不必编造定量预测、参数效应分解或反证条件。

实际强度按教师基准加格距乘整数刻度计算，默认一档为 10。由执行器构造数组并核对探索强度；不要伪标激进程度、改变格距、把反向档位当作物理总量守恒或私自扩界。具体未知邻域走外部范围取证，保留先小人口再完整确认的预算契约。

三种假设不强制各给固定数量，也不要求各执行一条。可以跨强度比较不同有希望的方案。没有值得尝试的新配置时保持当前最优；缺少范围证据时请求外部控制器，不重复生成已保存候选。最终仅输出提供的 JSON。

工作邻域只是优先搜索提示，不是永久盒子。在已确认档位之间，可以按本轮允许的激进程度进行较大联合跳跃，直接以正式人口测量；只有使用未确认强度时才需要额外范围取证。不要因为离现任较远就自动放弃有希望的落点。

说明文字 reason、improvement_reason、uncertainty 每个字段最多 3000 个字符（按字符计，不是 token）。足以表达探索落点、选择理由和不确定性即可，无需凑满。证据 ID 必须逐字复制实际已测身份或已读回执；较长文字不允许虚构证据。模型 token 与调用预算由外部配置控制，保持不变。
