## Decision-gap research, 2026-10-28

The following papers informed the second preference interview. They supply alternatives to discuss, not human-confirmed defaults. Actual answers and code-capability boundaries are recorded separately in `confirmed-search-policy.md` and the repository interview record.

| Inspected primary source | Decision mechanism | Transfer boundary |
| --- | --- | --- |
| [BOHB, ICML 2018, section 4](https://proceedings.mlr.press/v80/falkner18a/falkner18a.pdf) | Separate configuration search from evaluation-budget allocation; model with the largest budget having enough observations | Motivates a breadth-versus-confirmation question. Training fidelity differs from nested molecular populations; no BOHB implementation or numerical allocation rule is inherited |
| [Automatic LQR Tuning, arXiv v1, sections III-C and III-E](https://arxiv.org/html/1605.01950v1) | Information-efficient experiments; distinguish prototype optimization from per-trial operating performance | Asks whether a diagnostic trial may temporarily underperform. No fitted Gaussian process, entropy score or new risk allowance is implied |
| [AIDE, arXiv v1, sections 3.1 and 3.2](https://arxiv.org/html/2502.13138v1) | Candidate-tree search, draft/debug/improve modes, evaluation-informed concise summaries | Distinguish invalid execution from a valid poor result and a contradicted hypothesis. Consider measured-parent selection and evidence summaries without importing automatic retries |
| [AlphaEvolve whitepaper, arXiv v1, sections 2.2, 2.4 and 2.5](https://arxiv.org/html/2506.13131v1) | Evaluation cascades, prior-candidate feedback, retention of high-performing and diverse candidates | Consider complementary measured branches and context selection. This does not implement an island model or grant a new branch budget |
| [LLAMBO, arXiv v2, sections 5.1 and 5.2](https://arxiv.org/html/2402.03921v2) | Empirical uncertainty-calibration and example-order sensitivity; candidate quality/diversity tradeoff | Fluent confidence is not calibrated uncertainty. Preserve decisive counterexamples and source identity; a shorter prompt does not guarantee nontruncated reasoning |

The GitHub API returned a rate-limit response and Git transport failed during commit lookup. The inspected raw files were accessible; hashes above pin the bytes actually read rather than inventing repository commit IDs. No external source was used to select a teacher-specific numeric schedule.

Selection criteria were match to the actual action space, measurable feedback, separation of proposal from execution, and ability to transfer without changing the scientific algorithm. Publicity alone was not a selection criterion. Main-agent orchestration, model training, reward-code evolution and autonomous laboratory execution are outside this skill's authority.
