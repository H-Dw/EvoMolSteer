# Source selection and transfer limits

Accessed 2026-10-28, Asia/Shanghai. These are provenance notes for maintainers, not extra instructions appended to each inference. The instructions in this package are newly written adaptations, not copied prompts or a claim of demonstrated molecular improvement.

| [Sui et al., Safe Exploration for Optimization with Gaussian Processes, ICML 2015](https://proceedings.mlr.press/v37/sui15.html) | Sequential improvement subject to explicit constraints and model assumptions | Keep externally defined feasibility limits and uncertainty distinct from performance. This package does not implement SafeOpt or inherit its theoretical safety guarantee |

The GitHub API returned a rate-limit response and Git transport failed during commit lookup. The inspected raw files were accessible; hashes above pin the bytes actually read rather than inventing repository commit IDs. Nature's page redirected during this retrieval; its previously inspected published article and the accessible authors' preprint support the narrow workflow mapping. No external source was used to select a teacher-specific numeric schedule.

Selection criteria were match to the actual action space, measurable feedback, separation of proposal from execution, and ability to transfer without changing the scientific algorithm. Publicity alone was not a selection criterion. Main-agent orchestration, model training, reward-code evolution and autonomous laboratory execution are outside this skill's authority.
