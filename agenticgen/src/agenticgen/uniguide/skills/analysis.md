# Guidance Agent: evidence and mechanism analysis

Trace each conclusion from measured schedule to coordinate input gradient, time coefficient, actual increment vectors, native drift/noise, and the final returned pose. The loss is PLIP-only mean squared coordinate error on the predicted clean endpoint. Matching and its target are detached, but the endpoint-to-current input Jacobian is retained across the entire valid ligand. A changing assignment is a discontinuity, not proof of improved binding. Compare both current/predicted error and final corrector output.

The teacher pIC50 is a separately rescored final pose reference, not the differentiated reward. C is the mean geometric core RMSD over all attempted candidates with usable coordinates, including chemically invalid ones; report missing coordinates explicitly. Smaller absolute mean pIC50 gap is the secondary criterion within the anchored 0.02 Angstrom C band. Keep the best pIC50, validity, PoseBusters, PLIP recovery, clashes and diversity visible. A tiny difference is exploratory evidence, not a significance claim.

Separate a measured observation from a mechanism hypothesis. Cite actual run IDs. When comparing windows, inspect the full increment vector, assignment switches, and guidance/native increment ratio. Scale, unit conversion, loss reduction and model Jacobian jointly determine the intervention. A larger lambda can worsen final geometry despite reducing the endpoint proxy. No unmeasured affinity gradient, atom/bond loss or inferred clipping is permitted.

## Interpret the actual FLOWR update

In this implementation the coordinate correction in model units is delta = -dt * S * ((1-t+1e-6)/t + gamma(t)) * grad_x L(endpoint(x,t), detached_target). The endpoint Jacobian is retained; the target, assignment, parameters and self-conditioning state are fixed during this VJP. The time coefficient and Jacobian mean equal S does not imply equal displacement across windows or teachers. Read coefficient_first/last, gradient norm, increment RMS and maximum atom increment together. The field native_increment_ratio_mean is mean(||guidance_delta|| / ||native_proposal-current||), including native stochastic motion in the denominator. It is NOT the inverse ratio and is NOT a stability guarantee. A moderate mean ratio can hide an extreme atom displacement.

A window's first/last endpoint losses are measured at different states, times and possibly assignments, before that step's correction. Their difference is not the local directional derivative of one fixed loss. A rising loss alone does not establish under-dosing; a falling loss alone does not justify another increase. Prefer measured comparisons with identical earlier windows and a single changed window. Two-window redistribution is a coupled test: identify both changes and leave their individual causal contributions unresolved. For changed upstream schedules, downstream RMS changes mix coefficient and trajectory effects. Compare final C, gap and returned-pose quality before accepting the mechanism. A reported C_se is a marginal standard error, not a paired-difference error; do not invent paired significance from it.
