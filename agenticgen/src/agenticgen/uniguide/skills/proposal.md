# Guidance Agent: bounded scale exploration

Strategy starts from selected V17 ideas, without old target answers or scores. Use only fixed calibration and this version's dynamic history. Every physical continuation starts at shared R0 before step 10; a named measured action anchor does not select a different molecular state. Keep model, loss, VJP, native adapter, windows, random streams and budgets fixed. Failed attempts stay charged; no weaker retry or replacement sample.

Each private inclination returns exactly two distinct, untested legal options. Increase only raises one or two windows; decrease only lowers one or two; redistribute changes exactly two in opposite directions. One mode per option: fine is sqrt(2), coarse is 2. Use the supplied shared domain, never clip, round or silently make a multi-step jump. In final analysis (no_future_execution=true), return proposals=[]; a regular round-5 advice call still needs two options. No R6.

## Construct legal neighbors before writing their rationale

Work in integer lattice coordinates j=2*log2(S). Read the anchor's exact lattice values; fine changes each selected j by exactly 1 and coarse by exactly 2. For redistribution choose one donor and one receiver with opposite equal-magnitude j changes; the other two entries remain identical to the named anchor. Map back using the supplied lattice precision, then check bounds, signs, changed-index count and novelty against all measured history and the other option. State anchor ID, mode and changed windows in anchor_reason. Do not derive a numerical schedule from prose or mix changes from different anchors. Redistribution does not conserve integrated physical dose.

Begin with your last measured branch and comparison_best. If the branch is outside the minimum-C band, loses on gap within it, or carries an extreme inherited increment, consider a better complete measured anchor (including R0). Calibration is risk evidence, not an executable anchor unless its ID appears in history. One option should be a supported local test when available; increase/decrease prefer one-window fine steps near measured reversals. The other should test a different window or explicitly different mechanism. Cross-branch matched comparisons can support or contradict either option. A poor default is not a requirement to continue a poor trajectory.

Keep the search finite: choose a measured anchor and promising windows, form the nearest legal neighbors, discard duplicates/invalid options, and stop when two defensible distinct options are found. If those neighbors are exhausted, inspect another measured anchor. Do not repeatedly re-derive every combination or pretend to prove a global optimum. Each option needs a concise observation with IDs, mechanism, directional prediction and falsifier. Separate a prediction of improvement from a tolerance for deterioration: staying inside a C band alone is not improvement. Complete one JSON object with all required fields, without a second object or trailing prose; keep explanations brief rather than repeating the shared analysis. Provider parameters and output allowance remain fixed.
