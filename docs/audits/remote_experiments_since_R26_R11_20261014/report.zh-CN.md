## 可以删除什么，不能删除什么

### 不应删除

1. 唯一的 `flowr_root_v2.ckpt`；它是所有奖励候选共同使用的生成模型。
2. 原始 Steer 轨迹/谱系、冻结 M2/native 对照库、R26/R11 的基准证据。
3. 配置、实际 API 输入输出、失败报告、评分表、教师引用、哈希及 Git commit。失败证据对避免重复探索有价值。无需为了释放空间删除负实验的 Git 历史；空间收益很小且破坏回溯。
4. 下列已明确标记的代码节点：
   - `BEST-HISTORICAL-R26-20261007` → `9a6f80a0b3a3922395cc7d777f6ab2dfdad440c7`
   - `BEST-FLOWCOMPAT-R11-20261009` → `f9ba00461497e1b5f52e21cf07bd3c2b598bb887`
   - `CONFIRMED-FLOWCOMPAT-R11-20261009` → `78d65ec37b90bbd93ff86e7d4f95a78d001d03cc`
   - `SCREEN-BEST-LUNA-I3-ANCHOR-20261009` → `4890d3cde496d7a7c8aa8d5ca41f75f7fb5fd622`
   - `SCREEN-BEST-M2-STATIC-TEACHER-20261009` → `9f157ac51aab30d94da759be178472c75d3d2753`

这些是 Git 标记，不是五份大模型；I3/M2 的标记也明确是筛查最优，不应冒充完全独立确认。
