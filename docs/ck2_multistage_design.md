# CK2 连续多阶段奖励：Designer 决策

本文件由 **Designer subagent simulation** 形成，只使用 discovery 分析、完整连续 Analyst 输出及发现集富集表。未读取 validation、heldout 或新生成实验结果。对应的机器可读决策为 `configs/experiments/ck2_multistage_v1/Designer.decision.json`；确定性原型已完成并绑定，详见末尾原型记录；本文不编造未生成的实验指标。本文不是可执行奖励代码，也没有声称任何 GPU 验证已通过。

## 选择一个相关区域目标

采用二维观测向量

\[
 z(y)=\bigl(d_{\mathrm{ASN117}}^{NOS}(y),d_{\mathrm{VAL116}}^{NOS}(y)\bigr),
\]

其中 \(y\) 是 FLOWR 当前预测终态转换到固定 CK2 对齐坐标系后的 Å 坐标，NOS 是预测类别为 N/O/S 的有效配体原子槽。每次预测重新确定类别集合，在当前求导中将其冻结。两个残基共同构成一个区域目标，不作为两个独立机制重复计权。

区域距离沿用分析定义：

\[
 d_r(y)=-\tau\log\left[\frac1{|I||J_r|}
       \sum_{i\in I,j\in J_r}\exp\{-\|y_i-q_j\|/\tau\}\right],\qquad \tau=0.25\;\text{Å}.
\]

这是归一化 soft-min，既不是最近接触距离，也不是氢键或结合能。有 NOS 原子的配体才能提供该观测；没有时必须标记 unavailable、跳过该粒子并记录原因，不能补零当成完美奖励。受体点保持固定。

连续 Analyst 的证据表明 ASN117 的 NOS 距离全窗期望偏移为负，而全原子距离平均偏移为正，适合研究局部组成与位置，不能解释为把整个分子一同拉近。进一步核对发现集 `continuous/enrichment/function_summary.csv`：ASN117 的 lower/upper-tail 期望质量偏移分别约 −0.004734/−0.005871，q≈0.01380/0.005175；VAL116 对应为 −0.004954/−0.004964，q≈0.002352/0.002202。两端均减重，支持研究分布附近的区域，而非继续减小距离到任意低值。这些尾部采用时间匹配的背景阈值，不是物理距离界限。

反证同样保留：上述祖先低/高尾部的 q≈0.39–0.65，没有证明一个精确的最优保留带；同父 endpoint 差异近于机器零；每批初始50根到 t=.5 平均仅约1.214根。区域和保留原型都只是选择历史的关联假说。

## 原型与尺度分别来源于保留集合和背景

每个 discovery 批次在每个真实评分时刻各产生一个二维代表：

\[
 \mu_b(t_k)=\frac{\sum_i a_{bi}(t_k)z_{bi}(t_k)}{\sum_i a_{bi}(t_k)},
\]

\(a_{bi}\) 为该节点在最后一次窗口选择之后的后代拷贝数，求和限制在二维观测同时可用的节点。它描述回顾性的窗口保留集合，绝非 t=1 成功标签。批次内部用拷贝质量复原保留分布，批次之间始终等权，不能把拷贝数当作增加了独立证据。

预期最多有14个批次代表，但本次提取实际完整覆盖14批、51个原始时刻，逐批各时刻 retained-copy 覆盖率均为1。它们是 **batch representatives**，不是经过验证的真实姿态 mode。均值仍可抹平同批多峰，两维距离也无法唯一识别三维 pose；后续若声称保留完整分布，应先检查批内离散度，必要时使用带批次等权约束的真实分支代表或 medoid。当前选择的是简洁可验证的第一步。

尺度来自同一时刻的 unguided 候选。在每个 \(t_k\) 先计算各批次内部的二维协方差，再对批次等权平均。不要把0–.5的均值漂移池化为噪声，也不要从后代克隆数估计精度：

\[
 S_k=0.9\bar C_k+0.1\operatorname{diag}(\bar C_k),\qquad
 \Sigma_k=\operatorname{eigfloor}(S_k,0.01\;\text{Å}^2).
\]

这里“0.1 Å floor”是标准差或特征值平方根下限，对应方差下限 **0.01 Å²**。收缩系数和下限是预先声明的 pilot 稳定化假设，不是数据识别出的最佳核宽度。相邻时刻采用 \(\Sigma_k\) 的凸插值，保持正定；不对协方差元素直接 PCHIP。

## 相关混合 pseudo-Huber 奖励

令 \(e_b=z-\mu_b(t)\)，\(r_b^2=e_b^\top\Sigma(t)^{-1}e_b\)。采用

\[
 \rho_\delta(r)=\delta^2\left(\sqrt{1+r^2/\delta^2}-1\right),
 \qquad
 R(z,t)=wT\log\sum_b\pi_b\exp[-\rho_\delta(r_b)/T],
\]

其中有效批次均匀权重 \(\pi_b=1/B\)。无量纲 \(\delta=T=w=1\) 是本次形状约定；它们与外部注入强度分开。计算使用 log-sum-exp。其特征梯度为

\[
 \nabla_zR=-w\sum_b\alpha_b
 \frac{\Sigma^{-1}(z-\mu_b)}{\sqrt{1+r_b^2/\delta^2}},
 \quad
 \alpha_b=\operatorname{softmax}_b\{\log\pi_b-\rho_\delta(r_b)/T\}.
\]

这个式子在相关二维几何中靠近多个批次代表，不会把两个距离的任意组合都视为合格。距离代表较远时，pseudo-Huber 限制白化空间斜率；使用 log-mixture 可以避免直接 \(\exp(-\rho)\) 奖励的远场下溢与梯度消失。**奖励值本身不全局有界，live Jacobian 也可能放大梯度**，因此位移仍由外部控制器约束。

候选架构比较如下。

| 架构 | 决策 | 原因 |
|---|---|---|
| 两个独立矩形区间 | 不作为主方案 | 丢失残基间相关性，可能容许未观察到的组合，并重复计权 |
| 单一相关均值 | 可作诊断 | 保留协方差，却可能消除跨批次保留形态差异 |
| 批次等权相关混合 | 主方案 | 一个区域目标，多个经验代表，避免按克隆丰度扩大权重 |
| 有界指数混合分数 | 暂不采用 | 远场可能梯度消失，归一化后反而放大数值噪声 |
| 每个真实分支/medoid混合 | 后续扩展 | 更忠实，但依赖和规模较大，需先验证批次均值是否丢失重要多峰 |
| 按高阶多项式驻点切换 | 不采用 | 拟合在后期可与实际效应反号，不是可靠阶段机制 |

混合分量重叠时，责任度可能使梯度接近一个平均方向；对称或已满足目标时也可为零。不得为了“全程有动作”强制破坏这些零梯度。

## 多阶段是局部近似，核心目标贯穿全程

保留0、.01、…、.5全部51个原始时刻。以0和.5为初始节点，对每个批次代表的两个分量作 PCHIP；在所有原始时刻计算最大联合白化残差

\[
 E_k=\max_b\|\Sigma_k^{-1/2}
       [\mu_{b,\mathrm{raw}}(t_k)-\mu_{b,\mathrm{interp}}(t_k)]\|.
\]

每轮加入最先出现的最大违规时刻，直到所有 \(E_k\le0.1\)，必要时保留全部51节点。0.1是标准化插值误差容限，**不是0.1时间分箱**。节点、原始目标、插值残差与缺失均需保存；节点误差控制也不等于节点之间的全域误差保证。不得跨未定义 NOS 目标静默插值或补零。

各局部插值段始终使用同一个相关区域奖励，不到某个阶段就删除早期目标。在 \(.5,1)\) 冻结末端代表和协方差：

\[
 \mu_b(t)=\mu_b(.5),\qquad\Sigma(t)=\Sigma(.5).
\]

这是 **terminal-reference maintenance** 的显式试验假设，选择数据只支持到.5。它没有声称后半程最优，也没有外推高阶多项式。奖励和坐标梯度在.5处连续，外部时间导数可以存在拐折；\(df/dt\) 不参与冒充空间梯度。

## Live pullback 与外部强度

保持 MolExecutor 的基本语义：预测终态 \(y=s h_\theta(x,t)+COM\)，通过当前 native 坐标计算 \(g_x=J_y^\top\nabla_yR\)。模型参数、上一积分步和先前自条件均冻结；类别 mask 在本次求导中冻结。每个分子的奖励独立相加，不取 batch mean 缩小梯度。

先执行不变的 native 积分，获得 world Å 位移 \(u\)，再按可编辑原子的梯度方向形成额外修正

\[
 \Delta_{\rm raw}=\eta\,\mathrm{RMS}(u)\,
                  \frac{g}{\mathrm{RMS}(g)},
 \qquad \eta\in\{.05,.15,.30\}.
\]

这里 \(g\) 必须转换到相同 world-coordinate 基底并正确应用 mask。native 位移已包含真实积分步长与随机项，不应在归一化后再次额外乘 dt。只有有效且超过预先记录数值门槛的梯度才归一化；native RMS为零、NOS缺失、真零梯度及非有限值都单独记录。

每粒子使用同一标量施加最大原子修正 **.025 Å** 与累计已接受 RMS 路径预算 **2.5 Å**。后者在100步 × .025 Å的条件下主要是最坏加法路径上界，通常并非额外严格约束；FLOWR可放大早期扰动，因此它不是最终坐标偏移上界。

以同一未修正 native proposal 为参照，逐粒子回溯减半，直到满足：

- 没有新的受体原子对进入1.2 Å严重接近集合；应比较原子对集合，不能仅让新增与消失的碰撞数量抵消。
- 活跃配体原子对距离变化最大值不超过.05 Å；固定和非活跃原子保持不变。
- 数值、单步和累计预算全部满足。

回溯失败就保留 native proposal，不能扩大步长强迫运动。这些是几何工程约束，不是物理能量优化，也不保证最终化学有效。受体检查的原子集合必须记录，不能将局部口袋检查宣称为完整蛋白安全性。

## Pilot 校准与比较

先完成真实模型有限差分、100步零强度一致性、frame/scale/mask检查、逐粒子独立性以及后半程实际活动记录。三个 \(\eta\) 都作为预声明候选；它们尚未校准。建议在新的校准种子上仅根据数值可行性、实际/请求位移比及回溯效率选择强度，不按亲和力选择。

决策 JSON 提供了一个可选、必须在使用前声明的工程规则：在零已接受约束违规的候选中，选择 median(applied/desired RMS)≥.5 且完全回溯拒绝率≤5%的最大 \(\eta\)。这些门槛已作为本轮预声明可行性规则采纳，尚未声称执行通过。另要求每组12个样本的pilot中，有效分子数比matched unguided少不超过1个，最终严重碰撞数不增加；不按亲和力选优。门槛是工程约定，不是观察到的自然规律。没有候选通过时报告校准失败，不以强迫非零运动替代验证。

保留以下配对对照，固定 checkpoint、100步 native 设置和初始种子：

1. unguided。
2. constant terminal reference full：从开始就使用.5目标，全程作用。
3. multistage window only：连续目标作用到.5，后半关闭，作为明确消融。
4. multistage full：连续目标到.5，随后冻结端点参考，核心项保留至生成结束。

全程比较应报告局部插值误差、二维保留分布相似性、mode责任度/覆盖、实际接受位移及后半非零活动、最终有效性/连通性/独特结构/碰撞，以及单独的 CK2模型重评分。窗口组与全程组的累计剂量不同，不能只把结果差异归因于阶段设计。两个距离相似不意味着3D姿态或分子分布恢复，代理奖励提高也不等于亲和力提高。

先前早期控制可能受到短作用窗口、单侧中位数饱和、独立标量目标和未与native运动比较的强度限制。这是设计层面的解释；本次未读取新实验结果，不能断言它解释了某一具体实验的失败。
