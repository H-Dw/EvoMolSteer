# 完整选择窗口的连续分析 v3

主流程改为对实际选择窗口 0–0.5 的 51 个节点进行统一分析。没有 0.1 宽子区间的平均、分段检验或独立分段拟合。`stage=0` 只为旧读取器保留兼容元数据；新统计不使用这一列。实际 `resampled` 标记继续决定边界，不能把 t=1 的成功分子混入特征发现。t=.5 的被选 proposal 可处于约 .51，其选择事件仍是 .5。

## 三个不同的问题

1. **即时偏好：** 每次选择的 `sum(p_i f_i) - mean(f_i)`，与实际复制偏移、随机偏差及同父节点对照分别保存。
2. **累积筛选：** 将最后一次选择后的 B 个槽位沿完整父子边向前回溯，得到每个候选的窗口末端拷贝数 D_i(t)。D=0 的分支是窗口内灭绝对照；D>0 只表示谱系留存，不等于 t=1 分子成功。分别计算 D 加权祖先特征、留存/灭绝候选差异及相同时间背景差异。这是回顾性条件分析，不能单独证明特征导致存活。
3. **变化来源：** 对完整特征校验 `population(t+1)-population(t) = realized_selection(t) + mean(child-parent)`。保存两个分量、变化率及窗口内累积贡献，区分选择复制与后续模型/积分/类别变化。最后一次选择的输出不再作为下一个窗口内观测。

统计独立单位始终是粒子批次。时间节点、原子、克隆和父子边不是独立重复。保留谱系存活数、初始根数量、祖先有效样本量和筛选 ESS；根谱系塌缩会限制可学习信息。

## 特征和物理含义

单目标默认只测 CK2 区域，预测终点与 proposal 分别计算，共 424 个特征：

- 原有残基 soft-min 距离、N/O/S 条件距离、平滑接触比例、配体回转半径等。
- 接触加权配体重心相对残基重心的 x/y/z 偏移：使用共同对齐的受体坐标系；这是坐标协变观测，不宣称旋转不变。
- 接触区域的 N/O/S 组成、形式电荷与局部键级；全配体原子类别比例、键类别比例、键密度、键长均值/标准差和图不对称率。
- 平均平方近距离重叠量 `mean(max(2 Å-r,0)^2)`，单位 Å²，明确称为几何排斥代理。

FLOWR 键标签由源代码 `flowr/util/rdkit.py` 和 `flowr/util/molecule.py` 核实：0/1/2/3/4 对应无键/单/双/三/芳香类别，4 的名义键级取 1.5。中间类别未经化学有效性验证；芳香类别占比不等于已经验证的芳香环，形式电荷不是部分电荷。

原轨迹没有物理能量、逐区域力场参数或完整氢/部分电荷信息。pIC50 模型评分也不是结合自由能。本轮不制造“区域能量变化”数值。若后续增加真正能量特征，需要固定结构重建、质子化与力场方法，保存参数覆盖/构建失败，再明确可比较的分子组成和区域分解定义。[RDKit 的 MMFF 接口](https://www.rdkit.org/docs/source/rdkit.ForceField.rdForceField.html)提供原子类型及分项参数，但这些前提不能由原始类别标签直接替代。

新特征扩展点在 `chemical_features.extend_catalog/measure_chemistry`：输入为同一表示的世界坐标、原子类别、mask、键矩阵、形式电荷类别；输出为特征 ID→float64 候选向量，附带单位、区域和解释限制。后续物理能量模块应遵循同一接口，将失败输出为 NaN 并记录覆盖率，不能填成零。

## 富集与连续函数

富集同时计算低端与高端。阈值是 discovery 无引导背景在**同一原始时间节点**的 25%/75% 分位数；其他 split 沿用这些阈值。每次事件计算概率质量、实际复制质量、窗口末端祖先质量的变化，以及留存/灭绝的 log-odds。阈值随自然生成漂移，不把不同时间的候选混在一起比较。

对批次曲线 y_b(t)，在整个观测窗口拟合一个全局 Legendre 多项式：

`f(t) = Σ c_k P_k(2(t-t_min)/(t_max-t_min)-1)`。

候选次数为 0–5。按独立批次留一交叉验证，以原时间间隔的梯形积分权重计算预测 MSE，用 one-standard-error 规则优先选简单函数。不是按每个候选随机拆分，也不是对子区间各拟合一个函数。输出原始 t 的幂级数系数，可直接求值；一阶、二阶导数和驻点由多项式解析求得。禁止窗口外外推。函数拟合是对确定性观测的统计描述，不是新神经网络或 reward model。

完整批次曲线 bootstrap 给出系数区间、逐点区间和单条曲线的同时带；这些区间以已经选定的次数为条件，不包含模型选择全部不确定性。独立验证/留出批次评价冻结函数与常数基线，不调整次数和系数。只有完整覆盖窗口且达到最低批次数的特征才拟合；其余曲线和缺失率仍保留。

全局检验直接使用**未平滑的整条曲线**的均值平方积分，在符号对称零假设下对整个批次曲线统一 sign-flip。这样正负效应在窗口平均中抵消时仍有机会识别时间变化。BH 校正在 representation/arm/contrast 内跨特征进行。原始水平非零本身不表示优势；应读选择/祖先/背景差值。全窗口均值、首尾差值与逐事件导数另存，不用它们替代全曲线检验。

## 接口与文件

```powershell
.venv/Scripts/python.exe scripts/run_pipeline.py --root data/optimized/main1000_w050/analysis_inputs_v2 --output results/continuous_single_v3 --config configs/continuous_single_target.json
```

默认配置已指向 v3。历史 v2 默认保存在 `configs/selection_window_v2_legacy.json`；原冻结奖励及实验不改写。

`scripts/analyze_continuous.py --analysis OUTPUT` 可复用提取缓存；单独趋势/富集/差异/PCA 的原入口识别 v3 后调用连续分析。默认完成后回收本次可重建特征缓存，原轨迹和谱系保持不变。批次×节点×特征的统计表保留为 Parquet；不展开保存逐候选×特征的边明细。读取缓存可从原轨迹按哈希重建。

每个 split 的 `continuous/{trends,enrichment,differential,dynamics,pca}/` 单独保存批次事件曲线、点曲线、窗口统计和变化率。发现集另存 `functions.json`、`function_summary.csv`、`fitted_curves.parquet`、批次系数；验证集另存冻结函数误差。`lineage/window_ancestry.parquet` 保存所有候选及其窗口末端拷贝数，保留灭绝分支。

新 Analyst 输入为 `agents/Analyst.continuous.request.json`，包含独立连续分析 skill、严格 JSON schema 和可追溯证据。旧 2.0 的分段奖励编译器拒绝这一输入；本轮没有依据新拟合自动修改生成奖励或启动新的生成实验。

`df/dt` 描述时间演变，不能直接替代 `∇x R`。可进一步把经验证的 f(t) 作为连续时间的特征目标，但需要特征本身的空间导数、幅度控制和独立干预实验，才能判断是否接近有益生成路径。
