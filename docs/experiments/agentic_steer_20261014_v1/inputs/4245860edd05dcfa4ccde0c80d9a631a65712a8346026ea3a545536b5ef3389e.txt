---
name: agentic-steer-interface
description: Shared data and execution contract for native-continuation search decisions.
---

Choose registered historical states for complete native continuation experiments.
The supplied objective, clocks, budget, evidence IDs and response schema define
this task. Return one schema-conforming JSON decision. Cite only delivered IDs.

Separate current states, endpoint forecasts and decoded terminal outcomes.
Historical extinction is censored future quality, never an observed failure.
Model affinity is a prediction. A missing energy is unknown, not zero energy.
When execution status is complete, an undecodable or invalid molecule is a
chemical outcome failure, not an infrastructure or numerical job failure.
Use the host's explicit failure classification; do not relabel failed outcomes.
Do not request a graph-equality gate, alter the generator, or manufacture a state.
Continuation identity includes its actual state, time, self-conditioning and
child random stream; repeated use of the same identity reuses one observation.
Numeric uncertainty and actual trial costs come from the host, not verbal
confidence. Report concise hypotheses and decision reasons, not private reasoning.
The execution host validates IDs, budgets and code before running any action.

---
name: agentic-steer-omissions
description: Audit information and implementation omissions that can bias pathway selection.
---

Inspect supplied definitions, field availability and the baseline selection
logic. Distinguish an absent field from an available but unused field. Check
whether preprocessing removes signed regional changes and whether extinction
or clones are incorrectly treated as outcome labels. Verify a claimed loss
against the actual metric: Euclidean distances distinguish opposite vectors;
taking feature magnitudes first may erase sign. Test a minimal counterexample
before diagnosing code. Distinguish panel construction from budget allocation.
Name the precise omission and its decision consequence. Select a contrast or
additional continuation that resolves it. A checklist without a changed
experimental choice is not evidence that the audit helped exploration.
