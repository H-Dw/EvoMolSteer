# Agentic Steer 小预算渐进探索

目标是估计从实际中间状态原生续生成后获得结构合格、高预测亲和力终态的机会。首轮只改变实验起点及追加预算，不注入坐标奖励，不进行后续 SMC。

## 固定协议

- 教师/对照证据来自历史批次0–13的终态与真实祖先；探索卡来自14–17，隐藏其历史终态标签。该面板曾被项目其他研究使用，不冒充从未见过的数据；本次新的续生成随机结果尚未观察。
- 从完整重启快照的当前状态开始，首轮选第30积分步（约0.30）；保留100步原始网格，执行剩余70步及终态读出。学习支持由配置给出，不写入Skills。
- 模型使用历史v2 checkpoint；预检恢复后首个端点与历史预测是否匹配。主种子42，子流由节点和重复编号派生。每个续生成单独执行，结果不随运输批次组成改变。
- 结构合格定义为可解码、连通且没有0.8 Å以下的严重受体重叠；MMFF应变是次级单独报告。终态pIC50阈值取发现集有效连通终态的95%分位数，不能根据探索结果重调。
- 每条件选择4个方向，各2次初始续生成，再依据真实终态反馈追加4次，共12次逻辑试验。相同节点/子流跨条件复用结果，不重复生成，也不将复用结果计为新独立观察。
- 共享缓存仅在某条件请求某试验时对其开放，不提供未请求的终态结果。全历史坐标不复制，保留定位符；远端只保存终态SDF.gz、指标和短审计。

## 顺序与模块

P0先验证完整状态恢复、相同子流重复性、70步完成、SMC禁用和无梯度。
C0为当前head选择+测量后追加的确定性基线；C1–C6依次加入六份科学Skills。累计差异只作筛查，不能直接当作模块必要性的独立因果证据。

|模块|预期功能|行为验证|效果验证|
|---|---|---|---|
|K1 多假设|组织不同空间/动态解释|至少两条具有observable与否证条件的不同假设|选择覆盖及终态结果|
|K2 遗漏审计|识别删失、漏用变化、克隆问题|指出具体字段/代码及相应试验|被原head忽略方向的结果|
|K3 结构背景|区分几何与化学解释|引用真实锚点/身份，保留不确定性|结构条件化选择的增量|
|K4 小实验|构造区分解释的对照|有真实匹配状态及剩余混杂|对照是否区分未来收益|
|K5 反馈|用结果调整保留/预算|记录反馈导致的实际新增试验变化|命中、覆盖及预算收益|
|K6 编程|实现小型选择规则|AST白名单、实际字段与数值扰动响应|与此前规则的同预算比较|

阶段性规则：功能没有实施时，记录未响应，优化指令后重新建立版本；不能解释成该科学方法无效。亲和力下降时先检查执行和输入信息，保留原状态档案。六模块筛查后，只有响应和效果支持的模块进入更大预算验证，并设置完整/删除与不用LLM的模式保护对照。

首轮指标是全部尝试的预测pIC50、最佳结构合格pIC50、固定阈值命中率、有效率、严重重叠、应变、方向覆盖和seed-step成本。12次/条件仅为筛查，不能宣称统计显著优于原Steer。确认阶段应使用新的初始群体/子流、多个独立批次以及相同预算的原Steer、BoN和数值分配基线。

Agent采用真实deepseek-flash API、原默认调用温度；请求、回答、证据引用和实际动作都保存。反馈敏感性先以成对成功/失败情景验证，并保留真实反馈与置乱反馈的正式对照。基础合约与科学模块分别保存。
