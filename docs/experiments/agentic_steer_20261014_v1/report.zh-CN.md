# Agentic Steer 首轮小预算实验

本轮学习的是实际中间状态的后续生成潜力。每条试验从完整快照恢复坐标、类别、prior和self-conditioning，在原生100步网格执行剩余70步；没有后续SMC和gradient guidance。

发现集终态95%分位数冻结为 8.2589 pIC50。命中还要求可解码、连通且没有0.8 Å以下严重受体重叠。此处结构合格是初筛定义，不等于完整PoseBusters合格。MMFF94s松弛能量/重原子仅作为次级指标。

真实DeepSeek deepseek-flash API、默认温度0。八个条件共96次逻辑试验，复用后生成43条独立子流、15个起点，共3010个seed-step。母随机种子42；每个node/replicate有确定的独立子流。

## 概率与解释边界

每个方向单独保存成功/失败、重复数与二项区间。两次均未命中仍有很宽的上界；不能据此认定该路径没有潜力。自适应追加存在选择与停止偏差，正式确认需要未参与选点的固定重复。不同条件复用的子流不是新的独立样本。

开发面板起点head与原生后续平均评分的Spearman相关为 -0.0321，只描述本次选点面板，不代表全部历史样本。首预测最大恢复误差 8.25e-05 Å。

历史教师来自终态回溯的多条真实祖先；历史SMC条件下的后代成功不等于关闭SMC后的成功概率。灭绝与未观察未来仍按删失处理。本次没有将LLM文字置信度变成繁殖概率。

原始1000个Steer终态的全部评分均值为 7.6515、最高为 8.7048，仅作背景。计算预算、初始状态及结构判据不同，本轮不能作同预算优劣结论。

初始回答出现过将端点forecast特征称为current特征、将面板构建代码当成预算策略的解释风险；反馈阶段额外提供了实际策略代码与表示定义。K6在执行前检查raw单位、注册字段、纯函数AST和数值扰动；raw API提议与实际执行排序分别保存。

## 后续递增验证

先使用新的固定子流确认优先方向，并加入未被初始选中的方向作为实际对照；再做单模块完整/删除对比。获得命中后比较方向档案与全局top-k的保留差异，使用真实反馈/置乱反馈检验适应功能。最后才扩展到多个恢复时刻、完整树搜索和同预算Steer/BoN；本轮不能证明已超过原Steer。

## 小型纠正实验

补充完成状态/化学失败标签、真实策略代码、欧氏距离反例及确定性均值后，新的真实API检查四项误解全部纠正：True。选择程序数值与top4排序均发生变化：True / True。这证明输入和Skills修改得到响应，不能仅凭响应宣称质量改善。

修正程序依据先前12条C6观察，又请求4条续生成（其中1条新独立子流，其余复用）。新增请求的全部pIC50均值为7.1302、命中0/4、基础结构合格4/4。它是第二轮开发筛查，使用了更多先验反馈，不与原12次条件作同预算优劣声明。
