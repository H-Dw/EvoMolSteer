# 选点逻辑与首轮失败原因复核

本文件只复核已有数据，未运行新生成。历史终态回溯仅用于实验结束后的覆盖审计，没有将这些标签提前提供给实验Agent。

## Head基线的准确含义

C0从历史Steer在约t=0.30的24个注册起点中，按当前生成模型joint affinity head的pIC50取前4个：N006、N000、N018、N012。每个原生续生成2次。之后优先按实测高阈值命中率排序；命中率相同时，按全部重复的质量折扣pIC50均值排序，基础结构不合格的重复计0分。追加N000、N018各2次。没有使用应变排序。

因此，它是“head选点＋真实终态反馈分配”的无LLM对照。所有后续生成没有SMC或gradient guidance，但起点来自此前Steer，并且选点与追加本身使用了目标信息。它不是t=0起完全无选择的生成基线。本轮也不是与既有400个从头无引导样本的同状态、同预算比较。

## 当前LLM实际权限与指标

C1到C5每阶段返回JSON，指定已有node和重复号。C6返回选择代码，由主程序执行后覆盖文字node列表。每条选中的起点都交给FLOWR完成t=0.30到1的原生生成；LLM没有改变中间坐标、模型向量场或后续每一步的分支保留。调用也是初始一次、反馈一次，没有自主调用分析tools的多轮循环。

指标主要为23个端点forecast坐标特征及23个沿真实父子关系的相邻预测变化率：质心3、协方差6、原子间距离核5、三个口袋锚点各3。真实当前坐标只交付Rg；完整当前特征虽在预处理中计算，但未交给LLM。另有当前head、forecast Rg、硬原子类别数量及口袋锚点身份。未交付完整局部能量、配体typed接触、键空间统计、self-conditioning特征和多步稳定性。

教师库保存34条路径（11个elite、23个ordinary），但API每类只交付前4条；按批次顺序截断而非模式覆盖。提供的成功路径最高终态pIC50为8.3479，库中的8.6259与8.7048路径未被交付。另有6个批次的祖先均值差异和有符号变化率差异。没有在本轮交付正式的全窗口趋势拟合、置信区间或多重检验结果。

## 可确认的瓶颈

1. 200个历史状态被预处理限制成24个选项，其他状态无法由Agent主动申请。四个批次的历史最佳终态祖先均被遗漏：

|批次|最佳有效终态pIC50|t=.30祖先slot|当时head排名|进入面板|
|---|---:|---:|---:|---|
|14|8.1417|35|12|否|
|15|8.3001|21|8|否|
|16|8.1328|0|7|否|
|17|8.5844|48|8|否|

历史高阈值终态对应3个不同中间祖先，面板只覆盖1个。这不能证明遗漏状态关闭SMC后仍会成功，但能证明候选限制挡住了真实历史成功路径。

2. 教师标签是历史后续SMC策略下的成功，并非原生续生成成功概率。祖先只要有一个有效高分后代就被标elite，没有按复制机会数校准成功率。历史未来选择与本轮未来策略不同。

3. C6文字提议N002、N013、N000、N014；执行函数选择N013、N001、N000、N014。函数将shape_yy、shape_zz分别拉近6.6和6.7，叠加负tanh的锚点softmin变化率及正tanh的occupancy。数值安全检查没有检查文字假设与执行排名的一致性。N002四次续生成均值7.9127，N001三次均值7.0460；这是事后实测差异，不是独立验证的反事实改进。

4. 初始C6规则在看到真实反馈后逐字不变。解释更新并未使函数产生反馈响应。rate/landmark_05_softmin在24个候选中有13个经tanh后绝对值超过.99，另一个锚点有8个，说明未经尺度校准的非线性压缩丢失了很多幅度分辨率。

5. 输出存在可验证的科学错误：把forecast shape称为current shape；称欧氏距离自动丢失符号；把化学解码失败称为数值任务失败；C1/C5把均值7.8664列为最高，却把7.9123列为第二。这些不是字段格式验证可以排除的错误。

6. 每起点初始只有2个新结果，全部没有高阈值命中。没有足够的原生高质量正例和稳定的概率估计，当前规则仍是几何偏好，不是经过校准的未来质量函数。新的解释纠正测试改变了程序，但追加结果仍未改善。

## 结论边界

本轮证据说明当前工作流和选择函数没有形成整体生成增益。它不能说明LLM在完整候选库、更多原生反馈和真实tool调用条件下无效；也不能把含负对照的探索均值当成单纯优质生成性能。

优先应取消不透明的候选截断或增加注册状态检索接口；教师按模式覆盖并区分历史SMC和原生标签；补足真实当前状态、完整变化及确定性统计；把数字排序、失败分类和语义到执行的一致性检查交给程序。随后分别评价信息获取阶段和独立确认阶段，使用新的固定重复验证优先方向。
