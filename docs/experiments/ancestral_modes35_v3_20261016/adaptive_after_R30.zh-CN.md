# R31–R33 的前瞻回访

前30轮未超过 R02_v3 的8.699415，原 Steer目标为8.704806。保留原冻结确认范围与预算；仍在35个总条件以内，不增加优化轮次。

## R31：近目标分支与联合局部锚点

允许真实 API 在已有回访候选中选择：参考物理强度的±1%/±5%微调、晚期剂量分配或数据生成的联合锚点。目标是避免只做大幅机制替换而错过近目标分支附近的局部响应。联合支持由终态可追溯的杂芳 N 受体邻域与含 O 官能团邻域构建，点数受配置限制，不硬编码目标原子编号。孤立区域失败只构成联合假设动机，不能当成已证明协同。

## R32：用实测响应校准相对元素项强度

替换原本的“模块删除”占位。当前 incumbent 没有获得增量收益的复杂模块可删除；此前删除/简化会退回已测函数或只剩匹配成本变化，不能伪称有效的模块消融。

R27 的 N/C 场权重为 .5，但150个探针值的分项/总坐标梯度比例中位数仅0.01502。此前“元素项已激活”并不能排除实际贡献过小。新工具从该参考路径测量生成两个有界标量候选：目标参考比例 .25/.5，对应权重约8.3213/16.6426。上下限 [.05,32] 和目标比例均在配置中暴露。

处方是 `old_weight * target_ratio / median_observed_ratio`。这是局部一阶标定，新权重会改变总梯度和生成轨迹，实际比例必须重新测量；不能声称预先实现精确的 .25/.5。只改变相对类型系数，冻结原几何、概率导数路径、支持、时钟和总物理剂量。它会改变归一化后的方向，不是能被 RMS 约掉的共同 reward 缩放。

## R33 与冻结确认

保留一个确定性选择机会，数值重复不重算。不将单次选择对照当成完整搜索的 LLM 因果贡献证明。R34/R35 仍冻结同一尾部候选、各200个新引导终态样本并有匹配无引导对照；无 SMC，后缀无引导完成到1。
