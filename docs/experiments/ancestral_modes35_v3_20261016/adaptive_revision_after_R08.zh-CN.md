# R09 前的前瞻实现修正

此修正不重算或改写 R01–R08 的科学结果，不改变其亲和力、失败、平均值守卫或回滚记录。

1. 已观察的配对路径反馈不能支持“最近模板就是最佳路径”。新增有界的 response 路由对照：每个控制窗口在起点及中点刷新，各模式复用同一次生成 forward，分别计算坐标 VJP。分数为原始坐标叶节点上 N·RMS(gradient)/max(surrogate gap, floor)，只衡量一阶局部可控性；不解释为 affinity 或后续成功概率。相比单一势多出少量 VJP，无新增生成/affinity forward。记录所有路由响应与模式变化。
2. 原本距离兼容路由仍保留为竞争选项；Designer 绑定 Analyst 的模式集合。API 接收实际配对反馈，Skills 明确区分几何距离、局部可控性与终态收益；后续必须检查实际交付、选择和生成响应。
3. 冻结确认的候选选择明确为历史合格终态最高分分支，分别在两个未使用的新引导终态池确认。平均值守卫下的 incumbent 同时保留，确认不自动提升该分支或替换历史基线。此项在新模式实验之前固定；防止尾部候选因平均值守卫永远得不到新池验证。

单轮 n=50；最终确认每池四个批次共 n=200。所有分子完成至 t=1；仍只在配置学习域内控制坐标、允许图变化、无 SMC、无 affinity 导数。新增代码已通过有限差分与真实叶节点路由单元验证。
