# 元素控制阶段的前瞻假设与判据

此文记录可复现实验依据，不代替 Agent 调用原文、程序身份及终态反馈。

R13 相对其父版本仍是固定桥接目标，新增权重 .5 的停梯度元素空间场。三个探针显示该项非零，但在总坐标梯度中平均只占约 6.85%；零裁剪不能证明该项主导方向。R13 终态几何对应的 N 召回率约 .4867，父版本约 .4800，尚没有显著布局改善证据。总平均分上升、尾部下降，也不能归结为 N 位置已改善。

接下来按顺序区分：

1. **概率路径缺失。** 停梯度场只能依据现有类型分布移动坐标；让同一次 forward 的类型概率参与坐标 VJP，可能提供不同方向。固定支持、核宽、剂量和相对权重，只改变导数路径。看分项/总梯度比例及方向是否改变，再看实际边界/终态布局和终态分数。不得把新增概率导数叫作直接编辑类别。
2. **空间分辨率不足。** 如果宽核使不同原子的场高度重叠，即使梯度非零也可能区分不了具体 N 位置。核宽实验需与导数路径实验分开；核宽同时改变场尺度和响应形状，需记录分项梯度比例，不能只报告 raw loss。
3. **多数元素掩盖局部失败。** 使用各类精确率/召回率、类别平衡值及几何对应/跟踪槽位两种结果；不以总体匹配率代替 N 的空间布局。
4. **支持与化学角色不对应。** 后续分别测试界面邻域、芳香 N/C 邻域和含氧官能团邻域。元素 N 不是已验证的氢键受体；官能团名称与方向几何应有终态图和口袋来源。保持周围区域自由，并与同点数几何对照比较。
5. **形成与保持不同。** 控制项 VJP 非零为激活；窗口末端的实际布局为形成测量；同一支持在无引导后缀后的布局才提供保持信息。控制期间的零裁剪、恒定剂量不属于后缀保持证据。

最终分数仍是模型预测。N 布局、几何相似度、低代理损失均不能替代最终亲和力、失败覆盖与应变测量。原始 Steer 的最大值来自不同且有谱系依赖的预算；新池确认用于检验可重复性，不能把开发池最大值当作总体改进。
