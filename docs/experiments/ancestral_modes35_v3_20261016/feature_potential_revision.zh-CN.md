# 历史优势势上线前的表示与剂量校验

本修正在 R24 首次优势势试验之前提出，不改写 R01–R23 已运行的目标和结果。

1. 当前态 `x_t` 的历史矩与端点预测 `y_hat(t)` 的历史矩不是同一个随机量。当前/前瞻桥接模式使用对应实际祖先的当前态矩；端点预测模式新增同次历史 forward 保存的预测坐标矩。在线 observable、匹配参照、历史矩的表示必须相同，校验器拒绝交叉使用。
2. 两种矩都以固定终态局部坐标为核中心，避免“对自己居中所以占据恒为1”的循环定义。全窗口拟合与导数分别保存，不划时间箱。
3. 预测特征的选择位移为“按随后 proposal 选择权重对父状态的预测特征加权”；它不是 proposal 几何变化，也不包含未实际计算的原生预测位移。控制单位仍为唯一完整当前状态；克隆和不同投影不当独立终态证据。
4. 相同协方差近似的显式局部特征比值仍是探索代理。没有额外训练模型，也没有把它校准成未来成功概率。当标准化历史对比 `s=RMS((mu_focal-mu_background)/sd)` 接近零时，用 `s/sqrt(s^2+c^2)`（配置 c）在 RMS 归一化之后衰减实际剂量，避免将近零历史信号放大成固定满步长。该量是对比幅度，不是统计置信概率。
5. 首次势函数测试采用独立的几何目标包：几何对应、历史分析核宽、匹配表示的四维局部矩、标准化对比衰减。去掉其它元素/电荷项和几何到达减力，避免弱势信号连带衰减未校准的化学项。不把这个完整目标包对照解释为某一个系数的单因素因果效应。
6. 记录未截断优势值、截断饱和比例、对比衰减、原始梯度及实际位移；零响应可能来自截断平区或历史信号不足，不能一律归因于权重过小。
7. Analyst 假设组按教师区域、时钟、算子、路由和有效化学语义划分。Designer 只在同一科学语义内选数值参数，不能从“当前态”分析跳到“端点预测”程序，或从 N/C 分析切换到 N/O 通道。

新增 `forecast_evidence.py` 仅使用原压缩轨迹中已有预测；不增加任何生成/affinity 推理。原始当前态证据、预测态证据分别保存，旧目录保持原样。有限差分、零历史对比、表示不匹配拒绝、科学分组与旧函数回归均已验证。
