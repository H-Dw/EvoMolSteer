这是本研究的执行指引。调用者必须提供已实现的工具 registry、不可变证据包和输出 schema；缺少能力时返回工具需求，不虚构计算结果。本指引不自动激活奖励或生成实验。

## A1. 从终态与实际对照定义成功模式

先读冻结的终态评分、覆盖、结构代价及反例，按单个候选与可比对照提出局部差异。区分同图、相近角色、同谱系及混合总体的证据；独立 root 支持与克隆数分开。灭绝但没有终态的分支属于未知结果。

将几何/作用模式不同的成功方案保留为独立候选。不要默认最高分教师的一整条路径适合所有新 seed。优先找能解释终态成功、又确实随选择富集的局部量；原生生成变化、选择期望变化和随机复制变化分开报告。

## A2. 给每个 observable 绑定正确时刻与表示

从真实谱系抽取祖先节点，核对 forward 当前态、更新后 proposal、端点预测及复制状态。声明数据时钟、教师时刻、评估时刻、学习/控制范围和槽位映射。终态化学角色可以用来追溯位置，但不是早期已存在该角色的证据。

比较当前态对同时刻实际祖先、端点预测对同时刻教师预测，或前瞻桥接对同一前瞻时刻祖先。解释哪一部分改变了表示或时间映射。早期随机祖先的逐点相似度可能只反映初态，要检查相近初态/背景及更稳健的局部统计。

拟合整个学习窗口的变化及变化率，报告支持域、残差和分组依赖；时间导数不是空间奖励梯度。历史曲线也不是当前控制器的响应测量。

## A3. 提出可由不同 seed 自选的局部假设

为候选模式给出可计算兼容性：同刻局部形状、口袋相对位置、可靠角色、需改变的量和不可确定处。说明哪个 seed 状态更适合哪种模式，允许没有证据支持的 seed 暂时弱控制。模式先验不使用 LLM 文字置信度充当成功概率。

先检验兼容性指标能否区分已观测的终态收益。离教师更近、梯度更容易降低局部损失、最终亲和力更高是三个不同命题；不得相互替代。存在配对路径反馈时，引用实际相关性与反例，再选择静态分配、距离路由或真实坐标 VJP 的局部响应路由。后者仍是待检验的可控性代理，不能称为后续成功概率。

选择严格局部支持，包括方向/基团所必需的邻居。非连续区域可以联合，但要说明增量关系；所有正权重项/模式的直接支持并集也必须保持局部。少于全部点只是必要条件，每个点还需有机制或测量用途，不能删掉一个点就称局部。保留不受直接约束的自由度，同时承认模型 VJP 可有间接影响。

每次给出一个主假设、真实反例、预期 observable 变化和否证结果。小点云不是天然更优，必须与同大小或更简单对照区分。

## A4. 按当前研究等级读取药物化学指引

仅加载调用者明确启用的 [化学模块](references/chemistry-modules.zh-CN.md)：界面角色 → N/C 环境 → 官能团协同 → 电荷微态 → 溶剂与竞争。未开启模块不偷偷用于决策。用文献生成可检验替代解释，以本地结构、实际对照与可控性决定是否可激活；文献常见基团不是强制目标。

元素、化学角色、形式电荷、部分电荷、质子化和互变异构分别记录。对低阶段不可靠角色可以先用元素/几何软代理，不把 N 概率当作受体概率。固定坐标的合法标签换位只支持条件评分响应，不能直接变成坐标方向。

检查元素布局时同时读取每类元素的精确率、召回率和类别平衡指标；总匹配率可能只由多数元素主导。区分跟踪槽位与仅几何对应的结果。启用软元素或电荷项后，读取实际坐标导数探针，先确认该项有响应，再判断布局是否形成、是否在原生后缀保持及是否带来终态收益。

## A5. 选择下一项区分实验并交接

读取全部相关失败家族和 parent 控制响应。区分“函数方向不对”“真实剂量不足/归一化抵消”“目标无法形成”“后缀未保持”和“形成但终态无收益”。不要看到下降就一律加强权重。

梯度非零只证明控制项已激活；形成要看实际窗口末端的几何/元素布局，保持要比较同一支持的窗口末端与无引导后缀终态。零裁剪或恒定剂量不能证明后缀保持。原始分项梯度非零也不能证明归一化后的总方向明显改变，需读分项/总梯度比例与夹角。

存在多个 parent 时，先核对所选 action 的 parent_program_id，再引用该 parent 的评分和响应。当前 incumbent 的数据不能代替另一条高分或失败分支的数据。

优先选择能区分竞争解释的小实验。按 [交接契约](../../docs/plans/ancestral_modes_autoresearch_v3_20261016/contracts.zh-CN.md) 返回证据 ID、局部支持、模式/教师表示、目标时刻规则、可改 observable、化学前提、设计允许范围和否证条件。Designer 必须能从这些字段直接绑定函数，而非重新猜测分析结论。

以调用者明确的目标选择探索方向。若目标是发现极高亲和力候选，平均表现守卫与尾部探索分开：不能仅因均值较低就忽略已有近目标尾部分支，也不能把一个开发池极值当作整体改善。引用该分支自身反馈，用小幅、可区分的干预检验其可重复性。

只输出调用者 schema 允许的结构；引用必须来自实际工具结果。保留可复现的证据与选择理由，不输出内部推理记录。契约错误是接口问题，不能冒充该科学模块的性能结论。

## C1. 界面角色和互补性

输入：准备状态有来源的口袋、可解析的终态图、逐原子映射、候选/对照的局部接触。优先使用化学角色识别及几何检测工具，保留 H、方向或水缺失时的未知状态。

分析：对每个候选区域明确配体角色与口袋互补角色、距离、朝向、拥挤及反例。区分直接作用、水介导代理、疏水接触和芳香相对布局。对同一对原子的盐桥/氢键等重叠证据去重；不要奖励“接触条数越多越好”。

输出：作用站点、配体支持及必要方向邻居、相对对照的差异、替代解释、可微 observable 和未测条件。点云应保留识别该关系的必要信息，避免仅取一个靠得近的原子。PLIP/ProLIF 的离线二值检测是分析证据，不可直接当空间梯度。[PLIP](https://academic.oup.com/nar/article/43/W1/W443/2467865)、[ProLIF](https://pmc.ncbi.nlm.nih.gov/articles/PMC8466659/)。

模块验收：新输出应影响站点/角色/方向与支持的至少一项可操作字段；如果只追加文字，不宣称已实现药化区域选择。
