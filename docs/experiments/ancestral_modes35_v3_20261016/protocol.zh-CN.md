# v3 的 35 轮执行协议

用户于 2026-10-16 授权基于 v3 方案重新探索，最多 35 轮。本 campaign 与已完成的 v2 独立编号；最多 33 个开发条件及最后两个冻结确认条件。API/接口修复、重复数值程序、参考复现与小后缀诊断不冒充新优化轮，计算成本另列。

研究父程序为上一 campaign 的 R15_v2（复用其 n=50 的 R19 结果）；它是研究候选，并未通过独立新引导终态池确认。保留历史活动基线不变，原 Steer 最优参照为 8.70480632782，冻结尾部阈值为 8.13504886627。全部分数是模型预测。

## 已实现与边界

新增 `ancestral_modes` 包，独立实现多时刻真实祖先、同刻教师端点预测、前瞻桥接、归一化后时间剂量、每 seed 一个主模式/兼容路由/记忆、局部软元素/分电荷场、显式低维历史优势势。生成 head 可参与坐标 VJP；不对 affinity 求导、不增加每步 affinity 调用、不做 SMC、不限制化学图相同。

11 个终态模式来自 7 个已核验 root；它们不是 11 个独立路径实验。旧 20/25 点仅用于父版本/时刻策略的可比性，新化学支持至多 8 点且需要具体邻域依据。软多模式同时激活会带来支持并集问题，因此本轮采用每 seed 单一主模式；没有声称已实现软势混合或直接类别编辑。

窗口从配置读取，当前学习域为 [0,.5]，引导子窗口由条件选择，控制结束后原生完成到 1。原始当前态、proposal 和端点预测严格区分；历史概率保留 fp16 量化来源。终态化学角色不是早期真实角色。低维优势函数是描述性代理，未校准成未来成功概率。

## 顺序模块

01–04：同刻当前态、同刻端点预测、固定小前瞻、衰减前瞻。

05–08：参考预算校准的时间调度、达到后减力、起始时刻、总实际剂量。校准匹配的是固定参考的预测流权重，真实轨迹上的实际预算仍须报告，不能称已严格相等。

09–12：同点数的多成功模式静态分配、状态兼容路由、持久路由、记忆时长。

13–15：停梯度的元素空间场、类型概率/坐标联合 VJP、空间核宽。

16–23：界面局部支持、N/C 局部支持、官能团邻域、同大小几何对照、方向、口袋距离、内部关系、分电荷场。逐项启用药化文档，不自动全开；角色识别仅在可靠终态图/报告上进行。

24–30：成功/背景特征势、方差下限、优势势时刻、N/C 或 N/O 软通道、历史预测与终态身份参照、几何曲率、脱离梯度的匹配成本。

31–33：在已知失败与当前背景下回访、单模块删除、一个确定性选择机会。第 33 条并不是完整等预算搜索的 Agent 因果贡献试验，不能据此宣称 LLM 优于确定性搜索。

34–35：冻结同一程序，分别在 4 个新的引导终态 batch 上测试，每批 50，共每池 200 个。它们的历史 Steer 仍在教师先验内，所以不是靶点或初态先验留出。

若某模块在合法 parent 上没有新可执行 action，登记能力/条件缺口，并使用未测试的单因素简化回访；不能伪造该模块已测试。最后两次确认不占用作额外调参。

## API 与功能验收

真实 DeepSeek flash、temperature=0、thinking disabled。两轮有限工具查询，Analyst 选择局部支持/模式假设，Designer 在该假设组内选数值变体，确定性编译。这是注册算子内的设计，不是任意代码合成。

第一版功能测试虽送达了 C1，但完整/删除仍产生相同函数，并出现实际祖先与教师端点混称。原始调用完整保存。第二版加入精确时钟契约、所选区域自身的化学引用、来源一致性审阅及有界纠正。C1 完整/删除若仍产生相同函数，如实记为该案例没有数值增量，不人为迫使它改变点云以制造 Skills 效果。所有指引的最终贡献仍需真实生成比较。

## 对照、晋升与回滚

seed=42；同一实验使用同批次、样本数、实际初态、checkpoint、原生噪声/修正协议。旧结果只在元数据完整时作配对对照；缺少匹配控制只补对应无引导，不重跑完整旧 M2/Steer。

每个不同开发程序 50 次从头生成。冻结高分尾部效用 Uτ 为主要开发量，均值下降不超过 .03 才晋升；效用改进阈值 .0005。最高亲和力候选另行保留并允许作为诊断 parent，避免均值门槛掩盖尾部发现。连续两次尾部或均值下降回到当前研究最优的数值程序；保留正确性修复与全部失败证据。

所有新程序先本地 commit/push，远端拉取指定 commit 再推理。每次下载并核对 SHA 后清理本 campaign 的远端结构/分类快照和 extracted runtime，保留报告；原始 Steer 和模型不删。共享源码已有未跟踪历史目录不参与提交。

应变采用与上一轮相同的两阶段 MMFF 代理；PoseBusters 作为终态后验诊断，不设置化学图身份 gate。未测、失败、无法评分单列；相似度或类型形成不替代最终亲和力。原 Steer 的 1000 次有克隆依赖且预算不同，不把其最大值比较当显著性检验。
