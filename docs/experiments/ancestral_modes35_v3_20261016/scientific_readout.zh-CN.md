# 祖先模式 v3：35 条顺序条件的科学解读

本报告的最终数值由 [机器可读汇总](summary/summary.json)、[比较表](summary/comparison.csv) 和 [逐轮表](summary/rounds.csv) 支持。33 条开发条件共享同一初态池，R34/R35 为冻结确认，各 200 个引导分子及 200 个匹配无引导分子。确认结束前不修改奖励或依据新结果重新选择候选。

## 0. 最终结论

**35 个条件已全部完成，但没有实现接近历史极值的稳定发现，更没有超过原始 Steer。** 开发最优 R02=8.699415，比历史最优 8.704806 低 .005391；冻结后 400 个新引导终态最高只有 8.368182，匹配无引导最高为 8.346392。不得用开发池的一次近目标极值替代确认结果。

## 1. 本轮实际探索了什么

研究目标是发现最终预测 pIC50 接近或超过历史 Steer 的 8.704806 的候选，并维持可接受的结构与局部松弛代价。本轮不是对 35 组参数做完全因子设计，也不是 35 次独立重复。它是具有路径依赖的顺序研究：每次读取已有结果，改变一个主要机制或明确登记的一组相关数学设置；连续两次触发下降条件时恢复守卫 incumbent，保留修复后的接口与测量代码。

守卫 incumbent 与极值探索分支分开管理。前者仍是继承的 R15 兼容实现；后者 R02_v3 在开发池得到 8.699415。按 R09 前已登记的目标发现准则，R34/R35 冻结 R02 而非事后在确认池中选赢家。R02 的开发极值与 Steer 最优只差 0.005391，但本身不证明稳定提升。

## 2. 哪些 v3 假设获得支持，哪些没有

**时刻与表示匹配值得保留，但“越早的祖先越适合早期 seed”未得到本轮结果支持。** R02 比同刻真实坐标与前瞻桥接的开发尾部好；这是新 seed 端点预测和教师当次端点预测之间的控制。它没有强迫早期高噪声当前态复刻某个实际祖先。七点支持从固定桥接改为端点匹配也出现类似方向的改善，但样本与干预有限，不能归结为普遍定律。

**路由已经生效，路由指标缺乏未来价值标定。** 三种 seed 自适配策略均有真实分配与切换记录，却不如强单教师尾部。R02 初始误差与相对继承 R15 的分数变化之 Spearman 相关约 −0.125，最高分 seed 反而初始离目标最远；这里的比较对象不是无引导。用距离、局部损失可控性来分配模式，可能把可从强模式获益的 seed 过早送走。多模式有可用实现，不等于已经找到有效的多模式选择器。

**N/C 场不是完全没有梯度，但“更大梯度”未转化为正确布局。** R32 将元素分项真实贡献显著放大；最终几何对应 N 召回约 .4667，对比 R27 的 .4733；跟踪槽位 N 召回也未改善。由此不能继续只按“权重不足”解释失败。概率边际场、跨 seed 对应、角色近似、归一化以及生成器坐标可控性共同决定真实方向。固定坐标标签换位的 head 响应，不证明存在容易实现的坐标梯度路径。

**更小区域提供自由，但可能丢掉必要的协同约束。** 三/四点单区域普遍没有保住尾部。联合七点、端点一致匹配恢复到 8.5784，是值得保留的研究支线；尚不能据此声称七点优于 20 点。R02 仍为 20/25 点、覆盖较广的严格子集，不应包装成已证明的精细药化 motif。

**历史富集信号和未来成功价值仍有距离。** 当前显式优势势只使用四维局部矩：固定终态局部参考系中的高斯占据与有符号 x/y/z 一阶矩，全窗口拟合与导数另存。早期实现的自中心占据恒为 1 已修正并留档。端点损失读取端点预测统计，当前态损失读取当前态统计，禁止混用。现有背景是同批完整状态去重后的同时刻背景；它不等同于实际终态失败集。单成功路径对混合背景的低维势未学到可稳定提高极值的未来机会函数。

## 3. 冻结 R02 的实际奖励和剂量

在学习窗口 W=[a,b] 内读教师同一次 forward 的端点预测 `ŷ_teacher,1(t)`，新 seed 使用真实 FLOWR 输出 `yθ(x_t,t,pocket)`。本轮 `W=[0,.5]`、控制窗 `[.1,.5]`、100 步；这些来自配置。教师参照随 t 变化，**不是固定 t=.5 的点云，也不是实际终态结构**。

对教师局部 20 点 I，在每个 forward 以空间成本与元素相容成本求停止梯度的 Hungarian 对应 π：

\[
C_{ij}=\|y_{\theta,i}-\hat y_{teacher,j}(t)\|^2-0.5\log P_\theta(e_j^{terminal}\mid i).
\]

终态身份只参与对应，不表示早期已有该角色；没有图身份 gate。当前选出的对应分支上，奖励为

\[
R=-\frac1{|I|}\sum_{j\in I}\delta^2
\left(\sqrt{1+\|y_{\theta,\pi(j)}-\hat y_{teacher,j}(t)\|^2/\delta^2}-1\right),\quad \delta=1\,\AA.
\]

R02 没有非零元素/电荷空间场，没有 affinity 导数。通过同次生成 forward 的真实端点坐标 VJP 得到 `g=∂R/∂x_t`，不对未来随机后缀求导，也不对 Hungarian 离散切换求导。控制方向按每 seed 梯度 RMS 归一化；请求位移为

\[
\Delta x_{guide}=0.66\;\operatorname{RMS}(\Delta x_{native,pred})
\frac{g}{\operatorname{RMS}(g)+\epsilon}.
\]

随后应用每原子 .15 Å 步上限与各步 RMS 之和 6 Å 的累计上限，并记录请求/实际剂量和裁剪。没有共同乘奖励系数来冒充实际剂量调整。直接损失支持是 20 个匹配点；通过真实生成器 VJP，未匹配输入坐标也可能受到间接影响。本轮新增了该影响比例测量，不能把它称作模型注意力或作用因果归因。

最后一次控制发生于 t=.49→.50，后续到 t=1 全为原生生成。原生 SDE 的 score drift 与任务奖励引导不同；“后缀无 guidance”不意味着关掉原生随机流。原始 Steer 的驱动代码实际也把 SDE/noise 覆盖为相同值，已保存源代码和哈希。

## 4. Agent、Tools 与确定性执行链

Analyst 读取：真实谱系祖先库、去克隆同时刻背景、全窗口有符号局部矩/二次趋势及变化率、期望选择与实际复制的分解、终态评分/失败、候选化学角色/口袋位点、历轮真实响应、分类别布局与原生后缀保持。代码工具负责计算，LLM 不凭坐标文字猜 pIC50 或把灭绝标签当失败。

Designer 读取 Analyst 所选的局部支持、模式、表示、parent 与可检验假设，只能选择已实现且通过校验的算子。它不能脱离 Analyst 改教师/点集。真实接口为 `deepseek-flash`，temperature=0；不是 subagent 模拟。R33 是明确登记的确定性选择条件；R34/R35 冻结程序，不重新调用角色设计。

本轮发现自由文字会错误描述当前生效公式、parent 剂量，且追加一次 LLM 复核也未可靠发现。后续修复是：API 只返回六个字段（选项、交接组、parent、证据、简洁依据、否证条件）；确定性编译器验证身份和来源后生成有效公式、导数路径与参数差异。生效数值视图剔除无效继承参数。原始 API 回答和编译输出分开保存。真实 API 最小契约验证无格式修复；prompt 从旧验证约 11.1 万 token 降至约 4.06 万，且旧长输出失败留档。R02 的早期回答仍为旧接口，保留原件，不能倒称它由后续最小接口产生；冻结确认复用其已经选定的数值程序，不重新调用 Designer。

这些修复证明指令确实交付、函数确实改变、实际梯度确实注入。它们**不证明 LLM 的每条科学解释都正确，也不证明 LLM 搜索优于等预算确定性策略**。化学模块单次 on/off 验证输出仍数值相同，如实登记无可测新增作用，没有伪装成生成质量改善。

## 5. 统计、结构与比较边界

平均 pIC50 覆盖所有生成尝试中可评分记录；即使没有合法最终化学图，仍保留其 head 分数并单独报告失败。高尾部效用只让基本合格分子贡献：`Uτ=mean[1_qualified·max(pIC50−τ,0)]`，τ 是原 Steer 基本合格终态的冻结 q90=8.1350488663。基本合格是可构建、连通、最小受体距离≥.8 Å，不冒充完整 PoseBusters 合格。

确认 bootstrap 以 B50 初态批次为单位，两个池各四批、合并八批；seed 固定 42。它检验已知历史教师条件下的新引导终态，不是新靶点、未知教师或多随机种子的泛化验证。开发池反复调参极值、Steer 的 1000 个有谱系依赖样本以及确认池最大值都是不同预算下的描述性结果。

所有新结果和原 Steer 都用当前 PoseBusters 0.6.5 dock 与同一受体复评。原 Steer 945/1000 全通过，9 个计算未解决；原最优 F 当前检查通过。旧 PB 是 887/1000 通过，版本/选择项差异不能作为新方法优势。未解决不算通过。

能量统一为两阶段 MMFF94s：先固定重原子松弛氢，再全自由松弛，报告后一阶段能量下降/重原子。它是局部构象松弛代理，**不是结合能、绝对自由能或实验稳定性**。原 Steer 中位数 .5303，最高分 F 为 5.8923；R02 开发最高分分子为 .9597。旧初始氢放置造成的巨大能量下降不用于直接比较。确认总体的覆盖、中位数、p90 和收敛率见比较表。

## 6. 保留与后续研究建议

保存冻结 R02 尾部分支与继承守卫分支，是否采用必须服从确认结果；没有达到预定标准时不替换历史基线。本轮代码支持真正的阶段参照、动态剂量、局部多模式路由与离散感知，但可执行能力不等于已找到有效组合。

若进一步研究，优先用少量真实完整续生成，建立多个成功/实际失败祖先的条件对照，为模式路由校准未来价值；再测试价值与局部可控性的组合，而不是继续把最近教师或局部 loss 降得最快当作成功概率。药化方向应从已形成且后缀保持的区域出发，设计有符号、局部、类型相容的 observable，避免仅加强未形成的 N 场。先在匹配剂量/点数下隔离端点表示效应，再对强分支作小幅物理剂量探索。

本轮提供过但未被 Agent 选中的 target-mass 通道平衡、小幅 rho/晚期剂量选项不能算作实测失败。反过来，接口交付验证也不能用来证明这些科学方向成功。不要把新的研究建议混入已完成结果。
