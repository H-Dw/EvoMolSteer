# 终末后代信用：方案审阅

**值得补充这一离线监督角度，但应先做谱系、覆盖和标签审计，再决定是否构造新奖励。** 这是 Analyst/Designer subagent simulation 的只读提案；没有实现新奖励、运行模型或改变既有实验。特征仍只来自0…0.49预测endpoint三维坐标，监督标签则明确来自未来t=.99既有head。它是新的回顾性任务，不能沿用“所有信息均在控制窗口内”的描述。

R6、R9、R11在t=.49的两批平均记录head增益分别约+.11199、+.07060、+.07814，而最终decoded-rescore增益为−.00634、−.04143、−.03905；每步实际注入均约.0133Å。R7完整点云最终+.22929，说明即时目标并非一概无效；R12更高剂量最终+.13900，也不能把问题只归因于剂量不足。这些是开发数据，两种评分语义又不同，因此只能提出“目标时距不匹配”的假说，不能把差值当作已识别的因果遗忘量。

## 实际谱系核查

已直接读取本地原始single发现集0–13，14个HDF5的SHA全部匹配。每批100步、50个槽位，实际共有**51次重采样，score0…0.50**；最后一次对应state≈0.51。51…99步索引均为identity，step99记录head的时间为.99，最后原生状态时间为1。

终末回溯和严格state≤.5边界存活并不相同：在35000个批次/节点/候选标志中共有377处不同，各批6–65处。终末标签必须跨过真实的.50选择边，但不要提取该节点或.51/终态的坐标作为窗口内预测特征。

存活祖先数量限制很强：

| 特征时间 | 每批最少/中位/最多存活祖先 |
| --- | --- |
| 0 | 1 / 1 / 2 |
| .10 | 1 / 1 / 3 |
| .25 | 1 / 3 / 4 |
| .49 | 20 / 23 / 25 |

700个批次节点中349处少于3个、531处少于6个存活祖先；11/14批最终仅剩一个初始根。这里的“祖先”是不同当前候选节点，不等于独立根或独立分子模式。50个终末槽位不能当作50个独立重复。

## 正确映射与两个目标

第j步selected_indices[j,k]指向该步重采样前候选，形成下一步的第k个current槽位。对于head99[l]，令A[99,l]=l，然后按j=98…0递推：

A[j,l]=selected_indices[j,A[j+1,l]]。

不要把第99步已有head先套selected_indices[99]；该head在这次选择之前记录。本数据最后索引恰为identity，但实现合同仍要正确。若改用真正final-output标签，必须重新核对final槽位映射。

N[j,i]为祖先i的终末后代数；S=1(N>0)只表示其有可观测后代。C[j,i]为这些后代head99的均值；N=0时C=NA。核查计数和评分总和逐层守恒，本次14批全部通过。

应分开：

- **存活富集**：每节点存活祖先的200局部矩均值，减去灭绝节点均值；两个组内每个节点计一次，再按14批等权。它描述选择/存活关联。
- **存活条件下的后代信用**：仅在S=1中研究C及其与当前score、三维特征的关系。灭绝不等于坏亲和力，不能填低分、0或假想终点。

早期只有一个存活祖先时，存活对照均值可描述，但无法做有意义的组内credit排序或高低分层。高低组须各有至少3个真实唯一祖先且不因分位数并列重叠；不足则缺失。不能把晚期可用部分积分后称为完整窗口，也不能用重复祖先补齐教师数。

## 最小分析与存储

沿用预声明20区域×10字段、同一受体框架、Gaussian半径与已冻结尺度，先保留原始单位均值、存活对照、全50节点曲线、时间变化率及counts。整体均值和首尾变化率若各检验200项，应预声明联合400项BH；增加credit/边/全曲线检验时显式扩展或标明新检验族，不与旧600项q直接比较。批次bootstrap保留完整曲线；时间点、候选及后代数量都不是额外独立重复。

每节点记录唯一存活/灭绝数、根数、后代数分布、credit均值/方差、有效标签比例和同刻score关系。按当前父节点或根等权只做单独敏感性对照，不假称能够消除全部谱系偏差。保存700行批次统计、700行counts、全窗汇总与函数，以及必要的小型教师元数据；不新增逐候选×200缓存或重复结构库。

## 后续完整点云prior的合理边界

可以从每批每节点的唯一存活祖先中按C排序，选空间不同的**真实完整endpoint点云**，不平均成一个点云。空间差异采用固定受体框架Hungarian距离；稳定排序和每批上限须预声明。若只剩一个祖先，只存一次，并标明没有组内高低比较。保留父节点身份以检查跨节点教师切换，逐时最优不自动组成一条最优路径。

教师基础质量按批次等权，再按该批选中的祖先等权，不按N赋权。但C内部仍是实际终末叶子平均，仍受后续克隆分配影响；“祖先等权”不等于“完全无克隆影响”。若改成逐层分支等权信用，那是另一个估计对象，应单独报告。几何近邻截断和score先验还会再次改变有效批次权重，须在公式中明示。

可复用现有固定anchor/对应的点云混合奖励，只把离线教师及信用先验换成这一回顾性目标。它是高回报轨迹的经验模仿，不是拟合出的因果value function，也不是预期终态亲和力梯度。保持坐标表示、剂量、caps和控制窗口相同，才便于比较目标时距；若同时改变存活资格、教师数量、空间多样性和先验权重，就应称复合目标构造实验。此审阅不冻结新的η/β，也不启动实验。

## 最关键的限制与可证伪条件

第99步head来自t=.99的原生联合forward，不是最终corrector输出，也不是硬解码终态在.9999做的rescore。本次紧凑原始目录没有final_records，未计算二者的一对一相关桥梁。能提高head99仍不保证达到最终rescore目标，更不保证实测结合亲和力、有效化学图或低应变。

灭绝后的反事实结果缺失且由选择过程决定；少数存活根、高分条件选择、未来化学图变化和回报噪声仍会混杂坐标关联。原始.51之后没有再筛选，因此“终末存活”本身并不比post-.51群体提供更多存活信息；额外价值主要在后续head信用，而非重新命名同一存活标记。

若映射或守恒失败、credit无可分辨变化、效果仅来自当前score、根等权敏感性后消失，或教师去重后缺乏覆盖，应推迟机制/方向规则。未来若只改善head99而最终decoded-rescore不改善，应判定主要亲和力目标未达成，而不是事后换指标。该分支尚无新reward实现、GPU FD、零剂量证书或有效性结果。
