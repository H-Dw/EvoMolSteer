## 奖励与实施

新库每批 cap2，与 canonical R7 一致；节点总教师数17→28，原R7恒为28。按后代平均信用选完整祖先点云，固定受体框架 Hungarian RMS≤.001 Å只去近复制，不证明独立构象盆地。基础 log 权重为−log(每批教师数)，故基础质量先等批次、再等祖先；nearest-K与离线分数随后改变条件质量。

保持 R7 的 K4、β2、教师温度4 Å²、τ=.5、δ=1 Å、η=.3、ramp0。令 q 为匹配坐标的每原子均方距离，ρ=δ²(√(1+q/δ²)−1)，奖励 R=τ logsumexp(logπ−ρ/τ)。R≤0但无有限下界。对预测坐标求导，经真实 FLOWR 坐标 VJP 回到旧 x_t；固定 self-conditioning、anchor、匹配与 prior。注入发生在原生更新后，日志响应是旧状态的一阶估计。

生产仅使用已有一次原生 forward，亲和力输出 detach 并设拒绝梯度 hook；无额外生产 head/model 调用、SMC、图/类型 gate。完整支持窗口后继续 native 到1。继承的即时 high/low 与 `teacher_library` 元数据不是新终端证据；运行时已限制该参考仅能用于 endpoint_pointcloud。

这仍是**目标库整体修订**：存活资格、教师身份/信用、早期基数、基础权重与去近复制规则共同变化，不能把结果单独归因为信用。R19 β0只移除条件 logit 信用项，老师仍按信用选入。完整点云目标也不等于能量最小化或连续唯一祖先路径。
