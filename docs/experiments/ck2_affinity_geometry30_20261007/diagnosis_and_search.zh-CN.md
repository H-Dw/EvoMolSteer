# 引导差异诊断与新30轮检验逻辑

本文件依据已保留实验和代码说明可复核的判断，不记录私人思维链，也不把注册搜索冒充每轮独立的LLM设计。最终结果以summary.md与final_report为准。

平均预测亲和力接近无引导，不能单凭均值判定梯度没有作用。先核对真实FLOWR坐标VJP有限差分、50个窗口内的非零实际位移、限幅和拒绝比例，再查看配对分子预测值的平均绝对变化。若个体变化较大但均值很小，正负抵消是直接可见的现象；其根源还需要目标消融检验。真实生成模型的Jacobian指FLOWR endpoint(x_t)对当前坐标的导数，不是独立近似模型，也不是亲和力head梯度。

当前控制器归一化每个粒子的梯度方向。给全部奖励乘正数会在归一化中抵消；真正决定物理强度的是native_rms_ratio、逐时剂量、原生位移标尺及实际限幅。应记录实际Å位移而非仅报告奖励权重。R7平均每步约0.0134 Å、累计路径长度约0.670 Å，全部50步生效，窗口外没有注入。累计路径长度不等于最终净位移。

坐标挖掘只以真实学习窗口为几何支持，先按实际节点统计，再对整个窗口做富集积分、变化率和差异分析。批次作为统计单位，父节点内平均降低复制权重；不能把时间行/克隆数当独立样本。高分区域的时间变化率不能直接作为空间梯度。三维点云及受体框架中的位置保留坐标间联合关系；少数独立矩、距离或局部均值可能丢失兼容的共同构象。

当前发现集结果支持继续检验完整坐标目标：R7 meanΔ=+0.229293，区域加权R13=+0.212839；压缩吸引目标R9=-0.041429、加历史增量R11=-0.039052。R10剂量0.51改善+0.206789、R12剂量0.867改善+0.139001，所以不能把更强注入视为单调提升。上述是相同发现批次上的自适应比较，不能解释成因果优势或泛化证明。结构压缩的信息审计也没有证明完整点云与亲和力的相关性更高。

终端谱系修订以存活祖先完整预测点云和已记录后代评分构造目标，灭绝未来标签为空；未来标签可用于离线信用，窗口外几何不进入奖励。早期祖先严重稀疏，200字段×2指标联合BH的400项均无q<.05，因此不声称发现显著终端优势区域。新库最多每批2个教师，与R7一致；基础先等批次、再等祖先。条件nearest-K和分数加权会改变条件质量。该修订同时改变资格、教师身份和基础权重，单次比较不能归因于单一信用机制。

实际Skill响应由已授权subagent模拟接口生成并原样保存，检查不是仅检查关键词：响应必须保留当前R7赢家、对负效应修订坐标目标、区分灭绝缺失/低分、拒绝把根坍缩填成完整高低组、报告400项无显著证据、保留native/zero/gradient与真实GPU审计要求；9类哈希正确但行为错误的反例会被拒绝。新时钟修复没有更改这些指令、公式或数据。独立复核核对当前源码哈希后才启动远端。

26轮发现搜索完成后冻结有效程序和参考库，27–30用新配对批次验证，不以验证结果重新调参。主指标为全部尝试的预测亲和力均值，另报有效分子、去重、最高和Top5。应变只在清晰亲和力增益后作为次级指标，保留未收敛和失败分母；孤立配体MMFF松弛不是结合自由能。历史Steer100是未配对且预算不同的参照，其均值7.510351与有效最高8.347940分别比较，不能宣称是完整原始实验的全局最大值。

生产每步仅使用原生一次FLOWR forward，亲和力分支detach并有拒绝梯度hook；有限差分额外调用仅为一次性审计，单独计数。无SMC、无分支复制、无化学图/类型接受gate；控制结束后继续原生推理到1。程序、假设摘要、literal Agent响应、逐轮commit和精简评分/失败报告均保留，生成轨迹在验证归档报告后按轮删除；原始Steer及checkpoints受保护。
