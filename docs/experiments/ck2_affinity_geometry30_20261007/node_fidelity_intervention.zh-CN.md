# 第6轮之前的节点忠实性修正

## 已观察到的控制与终态响应

第5轮均值为7.494027，对配对无引导7.434275增加0.059752 pIC50，有效率均为98%。孤立配体MMFF松弛能/重原子中位数0.532696，比原生0.548773降低2.93%；周围区域松弛位移均值0.285068 Å，比原生0.327214 Å降低12.88%。这些是开发集的预测及代理物理指标，不是实验结合亲和力。

完整100步零权重与无引导的已导出科学状态逐字节一致。真实FLOWR端点坐标VJP的两项有限差分相对误差为1.854%和0.788%；仅一次审计额外4次联合模型前向，生产每步额外目标前向为0，affinity输出与奖励梯度分离。两个生成批次均有50个有效注入步骤，平均注入0.01332 Å，累计路径约0.66583 Å。引导已经改变轨迹；均值变化不能用于判定它完全未生效。个体正负抵消、代理与目标错配及批次异质性必须分别检查。

## 原拟合为什么不能直接进入奖励

稀疏先验保留74项坐标证据，以14个独立原Steer批次为统计单位，根据整窗q值、效应及方向一致性选出24项：2项形状、5项成对距离核和17项受体区域特征。整窗显著不代表每个节点同方向。

旧低阶Legendre曲线全部未通过新增节点忠实性标准。例如最后评分节点0.49，pair_kernel_2.5的经验标准化效应+0.04258，拟合为−0.46881；shape_yy经验+0.16330，拟合为−0.51282。原Agent曾准确复制旧曲线，但准确复制不能弥补输入拟合偏差。旧响应及旧Skill保留作为失败记录。

新版prior同时保留原拟合与实际50节点均值，并记录相对节点RMSE、强符号冲突和弱效应节点的拟合过度放大。当前24项均禁止以Legendre曲线执行。阈值是本地设计约束，不是阶段因果或统计置信证明。

## 实际Agent响应与可执行公式

独立Agent读取新版Skill、原样输入与prompt、完整先验及前5轮报告，真实选择全样本亲和力最优第3轮作为保留父程序，提交linear_node_effect及24×50个原始节点值。函数、74维binary weights、参考哈希、生产成本和动态窗口通过审计；这验证指令改变了本次输出行为，不证明LLM优于其他设计者。

令Phi_j(Y)为端点世界坐标的几何特征，s_j为固定尺度，e_j(t)为真实批次平均高低层效应的分段线性插值，v_j(t)为阶段平均标准化方差。奖励为

R_t(Y) = sum_j w_j * clip(e_j(t)/v_j(t), −3, 3) * Phi_j(Y)/s_j。

w_j在入选字段内按形状/距离/区域块重新归一化，块权重[0,1,2,1]。空间梯度为真实FLOWR端点Jacobian转置乘grad_Y R，不将时间变化率当作空间力。节点插值是明确的时间函数，没有额外亲和力网络。首比较eta=0.3与第5轮匹配；移除字段后的全局奖励倍率不能代替控制剂量。

支持由参考库动态给定，当前0–0.5；50个评分节点0–0.49对应更新至0.50。随后原生推理至1。新程序仍须自身真实模型差分与完整零权重核验，旧程序验证不能替代它。
