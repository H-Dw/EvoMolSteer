# 连续回溯执行

`scripts/resume_coordinate_campaign.py`在本地运行，接管已经启动的第14轮，随后逐轮执行到原有30轮上限。密码来自进程环境或隐藏输入，不写文件。输入为已有campaign配置、原始轨迹数据集、逐轮报告、冻结的奖励程序和参考分布；输出为各轮精简报告、决策、源码commit及清理审计。

每一轮严格串行：等待远端退出码与完整归档，下载并验证；本地评估actual中间态、终态品质、能量代理、预测head、多样性和梯度/执行契约；保存报告；清理本地旧原始数据；从一个已完成父配置恢复，只改变一个已允许参数；保存前轮退化项与下一假说，commit并通过本机VPN push；远端pull同一commit，并由既有runner清理旧数据后启动推理。表示架构没有新增重采样。引导覆盖学习窗口，剩余推理继续至1。

R15–R30是预声明的灵敏度探索，包括模式温度、摆脱首步cap饱和的低剂量、全程原子cap、方向性/条件形状的剂量与温度、预测流剂量、稳健曲率以及区域/全局展开度对照。R24只在前轮同时守住head和两种物理代理时加大剂量，否则恢复父配置降低剂量；R27/R30选择规则显式且记录开发集选择偏倚。任何部分退化均记为回溯触发，不作为自动停止条件。这些试验不会新增因果机制证据，也不是独立验证。

进度保存在`test/coordinate_campaign_driver/status.json`及`events.jsonl`，每个本地子步骤的日志独立存储。执行、网络、有限梯度或数据保护契约失败时明确记录execution_error并退出，不会谎报完成。当前脚本仅自动接管running状态，技术失败后需要检查状态与部分文件后恢复，不会盲目覆盖已有输出。

完成第30轮后还会清理最后一轮的原始结构/轨迹/下载包，原始Steer和模型保持受保护；源码、奖励配置、参考统计、失败包容报告与审计保留在Git。整个执行器在本地，远端只生成、解码和导出，不做奖励挖掘或科学评估。VPN、SSH与本地进程需要保持可用。
