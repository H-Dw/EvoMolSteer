# 回归诊断与继续探索的依据

第五轮结束不是30轮预算耗尽，也不应由部分指标变差触发。原停止决定已撤销；旧源码提交和配置保持可追溯，按已验证父配置恢复后继续试验。

## 可复核的发现

- 第六轮恢复第三轮，主要指标在1e-7内重现，排除了结果无法复现这一问题。
- 第八轮将eta减半，但首步实际RMS仅由约0.00505降到0.00482 Å，原子cap使名义权重与实际剂量脱钩。第十二轮单独将首步cap减半，RMS约0.00253 Å；后续控制参数相同，实际状态和剂量仍会随路径改变。
- 第十二轮首步逐粒子平方注入份额由约40%降到约14%，仍出现约13.8%的周围松弛退化。“首步过强”不足以解释全部问题。
- 第十轮去除刚体方向保留了首步约95%的梯度平方范数。形状改善2.74%，周围松弛退化15.34%；该投影未提供预期兼容性收益。
- 第十一轮经验密度对照约92.7%的粒子步骤没有背景支持，平均路径仅0.00012655 Å。完整零剂量对照一致，但这个剂量和支持范围未改善目标，不能据此否定全部密度比奖励。
- R3与R12配对中，82个双有效同图候选的平均head变化+0.00323，17个变图候选为-0.15057；剩余1个不满足双有效。此分组由终态决定，不能因果归因。变图候选的周围RMS变化还存在批次方向相反。

## 尚未得到证明的假说

坐标扰动可以通过后续原生预测与类别采样改变图；奖励几何统计的拟合和最终能量/兼容性存在目标错位。当前中心和展开度缺少方向信息；新的二阶矩奖励检验此表征问题。全局组成混合也可能让区域几何目标不适合当前类别，但相同N/O/S计数不代表相同键图，需要先做支持与条件矩稳定性诊断。

## 当前措施

R13恢复R5的VAL116/NOS与predictive_flow剂量，只测试方向性六分量表征并披露单槽位支持条件变化。数学统计与LLM证据使用全部真实选择节点；实际注入覆盖动态学习窗口内50个积分更新，随后继续原生推理至1。新增全局N/O/S计数挖掘只存批次统计、全窗口效应、函数与变化率；不用重复区域掩码制造多个机制。

部分回归触发保存报告、诊断、恢复父配置和新试验。每轮仍执行旧生成数据清理；原始Steer和模型输入不变。真实收益必须同时查看实际中间态、失败包容的终态品质和批次方向，不能只优化奖励残差。当前只有两个反复使用的开发批次，不提供独立验证或因果机制证明。
