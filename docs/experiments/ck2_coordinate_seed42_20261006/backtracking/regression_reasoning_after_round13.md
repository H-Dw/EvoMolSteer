# R13 回归后的条件几何假说

R13 实际完成100个积分更新，学习窗口0–0.5内50次控制，之后原生推理至1。新架构的全程零剂量与原生对照一致，真实状态上的条件坐标有限差分通过。原始Steer没有改动。

R13将VAL116/NOS中心和展开度换成六个方向性中央二阶矩。实际中间态对称形状距离变差0.22675%；全部尝试的预测亲和力头均值增加0.02743；MMFF每重原子松弛能量中位数变差4.0267%，周围原子松弛RMS变差4.0552%。因此没有同时达成几何拟合和终态兼容性目标。该结果不能解释为方向性几何无效，也不能只凭head上升认定有效。

下一假说是相同时间下混合不同预测原子组成的目标，会要求当前分子贴近不适合自己的几何。新增组成挖掘只提取一次全局N/O/S计数，以原始发现集0–13的所有真实选择节点计算全窗口统计。O计数与下一步head增益的条件相关为负，但只有13个可用批次、约78.49%时间覆盖；平均选择位移不显著。这是条件建模的线索，不能转化成“减氧”的编辑指令。

候选R14使用同一批次、同一真实节点、相同端点N/O/S计数下的经验几何矩。保留固定全窗口尺度；按每批条件计数的选择质量分配混合先验。均值来自实际中央矩的凸组合，避免线性外推产生非正半定的形状目标。条件分组重新聚合到父参考的原始均值和协方差，最大差约6.7e-16。

选择>=3记录/批次、>=2发现批次/节点，混合先验ESS>=1.5、最大留一批次中心偏移<=1个缩放RMS。覆盖51评分节点的梯形平均为82.25%；实际50更新的均值为82.52%，最低节点49.14%，最后更新54.71%。不支持的组成给零剂量、继续原生生成。这个回退会改变末段剂量分布，须与目标分层及先验变化一起披露，不能称为单纯更换一个目标。

256个保留时间/组成组合中232个至少含一个单根组件。重复后代不是独立样本；同一计数也不确定键图或电荷。留一中心检查不能证明协方差或梯度稳定。R14只是一轮明确的条件表示实验，保持R13全部剂量参数，并要求新的完整零剂量一致性和真实状态梯度检查。继续用独立于奖励的中间态几何、失败包容的终态结构/能量/head/多样性指标判断，再决定回到哪个已保存父配置。
