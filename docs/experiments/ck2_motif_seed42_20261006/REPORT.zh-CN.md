# Steer空间先验与gradient guidance：15轮最终报告

**15/15轮完成，共2000个生成尝试。核心联合目标尚未达到。** 三个冻结留出批次的平均预测亲和力相对配对native仅增加0.007137 pIC50；边界形状改善1.41%，能量p90改善10.11%，区域松弛RMS改善5.55%，但应变中位数恶化0.37%。这些是描述性模型结果，不是生物亲和力证明。

## 执行范围与比较设计

12轮发现探索、1轮验证、2轮留出测试。主随机种子42，批次种子为42+100003×batch；同批次各臂实际初始坐标/原子/键/电荷状态哈希配对。共1450个gradient、350个native、200个zero-dose尝试。每个尝试完成100步，动态学习窗口为0–0.5；梯度覆盖50个真实提案更新，之后native续推到1.0。新推理没有SMC筛选、克隆或重采样；化学图保持自由。

冻结方案来自第9轮，目标为真实0.5边界的存活祖先分布；all通道、joint质心/壳层/原子对几何混合奖励。η=0.05、τ=0.5、δ=2，连续剂量p=0；单原子步长上限0.025 Å，累计RMS路径上限1.25 Å。第13–15轮实际有效参数与第9轮完全一致，未根据验证/留出结果重新调参。

前8轮保留历史尺度，其中score=0.5对应proposal=0.51；该外部帧从未注入梯度。第9–15轮的尺度与实际边界谱系严格排除该外部帧。历史例外已保留并披露，最终候选只来自严格范围的第9–12轮。

历史Steer100是发现阶段基准；留出测试包含三个批次17/18/19，每臂150次。其原始模型和受体相同，但历史Steer不是配对随机留出臂。整个项目已有区域预选与历史探索，本次留出不能称为从未接触过的外部验证。

本次固定参考的25个原子槽位，以便进行匹配比较；原子类型、键与电荷仍由模型生成。这限制了对分子大小变化的推断，不构成化学图身份约束。

## 新增方法与Agent工作流

- 空间motif与边界谱系脚本流式分析整个真实选择窗口；按批次计算差异、四分位富集、根平衡/根内与下一步收益，并保存连续趋势、变化率、置信区间和p/q。没有0.1时间分箱或逐边大表。
- 系统发育方法启发谱系相关性控制；SMC复制树不满足Brownian物种树模型。motif方法启发同事件前景/背景比较；本任务的motif是空间描述量。Pareto探索用于奖励程序，未实现完整NSGA-II，也未在FLOWR内引入遗传筛选。详见[文献与工作流](../../motif_evolution_workflow_20261006.md)。
- [Skill](../../../skills/motif-evolution/SKILL.md)约束Analyst证据阅读、反证与时间支持；Designer选择登记的可微公式，经来源哈希、数值梯度与配置检查后编译。实际第9轮走过该接口。其余探索是Agent审阅后的架构/剂量搜索，不是15次独立LLM发明，也不是LLM读取坐标文本便理解了能量。
- [数学定义](../../motif_reward_math_20261007.md)区分d/dt与坐标梯度。当前直接提案奖励对确定性空间函数求导，不需要FLOWR终态预测Jacobian；预测终态上的新奖励则需要真实FLOWR反传。本次没有额外训练神经代理模型。

当前充分调整、根内关联与严格边界整曲线检验未建立稳定亲和力方向。两个相关通道的ASN117低x尾部积分耗竭通过FDR，但全曲线未通过；它们不能变成持续+x力或确定的结合能机制。现有奖励是探索性的经验分布模仿。

## 为什么没有达到核心目标

实验支持少量、随批次变化的几何与预测收益。当前低维质心/距离核没有覆盖化学条件、键角、扭转、平面性与少数高应变尾部；按时间独立的混合模式也不强制路径协同。这些是待诊断的机制假说，不能仅从最终统计证明为退化原因。化学图变化本身不被当作失败原因。

优先补足局部最坏几何及其应变贡献、受体方向性/类型相关重叠、化学属性与不确定性条件，以及区域与周边的原生流协同位移。不能把最终力场势直接搬到早期噪声状态；应先学习时变容许分布，或明确采用真实模型Jacobian评价预测终态。详见[策略与后续可证伪方向](../../motif_evolution_strategy_20261007.md)。这些新增方向未进入本次冻结奖励，本次预算外未追加生成。
