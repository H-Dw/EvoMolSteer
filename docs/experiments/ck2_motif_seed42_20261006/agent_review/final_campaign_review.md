统计单位是 **3 个配对生成批次**。150 个候选、谱系克隆以及 15 轮候选总数都不是独立实验重复。全程固定 master seed=42，本次不同批次流不能证明新主种子、新靶点或生物学泛化。留出结果未用于调参；历史聚合上下文曾可见，因此不应写成完全盲化的外部验证。R9 开发阶段 head +0.033956 等较大收益不能替代当前留出估计。

历史 Steer 的 100 个尝试提供绝对基准：all-head 7.510351，valid-head 7.501144，MMFF 中位数 0.398679，周边 RMS 0.202921 Å。留出 gradient 的 all/valid-head 仍低 0.043055/0.031930，MMFF 中位数高 **32.565%**，周边 RMS 高 **62.538%**。因此“提高 affinity 且构象/能量接近原 Steer”的联合目标尚未达到。该历史组来自发现批次且包含克隆，不能当成本次留出的配对随机化对照，也不能直接用 unique=99 对 24 宣称同条件多样性改善。

从 15 轮保留 candidate CSV、终态摘要和 window 批次表独立重算 **947 项数值**，最大绝对误差为 **1.78×10⁻¹⁵**；全部 retention 文件哈希一致。MMFF 统一为 `converged AND finite` 后，15 轮均无有限的未收敛能量、无非有限的已收敛能量；旧 outcome 的中位数、p90 和覆盖率仍一致。周边 RMS 使用有限可计算记录，概念上与能量收敛子集不同，本次留出二者覆盖恰好相同。能量失败没有被当作零值或从 attempted 分母删去。

最终候选池确为严格窗口 R9–12，选择 R9；R13 验证和 R14–15 留出沿用相同有效程序。实跑奖励为 boundary-survival、all/joint motif mixture，η=0.05、τ=0.5、δ=2、ramp=0、predictive-flow 剂量、相同 atom/path/clash caps。参考 SHA 为 `02bd7a4e31791454c91de606cd23e4f8718a782b3af2999e139df82f60153a3f`。尺度仅使用 score 0…0.49；最后注入为 .49→.50，之后 native 完成 100 步，无 SMC。所有轮次初态与匹配 native 一致；R13 两批 zero/native 的完整轨迹字段及 final tensors 逐字节相等。实际控制器、坐标特征和奖励运行逻辑跨 R9/R13–15 未变。详细文件哈希见同名 JSON。

两个易误读的元数据字段已核对：`apply_guidance=false` 关闭内置 Steer，不表示自定义梯度没有执行；`execution_report.reference_sha256=3315bd…` 指旧终点区域诊断参考，实际 motif 奖励由程序、coordinate audit 和 config extension 共同绑定 `02bd7a…`。该差异不构成奖励冻结失效。

科学解释仍有三条边界：真实 x_.5 的无类型槽位形状接近，不等于终态化学或结合模式一致；同图 MMFF 局部松弛能量释放及配体周边位移，不是结合能、受体松弛或已测环境相容性；发现集 root 塌缩和全曲线 nulls 不支持把经验 motif 目标宣称为因果亲和力优势区域。模型 head 也与原选择 oracle 共享模型。现有证据说明受约束分布模仿可以改变生成结果；没有 LLM 与非 LLM 设计流程的比较，不能单独证明 LLM 的必要性或优越性。
