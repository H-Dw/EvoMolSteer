# Designer 条件分支审阅

执行方式：用户授权的 LLM subagent 模拟。2026-10-05；输入为第3轮固定 seed42 汇总证据及第4/5轮冻结方案。此处保存可审阅的结论和依据，不保存私有思维链。

1. 第4轮先验证正确性：零注入时全100步及终态与 native 逐字节一致，只支持适配器不会在所测条件下扰动原生推理，不能证明奖励有效。
2. 若通过，第5轮冻结 η=.2、奖励、窗口和执行配置，使用未参加奖励构建和本次调参的全局批次14/15。历史聚合统计曾查看，应披露；不称全盲、新主 seed 或跨靶点验证。
3. 若失败，先定位首次张量分歧；第3轮差异暂不能全部归因于梯度注入。最后一轮可验证修复：原生 no_grad 输出用于积分，Jacobian 辅助 forward 恢复 RNG，并保护 self-conditioning、状态和缓存。该轮是工程验证，不替代预留批次验证。
4. 第3轮支持两批开发数据中预测终点局部指标改善，有效性大体保留。实际中间坐标另有几何评价，不能与终点局部特征偏差混称同一指标。
5. 独特结构增加不能证明未约束区域更合理；无 SMC 的 native 自身也有更多独特结构。MMFF 应变释放与周围松弛 RMS 未支持优于 native/SMC。
6. FLOWR head 是共享模型预测，不能作为真实亲和力提升证据。整体假设目前只获部分支持，周围兼容性尚未支持。
7. 本次最多5轮；依据第五轮所属分支报告局限，不增加第6轮以追求有利结论。
