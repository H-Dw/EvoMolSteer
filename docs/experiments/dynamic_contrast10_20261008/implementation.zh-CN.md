# 动态优质群体与区域奖励：实现、证据和复现接口

此轮从历史独立验证的R26构象奖励出发，新增动态质量群体分析和区域对比项。没有将历史失败的终末路径核替换成新的基线。实验协议在新批次评分出现前冻结，十轮结果另见最终总结；本文件解释算法与接口，不预设性能改善。

## 分析对象与动态划分

分析原始单目标Steer轨迹的14个发现批次。窗口由参考数据和程序读取，当前为0–0.5。使用评分节点t的FLOWR预测终点三维坐标，其真实对应提议状态为t+dt。学习网格为0、0.01、…、0.49，最后一次控制提议到0.5；原始轨迹中t=0.5对应0.51的选择事件不进入本次控制知识。原始边界结构仍在受保护的Steer数据中，后续原生续推完整到1。

每个节点按祖先家族平衡权重：每个root的总权重相同，家族内各粒子均分。对已观测连续pIC50排序，选择最大化加权类间方差的Otsu阈值。两侧保留模糊带，宽度为该事件加权IQR的固定比例。模糊带排除之后、难负例重加权之前，两类权重有效数仍需至少3。阈值随节点与批次数据动态变化；模糊带比例在对应实验前冻结。

正例、明确较低分对照、模糊样本分别记录为+1、−1、0。正例不是实测结合标签，负例也不是“被淘汰后续推失败”。没有终末标签的未来保持未知。初始划分有695/700个可识别事件，缺失5个事件不填零。

实际选择一致性审计显示，正例的事件平均后代数为1.142，低评分对照为0.744；86.76%的可识别事件正例后代期望更大。全窗口批次等权后代数差为0.397，批次bootstrap区间为[0.353,0.441]。它检查划分与同一选择机制的对应关系，不能作为独立亲和力收益。

难负例实验只匹配质心与协方差9项全局几何量。75%负样本质量侧重空间相近且明确低评分的候选，25%保留普通对照。不能用待研究的区域特征进行匹配，否则会人为抹平区域差异。原子类型与化学图身份不参与匹配。

最终权重有效数另有审计：R5的26/695、R6的33/692个可识别节点在难负例重加权后负类ESS低于3，最低1.496。R6扩大模糊带后共有8个不可识别节点。原始普通对照的ESS均满足划分下限（容许浮点误差）。这一浓缩效应是解释困难对照与统计结果的限制，不说明它已经造成性能下降；R5实际上优于同剂量普通对照。验证期间不回改这些冻结参数，后续若继续探索，可单独测试按ESS自适应降低难度的策略。

## 全窗口富集与趋势

沿用R26受体参考系的20个几何landmarks，计算74项纯坐标特征：质心3、协方差6、原子对距离核5、每个landmark的softmin距离与3Å/5Å高斯壳层密度。壳层密度不是球内原子计数，也不直接表示氢键、疏水接触或能量贡献。原子类型没有进入新的区域奖励。

每个批次/节点只保留两类均值、方差、标签有效数与谱系覆盖。正负差以真实endpoint群体尺度标准化，远端低占据场使用同类landmark尺度下限，避免几乎零方差制造巨大效应。全窗口对原始网格积分，缺失事件使用观测网格质量归一化并报告覆盖，不把未观测值当优势。

独立单位是生成批次；复制后代或50个时间节点不是新的独立重复。全窗口效应用批次bootstrap区间、批次效应检验、74项BH校正和方向一致性筛选；q≤0.05且至少75%批次同方向的区域特征才合格。按区域最大绝对效应排序，最多四个区域进入本轮奖励。全局形状和距离核结果仍作为混杂线索保留。

用0–3阶Legendre函数拟合整个窗口的标准化差异，留一批次交叉验证并用一标准误差规则选择最简复杂度，保存解析时间导数。初始74项都选择0阶：跨批次稳定的平均差异有证据，额外时间曲率没有。观察到的端点差不能取代交叉验证结果；时间导数也不是坐标梯度。奖励仍可使用各节点观测到的群体中心，中心的变化与两群体差异曲线的变化是不同问题。

初始七项候选：L00距离减小/3Å壳层密度增加；L03距离增加/3Å与5Å壳层密度下降；L04距离减小；L12的3Å壳层密度下降。L04、L12的批次一致性较弱，是待实验验证的假设，不能据此指定真实化学作用。完整效应、区间、q值、原始曲线与拟合函数见rest_mining。

额外坐标注释将L00映射到Val53 CG1、L03到Asp120 OD1、L04到Glu114 CD、L12到Glu55 OE1，均与参考PDB原子坐标精确重合。该注释帮助定位区域，不证明相互作用；初始Analyst/Designer调用没有使用这些事后添加的残基标签。壳层密度上升也不等于所有原子向landmark移动：原子位于壳层峰值内侧或外侧时，局部梯度方向不同。

## Analyst、Designer与可微函数

Analyst读取基础Skill、通用dynamic-cohort-contrast模块和冻结的证据包，区别质量、选择、缺失未来、谱系依赖和空间场含义。Designer读取Analyst响应、相同证据、已验证R26及执行合同，提出注册的坐标标量。指令、输入、响应分别保存SHA并核验；响应确实解释了695/700覆盖、家族依赖、七项字段、常数趋势及相反证据。此检查是一次真实sub-agent调用的绑定与证据一致性检查，不是反事实Skills消融。

令y=Fθ(x_t,t)为FLOWR预测终点的世界坐标，φ(y)为筛选的区域字段，z=φ(y)/σ_t。每个发现批次b提供正、负群体中心m⁺、m⁻；共用无量纲带宽v_t等于两类标准化方差平均值加0.25稳定项。对K个字段定义：

\[
c_b^{\pm}(z,t)=\frac{1}{2K}\sum_k\frac{(z_k-m_{b,k}^{\pm}(t)/\sigma_{t,k})^2}{v_{t,k}},\qquad
L^{\pm}=T\log\left[\frac1{B_t}\sum_b\exp(-c_b^{\pm}/T)\right].
\]

\[
H=C\tanh((L^+-L^-)/C),\qquad R(y,t)=R_{26}(y,t)+\lambda H(y,t).
\]

T=1、C=2是冻结的实验选择，不是文献或数据自动决定的常数。λ按顺序测试0.05、0.15、0.40；λ=0严格恢复R26。另一个预设检验使用H=L⁺，去除低评分密度排斥，保留正例吸引。共用带宽和tanh仅使对比数值有界，不能证明高亲和力或推断原生密度比。

梯度可以明确写出。令ρᵇ±=softmax_b(−cᵇ±/T)，则

\[
\nabla_zL^\pm=-\sum_b\rho_b^\pm\frac{z-m_b^\pm/\sigma_t}{K v_t},\qquad
\nabla_yH=J_\phi(y)^T\operatorname{diag}(1/\sigma_t)
\operatorname{sech}^2((L^+-L^-)/C)(\nabla_zL^+-\nabla_zL^-).
\]

除法均为字段逐项运算。对距离dᵢ=‖yᵢ−landmark‖，softmin字段的原子梯度是softmax_i(−dᵢ/0.5)·(yᵢ−landmark)/dᵢ；半径r、宽度s的平均高斯壳层字段梯度是−(dᵢ−r)/s²·exp[−(dᵢ−r)²/(2s²)]·(yᵢ−landmark)/(N dᵢ)。这些是实际Torch坐标程序的解析解释，不依赖LLM对浮点坐标直接求导。

实际坐标方向为J_Fθ(x_t,t)^T∇_yR。真实FLOWR模型提供Jacobian向量积；亲和力输出脱离梯度，没有代理模型、每步额外生产前向或Steer重采样。每步沿用R26的预测flow RMS剂量、原子步长/累计路径上限和新严重受体碰撞检查。坐标梯度在原生更新前计算，再做滞后的更新注入；Hungarian对应和self-conditioning条件固定。一次有限差分核验额外前向单独计数。

λ主要改变合成梯度方向，不等于按λ直接放大位移，因为控制器做RMS剂量归一化。比较剂量参数之前必须检查方向是否正确；本轮不同时更改物理控制强度。所有学习窗口步参与引导，窗口之后仅原生续推；化学图变化自由，没有图身份或配对距离接受gate。

## 可复用输入输出

在仓库根目录运行，下列相对路径是示例数据集配置，窗口、批次及参考可通过参数或输入声明替换。

```text
python scripts/mine_dynamic_regions.py --dataset DATASET --campaign CAMPAIGN
  --incumbent-reference REFERENCE.json.gz --output ANALYSIS_DIR
python scripts/audit_dynamic_selection.py --events ANALYSIS_DIR/event_cohorts.parquet
  --manifest ANALYSIS_DIR/manifest.json --output SELECTION_AUDIT.json
python scripts/annotate_reward_landmarks.py --reference REFERENCE.json.gz
  --receptor EXACT_RECEPTOR.pdb --output LANDMARK_ANNOTATIONS.json
python scripts/prepare_dynamic_agent_inputs.py --repo . --role Analyst
python scripts/prepare_dynamic_agent_inputs.py --repo . --role Designer
python scripts/run_dynamic_contrast_campaign.py --start 1 --last 10
python scripts/report_dynamic_campaign.py --reports REPORTS_DIR --configs CONFIGS_DIR
  --output SUMMARY_DIR --steer-metrics STEER_METRICS.csv
```

Agent准备脚本是当前campaign的任务适配器，读取本轮声明的证据路径，写入round02_agents目录；它不是任意数据集的通用导入器。更换实验需配置对应任务适配器，基础Skills和动态对比Skill保持通用。脚本生成调用材料，LLM响应仍需实际接口或sub-agent执行。远端生成调用接受FLOWR程序路径、checkpoint及不可变reward/reference；运行后只回传验证过的评估材料，本地完成科学分析。

存储没有展开每个粒子74项宽表或复制坐标。初始分析的三张无压缩Parquet共约250KB，一字节群体代码约8KB，函数约49KB；3.35MB参考还包含原有R26多模态pointcloud教师。各轮只长期保留程序、紧凑报告、分析摘要、SHA与commit；生成原始结构在本地报告验证后、下一轮前清理，原始Steer与模型checkpoint保护保留。

## 验证边界

第1–7轮在一个新筛选批次比较，重复初始状态用于控制变量，不是七次独立发现。第8轮前冻结候选，第8–10轮使用四个新批次：R26/原生对照、候选同批次比较、另一个候选/原生面板。总计900条生成尝试；有效输出、有效高分尾部、PB-fast与MMFF应变分别报告，化学图去重仅用于统计。不同计算预算的历史Steer结果是非配对参考。

随机性沿用现有控制器：主seed为42，各批次的推理流使用42+100003×batch；对应实验臂使用相同批次流，并验证初始坐标、原子和键数组SHA完全相同。它是固定主seed下可复现的配对批次，不是声称每个批次的所有随机调用都重新初始化为42。初始prior按原生数据加载顺序生成。

若独立面板没有超过R26，仍保留R26为推荐入口，并报告新模块的失败证据。在线pIC50富集不自动等于最终生成亲和力改善；局部均值核可能丢失区域之间的联合相容性，也可能放大同一评分模型的偏差。
