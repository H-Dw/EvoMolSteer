# 20轮串行路径探索：结果与推荐配置

全部20轮已完成：3轮本地数据基础模块、14轮FLOWR对照/自适应探索、3轮冻结验证。每轮仅改变一个模块或参数轴；下降后从保留父方案恢复，未并行优化。共1,350个非重复实验尝试；第8轮另做50个完全相同配置的评估修复重放，不计独立发现。

**结论：保留旧R26奖励为当前推荐配置。** 新路径源方案相对无引导的平均预测亲和力收益在四个新批次中复现，但在相同的独立对照面板上落后旧方案0.09479 pIC50。高亲和力尾部的发现与保留没有通过独立验证，因此不替换现有最佳奖励。新增谱系、终态信用、路径库和非神经潜势模块保留为可复用研究实现。

## 为什么本次不替换旧奖励

已验证的直接证据是：新终态标签源在独立批次落后旧源；背景归一化潜势没有恢复分布主体；更大剂量也不能救回方向；晚期剂量与更大路径覆盖找到少量高分结果，但平均分或物理质量下降。故保留旧奖励是依据实测比较，而非否认路径先验方向。

仍需检验的机制包括：终态标签是继续Steer筛选后的结果，不是native未来；早期后代严重删失；每祖先最大值和只归档高分后代使标签偏乐观；背景减法移除了有用的几何吸引；粗几何尺度及局部teacher切换未能识别真正有利的坐标方向。这些是有依据的候选解释，未作为已证明的因果原因。

下一项优先研究应是少量匹配已选/未选节点的native续跑标定，或独立确认高尾部候选，再建立有真实对照的区域占据/方向效应。不能单靠换Skills措辞、把被淘汰分支视为零分，或把时间趋势导数直接当作空间奖励梯度来填补该信息。此20轮预算内没有追加上述实验。
