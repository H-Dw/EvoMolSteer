# Final-first region guidance contract

The configuration supplies terminal time, teacher time, guidance starts and end,
the authoritative final-score column, units and paired random inputs. Terminal
quality means actual final head prediction and structure evaluation, not
experimental binding affinity.

## Representations and lineage

`terminal_world_A` is the actual output sent to the terminal decoder at the end
of inference. `current_world_A` is the recorded pre-integration current state at
the teacher clock. `predicted_endpoint_world_A` is a different representation
and is not accepted for either input in this workflow.

An ancestor locator binds campaign, arm, batch, terminal slot, integration step,
actual ancestor slot and trajectory hash. Recover it by composition of actual
selected indices. Verify current coordinates copy from the selected prior-step
proposal. Terminal atom slots remain constant along that trajectory; no such
index equivalence is assumed between teacher and new generated molecules.

## Final evidence and handoff

Analyst reads one candidate's coordinate evidence against all other finals.
Primary one-to-rest differences are descriptive, with empirical percentile and
scale, not a p-value from one independent positive. Region boundaries are frozen
in the receptor frame before the comparison. Retain a valid-rest sensitivity
analysis and failures in the inventory. The same batch/root dependence must be
reported; clone multiplicity is not independent replication.

Analyst declares `candidate_id`, `decision`, and hypotheses containing exact
`region_id`, `atom_slots`, `observable`, `evidence_id`, `claim_kind`, `proposed_advantage`, and
`falsifier`. Numeric contrast values come from the cited row, not mental arithmetic.
Designer declares hypothesis/region/slot bindings and the registered formula.
The compiler rejects changed candidate IDs, unsupported slots, forecast teachers,
wrong times and unmatched parameters. Operative prose is rendered from compiled
fields; optional rationale cannot change the program.
Claim kinds are descriptive occupancy, coordinate offset or axis dispersion.
Covariance entries alone do not establish planarity, rigidity or binding energy.

## Same-clock coordinate evaluation

For the supported linear endpoint-parameterized flow, let the teacher clock be
tau, current clock t <= tau, real current coordinates x_t and the generator's
endpoint prediction f_theta(x_t,t). Evaluate the candidate teacher loss at:

    z_tau|t = ((1-tau)/(1-t)) * x_t + ((tau-t)/(1-t)) * f_theta(x_t,t).

This is a one-forward linear bridge approximation to the teacher clock, not
an exact future rollout or SDE success probability. It avoids calling a real
intermediate teacher a final endpoint. Verify the integrator's linear schedule;
unsupported schedules require their own tested adapter.

The gradient is:

    dR/dx_t = a * dR/dz + b * J_f_theta(x_t,t)^T * dR/dz.

Use actual autograd through the coordinate output with frozen parameters and
detached categorical/self-conditioning context. No derivative of the affinity
head and no additional per-step affinity inference is permitted. The identity
term must not be dropped. This is a controlled flow experiment, not a claim of
exact density tilting.

## Registered reward and controls

For one fixed teacher, spatially assign selected teacher points to distinct
generated active atoms. Freeze assignments for that derivative. With normalized
teacher weights w_j, define q = sum_j w_j ||z_pi(j)-y_tau,j||^2 and:

    R = -delta^2 * (sqrt(1 + q/delta^2) - 1).

This uses M2's robust matching idea but one candidate and a real intermediate
teacher, with no dynamic/final teacher mixing. The whole-cloud control uses all
active teacher points. Local mode uses the approved slots only. Its direct
point-cloud derivative on unmatched z atoms is zero; the pulled-back current
gradient can be dense. Atom types and chemical graph equality do not gate it.
Teacher-point weights are uniform and normalized. Point-cloud imitation is a
proxy for the reported terminal observable, not the same function as regional
mass or covariance; improved matching is not a guaranteed affinity improvement.

Use the same frozen dose, robust curvature and per-atom limits for paired local
and whole-cloud tests. Record actual gradient and displacement RMS; fixed numeric
weights do not guarantee identical realized dose after clipping. Primary start
time comparisons keep per-step settings; a duration difference changes total
exposure and must be reported. Any dose-matched comparison is a separate condition.

Active updates satisfy start <= t and t+dt <= end <= tau. Inference always begins
at zero and ends at the terminal time. Delayed starts mean an initial native
prefix, not restarting from a historical intermediate state. Complete the suffix
without guidance or SMC. With a 100-step linear grid, a task using starts 0/.1/.3
and end .5 expects 50/40/20 active updates; other configurations derive counts
from the actual grid rather than hardcoding them.

## Consistency evidence

Bind Analyst, Designer, teacher and compiled program hashes. Require exact set
equality between approved slots and active teacher points. Verify analytic/finite
difference derivatives with frozen assignment; moving an active matched point
away should lower the reward. Test zero direct unmatched-point derivative in

before claiming production readiness. Execution logs must match the requested
window and nonzero dose. A mismatch is a failed implementation check, never a
different valid experiment.
