# 从真实终态假设到真实半程教师：配对小样本验证

本流程按照本次用户要求重新建立，未沿用旧 Agentic Steer 的中间 head 短名单，也未将半程端点预测当作真实半程坐标。

## 1. 终态先行

全量历史单目标 1000 个终态按 `pic50_on_rescore` 降序稳定排序，失败记录保留。每次处理一个候选，将其与其余 999 个比较，不先聚合为 elite 组。当前预算为先验证排名第一的候选，余下 999 个仍在目录和处理游标中，属于待分析，不能报告为已经逐个分析完成。

真实终态直接取生成完成后供解码使用的张量，保留原始原子槽位，避免 SDF 重排。确定性工具按固定受体坐标系中的空间锚点计算局部占据量、坐标偏移、协方差，给出单候选相对其余候选的差值、标准化差值、经验百分位、有效结构对照和支持数量。空间核 `(1-d²/r²)_+²` 在区域外严格为零，使测量区域与后续转移的原子集合一致。空区域的条件矩为缺失，不伪造零几何。

这些数值是描述性对比。一个高分候选不能给出独立重复意义上的 p/q 值，也不能证明坐标差异造成亲和力提高；克隆依赖和可能的评分偏差均须保留。二、三个点的小协方差不能作为平面性或刚性优势。

## 2. 冻结假设，再追溯教师

真实 API 使用 `deepseek-flash`，Analyst 只先看真实终态证据。冻结其候选、区域、可观察量、引用和原子槽位后，确定性程序组成实际重采样索引，找到配置教师时刻的真实 current 状态，并验证其坐标从上一轮被选择的 proposal 复制而来。

当前首例：`F_b011_s030`，终态预测 pIC50 为 8.704806；真实半程祖先是 batch 11、step 50、ancestor slot 37。Analyst 选择 R00 的 `[4,15]` 与 R19 的 `[22]`，占据量相对其余候选有所提高，并提出 R00 的轴间协方差偏移假设。均属于有竞争解释、可否证的假设，不是已证实优势区域。

Designer 声明实际教师、所采用的假设和槽位集合；编译器验证集合完全相同，拒绝自动替换区域。局部奖励仅使用并集 `[4,15,22]`；全云对照使用同一祖先的全部 25 个点。教师槽位的身份只在历史谱系内成立，与新分子的原子编号不存在等价关系。

## 3. 可执行奖励与时间

单一教师采用 M2 的稳健点云匹配思路，不使用 M2 原先的时间/终态教师混合。均匀归一化教师权重下，先以 Hungarian 空间分配匹配不同的生成原子，求导时固定该分配：

`q = mean_j ||z_pi(j) - y_tau,j||²`

`R = -delta² * (sqrt(1 + q/delta²) - 1)`

实际执行梯度上升，降低 q，使负奖励趋向零。点云模仿是占据量、协方差假设的代理，不等于直接优化这些统计量，也不保证亲和力提高。

真实半程教师不能直接被称作最终端点目标。本次在已核实的线性端点参数化 FLOWR 中，用一次前向的教师时刻估计：

`z_tau|t = (1-tau)/(1-t) * x_t + (tau-t)/(1-t) * f_theta(x_t,t)`

梯度包含当前坐标直接项与真实 FLOWR Jacobian 回传项：

`dR/dx_t = a*dR/dz + b*J_FLOWR^T*dR/dz`

这只是教师时刻坐标的线性近似，不是完整 SDE 续生成，也不是成功概率估计。分类状态和自条件上下文不求导；允许原子类型及化学图随原生生成改变。局部奖励在未匹配的 z 点上直接导数为零，真实模型回传后当前坐标导数可为稠密，不能误报为“周围原子完全无影响”。

所有条件都从同一个未筛选的随机初态开始生成，随机种子 42。引导窗口由配置动态指定，此例为 0/.1/.3 至 .5，100 个积分更新分别覆盖 50/40/20 次；之后原生、无引导完成至 1。全部条件禁用 SMC，不对 affinity head 求导或额外按步调用亲和力评分。

剂量保持配对一致：相对预测流坐标增量 RMS 为 .33，单原子单步上限 .15 Å，累计 RMS 上限 6 Å，稳健尺度 delta 为 1 Å。时间起点比较保持单步剂量，覆盖时长不同，因此不是累计剂量匹配实验。实际梯度及位移另行审计。

## 4. 验证矩阵和交付

先运行局部/全云 × 三种起点，加无引导，共七个条件，每条件 8 个相同初始候选。该小样本用于验证链路与方向，不足以宣称稳定超越 M2 或历史 Steer。记录全部生成尝试的最终 pIC50、结构失败、MMFF 应变代理，另存真实教师时刻与终态两个坐标快照，避免重复保存全轨迹。

主要因果对照为本次完全配对的无引导。既有 M2 400、无引导 400 和 Steer 1000 结果只能提供历史参考；批次、总样本量或随机输入不一致时不作为本次配对结果。

执行一致性检查覆盖：实际交付 Skills 哈希、证据引用、教师来源、原子集合、奖励正负方向、空间对应、有限差分、真实模型回传、时间窗、非零实际剂量和完整无引导后缀。自然语言的执行描述由编译后的程序生成，LLM 的科学解释不能覆盖数值程序。接口修订前出现的描述矛盾已保留为未执行的协议样例，不能混入正式生成条件。

复用入口：`scripts/run_final_region_guidance.py --config configs/experiments/final_region_guidance_20261014_v3/config.json --action prepare|analyze`；推理入口 `scripts/generate_final_region_guidance.py --repo ... --config ... --flowr-root ...`。时间、区域尺度、候选预算和样本数量都在配置中，科学 Skills 不包含环境配置或目标残基硬编码。
