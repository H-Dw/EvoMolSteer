## 4. 平均区域方向比逐步教师方向更可信，但还不是亲和力梯度

region17/深度5逐事件完整XYZ的跨批次余弦均值仅0.045882，正向对比例0.53431，尽管观测方向覆盖完整。哈希绑定的后续摘要报告，对14个批次各自全窗口汇总后得到余弦均值0.420743、正向对比例约81.32%。91个批次对相互依赖，仅是描述性比较，推断样本仍为14；缺失或零向量不会被填成一次观测余弦0。

旧的两步教师联合场同样很弱：非零confidence占20.64%，最大0.00107922、均值1.98260e−5；可用完整教师方向的跨批次余弦均值约−0.002824。它的非零覆盖与区域平均关联是不同统计对象。取confidence平方根、归一到最大值或幂零只会改变剂量，不能提高方向可靠性。将原始confidence同时当位移、区域权重和剂量还会重复收缩。

全窗口区域协方差向量可提出如下后续假设：在一个完整联合teacher背景下构造受限内部位移，使region17/18的变化方向与已观察均值兼容，同时保留周围点云的空间关系。需要新增确定性几何工具，将teacher条件下的软区域成员、重叠约束、整体平移投影、观测变异尺度、缺失支持和跨批次诊断共同转换为完整点云位移。不能把多个区域独立切开、分别吸到不兼容的位置，也不能直接把Å·pIC50协方差当成Å位移或已知亲和力空间导数。当前没有注册这个工具、参考或公式，故只保留为待实现假设。

## 5. Designer当前的两个可执行边界

当前注册表只有以下两项，不能用未注册区域公式替代：

- `branch_mixture`：保留完整原teacher与评分先验，用观测分支RMS并以0.2Å封顶形成虚拟中心；原中心质量至少为1−α，α∈[0,0.5]是探索预算。只调整一个已注册参数轴，冻结资格、尺度、对应关系、符号和其他权重。先做α=0/空方向逐位对照，核实新增梯度方向、实际注入剂量和配对坐标改变，再以冻结预算作正/反方向实验。当前弱teacher方向使它仍是探索性检验。
- `native_control_v2`：原R26标量不变，独立测试一个注册的剂量/方向控制参数，例如既有反向传播得到的VJP增益门。它是控制策略试验，不是区域信息已经进入reward，也不是精确的引导密度。与空间模式试验分开，报告真实累计动作成本，不能把相同请求比例说成相同实际剂量。
