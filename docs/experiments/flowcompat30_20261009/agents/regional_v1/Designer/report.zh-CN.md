## 为什么只试小预算

新增参考由独立 `regional_common_depth` 工具实际生成，而不是旧branch工具或混合深度v1输出。声明深度2/3/5/8/13的合格区域数分别为3/7/6/4/0，按固定发现规则选共同深度3。所有入选区域使用相同观察跨度，避免让较长lag的累积协方差因量级较大而不成比例地控制方向；没有用新生成亲和力选择lag。

入选区域为3、6、11、12、16、17、18，均保留XYZ全向量，14独立批次、原BH校正q/置信区间及LOO支持。输入是相同祖先背景下软区域内部位移与当步在线评分的调整协方差，单位为Å·pIC50。主要方向是区域3/11/12/16的负y和区域6/17/18的正y组合，但不能把保留的每个XYZ分量都称为显著优势。区域16的协方差范数最大，区域6只有10/14正LOO方向；区域重叠、密度差异和不显著分量仍然保留。

所有选中XYZ函数都是degree0，观察支持0.03–0.49，解析时间导数为零。因此本次没有阶段切换、时间力或平滑起始规则。动态学习/控制窗口直接读取请求与参考的一致声明，本次为[0,0.5]；评分节点0–0.49的最后一次更新到达0.5。共同深度之前的0、0.01、0.02没有新增方向，原R26奖励照常；285/1400教师具有新增场，旧资格为289/1400。缺少的四个0.02教师没有被补造。

必须同时看已有反证。绑定的 `round09/comparison.json` 与 `implementation_gate.json` 是补充上下文，而非新挖掘证据ID：旧原始分支方向在α=0.1时已产生1.4900%的条件梯度变化和0.0243794Å的配对窗口坐标变化，实施门通过；但两个筛选批次对R26的全部尝试亲和力差分别为−0.00317792、−0.0344350，均值−0.0188065 pIC50。它仍高于无引导+0.0826435，不能据此忽略相对R26的退步。

新区域方向具有不同的信息来源，但仍只是统计方向假设。选择α=0.05是将旧失败试验的虚拟质量预算减半、保留至少95%原教师质量的谨慎试验决策，不是从统计推导的最佳α，也不声称α减半会令真实更新线性减半。不能因旧方向失败就放大新方向或confidence；如果小预算没有实际响应，先报告机制未检出，再按顺序考虑已注册单轴剂量，而不是同时修改方向、区域权重和控制器。

## 可执行的联合奖励与真实空间导数

令完整原教师点云为 \(T_k\)，输入受体landmark为 \(L_r\)，冻结区域宽度为 \(w\)，共同深度3的全窗口XYZ协方差函数为 \(C_r(t)\)。实际注册的区域场为：

\[
h_{ri}(T_k)=\exp[-\|T_{ki}-L_r\|^2/(2w^2)],\qquad
b_{ki}(t)=\sum_r C_r(t)[h_{ri}(T_k)-\bar h_r(T_k)],\qquad
d_k=b_k/\sqrt{N^{-1}\sum_i\|b_{ki}\|^2}.
\]

完整点云共同背景决定成员关系，不产生互不兼容的独立区域位置目标。减均值消除整体平移，但不消除刚体旋转或力矩；RMS归一化保留联合方向，却丢弃绝对协方差和成员密度尺度。因此 \(d_k\) 不是评分空间梯度、化学相互作用或神经模块的重要性归因。

旧数据资格 \(e_k\) 要求原有lag2观测、同祖先且不同立即父节点的低评分变异对照、非零自然幅度和原positive confidence；共同深度新场缺失时资格不激活。物理幅度来自旧分支实际变异：

\[
a_k=\min(\mathrm{raw\_direction\_RMS}_k,0.2\,\mathrm{\AA}),\quad
T_{k0}=T_k,\quad T_{k1}=T_k+a_kd_k.
\]

这里的 \(a_k\) 是Å单位的自然lag2变异尺度； \(C_r\) 是lag3的Å·pIC50统计量； \(\alpha\) 是无单位的额外探索预算，三者不能混用。原confidence仅沿用资格含义，不乘到位移、不取平方根、不称为校准可靠概率。当前 \(\mu=0\)，代价原子权重为1；原参考中保存的atom weights没有被删除或重新估计。

未移位的原中心决定冻结Hungarian对应 \(\sigma\)、原最近教师集合和评分/距离先验 \(\pi_k\)。原/虚拟中心的质量是：

\[
p_{k0}=\pi_k(1-\alpha e_k),\qquad
p_{k1}=\pi_k\alpha e_k,\qquad\alpha=0.05.
\]

各原teacher合计先验仍为 \(\pi_k\)，每个原中心至少保留 \(0.95\pi_k\)；无资格中心保持完整原质量。定义：

\[
q_{kb}=N^{-1}\sum_i\|Y_i-T_{kb,\sigma(i)}\|^2,\quad
\rho_\delta(q)=\delta^2(\sqrt{1+q/\delta^2}-1),\quad
R(Y,t)=\tau\log\sum_{k,b}p_{kb}e^{-\rho_\delta(q_{kb})/\tau}.
\]

保留代码中的 \(\tau=0.5\)、默认 `pointcloud_delta_A=1`Å；程序的其他`robust_delta`字段不替代这个实际点云参数。固定模式/参考/对应后，\(A_{kb}\)为上述logits的softmax：

\[
\nabla_{Y_i}R=-\sum_{k,b}A_{kb}
\frac{Y_i-T_{kb,\sigma(i)}}{N\sqrt{1+q_{kb}/\delta^2}}.
\]

这是注册scalar真正的可微空间导数，不是时间趋势导数或直接把协方差当成亲和力力场。α=0、空方向或无资格节点委托原reward计算，要求数值逐位一致，而不仅仅是代数上等价。

FLOWR的实际端点映射为 \(Y_\mathrm{native}=F_\theta(X_t;\mathrm{pocket},t,\mathrm{detached\ selfcond})\)，世界坐标为 \(Y=sY_\mathrm{native}+\mathrm{COM}\)。使用：

\[
g_X=J_{F_\theta}(X_t)^\mathsf T\,s\nabla_YR.
\]

这个Jacobian来自真实FLOWR模型。生产活跃节点保持一次正常forward加一次reverse/VJP；affinity输出detach，不对head求导，不增加生产forward或亲和力网络。冻结实现原有一次性有限差分预检如执行，其额外调用单独记录为审计，不计作每步生产调用，也不是本次新增功能。旧self-conditioning、离散标签、模式选择和对应不沿梯度求导。它是当前坐标的条件端点pullback，随后在原生更新后注入，不能称完整未来路径Jacobian、精确条件流或物理能量梯度。

控制参数继续来自R26：请求的`native_rms_ratio=0.33`、predictive-flow标定、原子/累计位移caps与新严重碰撞回退保持不变。整体scalar的倍数会被梯度RMS归一化消除；α主要改变多模态合成梯度，实际剂量仍受轨迹、flow和caps影响。窗口与原生续推均从输入程序/参考读取，超过窗口不再guidance。原生随机流、积分和自由化学图变化不加限制。

## 先验证响应，再比较收益

本次新区域候选尚未运行。后续按单个模块顺序进行，不把这些控制写成已完成结果：

1. 对实际编译request/reference/numeric源码、checkpoint和执行记录作哈希绑定，确认真实模型VJP通过；α=0或空新方向必须与配对R26窗口、终态逐位一致。既有R26非零gradient不能证明新区域知识生效。
2. 在相同种子42、初态、checkpoint和随机流上，冻结α及尺度/资格，分别执行正方向、反方向、空方向。反向由控制工作流单独生成合约，不在本次更新中改第二个参数。检查`branch_gradient_relative_change`、`branch_virtual_teacher_shift_rms_A`、`branch_virtual_mass_mean`、配对窗口坐标、caps/回退，以及raw scalar gradient与实际注入的内积。
3. 报告逐步实际RMS、累计动作成本和亲和力全部尝试均值/有效率/上尾/极高分产率。相同请求η不保证累计实际剂量相同；正反均受益时先检验模式平滑或dose效应，不能宣传方向已学对。
4. 亲和力先与配对R26和无引导比较，正方向还应优于反方向才支持方向信息；反向更好或候选低于R26则撤回当前试验、保留R26。适应性两批筛选不能当独立确认。明确亲和力提升后，再判断应变、构象合理性和周围兼容性是否接近或优于基线。
5. 历史Steer保持非配对参照：其1000样本均值7.65148、最大8.70481；供体参与规则发现且包含额外评分/重采样预算。小候选批次最高值、供体均值或跨预算平均值不能证明优于Steer。

主要反证仍是选择条件、灭绝未来删失、方向在逐节点噪声大、完整XYZ中的不显著分量、旋转与区域兼容性、自然lag2幅度转用于lag3区域场、及单位RMS对弱效应的放大。当前只能检验一个有限、完整构象邻域的探索假设。campaign已完成9轮、第10轮运行中，未完成30轮；本报告没有新的性能提升结论。
