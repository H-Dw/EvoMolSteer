# 联合坐标选择创新特征

正式输出为 `joint_contrast_v2/`。`joint_contrast_v1/` 是未用于实验的初稿，包含已撤销的选择概率和符号校准零假设检验，不得作为正式推断证据或奖励设计输入。两项仅由构造而来的正值在 v2 中保留描述统计，不再报告 p/q。

本工具读取原始 Steer 的 14 个发现批次，共 700 个真实选择节点。参考库的评分节点为 0.00–0.49；最后一次对应的实际积分状态为 0.50。整个范围统一分析，未划分 0.1 子区间，未输入末端预测亲和力标签。

每个固定教师端点先以世界坐标中的 Hungarian 匹配找到同一事件的较低评分近邻，保留口袋中的平移和旋转。令 Δⱼ=T−match(Yⱼ)，dⱼ 为全点云 RMS 距离，gⱼ 为正评分差。利用几何邻近权重和根谱系平衡，计算联合场

`v = sum_j w_j * tanh(g_j / s) * Δ_j / (1 + d_j)`。

按整体 RMS 归一化获得方向，保持每个原始教师的完整坐标、评分和批次不变。精确评分并列和精确相同点云产生精确零方向。原子局部幅度权重平均为 1，并限制在 [0.5, 2]。该场是几何外推假设，不是拟合的亲和力梯度。

支持度将根权重 ESS、方向相干性和独立其他批次的方向一致性相乘，并施加最高 0.2 的局部收缩。单根控制必定产生零支持度。根和教师都不是新的统计独立单位；置信区间和全局趋势均以批次为单位。全范围趋势采用留一批次验证的 Legendre 拟合，同时保存解析时间导数。时间导数不是空间力。

父子分析严格沿实际选中索引，计算下一节点的模型端点预测减去对应父节点的端点预测，并与此前的原生积分位移比较。子代先在同一个保留父节点内平均；被淘汰父节点的后续表现未知。当前数据中的父内分支变异不足，无法计算有效的父内创新幅度与评分增量相关性，该项明确记为不可用。

主要结果：联合差异幅度为 0.06567 Å，噪声 RMS 为 0.06668 Å；方向能量约 78.65% 属于内部形状变化，13.22% 属于平移，8.12% 属于小转角旋转。参与度约 38.35%，说明方向在部分空间槽位上集中，但不能据此命名化学官能团或声称神经网络模块归因。教师预测创新与优势方向的平均余弦为 0.22609，批次 bootstrap 95% 区间为 [0.19691, 0.25161]，q=2.22e−9。创新与原生位移平均余弦为 0.09179，区间为 [0.08092, 0.10348]。

观测到的子代评分变化平均为 −0.03633；这是选择后、时间变化下的条件关联，不能解释为淘汰分支更优。评分差又来自选择器本身，因此同一节点的优势方向并未获得独立未来亲和力验证。

保守支持度仅在 11.5% 教师上大于零，最大值约 0.00769；后期根谱系坍缩使 0.3、0.4 附近支持度为零。奖励设计应明确面对这一支持不足，先验证真实的坐标注入和生成响应，不能把小支持度误称为覆盖全程的有效亲和力引导。

原始参考记录的是转换后 HDF5 来源标识，而当前读取的是原始 NPZ。工具分别保留两套文件来源标识，并逐个以坐标及评分验证教师一致性；最大 RMS 误差为 1.22701e−6 Å。没有读取模型激活、模块注意力或 Jacobian，故没有神经网络模块因果归因。

输出共 4,838,509 字节，其中增强参考占 4,683,486 字节，其余仅为事件统计、全范围效应、趋势函数和来源清单。没有保存逐节点宽特征缓存或完整父子边明细。7 项针对符号、置换/旋转、复制、空支持、父子平均和空间分解的测试通过。
