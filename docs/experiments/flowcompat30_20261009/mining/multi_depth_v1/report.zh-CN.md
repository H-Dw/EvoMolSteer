# 多谱系深度的局部坐标变异

本次使用独立新增工具，实际运行深度2、3、5、8、13的共同祖先比较。未修改已经冻结的 branch_mutation、selection_innovation、Agent接口、Skills、奖励或控制器；未生成、提交或执行远端任务。工具进程在执行前记录字面命令、源代码与实际输入哈希，在执行后验证输入和代码未变并记录输出，真实receipt不是事后补写的历史声明。

方法沿当前节点向前组合实际 selected_indices，找到对应深度的共同祖先。首先合并同一个立即父节点的复制子代，再在共同祖先内部中心化端点特征创新与评分增量，每个有真实分叉的祖先权重相等。只读取输入学习窗口[0,0.5]内的评分节点0.00–0.49；各深度的前depth个节点没有足够祖先，保持缺失。不存在0.1子区间划分、终态标签、灭绝分支的未来补值或新预测模型。

特征包括74项原有端点几何、3项联合/平移/内部创新幅度，以及20个固定受体坐标区域中的内部位移XYZ，合计137项。区域使用祖先端点对受体landmark的4Å宽Gaussian密度作为软成员权重，以全部活跃槽位数归一化，先减去全点云共同平移。没有将远离所有槽位的弱成员权重重新归一化为强区域。坐标槽位沿真实轨迹保持对应，不能据此宣称同一个化学原子的物理运动。

正式运行的调整量为原子标签变化比例、无向键标签变化比例以及全点云XYZ平移。调整是加权线性投影的混杂诊断，保留原始与调整后结果，不优化原子标签、不约束化学图。全局centroid与调整量本身重合时会投影为无剩余信息，其相关性保持缺失；运行中对空观察均值的提示来自这些缺失字段，没有补成零。

坐标区域还提供了带明确方向和绝对尺度的局部信息。例如深度5的region17内部+y变化，调整后相关性+0.12257、q=0.003922，协方差+3.85376e−6 Å·pIC50、q=0.012369；同深度region13的−y方向协方差为−8.67523e−6、q=0.016915。region03的−y变化在深度3、5、8分别得到协方差−4.40787e−7、−1.33962e−6、−3.33015e−6，均通过校正。必须同时读绝对效应；统计显著不等于大幅可用的坐标控制信号。区域名称仅标识输入landmark的空间邻域，不命名化学相互作用或神经模块。

“方向一致”需要分清两个尺度。逐事件的批次间完整XYZ协方差方向平均余弦多数只有约0.02–0.06，说明即时向量噪声很大。对已保存的batch_window_statistics进行只读整体窗口汇总后，14个批次的区域方向更一致：region03/深度3的平均批次对余弦0.48038，85.71%批次对为正；region17/深度5为0.42074，81.32%为正；region13/深度5为0.37591，75.82%为正。91个批次对相互依赖，仅是描述统计，不能当作91个独立重复。所有方向计算排除缺失或精确零向量，缺失余弦从未填0。

因此存在值得后续Agent检查的、经过时间总体总结的区域方向，但现有证据更支持低噪声的全窗口函数与完整联合空间背景，而不是直接放大每个事件的原始向量。多深度一致的幅度关系也不能推出禁止变化、化学图gate或亲和力因果机制；分支已经过选择，在线head同时影响选择。当前未提供未来亲和力、能量或模块干预证据，也未生成新的完整教师参考或奖励。

全窗口拟合的具体方向应从三个调整后协方差函数共同读取，而不是只挑显著分量。令u为各深度实际可观察时间范围映射到[−1,1]的坐标，逐分量拟合`C_axis(t)=Σ c_j P_j(u)`。留一批次的一标准误规则对上述三个候选区域的XYZ都选择了0阶：深度3/region03约为(−1.039e−7,−4.408e−7,+2.844e−7)，深度5/region17为(+7.987e−7,+3.854e−6,+5.205e−7)，深度5/region13为(−9.135e−7,−8.675e−6,−2.438e−6)，单位均为Å·pIC50；解析时间导数为0。因此数据支持相应观察范围内的平均方向，而没有支持给这些区域编造阶段切换。不能将缺失的前depth节点或0.5以后用此常数填充。

这些方向描述“祖先软成员区域中相对全局平移的内部变化与评分协方差”，并不直接给出当前端点的绝对理想位置。成员权重固定在该分支的祖先端点上，区域外槽位仍属于完整分子并影响整体兼容性；不能切割区域后分别朝不兼容的位置吸引。若后续将其转为试验奖励，需要说明如何把共同背景条件转换为生成时的可观察参考，并保持完整教师/空间上下文、真实FLOWR条件VJP以及实际剂量验证。协方差大小或时间函数本身都不是已知的空间奖励导数，不证明head机制或模型模块因果贡献。
