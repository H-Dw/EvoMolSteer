# 数值策略修正审计：方向支持、空间尺度与实际控制剂量

日期：2026-10-09。只读审计，未修改冻结的数值模块、Skills或Agent合同，未运行模型、未追加推理。本报告不是Designer design response；新公式若采用，必须重新注册、请求实际角色响应、测试和提交。

## 1. 当前场为什么几乎不会改变R26

`generation/innovation_reward.py` 采用虚拟中心 `T'=T+λ c^γ d`，d为RMS归一化的完整点云方向。原innovation的c最高0.007693，默认γ=1时λ=0.25Å产生的最大中心变化只有0.001923Å。

新 `branch_mutation_v2` 的两步祖先条件场虽然恢复了后期局部变异比较，c反而更小：最高0.0010792189，均值1.9825987×10⁻⁵。λ=1Å时最大teacher变化仅0.001079Å，平均约0.00001983Å。不能把参数“1Å”或基线每步非零引导，解释为这个新机制具有1Å或足够的作用。

另一方面，`local_reward.py::bounded_local_step` 把梯度归一到η×predictive-flow RMS。因此将整个reward乘一个正系数，一般不会改变真实更新；增大新项权重只有在它改变合成梯度**方向**或gate时才有效。必须分别保存基线梯度、新增项/teacher改变、新旧合成方向余弦、实际注入与配对轨迹响应。小teacher移位确实可能因离散随机路径产生巨大终态差异，但这种放大不是信息有效或性能提升的证明。

新confidence是几个收缩启发的乘积，并非校准概率、p值、或可直接赋予Å单位的系数。它既含局部分支数、信噪比，也含跨批次一致性；再将它同时乘到teacher距离、区域权重和剂量，会发生重复收缩。反过来，取sqrt(c)、γ=0或除以很小的c最大值，也不能凭空提高方向可靠性。

## 2. 小confidence的真实来源不能略过

两步共同祖先的识别修正是必要的：紧邻复制子代的endpoint严格相同，只有在后续原生提议变异之后才有可比较的分支。初始root只剩一个不意味着没有局部变异；独立统计单位仍是14个批次，不是分支或复制数。

新场1344个有两步观测的teacher中，595个有非零原始联合方向（44.27%）。从增强reference只读计算：

|量|均值/关键分位|含义|

|局部confidence|均值0.005443，最大0.035585|尚未叠加跨批次收缩|
|不同可观察变异数|均值1.609，p90=3，最大7|很多teacher只有自身，没有低分自然分支对照|

当前跨批次匹配按完整空间模板挑最近teacher，再取其方向余弦。若另一批次没有分支方向，cos(v,0)数学上未定义，应报告不可用及覆盖，不填成一次实测0余弦。修正该语义有助于正确解释支持；上面的实测结果同时说明：**不能借此宣称修正即可恢复有效空间方向**。方向缺乏一致性，仍需要分模式/局部背景、不同分支深度或更好的区域表征。

## 3. 确认两处trace/区域权重语义错误

### 一阶奖励变化应使用原标量梯度

`flowcompat_controller.py::after_native` 把 `adjusted` 写入cached后交给 `endpoint_controller.py`。基类记录 `first_order_reward_change=(g*actual).sum`；此时g已是控制向量Pg，不是被评估标量R的梯度。

正确的一阶估计必须为：

`ΔR_first_order = <g_raw, actual_injection>`，其中g_raw是旧X_t上真实scalar reward的VJP。

`<Pg_raw, actual>` 可以另存“控制向量与动作的内积”，不能冠以reward change。即使后续执行rigid-pose投影，reward导数仍应使用原始g_raw；投影梯度另存诊断。当前R26不启用pose投影，因此修复不需要改变基线数学路径。

parallel控制可写为 `P=I+(a−1)P_flow`，P_flow是flow方向正交投影。当a≥0时P半正定，在只有该预处理和统一正缩放时 `g_raw^T P g_raw≥0`；这不等于Pg是另一可积分scalar势，也不保证经过native滞后和离散变化后的终态reward增加。多种非交换投影、逐原子修正或碰撞回退后更应直接记录raw内积，而不是套用该性质。

### 区域权重必须对可用证据有条件

当前 `innovation_reward.py` 的区域权重为 `w=(1−μ)+μ·m`，没有使用confidence。因此即便teacher的c=0，region_weight_mix仍可能把无支持或缺失方向关联的atom权重用于代价，违背了“没有支持就保留R26”的解释。

最小语义修复为：`w_ki=1+μ·s_k·(m_ki−1)`，其中s_k∈[0,1]是明确记录的支持门，c=0/无对照/零方向时s_k=0。若暂时沿用现有启发，s_k=c_k，不随意开方或幂零。m原有均值1、范围[0.5,2]，因此均值w=1；s=0时严格w=1。如果以后改为基于独立支持资格的s，必须单独注册并明确它不是原c概率。

μ=0、λ=0或无信息输入应直接走原R26运算，不能仅以乘单位矩阵/加零后“理论相同”替代逐位相同。所有本轮修改在新模块/版本中完成，不回改冻结的R1/R2数值证据。

## 4. 推荐的新可微形式：保留原模式质量，分离变异尺度与试验预算

不建议继续把λ×极小c作为唯一有效幅度，也不建议用sqrt(c)强推噪声。更清楚的实验设计是区分三件事：

1. **方向资格与覆盖**：同祖先真实变异、复制去重、非零坐标差和在线差，独立批次方向/模式支持与不确定性；无资格的teacher不扩展。
2. **物理尺度**：记录的自然分支差幅度a_k（Å）及局部噪声/距离支持范围，而非统一假定一个Å。
3. **额外探索预算**：预注册的小混合质量α，明确它是实验控制参数，不是confidence概率。

以下是需新增注册的候选公式。保留全部原始teacher T_k、未移位匹配σ、R26评分先验π_k和原有多模态背景。资格 `e_k∈{0,1}`由冻结数据规则给出；e=0不扩展。方向d_k的RMS为1，变异尺度取 `a_k=min(raw_branch_RMS, frozen local-support cap)`；不外推超过已观测局部尺度。固定κ后建立两个中心：

`T_(k,0)=T_k`，`T_(k,1)=T_k+κ a_k d_k`。

用单轴α控制virtual mode质量：

`p_(k,0)=π_k(1−α e_k)`，`p_(k,1)=π_k α e_k`，`0≤α≤α_max<1`。

所有原teacher至少保留1−α_max的质量。α=0与无资格e=0必须委托原reward；κ、资格、尺度cap和支持判据都先冻结，不能同时调参。原c可作为同资格模式中的相对优先级诊断，不能未经验证把极小数字归一后称为高置信度。当前跨批次方向结果很弱，e_k的资格规则应保守或将这项明确列为小预算试验；尚未获得可靠资格就不强行推广至整个窗口。

令 `r_(k,b,i)=Y_i−T_(k,b,σ(i))`、`q_(k,b)=mean_i w_ki ||r_(k,b,i)||²`，保留R26稳健代价ρδ与τ：

`R_new(Y,t)=τ log Σ_(k,b) p_(k,b) exp[−ρδ(q_(k,b))/τ]`。

令posterior `A_(k,b)=softmax(log p_(k,b)−ρδ(q_(k,b))/τ)`，则冻结资格、模式、匹配、权重和尺度时：

`∂R_new/∂Y_i=−Σ_(k,b) A_(k,b) w_ki r_(k,b,i) / [N√(1+q_(k,b)/δ²)]`。

真实FLOWR控制仍是 `gX=J_Fθ^T scale ∇Yworld R_new`，与现有self-conditioning、原生SDE、动态图采样及窗口结束后的native续推相容。新增模式只增加少量点云代价运算，不增加模型forward或亲和力推理。此公式保持完整联合构象，不是把此前失败的边际区域场或背景减法改名。

备选是将新旧scalar差显式写成 `R=R26+α·B_t`，B_t按冻结teacher、自然变异尺度和支持资格构造；如以端点空间梯度校准α，校准只用已有几何及CPU可微函数，记录比例及分位数，不把它解释为真实FLOWR经过VJP后的增益。实际gX方向和剂量仍须在正常生成中验证。不要为分离两项gX另加生产模型forward或额外全模型反传；联合scalar保持一次reverse。

## 5. 两个可执行的顺序比较策略

### A. 自然分支尺度的正/反/零方向试验

将κ、局部a_k cap、资格和模式权重冻结，只改变α。先做空机制逐位控制，再在相同初始状态与随机流上比较正方向、反方向及R26；反方向需要新注册sign，不能偷偷翻转冻结reference。+d和−d使用完全相同的资格、尺度、预算及匹配，额外模式都保留原始背景。只根据自然变异尺度定义位移，实验α取小预算并公开其经验选择；不要从最终评分反调方向或资格。

以actual RMS剂量、累计动作成本 `Σ ||ΔX||²/dt`、clash回退和有效节点覆盖检查可比性；η保持R26时通常只是**请求剂量相近**，因路径改变后flow RMS也改变，不能声称实际总剂量完全匹配。如果正反都类似获益，可能是额外模式平滑/预算效应；只有正方向持续胜过反方向和R26，才支持方向信息有用。亲和力为主，应变作为后续质量约束，不禁止化学图变化。

### B. 先用baseline诊断冻结增益门，再配一个等预算固定门

原R26 reward不变，同次reverse已经可得 `G=RMS(gX)/RMS(gY_native)`。先用新接口空控制获得固定baseline，冻结G_ref，然后试 `h(G)=G/(G+G_ref)`。改变的是剂量分配，不能叫新空间reward或精确flow条件分布。

门控会降低平均剂量，故另做总预算相近的固定门对照：从baseline路径按predictive-flow RMS加权计算h均值，冻结补偿常数；以同一注册“单轴门法则”派生门与补偿，不把补偿当第二个自由超参数。candidate路径会改变G和flow，实际剂量仍要报告并检查容差，不能事后按亲和力重调。增益门优于低剂量固定门且实施响应明确，才支持模型敏感度的时空分配价值；若只是两者同样优于R26，优先解释为剂量降低而非新信息。

这两类顺序实验分别检验方向与dose，不能一起改变。原有time-envelope、parallel-precondition不与其叠加，避免再次无法区分机制。

## 6. 全窗口三维优势区域信息还缺什么

现在lag2的全窗口事实是：较大joint/internal innovation与较低在线评分关联（调整相关性−0.14993/−0.13733）；该规律不能自动变成“普遍限制变化”的控制。shape_yy与occupancy的相关性也不能单凭显著性优先推，因为绝对协方差可能极小。

仍缺四类具体信息：

- **同背景的有符号区域联合变化**：把祖先内3D变异分解到可重复的局部点云、区域相对距离/角度与受体占据共现，条件控制整体pose；报告原始Å位移、协方差、噪声及模式对应。RMS只有幅度，没有优化方向。现有权重不能单独命名官能团或残基作用。
- **条件于空间模式的跨批次方向支持**：整体Hungarian最近模板不一定代表相同局部生成状态；需要比较区域内联合方向与周围兼容性、分叉深度和状态背景。缺方向保存不可用，不补零；输出coverage、独立批次CI、留一批次验证与失败模式，不能只取正余弦。
- **选择压力与真实未来收益的区分**：所有在线标签参与selector，lag2分支仍条件于之前生存。当前数据没有被淘汰分支的native未来。若要作因果/长期判定，需要少量匹配分支恢复后的native续推（是独立推理试验而非每步额外forward）；本审计不执行。可先充分利用已观测的多个分支深度，所有缺未来保持删失。
- **奖励方向实际通过模型传递到哪里**：新增既有forward/backward hook只测当前奖励的敏感度。需保存区域gY/gX能量、分支创新/梯度角度、teacher切换、控制动作及最终质量关联的精简批次×时间统计；不能把attention或decoder梯度叫训练时的因果“重视”。

模型没有额外被训练，LLM没有凭空学习一个亲和力网络。数值工具负责确定性几何/谱系统计与紧凑存储，Agent负责有来源的假设与注册公式选择。有效字段、资格和时间支持由输入数据决定，不把当前分子或残基硬编码进Skills。
