# 选择机制、已有证据与尚未实现的特征

本文件是本轮发现结果之后的公开研究建议，不是冻结 Analyst/Designer 已消费的输入，也不宣称以下未实现方法已有性能反馈。当前实施与结果以逐轮报告为准。

## 为什么 Steer 有效

Steer 根据在线评分分配后续计算预算：评分较高的候选有较大期望复制数；复制状态和条件后，随机续推产生新的分支，再重新评分。它可以在不计算亲和力坐标导数的情况下保留多种有利路径。一次实际存活既受评分影响，也受随机重采样影响；“被留下”不能直接作为某个空间区域具有因果优势的标签。

现有 `selection_pressure.price_terms` 将任意一致定义的空间特征 f 分为原生生成变化、期望选择变化和重采样噪声：

`Δ_native = mean(f_proposal) − mean(f_current)`

`Δ_expected = Σ_i p_i f_proposal,i − mean(f_proposal)`

`Δ_realized = Σ_i (offspring_i/Σ offspring) f_proposal,i − mean(f_proposal)`

`Δ_resampling_noise = Δ_realized − Δ_expected`。

这些是精确记账关系，不是坐标力。平移/旋转、内部形变、区域接触和局部距离应以一致的坐标表示分别分析；不能将端点评分和积分提议的位置混为同一个量。

新增共同祖先工具进一步比较实际发生分化的分支，折叠立即复制的相同样本，并按祖先和生成批次处理统计单位。它发现再预测内部形变与评分的关联及少量区域 XYZ 方向，但方向证据弱于“区域具有显著标准化关联”这句话给人的印象。当前全窗口合格方向的拟合是常数，没有证明人为设置多个阶段切换有效。

## 仍值得挖掘的信息

|候选信息|为何可能解释高质量路径|如何确定性计算与避免误读|
|---|---|---|
|期望选择优势与随机存活优势的分离|高复制数可能来自评分，也可能来自抽样噪声|将已有 Price 分解应用于区域特征，保留批次曲线及全窗口效应；不把真实复制次数当独立样本数|
|刚体姿态和内部形变的分离|局部 XYZ 协方差可能只是整分子的转动或平移|在真实祖先内做匹配与刚体/内部运动分解，保留两个分量；固定蛋白坐标系中的整体姿态本身可能影响结合，不能一概删除|
|同一优势方向的跨祖先深度持续性|短期方向可能是再预测噪声，长期方向可能来自条件筛选|比较相同区域、相同单位、相同观察跨度的绝对效应、缺失支持与留一批次稳定性；长深度不增加独立重复|
|预测端点到真实积分状态的传递误差|高分预测可能在随后原生随机续推中被改变|联合现有 forecast innovation、native/proposal 距离与梯度时序一致性；不把已淘汰分支未观察的未来填成失败|
|坐标与自条件记忆的联合优势|Steer同时复制current、prior和cond_batch，高质量路径可能同时受空间状态及预测记忆影响|先沿真实复制索引核对上一预测端点与本步自条件坐标，再比较状态/记忆的区域一致性；现有forecast innovation只覆盖部分信息，完整条件状态审计尚未实现|
|教师模式切换与梯度冲突|相邻时刻切换目标可能消耗引导预算或破坏区域协同|记录匹配模式身份、后验质量、模式梯度夹角与实际注入；现有 gradient-lag cosine 只提供部分诊断，尚未完成模式身份审计|
|区域间协同接触 motif|单区域平均位置可能丢失高亲和力构象的联合相容性|优先使用低阶联合距离/角度和同祖先对照；控制多重检验，采用分块矩和紧凑效应表，避免保存所有原子对宽缓存|
|极高终态亲和力路径的祖先信用|平均在线高分路径未必产生极高终态分子|对已观察终态路径回溯祖先，去复制并与同背景对照；未继续生成的负分支是删失，不能假造反事实终态|
|真实模型对局部方向的响应|同样的端点空间方向可能在模型中被放大或衰减|使用真实 FLOWR 的条件 VJP和已记录敏感度。现有模块输出 RMS不能证明attention或affinity因果贡献；完整教师强制重放/模块干预尚未实施|

当前工具未重建中间分子的物理能量曲线。噪声状态不一定存在有效化学图；对其强行计算 MMFF 能量会引入缺失和选择偏差。现有能量评价是终态有效分子的 MMFF 应变，应与中间几何代理区分。

## 奖励与 flow 控制需分别检验

已有奖励保留完整教师模式，只为有观察支持的方向建立有界虚拟邻居。它是局部几何外推假设，不是学习得到的亲和力导数。新方向在固定输入上改变梯度、再改变真实路径，只证明实施；亲和力收益仍需独立配对检验。

当前真实 `J_Fᵀ ∇_Y R` 是当前端点预测对坐标状态的条件 VJP。控制被加到原生积分提议之后；它不是下一步模型的 Jacobian、完整未来伴随梯度或精确 FK/Doob 控制。实际 FLOWR SDE 项与普通确定性 flow 不同，不能直接套用在 t=0 奇异的通用 `(1−t)/t` 因子。奖励的全局倍数还可能被 RMS 归一化抵消。

已读取的实际 `fm_pocket.py` 还显示，SMC选择会同步索引current、prior和cond_batch。本次梯度控制保留原生条件更新，并在条件VJP中固定自条件；它没有复制整个高分条件状态。这是两种算法的重要差别，也是不能单凭坐标关联声称已完整模拟Steer的原因。尚未进行控制自条件记忆的因果对照，不能把剩余性能差距确定归因于自条件模块。

后续可检验的独立方向是：使奖励坐标表示与实际施加控制的状态一致；在不增加生产前向的约束下使用明确的局部近似；基于已观察模式冲突控制教师切换；以实际注入量而非名义权重比较预算。每项都应先新增对应诊断与受约束公式、经真正角色调用及空规则检查，再作单轴推理实验。不能仅因为数学描述更接近 flow 原理便宣布有效，也不能将负的“梯度与原生流夹角”自动作为拒绝门。

历史 Steer仍保留稀有高分路径发现、多个未来分支探索与在线重新分配预算的优势。有限历史路径的确定性局部奖励未必覆盖这些反事实未来；本轮六批冻结确认用于检验实际收益，而非证明两者采样分布相等。
