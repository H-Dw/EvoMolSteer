# 历史选择路径如何转化为 FLOWR 坐标控制

本文件记录可复现的科学假设、统计定义、公式与实施边界。实际逐轮指标和最终确认结论由 `progress.zh-CN.md`、`rounds_summary.csv` 与 `confirmation.json` 给出；不能把本文件中的假设当作已验证收益。它不是私有推理过程记录，也不是事后补写给冻结 Agent 的输入。

## 选择数据能回答什么

Steer 将在线评分高的候选赋予更大的期望复制数，复制其生成状态及条件信息，再通过后续原生随机生成得到新分支。它同时进行计算预算分配与路径探索，不必知道提升评分的坐标导数。高分只是存活概率更高；一次实际淘汰可能来自抽样运气。缺失的淘汰分支未来是删失观测，不能直接标为终态低亲和力。

历史记录必须区分当前状态 `X_t`、模型预测端点 `Y_t`、积分提议 `Z_(t+dt)`、在线评分和真实复制索引。FLOWR 的在线亲和力对应当步共享前向的预测端点，复制的是积分提议及条件。用 `X_t` 的坐标解释 `Y_t` 的评分、或把一个预测端点当成实际生成终态，会混淆选择机制。

立即复制的同胞端点坐标完全相同。本次真实记录的复制误差为零；共享预测的评分别名误差可到约 `1.91e-6`。因此，不能通过立即同胞差异制造“优势变异”。应沿真实复制索引回溯共同祖先，比较其下已经观察到的不同 immediate-parent 分支。早期谱系根数量下降，也不表示后期条件变异消失。

本次工具使用原历史单目标 Steer 的十四个发现批次，覆盖输入声明的学习窗口。当前数据中评分节点为 `0,.01,...,.49`，最后一次积分提议到 `.5`；工具不把它们分割成固定时间箱，也不把窗口外终态作为新的选择事件。最终亲和力、有效率和应变用于评价控制效果。这里的 flow 时间没有物理时间单位，坐标变化率不是分子动力学速度。

祖先比较中先折叠立即复制的重复分支，再在共同祖先内中心化，并给予每个可比较祖先相同总权重。批次是统计不确定性的基本单位，后代数不是独立样本量。几何与化学标签变化、整体姿态相关，调整项只是混杂诊断，可能移除中介信号；它不限制生成的化学图。

两步数据的联合再预测 RMS 与在线分数变化呈负关联：调整后相关约 `−0.14993`、q≈`0.000282`；内部再预测 RMS 约 `−0.13733`、q≈`0.000970`。对应绝对协方差只有约 `−3.60e-5` 和 `−3.42e-5 Å·pIC50`。部分标准化区域关联显著而绝对协方差接近零，不能仅凭显著性构建强吸引势。原分支场的逐步跨批次方向平均余弦约 `−0.00282`，同样不能据此宣称稳定坐标力。

选择创新工具还有一项反证：已观察子代再预测评分相对被复制亲本平均下降约 `.03633 pIC50`。Steer 可以保留相对较有利的路径，却不保证每条已保留路径的绝对在线预测分数逐步增加。再预测的一致性值得测量，但负相关也不能被直接翻译成“禁止坐标变化”的规则；坐标探索仍是发现更高分路径的来源。

较长共同祖先深度进一步暴露了局部方向：例如区域 17、深度 5 的 +y 分量相关约 `+0.12257`、q≈`0.003922`，绝对协方差约 `+3.85e-6 Å·pIC50`；区域 13 同深度的 −y 协方差约 `−8.68e-6`。全窗口平均方向比逐步方向更一致，但窗口平均不能证明每一步方向一致，批次两两余弦的配对数量也不是独立样本量。

XYZ 趋势采用整窗多项式候选和留一批次交叉验证、1-SE 简化规则，并保存函数与导数。用于区域规则的合格 XYZ 最终选择的是常数拟合，其导数为零。这表示现有证据支持一个全窗口平均关联，没有可靠发现多阶段方向切换。不能为了“多阶段奖励”人为设置区域阶段；实际奖励仍通过时间对应的完整教师点云与当前模型端点连续变化。

最初的区域合成混合了不同祖先深度，可能让较长观察跨度的绝对协方差主导场。新工具以合格区域数量、平均 LOO 正方向支持、较浅深度的固定顺序，只用发现统计选一个共同深度。得到深度 3 与区域 `[3,6,11,12,16,17,18]`；数值编号属于本次数据输出，不写入通用 Skills。此修正避免混合观察跨度，仍不把协方差变成因果梯度。

## 从数据特征到受约束奖励

保留历史 R26 的完整联合教师点云 `T_k(t)` 与评分先验，而不是分别吸引到各区域平均坐标。四个邻近教师的先验来自固定坐标匹配代价与在线分数。几何模式保留局部区域之间的相容关系；独立区域吸引可能拼接出历史中不存在的构象。

对共同深度 d、区域 r 计算冻结的协方差函数 `C_r(t)`，用教师端点上的软区域密度形成联合场：

`h_ri = exp(−||T_ki−L_r||²/(2w²))`

`b_ki = Σ_r C_r(t)·(h_ri−mean_i h_ri)`，`d_ki=b_ki/RMS_atom(b_k)`。

这是一个去整体平移的联合点云形变，w 当前为 4 Å。它没有移除刚体旋转；区域重叠、弱密度与单位 RMS 归一化仍可能放大不可靠相对方向。完整 XYZ 中也可能包含单独不显著的分量。原分支描述性 confidence 不能当作新区域的概率校准。

新分支混合公式设置虚拟邻居：

`T'_k = T_k + sign·a_k·d_k`，`a_k=min(历史实际分支 RMS,0.2 Å)`。

只有实际存在不同共同祖先后代、较低评分对照及有效方向时，资格 `e_k=1`；缺失节点为零。原模式质量为 `π_k(1−αe_k)`，虚拟模式质量为 `π_kαe_k`。参数 α 是奖励混合预算，不是生成高质量分子的概率；该公式不新增神经预测器，也不替换原教师。

固定 Hungarian 对应后，令 `q_m=N⁻¹Σ_i w_mi||Y_i−T_mi||²`，区域代价权重默认为 1，

`ρ_δ(q)=δ²(√(1+q/δ²)−1)`，`R_t(Y)=τ log Σ_m p_m exp[−ρ_δ(q_m)/τ]`。

当前 δ=1 Å、τ=.5 Å²。其端点空间梯度为

`∇_(Y_i)R=−Σ_m posterior_m·w_mi(Y_i−T_mi)/(N√(1+q_m/δ²))`。

这是真实可微坐标奖励。它基于观察方向的局部外推，不能声称等于亲和力导数。虚拟邻居方向正/反实验、零质量精确 null、强度单轴实验共同检验这项假设。

## FLOWR 原理与控制接口

真实模型输出 `Y=Fθ(X,C,P,t)`，主控制方向是

`g_X=J_Fᵀ·scale·∇_(Y_world)R`。

J 来自实际 FLOWR checkpoint 的自动微分，没有构建 Jacobian 拟合模型或稠密 Jacobian。旧自条件、离散标签与本步教师对应冻结；这是条件于当前状态的端点 VJP，不是从 t 到终态 1 的完整随机、离散生成 Jacobian。

实际积分器同时包含 flow、score 漂移和随机坐标项。已核验源码的非 cosine 设置为 `v=(Y−X)/(1−t)`、`g=1/(t+.01)`（t<.9）、`score=(tv−X)/(1−t+ε)`，原生提议为 `Z=X+dt(v+g·score)+dt√(2g·noise)ξ`。噪声项在该实现中乘 dt，不能直接套用标准连续 SDE 或简单 ODE 的分布保证。

当前控制在旧 X 处计算、原生积分提议 Z 后注入，因此只能记录旧状态奖励的一阶方向估计，不能称为新 Z 处真实奖励增量。原生提议的条件 Jacobian 还包含 identity 与实际 dt/schedule 系数，不等于 J_F。完整推导见 `model_compatibility_audit.md`。

控制方向按 `η·predictive_flow_RMS` 校准，再受逐原子位移、累计 RMS 与新严重受体碰撞上限约束。默认 η=.33，逐原子上限 .15 Å，累计 RMS 6 Å。奖励乘一个全局正常数大部分被 RMS 归一化抵消；相对奖励权重影响方向，η/gate 影响有效剂量。不同方向在约束作用下也可能有不同实际剂量。

因此，单独检验 `g_perp+s·g_parallel`，以及同一次反传可取得的无量纲增益 `G=||g_X||/||g_(Y_native)||`、有界 gate `G/(G+G_ref)`。负的梯度—原生流余弦不自动等于错误方向；必须通过配对实验判定。gate 与均匀减小 η 的对照仅作预先冻结的剂量代理匹配，真实注入 RMS 仍需报告。

引导复用每步一次正常 target 前向并增加一次奖励反传；原生 `_generate_selective` 的 untarget 诊断前向保留，所以这不是每步模型总调用数为一。没有额外生产 target 前向、affinity-head 求导、粒子重采样、原子类型目标或化学图 gate。每个梯度批次的一次有限差分检查使用两个步幅的中心差分，共四次额外 target 前向，单列于 preflight；终态 target/untarget 重评分也另算。窗口完全从输入读取；当前 50 个学习步后，剩余 50 步原生无引导推至 1，并最终预测亲和力和本地评估构象/应变。

## Agent、Skills 与反馈闭环

本次实际运行了 Analyst/Designer subagent，并保存原始响应、规范响应与校验结果。并非为每个参数试验调用一次新的 LLM。三套独立知识版本保留各自的请求、literal Skills、registry、tool receipts 与完整输入/源码/输出哈希；新区域参考使用新工具身份，不冒充旧 branch 工具输出。

Analyst 消费确定性脚本结果，明确共同祖先、绝对效应、反证、缺失支持和依赖观测；Designer 消费已导入 Analyst 文档，并只能选择注册的坐标公式与单一有界参数。程序由校验器编译，不执行任意 LLM 返回代码。当前区域 Designer 选择 α=.05；随后预登记同预算反方向与 α=.15 单轴试验。

API 接口仍可通过各 `flowcompat_*_agent.py --action api` 使用明确配置的 OpenAI-compatible 服务。API 和 subagent 响应走同一 schema、证据引用、输入/源码哈希与编译校验。真实外部 API 本次未调用；不能把 subagent 模拟报告成 API 性能测试。

实施门先于终态亲和力分析：核查 actual tool receipt、字面量指令/响应/程序绑定、原教师不变、固定端点梯度差、真实模型 VJP、配对窗口坐标响应、窗口内覆盖与窗口外零注入、初态/RNG、精确空规则算术及真实最终 null 一致。非零旧梯度不证明新知识生效。

实施门通过只表示机制已部署并扰动生成；是否有益是下一项独立检验。筛选使用配对的全部尝试平均预测 pIC50、批次方向和有效率/PB，最后冻结一个候选在六个新批次确认。确认期间不调参。失败/未确认方案保留报告与提交记录，默认恢复历史 R26；所有删除只针对本次已校验报告对应的生成文件，原 Steer 和 checkpoint 保留。

## 仍未得到的数据与适用边界

历史文件没有模型 hidden activation/attention 或模块干预记录，不能从坐标反推出“哪个模块因果关注哪个区域”。同一反传的 decoder 输出 RMS 只是当前奖励的敏感度，不同输出单位与形状不同；比较只能在同一模块/同一输出表示内进行。未来若需因果归因，应另行登记小样本区域条件干预或模块干预并计入额外前向预算，不能混入当前生产推理。

尚未实现为控制知识的候选包括：去刚体旋转后的区域方向持久性、teacher/对应切换与局部梯度转向、局部点云谱/跨区域接触共现、选择概率预期富集与实际复制运气的分解、删失路径的有界未来价值估计。这些可继续作为独立紧凑工具探索，但不能在本轮报告中伪称已经证明或已被冻结 Agent 消费。

中间流状态也并非每一步都是可 sanitise 的物理分子，当前新方向工具不声称取得了真实中间势能曲线。终态应变和 PoseBusters 检查作为次级质量指标。历史 Steer 的供体参与奖励设计，样本量和在线评分预算不同，因此只作非配对参照；当前模型预测亲和力改善也不等于实验结合常数改善。

## 文献依据

[Feynman–Kac steering](https://arxiv.org/abs/2501.06848)支持将 Steer 理解为以奖励重新分配粒子路径预算；它不保证把历史坐标协方差直接转为无重采样梯度就能得到同一分布。[On the Guidance of Flow Matching](https://proceedings.mlr.press/v267/feng25s.html)区分一般 flow guidance 与条件近似，支持明确状态、Jacobian 和调度假设。[Training Free Guided Flow Matching with Optimal Control](https://arxiv.org/html/2410.18070v3)强调完整动态响应与控制代价；本项目只借鉴诊断思路，没有实现其多次完整轨迹求解。

[Feynman–Kac–Flow](https://arxiv.org/html/2509.01543v1)进一步讨论了确定性 flow 中复制路径缺少新探索的问题，以及引入保持边际分布的随机动力学。它仍采用粒子重采样，不是本轮无需重采样的梯度控制实现；其连续 SDE 假设也不能直接替代已捕获的 FLOWR 积分源码。[Price 方程的选择/传递分解](https://pmc.ncbi.nlm.nih.gov/articles/PMC4415573/)为谱系内外比较提供概念依据，但坐标—在线评分协方差不是繁殖贡献的完整 Price 分解，更不是空间因果梯度；[因果分析讨论](https://pmc.ncbi.nlm.nih.gov/articles/PMC7133506/)也明确了协方差分量不能自动解释为独立因果作用。

实际 FLOWR 执行版本以 checkpoint 和捕获源码 SHA 为准，参见 [FLOWR.ROOT 作者仓库](https://github.com/jule-c/flowr_root)。没有宣称严格 FK/Doob 控制、完整 OC-Flow 或注意力因果解释。
