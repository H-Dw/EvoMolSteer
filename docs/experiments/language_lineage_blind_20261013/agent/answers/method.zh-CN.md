# 语言先验盲选方法

规则由人工预先固定：对每个匿名状态与同一 t 的五条 P 描述计算几何绝对差。当前云与预测终点云各半权重；使用 Rg、三个二阶矩、2.5/7 Å 对核、最短间距，及 R00/R05/R15 的质量、局部偏移和壳层核。父子当前位移 RMS 与终点修订 RMS作为较低权重稳定项。所有量按固定容差归一化后取平均，分数越小越匹配。局部区域和全局形状同时参与；current 与 forecast 分开比较，不把终点硬标签或未来状态用于早期。该规则只表达结构相似性，不能推出能量下降、亲和力或终态质量。

回放使用状态卡中的真实 parent 关系：每一步只保留上一排名 ID 的可见子状态，排序后最多五个；无子状态即停止。程序自动执行数值排名，人工决定的是上述公开规则。
