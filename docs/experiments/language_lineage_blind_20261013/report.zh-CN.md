# 语言先验识别Steer优质祖先：实际盲选与逐0.01回放

本次已完成五条优质候选的语言描述、GPT-5.6 Luna subagent盲选、五组逐0.01历史分支回放和主agent解盲核验。**同阶段几何相似性在0.30识别到了测试集最优终态的祖先，但没有稳定识别早期祖先，也没有保住已识别的优势路径：该路径在0.40被几何匹配排序排到第六，遭到五方向预算淘汰。**

这说明本次Agent执行的匹配规则尚不能替代Steer选择。被原始Steer淘汰的状态没有终态标签，不能由本实验断言它们的反事实亲和力低。

## 数据、时间和盲法

- 原始数据：`ck2_clk3_lineage_20261003/results/main1000_w050/single`，单目标Steer臂，固定seed=42，20批次，每批50槽位，每分子25原子槽位、100积分步。
- 描述教师来自批次0–13；识别池来自批次14–19。形成本次语言先验时二者分开。后者曾被历史项目使用，因此这是本次描述形成的批次隔离测试，不能声称项目从未使用过这些数据。
- 教师：有效连通、PB快速通过、MMFF收敛、应变/重原子不超过训练质量合格群体90%分位数，再按最终共同重评分pIC50排序，每独立批次至多取一条，共五条。P1–P5随机分配，不表示排名。
- 优质祖先真值：至少一个符合上述质量要求的已观察终态后代，最终pIC50不低于训练质量合格群体95%分位数8.258940792；应变上限1.338823508 kcal/mol/重原子。阈值在盲选前冻结，不由测试结果调整。
- `t`是模型输入/评分时刻；`proposal`是积分后`t+0.01`的状态。父子关系使用`selected_indices[t, child]`，不能把固定槽位号当作持续身份。
- 原始记录在评分时刻0.00–0.50（含两端）有51次重采样事件；0.50事件产生0.51状态。本次五方向回放比较的是当前态0.01–0.50。教师完整描述另外覆盖0.00–1.00，每0.01一节点。
- 同批、同刻完全相同的当前坐标、原子、键、荷电状态合并；重复槽位数、选择概率、评分、根身份、最终后代数和来源批次不交给subagent。
- 模型：GPT-5.6 Luna，空白历史上下文。subagent只获语言先验、匿名状态卡和协议；几何数值允许使用，预测affinity数值全部保留在主agent oracle。原始三维坐标可选提供，但实际选择程序没有读取它们。
- 五个初始条件先按时间顺序排名并封存；此后才能逐0.01读取后续测试状态。每次只能从前一批保留方向的已观察子状态中继续选择，最多五个，不重新注入其他方向。
- 这是历史Steer已生成分支的回放，不是新的FLOWR生成，也不模拟被淘汰状态在新选择策略下的后续发展。父子链接在下一节点揭示时会透露该步已发生的生存，但初始排名不获未来链接。
- 盲法是目录访问约定与调用/文件日志审计，非操作系统隔离；共享文件系统下不能宣称不可突破的安全盲法。

## 优质候选究竟怎样生成

五条路径的共同形态是：**噪声槽位云在首步明显收缩，随后随着生成时钟逐渐展开；模型预测的终点几何则从早期就呈较扁平、较展开的形状，并在局部口袋区域不断修订。** 当前态的展开和预测终点的修订是不同过程。

记录中首步当前回转半径从1.39–1.91 Å收缩到0.086–0.116 Å。这是实际积分记录，不能说成分子通过能量下降“塌缩成优势核心”；原始运行启用了SDE积分，其早期状态也不是物理成品分子。

随后每0.01都有实际父子边。到0.05，当前回转半径0.164–0.202 Å；到0.10为0.342–0.367 Å；0.20为0.697–0.719 Å；0.30为1.027–1.066 Å；0.50为1.732–1.812 Å。同时预测终点的回转半径保持约3.39–3.64 Å。仅匹配“早期很紧、后期逐步展开”主要是在识别生成时钟，未必能区分优质和普通分支。

预测终点在固定受体坐标系的三个二阶矩通常表现为一个轴较薄、另两个轴展开；最终解码分子多为稠合芳香/杂芳香体系。这不表示早期硬键已形成稳定环，也不等于证明平面化是亲和力提升的原因。

既往Analyst的训练证据给出了短程pair核正向、7 Å长程核反向、R00壳层占据正向的选择关联。后续时序Analyst进一步指出：局部坐标分量反复换号，不能将全窗口平均方向当作每一节点都要执行的指令。本次描述因此保留五条完整路径，而没有制造一条“所有优势种都单调向R00靠近”的假轨迹。

三个锚点来自受体实际原子：R00=VAL A53 CG1，R05=GLY A48 O，R15=GLU A52 CB。它们是几何参照，不能仅由锚点名称断言具体结合功能。高斯质量以5 Å核计算，3 Å壳层核的宽度为1 Å；这些都是无量纲坐标分布代理，既非作用能也非接触计数。

## Subagent实际执行了什么

subagent自行编写文本解析和匹配程序，将自然语言中的几何数值提取为47维向量：current 22维、forecast 22维、三个RMS。每个候选与**同一时刻**的五条教师计算归一化绝对差，取最近教师，再取分数最小的五个。相邻节点允许切换最近P路径。

这是一种由LLM提出、程序自动执行的语言到几何匹配规则，**不是每个节点再次调用一次LLM，也不是纯定性语言判断**。五个初始排名和后续回放来自同一个冻结程序。

主agent与用户没有指定数值容差；`.08/.12/.25/.18/.35`由subagent自行设置，未经过统计校准。代码按向量索引分段使用容差，混合Å、Å²和无量纲核。虽然current/forecast字段数相同，实际有效权重并非严格各一半。

执行审计还发现，程序**没有解析或使用已提供的绝对全局重心、有符号局部坐标增量、各特征变化率**；只附加了非负RMS。它也未对最近P路径跨时刻切换施加连续性要求，没有检查被保留五个方向是否都挤在同一几何模式。详见[执行方法](agent/answers/method.zh-CN.md)、[subagent事实自审](agent/answers/self_audit.zh-CN.md)和[主agent程序审计](evaluation/selector_audit.json)。

## 没找对、没保住的具体原因

### 1. 早期描述相似，并不等于判别优势

当当前云都接近一个很小的团块时，Rg及形状的阶段性变化对大量候选都成立。程序识别到了“像该阶段的教师”，却没有建立“为何比同阶段失败对照更好”的判别规则。主agent解盲发现几何相似度与当前模型评分的Spearman相关仅约0.020、−0.078、0.074（起始0.01、0.05、0.10），几乎没有共同排序。

两个真正的优质祖先在0.01的程序匹配排名为21、166；0.05为99、186；0.10为121、131。不是初选池里不存在优质祖先，而是本次语言到数值匹配把它们排到了预算外。其偏离教师外观不能证明它们结构低质。

### 2. 提供了动态信息，Agent却没有落实到执行函数

语言卡明确给出每0.01的局部dx/dy/dz变化和变化率。程序只匹配状态数值并使用三个非负RMS，无法区分“向某个方向修订”与“同幅度朝相反方向修订”。也没有比较预测终点位移与当前生成位移之间的方向一致性。

这属于执行功能缺失，而不能把结果全归因于LLM不理解三维数据或语言描述没有动态信息。后续若试验方向导数或路径一致性，应先核验这些字段确实进入了排序函数，再判断它们有无增量作用。

### 3. 0.40发生了可以定位的主动误剪枝

0.39尚保留优质祖先，其下一刻有6个真实可见子方向。预算为5，程序保留前五个，将`Ca6b4a2ec7b`排到第六。该方向是唯一包含8.584398终态的祖先，几何距离0.232702；第五名`Cfbce64174c`距离0.229796，没有已观察终态后代。两者仅差0.002906。

二者都匹配P5，预测终点十分接近：被删优质方向Rg=3.574 Å，第五名3.575 Å；短程核同为约0.269，长程核同为约0.213，R00质量同为约0.577。被删方向预测二阶矩(0.053,6.455,6.264)，第五名(0.052,6.474,6.255) Å²。当前云Rg分别1.409、1.410 Å。

分组贡献表明，二者forecast误差几乎相同（约0.14721与0.14725）；优质方向的current匹配误差略高（约0.08014与0.07695），RMS误差则略低。固定容差的微小排序差别决定了淘汰，不能说被删状态在真实结合几何或能量上更差。

与此同时前四名是更贴近P3的另一个模式。五方向预算被一个相似模式大量占用，缺少模式级保留策略；这解释了“先发现、后丢失”，不是原始Steer没有继续生成优质子状态。这里只说明该规则的失败位置，并未验证增加多样性一定改善亲和力。

### 4. 中间头评分、最终读出评分、结构摘要都不等价

0.20的第二名中间模型pIC50约9.143，但其质量合格终态后代最大值仅7.780；第三名中间约9.119，终态最大7.967。subagent从未看到这些分数，它们只是主agent事后核验。预测终点外观和中间评分都可能修订，不能把一次终点预测当成确定的最终构象/质量。

此外47维摘要遗漏坐标分布中的部分信息，例如完整局部协方差、非对角分量、逐区域内部排列和预测变动方向。三维结构不同可能被映射成近似相同的摘要；加入这些信息是否有增益，需要新的盲测验证。化学图变化允许发生，不把图变化当作质量下降的原因，也不提出限制化学图的gate。

### 5. 原始Steer选择含有本实验刻意隐藏的随机性

每次原始Steer依据模型分数随机重采样，短期生存不是确定性几何阈值。只知道结构摘要，通常不能准确复现一次已发生的随机选择。早期祖先收敛造成严重删失；若要评价被历史Steer淘汰但语言匹配良好的方向，应从其保存状态恢复、用相同预算进行独立续生成。本次没有运行此类反事实实验，不能把删失伪装成负亲和力样本。
