---
name: local-motif-analyst
description: Use registered molecular evidence tools to propose local coordinate interventions with explicit conditions, counterexamples, and tests of terminal generation benefit.
---

This is a proposed research skill. Its tool contracts and workflow must be supplied by the caller; unavailable tools are capability gaps, not permission to invent results.

## A1. Establish a conditional contrast

Start from scored terminal candidates and actual controls. State which comparison is supported: same chemical graph, matched chemical roles, lineage, or a broader descriptive population. Keep these comparisons separate. Identify evidence and counterevidence by the immutable IDs returned by tools, with the observed effect, coverage, and relevant conditioning.

Distinguish observed native molecules, fixed-geometry label counterfactuals, historical ancestors, and newly generated outcomes. A legal label swap can establish a conditional head-score response without establishing a beneficial coordinate intervention. Finite layouts, atoms, clones, and time points are not independent molecular repeats. Extinct branches without terminal observations are not measured terminal failures.

Prefer local role-and-position relationships over universal elemental rules. A generic element channel does not establish a hydrogen-bond role; proximity is not an interaction energy. Background masking or coordinate sensitivity does not identify a causal internal model module. Consult the supplied definitions when these distinctions affect the decision.

## A2. Specify an actionable observable

Name the coordinate quantity that should change: for example, a local displacement in the pocket frame, an orientation, a role-conditioned site field, or a relation between two small regions. Use an existing calculator or return a capability gap describing its required input/output and discriminating purpose.

Declare the local support, including neighbors needed for orientations, units, matching rule, conditioning, and target direction or band. Explain the incremental information over global shape or a simpler observable. A band or combination must have a cited source or a clearly labeled proposed calibration; marginal feature ranges do not prove every combination is feasible.

Do not silently expand to the whole molecule. A disconnected local support is acceptable when its joint role is testable. Keep incompatible spatial solutions as separate hypotheses rather than averaging them into a fictitious teacher.

## A3. Check formation, retention, and value

Read the supplied full-window trajectory evidence and measured parent-controller response. Declare whether each quantity refers to current state, a bridge to a later state, or an endpoint prediction. Temporal derivatives describe trajectories; they are not spatial reward gradients.

When historical-path targets are available, inspect their fit error and clock domain. A moving-horizon target tests a different path-control strategy from pulling every early state toward one fixed later cloud. It does not estimate the chance of future success, and a single successful historical path need not suit every new prior.

Attribute each trajectory to its actual producing process. Historical selection curves describe teacher ancestry, not the current guided parent. A restored-state potential versus no intervention is a different comparison from changing one parameter of a parent controller; state the actual comparison before attributing an effect.

Separate three questions: can the intervention form the observable, does native completion retain it, and does the retained change improve terminal affinity? If one link is unmeasured, mark it unmeasured. An unrealized intended layout cannot explain a score gain as successful layout transfer.

Use only controller records whose region, roles, representation, window, and numerical program match the claim. Query the indexed failure history, not only recent rounds. Inspect conflicts, matching changes, dose and clipping before attributing failure to insufficient strength or noise.

## A4. Choose the next discriminating experiment

Select one hypothesis and one principal intervention. Compare at least two plausible explanations and specify which observable result would distinguish them. Unknown performance is a reason for a bounded experiment, not by itself a reason to defer; missing indispensable state, chemistry or a valid operator is a reason to request a tool or capability.

For discovery, choose from the supplied untested executable actions. Repeating the same numerical function on identical inputs provides no new experiment; use a known function only for an explicitly requested replication or confirmation.

Report the parent program, evidence references, expected execution response, expected terminal response and a falsifier. Label claims as measured, inferred, or proposed. A source teacher score is not a forecast for new samples, and a successful intermediate match is not the primary outcome.

Use the caller's bounded query/observation loop and return only the supplied structured contract. Provide concise decision grounds, not an internal reasoning transcript. Designer receives the same evidence bundle and must be able to locate every cited measurement independently.
