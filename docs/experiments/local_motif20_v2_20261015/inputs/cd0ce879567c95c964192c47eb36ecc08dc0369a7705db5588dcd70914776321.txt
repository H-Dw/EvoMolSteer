## D1. Bind the hypothesis to executable terms

Read the Analyst hypothesis and its cited measurements and counterexamples in the shared immutable evidence bundle. Bind every active term to an Analyst observable, support, and evidence ID. Keep the selected teacher or target relation, conditioning, units, and matching semantics explicit.

Do not add points, switch chemical roles, or substitute a generic element objective for a missing geometric operator. Return the hypothesis for revision if additional support is necessary. Choose the smallest implemented operator that can test the hypothesis. Local target bands, relative geometry, or separately represented modes may be appropriate; exact teacher imitation is not automatically the objective. Do not combine independently supported marginal ranges into an untested joint optimum.

## D2. Explain actual response and dose

Read the parent program and response probe before choosing parameters. Distinguish raw reward scale, component direction mixture, spatial curvature, and actual coordinate displacement. Common scaling can disappear under normalization; detached assignment costs change correspondence rather than directly adding a differentiable force.

Declare each changed parameter, its parent value, unit, source, and expected measurable effect. Check whether a nearly satisfied term retains an unnecessary normalized force and whether components conflict or are clipped. Preserve one principal experimental change; calibrate the dose of a new operator separately from changing its scientific target.

A target-band controller should reduce force when the target is attained. Its response and zero-gradient behavior require deterministic checks. Do not claim a confidence multiplier changes a fixed-state gradient direction unless the implemented composition actually does so.

## D3. Respect representation and native dynamics

Bind each target to the same state representation and time as its observable. A bridge evaluated at a later clock uses a target at that clock; a current-state trajectory target uses current time. Read learning and control windows from supplied configuration rather than embedding them in the skill.

Use the implemented true-generator coordinate VJP. State that it is conditional on the current model call and saved conditioning, not differentiation through all future random steps. Require a native-completion check when the hypothesis depends on persistence beyond control.

Maintain the supplied coordinate-control scope, native protocol, graph freedom and local support. Do not introduce affinity-head derivatives, per-step affinity inference, particle resampling, or categorical logit control under the name of a coordinate reward.

## D4. Make the decision testable

Return the hypothesis ID, evidence hash, parent program hash, positive-weight terms, support hash, parameter changes, target representation, clocks, and required checks. Any claim of an anchor, orientation, or role effect must correspond to an enabled operator with nonzero measured response.

Specify both a control-level falsifier and the terminal evaluation. Improved similarity, role retention, or lower loss alone cannot establish affinity improvement. Evaluate affinity first and report structural and energy side effects using the frozen definitions.

Defer for an invalid mapping, missing indispensable evidence, or a numerical no-op; label interface failures separately from scientific negative results. Use the supplied schema and return only structured output. Provide concise design grounds and reproducible choices, not an internal reasoning transcript.
