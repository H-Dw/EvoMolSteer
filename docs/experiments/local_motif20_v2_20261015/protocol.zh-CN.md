# 局部motif auto-research v2执行协议

本campaign获用户新授权，重新计数，最多20个顺序研究决定。R01/R02为各12次原生后缀完成（含对照）的机制诊断；R03–R18为自适应局部函数/区域/控制单因素研究；R19/R20冻结所选程序并扩大至50个原池/新池输入。工具与API正确性测试、冻结对照重放另外记录成本，不冒充新的科学方向。

主目标为终态预测亲和力。筛查阈值在新结果前冻结为原始961个基本合格终态的q90=8.135048866271973。主要尾部产出U为全部尝试分母的合格正超额均值；同时报告全部有分数尝试均值、覆盖、失败、最高合格分数和超过8.7048063278的数量。均值退步容忍.03；U数值比较容差.0005；连续两轮下降恢复活动最佳。只有新池冻结确认支持才登记验证最佳。

根种子42。后缀使用显式派生child stream，恢复prior/current/conditioning/times，不声称重放历史RNG。所有真正生成保持原生类别/图变化、无SMC、不对affinity求导、不增加逐步affinity调用；控制只在声明学习窗口内，随后原生到1。局部直接支持必须是严格子集。

Analyst/Designer真实DeepSeek API：deepseek-flash，沿用temperature=0和thinking disabled。两角色读取完整相同证据，有限工具查询后提交结构化假设与可执行函数。算子未知时返回能力缺口；未有终态收益不是拒绝一个合理前瞻实验的充分理由。

S0首个真实API测试发现工具规划question过长，以及输入未充分说明已有几何算子，导致不必要的能力缺口。保留原失败请求于functional/，在functional_v2/明确算子注册表与问题阶段。后续验证不修改旧调用记录。

每轮本地提交并push，远端经本机代理拉取指定commit才推理。结果下载逐文件SHA256核对后，远端删除派生SDF和坐标geometry，保留评分/失败/控制报告。原始Steer、冻结模型和本地可复现结构始终保留。
