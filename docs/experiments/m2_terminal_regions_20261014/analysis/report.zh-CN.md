## Agent 实际读取了什么、实际运行了什么

使用真实 DeepSeek API 的 `deepseek-flash`：Analyst 七次 action 调用，Designer 一次调用，全部正常 `finish_reason=stop`。Analyst 的两次过早 finish 因尚未读取三条不同区域曲线/引用不完整而被确定性科学校验拒绝，随后继续调用工具补齐，最终完成。没有把失败 Agent 输出替换成 M2 后冒充局部实验。

全体 20 个历史批次动态划分为 16 个发现批次和 4 个留出批次。Top10 根据**发现批次的终态预测 pIC50**选择，保留有效结构并按 SMILES 去重；通过真实 `selected_indices` 回溯，包括学习窗口之后的选择记录。它们在最后学习节点合并为九个不同祖先。教师是这些祖先在 score time=0.49 的**预测端点点云**，在引导窗口内固定复用；不是最终解码 t=1 构象，也不是 noisy current state x₀.₄₉。Top10 没有独立路径根去重，因此不能解释为十条独立路径。

本轮特征为 20 个固定空间 landmark × 10 个坐标统计量：Gaussian soft mass、局部三维一阶矩和六个协方差分量。比较未来产生 Top10 的真实祖先与有已观测有效后代的其他分支；分析区域特征与未来终态效用的偏秩相关，控制当前评分。无已观测终态后代的节点保持缺失，不视为低亲和力。全窗口汇总只积分相邻有效节点，不跨缺失时段插值。

Analyst 读取区域目录和以下三条实测曲线：

1. `future_partial_correlation/landmark_19_soft_mass`
2. `future_partial_correlation/landmark_08_local_dz`
3. `future_partial_correlation/landmark_00_cov_xy`

Designer 选择 **region 19、radius=4 Å、weight=1、global background=0**。Region 8 在所提供的半径下没有教师点云支持；region 0 的终态相关证据较弱。选择置信度是 exploratory，不能称为已经证实的关键结合区域。

region 19 soft mass 的发现效应为 +0.22297，区间 [0.10412, 0.34359]、p=0.00396、**q=0.19944**；留出效应为 **-0.14503**，区间 [-0.36963, 0.21345]、q=1。留出估计方向相反但区间很宽，不能称为确认反向；也没有复现发现组正向关联。发现曲线仅在 **0.31–0.49** 有可计算值，范围约 [-0.19851, 0.64424]。早期缺失表示不可辨识，不能解释为效应为零。

Designer 原文有两处需要纠正的解释，原始回答保留：一是 q 实际已经对每个 split 的全部 200 个特征、两种统计量合计 400 项作 BH 校正；二是固定教师点云匹配并不保证 Gaussian soft mass 增加。格式/引用校验成功不等于科学解释已被自动证实。

## 为什么本次局部奖励退步

确定性执行日志见 [execution_and_evidence_audit.json](execution_and_evidence_audit.json)、[guidance_batch_summary.csv](guidance_batch_summary.csv)。

四组真实 FLOWR 端点 VJP 均通过有限差分校验；窗口内没有零注入事件。局部最近教师区域 RMS 从约 0.422 Å 降到 0.105 Å，延迟组从约 0.177 Å 降到 0.102 Å。这个首末差包括模型自身演化和最邻近教师变化，不能独立归因为 guidance，但证明记录中的局部距离已很小。逐步一阶奖励响应都为正，是梯度上升的局部性质，不能替代最终亲和力评价。

本轮直接验证的事实是：引导生效、局部距离缩小，最终亲和力和应变却没有获得所希望的改善。以下是由代码与证据支持、仍需分开测试的原因假设：

- **目标过于稀疏。** 4 Å 支持范围在九个教师中各只有一个原子；跨四教师匹配的核心平均约 1.05/25 个原子。单点匹配没有明确限定局部取向、邻接几何或整体口袋配合。Hungarian 匹配仍允许不同原子索引充当该点，保持化学图可变。
- **统计特征与奖励不一致。** Gaussian soft mass 使用所有原子的连续距离贡献，而实际奖励对 4 Å 之外的教师原子严格置零，并最小化局部点云距离。选出“soft mass 与未来评分相关”的区域，并没有给出“匹配其一个教师原子就会优化亲和力”的干预依据。
- **“零背景损失”不等于局部当前状态位移。** 端点奖励在核心之外的直接梯度为零，但 `J_FLOWRᵀ∇R` 会耦合到其他当前坐标；约 86% 的实测注入平方范数位于匹配核心的索引之外。这不是偷偷添加全局奖励，也不是化学图变化 gate。它说明局部端点目标并不能自动保证其他区域不受影响。
- **相同总 RMS 强度不等于相同空间分配。** 全局和局部均实际注入校准位移的 33%，局部只剩一个稀疏目标却仍使用全分子的剂量归一化。现有数据支持排查空间剂量和目标维度，但不能仅凭这一观察断言稀疏梯度一定过强。
- **时序与可靠性不足。** 目标来自最后节点，区域正向关联仅是发现组晚期可观测统计。两个窗口都把它施加到更早的状态。延迟到 0.1 仍早于可观测关联出现时刻，并且少了十次更新。此次比较检验的是“延迟且减少总引导”的组合，不能把所有变化单独归为开始时间。

本轮没有逐分子模型 attention/module attribution，不能认定某个 FLOWR 网络模块导致优势。也不能把化学图多样性上升作为分子质量下降的原因。

## 后续方向与当前选择

保留冻结 M2；本轮数值最优候选为 Top10 全局 0–0.5，可以作为进一步研究的父版本，但不宣布已经显著超过 M2。局部两组保留为失败证据，不替换现有基线，也没有自动启动下一轮。

下一轮应优先核验“证据特征→可微 observable→实际空间响应”的对应关系：给候选区域增加多原子几何与整体运动的条件对照，明确哪些证据可跨批复现；直接设计与已挖掘 observable 对齐的奖励，避免把占据效应直接替换成单点匹配。若测试更宽局部支持或少量全局兼容性项，应创建独立配置，不能改写本轮零背景条件。剂量与时序需分别探索，实际 FLOWR 回传的空间分配必须同时报告。每条路径仍按真实父子索引回溯，并将独立路径数与终态图去重分别处理。
