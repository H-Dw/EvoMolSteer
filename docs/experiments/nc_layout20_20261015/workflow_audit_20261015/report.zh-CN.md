**4. 奖励和控制的数学问题**

半程桥使用

\[
z_{\tau|t}=a_tx_t+b_tf_\theta(x_t,c_t),\quad
a_t=\frac{1-\tau}{1-t},\quad b_t=\frac{\tau-t}{1-t},\quad\tau=.5.
\]

它是一次 forward 的线性预测，不是原生 SDE 续生成。在 t=.49，a≈.9804、b≈.0196：半程项大部分是在直接拉当前点云，不能等同于优化终态 N/C 保留率。自条件 c_t 作为固定输入，未对其历史展开求导。

几何奖励为聚合平方误差 q 外面的 pseudo-Huber：

\[
R_\delta=-\delta^2(\sqrt{1+q/\delta^2}-1),\qquad
\nabla R_\delta=-\frac{\nabla q}{2\sqrt{1+q/\delta^2}}.
\]

在当前逐样本单位 RMS 归一化下，右边的正标量被抵消。因此 δ=0.1、1、10 Å 不会改变归一化几何方向；单项时还会再被最终剂量定标抵消。离线代数探针最大差 4.44×10⁻¹⁶。它不是逐原子 robust loss，不能通过改 δ 选择性放松离群点。结论限于对应固定、有限非零梯度高于数值 floor 的通常情况。

实际更新近似为

\[
g=\sum_kw_k\frac{g_k}{\operatorname{RMS}(g_k)},\qquad
\Delta x=\rho\operatorname{RMS}(\Delta x_{\rm predictive})\frac{g}{\operatorname{RMS}(g)},
\]

之后再做逐原子及累计裁剪。这有三个后果：

1. 所有项权重一起乘 10，不会放大最终剂量。离线探针最大差 6.94×10⁻¹⁸。要改剂量应改 rho 或已生效的上限/调度。
2. 0.85 几何 + 0.15 类型主要是改方向。在两个单位范数分量、裁剪前，相对纯几何方向的最大偏转仅 arcsin(.15/.85)=10.16°；0.6/.4 时上限约 41.81°。小类型占比难以推翻原几何偏好。这个角度界不是实测模型夹角。
3. 归一化消除了原始梯度幅度的信息，弱、噪声大的分量也可能获得固定份额。各项夹角、梯度互相抵消程度、各步实际局部响应尚未记录。

这解释了为何“把类型权重 .15 提高到 .4”不是一次完整的强度优化。R13 与 R14 的累计每步 RMS 位移之和分别为 0.5969、0.5945 Å，几乎相同；它们不是净位移，不能解读为分子最后移动了同等距离。每步平均实际控制约 0.015 Å。

类型奖励目标是 generic N/C decoder log probability。`full_ce` 的梯度通过坐标 Jacobian间接改变标签偏好，不直接更新类别；`cn_conditional` 只比较 C/N 比值，可能在 C、N 总概率均低时仍给出好值。R15 的电荷/芳香邻接软项也没有完整约束吡啶角色；芳香 bond 类别索引 4 直接写在源码里，迁移模型时必须与词表核验。

方向项采用固定 3 Å、0.4 Å 高斯距离核及两侧正向余弦平方。反向时 `clamp_min(0)` 有零梯度区域；远距离又有小梯度。它可能无法引导一个尚未对准的点转过来，或在归一化后放大极小信号。这是函数形状风险，尚未单独验证因果影响。

R18 在相同两个位置额外更新 logit：strength=8、逐通道 cap=4。该修改也进入下一步的 self-conditioning。它不是单纯增加坐标剂量。强度没有做分级扫描，而且没有显式 dt 缩放，改变步数时需要重新说明控制协议。

**5. 原生动力学是重要的参数风险**

当前及历史原始 Steer 的实际脚本都将 SDE 开启、坐标参数设为 .2。旧 config 的 `flowr_args.use_sde_simulation=false` 是运行时覆盖前的值，不能据此说两种方法使用了不同 SDE；已核对原始 `run_lineage.py` 的覆盖语句。

当前类别积分为 uniform-sample、类别噪声 eta=1、15 个原子通道、dt=.01，Euler noise guard 关闭。原生代码中的非当前类别概率为

\[
\Delta t\frac{1+\eta+\eta(K-1)t}{1-t}p_j+
\Delta t\eta p_{\rm current}.
\]

即使预测对当前类别完全集中，仍给其它 14 类各 .01 的概率，总离开概率为 **14%/噪声步**。这是对源码的条件计算，不是对本轮实际每步翻转率的估计。49 个噪声步完全不换类别的理想化概率约 .000617，但它**不是最终保留率**，因为类别还可以变回来。若临近终态的预测与当前类别不一致，离开概率总和还可能超过 1，当前对角概率被截成 0 后重新归一化。

这提供了一个明确、值得对照测试的保留机制风险。它不能单独解释 R18 的最终下降：网络自己的无倾斜概率、局部坐标是否适合目标身份、自条件，以及最后一次终态预测都同时参与。

坐标噪声参数 .2 不能直接叫作每步 .2 Å。实际随机项是

\[
\epsilon\sqrt{2g(t)\eta_x}\Delta t,\quad g(t)=1/(t+.01),\quad t<.9.
\]

coord_scale=1 时，三维随机向量期望 RMS 在 t=.1 约 .0330 Å，t=.49 约 .0155 Å，t=0 约 .1095 Å。这与约 .015 Å 的每步控制同量级或更大，但仍不能由此断言控制必然被噪声抵消。控制剂量依据纯预测流，不含 SDE score drift；当前没有记录实际三者的向量关系。

还存在被旧报告简化掉的一步：`final_corr_pred=True` 默认在 100 步后执行 .9999 的无引导预测，最终输出取 predicted，不是直接返回最后积分 current。`corr_iters=0` 并不会关闭这个步骤。应将 t=.5、t=1 积分后 current、最终 predicted 分别保存紧凑标签与局部坐标，才能分清损失发生在哪里。不能把所有变化都归到“最后 50 步的随机噪声”。

本次远端读取的 `_generate` SHA 与 R18 已保存的执行源码 SHA 完全相同。积分器完整文件本轮才补取，旧实验没有单独保存其文件 hash；因此历史逐行身份仍有审计缺口，虽然实际运行 hparams 已保存。

|极重碰撞阈值/MMFF|.8Å；MMFF94s；500次最小化|评价约定，不是完备结构合格性或结合能|
|搜索/回滚|固定最大合格值；下降 .01；连续2轮|`performance_metric` 与 `rollback_declines` 配置未实际驱动对应逻辑|
|筛查初态|seed42；batch0前24个；确认50、新池batch2|复用公平但缺少早期独立验证；不能用极值忽略均值下降|
|未使用入口配置|`hard_negative_count`、`region_sizes`、`tail_top_k` 等|当前 NC 路径未读取；改这些值不会产生预期分析变化|
|缓存有效性|batch/n/奖励签名；已有round配置直接复用|未来改模型、seed、动力学或master配置时可能误复用；当前冻结20轮未发现因此错用|

另一个迁移风险：mining 追溯教师时传入 base_config，而不是把新 master 的 teacher_time 覆盖过去；当前两者均为 .5，未造成这轮时钟错配，但以后修改教师时间可能不生效。NCReward 也缺少旧 HalfStateReward 中的 program/teacher 时钟一致性断言。必须在运行前检查，而不能只改 JSON。

**7. 对失败原因的优先级判断**

已确认的问题：

1. 模型输出控制有作用；“所有权重都太小、完全没生效”不成立。
2. .15→.4 没有改变总剂量，几何约束仍主导；总体剂量未探索。
3. R18 目标部分形成后未保留；现有奖励没有以原生未来保持为目标。
4. 14/20轮 Analyst 无区域选择自由，20/20轮 Designer 无参数设计自由；此次不能视为20轮完整的自主科学探索。
5. 特征包省略了报告的大量科学对照，也没有使用布局的时序可达性、具体原生分类偏好和布局保持证据。
6. 终态校正、类别噪声与近终点Euler转移存在重要且未消融的动力学风险。

目前仍待实验区分：目标的化学上下文是否不兼容；类型梯度是否与几何方向持续冲突；匹配是否频繁切换；提高实际剂量是否有用；减少类别噪声是否改善保持且保留亲和力；最终预测替换了多少已形成布局。现有日志不足以把这些风险排序成已证明的因果贡献。

**8. 建议的修复与验证顺序（本次未启动新实验）**

第一步先补执行与数据接口，不改变奖励数值。所有有效参数生成一份 resolved manifest；未知/未使用配置报错；固定时钟/词表/源码/初态/随机输入哈希绑定；缓存加入完整数值身份。只保存逐步标量和少数局部边界信息：匹配变更率、每项梯度夹角、控制与原生随机/漂移的比例、裁剪率、目标 N 与 C 各自概率、实际类别、t=1积分前后与最后预测差异。

第二步重做精简科学交付。每个候选交付原布局、多个合法替代及单交换反例、局部坐标/化学角色/口袋背景、质量条件；把“偏好N”与“联合补偿C”分开。保留 O 与周围空间信息作为兼容性证据，不要求把整个点云加进奖励。Analyst 得到按 patch/窗口/算子分组的简洁历史，由确定性程序生成数值比较，不能再让它从几万 tokens 中拼对照。

第三步允许 Analyst 通过有界工具查询局部联合布局、轨迹与失败原因；允许 Designer 在注册可微族内给出有证据的参数提案，而不是必须回显常量。实验阶段再冻结提案，每次改变一个因素。记录“实际可选集合大小”，避免把唯一允许选项包装成自主发现。

第四步先做实现性对照，再做亲和力搜索。固定同一局部假设，分开扫描类型混合占比与 rho；剂量可从 .33 的上下档开始，但数值由实际位移/裁剪诊断约束。不能用全部权重同乘或当前 δ 变化代替剂量实验。比较 .5 形成率、无倾斜模型支持、后续保持，再评价终态亲和力。

第五步单独检验原生动力学参数。以固定奖励比较类别噪声、合法数值积分分辨率或末端预测的影响。每次动力学变化都要有相同设置的无引导对照；旧对照仍保留为参考，不能直接复用成改变动力学后的因果对照。这里研究的是采样转移，不是固定化学图；继续允许正常图变化。

第六步才研究新的局部奖励：用原生未来能支持的局部角色/坐标组合、可区分的多教师局部模式，以及 N/C 与周围 O/电荷/环环境的兼容关系。控制时间仍应落在已定义学习窗口内；若要延长，必须先改变研究设计和证据范围。不能偷偷在 .5 后继续控制来制造保持率。

优化应同时报告全部尝试的亲和力均值、上尾和高分成功率、评分覆盖，以及原本要求的应变/结构指标。目标仍为提升 affinity；质量指标负责识别副作用，不恢复限制化学图变化的 gate。小样本极值只用于探索，独立确认才能决定是否更换基线。
