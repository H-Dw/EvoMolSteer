# 部分点云区域选择的顺序迭代协议

目标是生成有效结构中接近或超过终态教师 F_b011_s030 的预测 pIC50 的分子。完整点云是软约束，没有理论上的教师分数上限；部分点云是本次主要研究对象，其价值通过实际终态验证。

前 18 轮分别测试一种区域选择研究指引，使用相同 batch 0 的前 24 个随机初态、种子 42、100 个积分更新及三个引导起点 0/.1/.3，结束均为 .5，之后原生完成至终态。共享无引导、冻结的先前三点局部策略、同教师的全云对照只生成一次，所有条件的同一池使用同样随机输入和生成代码。

选择前先比较真实终态候选与其余 999 个终态；新增候选自身为中心的不同大小点集，完整覆盖所有教师槽位。证据包括 receptor-frame Hungarian 匹配、扣除整体相似度并作批次中心化后的秩关联、根谱系聚类 bootstrap、有效结构及去除教师批次的敏感性、近似几何但低分的真实反例及未指定化学类型的受体空间背景。1000 个终态只有 23 个初始根，不能解释为独立重复。没有训练新的亲和力预测器。

Analyst 冻结区域和点的重要性后，Designer 才得到真实半程祖先。Designer 不能更换、添加点或重写权重。前 12 轮统一权重，后续特定轮次允许 Analyst 根据证据提出相对权重；始终使用同一稳健点云函数及真实 FLOWR 坐标回传，禁止 affinity-head 梯度、SMC 及化学图相同 gate。两个选中区域仅编译成一个 union 奖励，不声称已分别测量它们的作用。

轮次使用可检验指引：增量辨识、近似低分反例、保持上下文的核心、逐点释放、口袋背景、核心/边缘权衡、尾部辨识、依赖稳健性、负面区域、互补区域、最小足够上下文、可观察量转移、条件点重要性、不同起点兼容性、反例修正、上下文扩展、证据加权、有效规则组合。每轮真实 API 响应、Skills 快照、函数、哈希及终态反馈保存。探索轮的完全相同算子不伪装为新函数；数值相同的程序复用结果并标记。

主搜索指标前瞻固定为最高 5 个基本结构合格分子的平均预测 pIC50，另报全部评分的均值、最高有效分数、超过教师的数量和失败率；能量为次级报告。起点也在训练池选择，因此该池的赢家分数存在搜索选择偏差，不能用来宣称泛化提升。

若连续两轮的该尾部指标相对当前最佳下降超过 .01 pIC50，恢复最佳 Skills 快照和活动推理配置，保留失败实验和 commit。数学执行合同属于固定约束，不通过破坏算法制造消融效果。

第 19 轮冻结最佳区域、权重和起点，扩充到同批次 50 个配对样本；第 20 轮在未用于调参的 batch 1 使用 50 个配对样本作独立验证。两轮有各自的同池无引导及冻结局部/全云对照，不利用独立验证调参。最多 20 轮包括这两轮确认。

全部源码本地修改并提交、经本机代理 push；远端 Git 拉取已提交版本后只执行 FLOWR。每轮远端不保存全程大轨迹，保留评分和两个坐标快照；完整 SDF 下载并验证长度后清理远端副本。原始历史 Steer 保留。允许化学图变化，最高分仅指模型预测而非实验结合亲和力。


## 执行中按真实反馈进行的修订

R01-R03 原始评价以最高五个合格结果均值进行，原记录保留。从 R04 起，为对应用户明确的单分子高亲和力发现目标，主探索指标改为最高合格分子的预测 pIC50，前五均值及全部均值继续报告；回滚使用该主指标的 .01 阈值。该修订不重写早期结果，最终扩大与独立池验证用于检查最高分选择偏差。

R05-R11 多个研究指引只改变了理由，返回相同算子，因此直接复用结果，属于无新增执行函数的调用，不能归因为新增性能收益。R13-R18 将从未测试的注册空间区域中选择一个新区域，规则仍由真实 API 决定，点云成员由确定性程序扩展。

R12 固定已选区域，测试可观察量转移：在相同选中槽位上同时使用实际半程及实际终态两个坐标视图，以同一个空间分配计算两个稳健损失，成分系数预先固定为 .5。它不同于温度消融或 M2 的教师混合温度；这是新的损失定义，单独记录。其梯度为半程桥的直接项与真实模型回传项，加上终态预测坐标的真实模型回传项。两者共用现有一次生成前向，不对 affinity head 求导。增加同系数的全云与冻结旧部分点云对照，以区分损失定义和选区效果。若失败，不继承该损失；后续从表现更好的实际 checkpoint 继续。

独立确认的 batch 1 原生引导推理结果未参与本轮调参，但其历史 Steer 终态属于先验目录；这里验证新随机初态下的生成效果，不宣称整个历史证据从未看到该批次。
