每轮的 API 原始回答、确定性点集扩展、真实教师、Designer、函数及哈希均保留在对应目录。R01-R03 旧前五均值判据及回滚保留，R04 起以最高有效分数为主；这一目标修订不能用来把早期失败改写成成功。所有候选都从原始随机输入开始，种子 42，无 SMC，结束引导后完整生成至终态。

部分点云通过注册区域和精确槽位查表获得；两个区域只产生一个并集奖励。数值比较和点列表由程序生成，避免 LLM 算术、抄录及符号错误。Designer 不得更换区域、点、点权重、教师或时间窗。R12 的双时刻检验在相同点上同时使用真实半程和真实终态两种坐标视图，使用共享空间分配和固定 .5 系数；它不同于教师温度消融，保持每步剂量且没有额外模型前向或 affinity-head 求导。

所有亲和力都是预测值。历史 Steer 的 1000 终态只有 23 个原始谱系根，区域关联不是独立因果证据。初态验证没有使用其本轮引导终态结果调参，但该批历史 Steer 结果属于先验。基本结构检查不等于完整 PoseBusters，应变为 MMFF 松弛代理。目标是否实现应根据最终分数和有效结构报告，不能用低半程匹配误差替代。
