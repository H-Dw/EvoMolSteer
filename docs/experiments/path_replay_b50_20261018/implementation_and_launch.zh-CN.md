## 为实现真实路径对齐修复的数值问题

1. 原COM保存为(B,1,3)，输入控制器和评分器时必须展开为(B,3)，避免多出广播维度。
2. 保留模型原有autograd标志。统一requires_grad_(False)会改变当前运行时的预测数值；不训练权重通过不使用优化器、检查参数版本及.grad实现。
3. 原Steer的口袋编码按原始B50计算后随谱系复制。重组后重算编码会出现数值差，进而引起离散分叉；新接口恢复原来源批次编码、root对应及首次选择的布局变化。
4. 原生终态评分也恢复原来源批次的口袋编码。评分器仍仅读取当前生成配体；不输入历史终态配体坐标或分数，不增加评分次数。
以上均为运行时和接口一致性修复，没有重新调用Analyst/Designer，也没有优化数值奖励。验证阈值始终未放宽。
