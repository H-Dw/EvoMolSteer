# B50统一批量与历史路径随机输入对齐

本实验冻结历史奖励、教师、权重及作用窗口，不新增Agent调用。全部条件以B50执行100个积分步，关闭SMC；窗口外使用原生推理完成至t=1。FLOWR使用原Steer运行时的提交739a33c2aab74d074dd24605b9a2e34dc809ae9c及原v2模型，隔离运行，不回滚共享源码。

## 条件与预算

|条件|路径数|执行组数|结果来源|
|---|---:|---:|---|
|No guidance|200|4|原Steer前20%对应路径|
|M2|200|4|相同200条路径|
|N/C R11|200|4|相同200条路径|
|祖先模板R02_v3|1000|20|原Steer全部路径|
|R15的B50扩展R19_v2|1000|20|原Steer全部路径|
|局部motif R15_v2|1000|0个新增组|共享R19_v2数值等价结果|

六个历史名称、五个独立执行条件、2600次正式推理。R15/R19只在程序名及来源哈希上有差异；验证奖励、坐标梯度和注入位移一致后复用。两者不计为独立重复。

共同路径清单先放前20%的200条路径，再放剩余800条；两个集合内均按历史批次及终态槽位排序，固定50个一组。因此200例与1000例条件的前四个执行组具有相同配对成员。1000例条件不删除任何路径；Top5/10/20采用原Steer终态评分冻结的统计掩码。排名保留全部1000条有限评分记录及其失败标签，不改成有效分子单独排名。

## 随机输入恢复

令s[k,j]为第k步选择后槽位j对应的选择前父槽位。从终态槽位逆推100步，得到每一步的父槽位。这与始终使用初始root槽位或终态槽位不同。

离线验证阶段按原始调用顺序恢复坐标正态噪声、原子/电荷/键的分类随机输入，并重放原SMC的随机数消耗，以核对所有保存的RNG锚点及选择索引。这一步不调用模型，也不产生新SMC样本。

正式推理不进行SMC：每条路径使用其真实初始张量和逐步祖先随机输入。坐标采用原始正态随机变量。分类采样采用PyTorch单次multinomial的指数竞争实现argmax(p/q)：p取当前反事实路径的概率，q取历史同一调用及父槽位的指数随机变量。不能复制历史原子/键结果，也不能用历史结构覆写当前状态或自条件。

存储每次调用前的CUDA RNG状态、原始张量尺寸、祖先索引和源文件哈希，按需再生随机张量。原始轨迹、口袋、初态和模型只保留原有共享副本。

口袋条件也保持计算过程一致：先按历史完整B50计算口袋编码，再按root槽位提取，继承原第一次选择造成的缓存张量布局变化。重组后重新编码虽然输入逐元素相等，实测仍有约5.49e-4的不变编码误差，会逐步导致离散采样差异。评分阶段按历史终态槽位/root映射恢复原来源批次的口袋编码，统一供原生评分器使用；不使用任何历史终态配体坐标或分数作为评分输入，不增加affinity推理次数。

## 接口

入口为`python -m evomolsteer.path_replay ACTION --repo REPO --config CONFIG`。

- `prepare`：读取本地原Steer数据，冻结全1000条路径及输入身份，写出配置。
- `verify`：在远端校验源文件、恢复20批随机输入、核对全部RNG锚点及选择索引，验证R15等价性。
- `run`：顺序执行容错队列。先完成200条无引导回放，通过整段轨迹和终态一致性检查后运行引导条件。
- `status`：读取队列、工作进程和完成数量。
- `collect --output -`：流式输出带逐文件校验清单的紧凑结果快照，不在远端复制归档。
- `analyze`：输出performance.csv、paired.csv、summary.json及中文报告，可重复调用。

本地远端接口为`scripts/deploy_path_replay.py deploy|status|collect --config CONFIG`；登录凭据仅从进程环境变量MOLSTEER_SCNET_PASSWORD读取，不写入仓库。部署通过本机VPN拉取已推送的Git提交，然后冻结独立运行时并后台运行。

## 验证与容错

原20批的所有保存RNG锚点和选择事件必须精确一致。无引导200条路径的全部积分步和终态离散状态必须一致，坐标最大误差不超过1e-5 Å，终态pIC50误差不超过1e-5。报告分别说明逐位一致与容差一致；不通过时阻断所有引导比较，不放宽阈值。

保留原FLOWR加载后的参数autograd标志，不统一调用requires_grad_(False)。真实诊断发现该调用在当前运行时改变预测数值，初步坐标差约7.55e-4 Å；保留原标志后相同B50输入的预测与历史保存结果逐位一致。保持标志不意味着训练：不创建优化器，仅对坐标求VJP；每批检查参数版本未变且没有累积权重梯度。该项属于运行时一致性要求，不改变奖励、教师或引导强度。

独立引导批次失败写明失败记录；进程崩溃允许一次重启，继续其它组或条件。共享模型、源码、谱系、随机输入或无引导回放验证失败则阻断整个实验。空间少于256MiB时保留进度并停止，不自动降为B24。

保存t=0.5及终态紧凑结构、终态SDF、评分、结构失败、PB检查、MMFF94s松弛差/重原子及每步实际注入记录。能量指标是统一协议下的构象松弛代理，不等同于实验稳定性。

## 统计解释

报告均值、中位数、P90/P95/P99、全部评分Best、有效结构Best、PB通过Best、高分数量、评分覆盖、结构有效率和应变。配对均值差按历史来源批次进行10000次聚类bootstrap，固定随机数42；执行组不作为独立统计单位。

无引导历史路径回放是事后成功路径条件下的对照，预期接近原Steer对应结果。它不代表从随机先验出发的原生无引导分布；原生无引导历史池另列为非配对参考。M2/R11只有200条配对路径，不能报告其完整1000条配对表现。缺失结果单独报告，不填零、不冒充完整样本。
