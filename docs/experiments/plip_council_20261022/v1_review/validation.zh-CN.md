# V2 技能修订的离线验收

本文件记录规则层面的人工反例审查与来源核验，不声称已经测出 DeepSeek 的新行为或未执行方案的亲和力。实际行为和同预算效果由 V2 验证。

| 反例输入 | 应得结论 | 本次检查 |
|---|---|---|
| A=latest，B=incumbent，B−A 为正，但绝对 latest 较低 | 正值支持 incumbent；不能宣称新组获益 | 两份技能明确差值、胜率方向与绝对均值核对 |
| 有效分子数改变，幸存者 Mean 提高 | 报共同有效配对、转换数；不能只比幸存者 | 两份技能保留所有尝试并区分有效集合 |
| 提高控制但裁剪后实际位移不变 | 区分名义与有效控制；减少或换窗口是待检验方向 | analyst 的裁剪分支不自动宣称降低必有收益 |
| 无裁剪、实际位移增加，但局部几何或 affinity 未改善 | 不把它称为未执行或已饱和；分别定位响应环节 | 两份技能区分交付、几何、代理目标与最终评分 |
| 少数有效候选正变化拉高 Mean，中位数接近零 | Mean 仍是主目标，另查集中度和质量 | delta/n、禁止默认排除异常值、无中位数附加门槛 |
| 一次增加获益，进一步增加变差 | 考虑局部非单调与组件/反方向试验 | 没有固定区间或固定幅度答案 |
| 相反动作产生相反的差值 | 统一方向后可与稳定局部响应相容 | 不再把互逆差值直接称为随机符号 |
| 某组低于逐链 TOP1，但高于 R0 | 分开报告系统择优差距和固定组改善 | 不把 TOP1 当作单一调度或唯一有效性门槛 |
| 同样证据仅交换靶点、教师、候选标签 | 规则、评价方向及试验类型不应改变 | 技能未包含真实标识、原子数量阈值或最优表；标识只用于引用 |
| 最后一轮预算为零 | 建议只能记入复盘，不执行下一轮 | 两份技能明确 review-only；执行器旧门槛保持 |
| 已有公共结论与实际工具数据矛盾 | 纠正记忆并引用实际证据 | 汇总新增发布前的符号、动作、历史及预算检查 |
