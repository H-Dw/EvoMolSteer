# V1–V4通用技能修订与固定调度实验比较

2026-10-22。已将自动巡检plip-11762调整为每40分钟一次，保持启用。本文仅分析已完成的V1–V4；V5已经部署，其效果不在本次结论中。没有为本次比较追加采样、修改冻结实验或重启工作进程。

**主要判断：Agent对当前固定0.5起始组的收益依教师而异，Top2有较明确的条件性改善，Top1主要表现为搜索择优；V2–V4技能修订没有带来持续的pIC50提升。两教师当前结果仍明显低于历史Steer的平均质量。** 事实核对和决策行为有所改善，不能据此认定亲和力优化已有效。

**比较对象与统计口径**

教师限定为5nn4_SC2_A_1017原Top1、Top2，不混入以前的其他教师。所有数值均为pic50_on_rescore。每位教师100个起点，两教师共享这些起点；每版四个假设、五轮，每教师2000条优化结果，保留100条逐链TOP1。各版复用同一R0、清空搜索历史。

- 固定R0：当前系统Endpoint局部坐标奖励，10–90步共81步幅度0.5，其余为0。
- R5四组Mean平均：末轮四个100候选组的Mean等权平均，没有再从四组择优；其父状态仍来自前轮逐链TOP1，所以仍是搜索后的结果。
- R5整组选优：末轮四组中Mean最高的一组，带有组间选择。
- 逐链TOP1：每条链跨轮次、跨假设与R0择优后的集合。它是系统交付物，但其Mean不能单独证明未选择的生成分布改善。

**V1–V4具体发现与修订**

V1首先建立了四组私有分析、第五个汇总Agent、注册统计工具、同轮共享随机流、局部小步调节、公开反思和逐链TOP1清理流程。后续修订主要是两份通用analyst/synthesizer技能。时间顺序必须区分：V1的问题在V2验证，V4发现的问题已用于V5，不能把后续修订的收益倒算给发现问题的版本。

这些修订没有增加程序化事实核验工具，不能声称文字规则已经消除了计算或归因错误。早期JSON校验诊断修复和V3有界分析恢复属于工程可靠性改进：失败请求与成本保留，成功分支和已有400条采样复用，没有放宽动作边界或重抽分子。

几个足以影响策略选择的具体例子：

1. 相同背景下某段增加与随后减小产生相反Mean变化，本应视为相容的局部响应，曾被描述为“符号不稳定”。必须先统一动作方向，才能比较响应。
2. V4 Top2 R1的Mean增益约0.054475，两个候选贡献合计约0.0677，其余净贡献为负。这是集中的真实Mean改善；应报告脆弱性，不能因未覆盖多数分子就取消其Mean价值。
3. V4 Top1全0.5重放Mean为4.164901，而共享R0为4.172401。幅度数组相同不代表批次、恢复入口和父状态相同。V4最终撤回了旧分数必可恢复的预测，这比V3的公共记忆更准确，但发生在末轮，没有后续采样验证收益。
4. V4 Top1某分析引用的0.01545等数值确实在工具中，但属于26–50区间最大值，被拿来解释51–75区间。问题是字段错配，不是数字凭空捏造。

**当前最有用的判断与下一改进方向**

实际证据支持的是：群体Agent系统在Top2条件下找到了有收益的局部方向；Top1更接近局部无效或收益受少数分支限制；V2–V4主要改善了部分决策记录与稳定性，没有提高整体搜索效率。两教师反复用于技能开发，结论仅限这组开发样本和共同随机设置。

后续改进应优先把比较对象、幅度起止边、区间字段、候选贡献和已执行状态绑定为程序化事实，减少LLM重复人工解释同一批数值；再检查这些错误减少是否提高单位采样和单位token的Mean收益。局部坐标更像教师不必然提高亲和力，且当前Agent只能改幅度，不能改奖励或离散特征，这也是需检验的能力边界。上述是下一步诊断方向，不构成已经验证的原因；本次没有更改V5冻结设置。
