## Top1逐轮观察

1. Bootstrap把自配对零差识别为同一R0，读取区间交付后提出早窗正负、第二窗和末窗方向试验。R1四组均低于R0。私有组仍有只翻Mean符号、不翻胜率和极值方向的错误，也把按latest分位得到的组误写为R0分位。汇总读取同波配对，正确去除同轮和R0重复，下一轮全部选择新数组，这是可观察的改进。
2. R2部分会话显式区分R0、固定组和TOP1，直接查询真实最后动作；另一些仍从选择后缺口推断幅度响应。G1把26–50的最大指导比、最大局部位移当作51–75的诊断值。原始完整工具含这些数字，问题是区间和统计量错配，不是数字凭空产生。G2错误认为一格限制阻止从6到7，说明合法动作空间仍理解不清。汇总继续消除当前及历史重复，选择四种新数组。
3. R3汇总识别当前重复和不同作者提出的同数组，恰好有四种新数组，全部入选；没有为了安全而重放旧赢家。部分会话正确保留集中Mean贡献，但反证条件仍要求更多候选或特定分群获益，把描述性广度变成额外接受门槛。名义单因素、跨轮继承、同波次与TOP1父状态仍被混用。
4. R4汇总用当前同波结果纠正作者预测：[5,5,4,5]相对其比较组实际仅约+0.000060，并非+0.004至0.008；[5,4,5,4]实际约−0.000136，并非+0.003至0.007。反证确实改变选择。当候选集合仅三种新数组时，固定选四种合同下至少一项重复不可避免；汇总如实说明，并把全0.5重放限定为上下文转移问题。此前公开记录知道[5,5,5,4]的历史分数，与没有当前直接转移测量是不同问题，不能把当前来源映射不足说成历史数值不存在。
5. R5全0.5重放Mean为4.164901，未恢复原R0的4.172401。私有G1和汇总明确撤回“旧分数可恢复”的预测，改用本轮实测作为未来参考；这比V3末轮仍承诺旧分数的行为更好。该反思发生在预算耗尽后，所有下一方案仅归档、无R6，不能据此宣称本版采样已经获益。另有会话没有查询真实最后动作、把最大贡献之外的剩余项直接称广泛改善，其分布与身份仍未知。

Top1没有发现V3式非法动作导致的分析重试，当前36个格式约束核验中没有额外修复诊断；这不等于事实与机制解释完全正确。Top1未调用几何/候选身份诊断工具，不能把交付变化当模板结构变化或宣称已找出贡献者。

## Top2逐轮观察与反例

1. Bootstrap实际调用geometry_diagnostics比较0与100步，局部RMS从约4.834降至2.015 Å；因此不能把Top1没查几何推广成所有Agent都没查。局部几何改善本身不保证亲和力改善。R1早窗增幅固定组Mean增加0.054475，主要来自两个中间分位候选，贡献合计约0.0677；其余净贡献为负，集中性不能抹掉正Mean。另三臂略负。汇总用同波结果选择四种新数组，未把R0或当前重复当新探索。
2. R2进一步早窗增幅使Mean下降0.063475，Agent与汇总据反证停止继续加力。不同会话主动查询真实最后动作、R0对比、分群和交付是可观察进步。跨轮+0.055880是早窗变化，后续却被某私有Agent误记为index2作用。相对TOP1的缺口不能代表新调度收益；近似Best更不能证明同一候选被固定。
3. R3弱背景的联合变化仅+0.003172。私有Agent把其中4→5与历史5→6比较，推断另一窗口抑制了早窗作用，两个比较并非同一条幅度边。汇总读取同波匹配，得到强/弱早窗相差约0.059299，纠正了抑制叙事。另一同波index2条件差约+0.003200主要由一个约0.3215的候选贡献，仍是真实Mean差，不要求先变成广泛收益。
4. R4个别私有Agent说历史已执行数组尚未解决，或提出本轮其他组已执行数组；私有无法看到当前兄弟分数，但此前公开已选数组仍可查。汇总去重，从五个新数组选四个，并明确放弃一项匹配对照的机会成本。没有执行该对照，就不能声称隔离了双组件的贡献。R4早窗弱背景转移+0.059084支持条件响应；不意味着同期错误的index2效应解释也被证实。
5. R5高侧index2及index1分别约−0.00000964和−0.000136；Agent撤回预期正收益，区分选择差、最大个体差和Best更准确。双组件+0.015711仍不能分解；下一步5→6不能直接解释上一步4→5。最终汇总识别两个作者的同数组，只归档四个假想后续方案，没有R6。部分文字仍将正负括号称局部峰、把无控制变化视作最优，或声称停止升幅又推荐另一背景升幅而没说清竞争解释。

## V5通用技能修订与适用范围

本次改写两份通用技能，按观察核对、条件解释、预算决策、输出校验排列，替代继续堆叠相似提醒。保留V4的配对方向、选后父状态、Mean优先、合法性和去重原则；旧文本完整保留在Git历史。以下修订均来自两教师中的问题与反例，而非最优数组迁移：

| 触发条件 | 必须核对的证据 | 候选行动与反证/停止条件 |
|---|---|---|
| 比较两个“+1”响应 | 明确旧→新幅度、全部未变背景和父状态 | 不同边保留为竞争解释；通过合法同边条件比较检验背景效应，不能直接称抑制 |
| 引用交付或结构数值 | 区间起止、状态/步、均值/最大值/分位、单位 | 不匹配则不引用；控制未变先诊断交付，不能判曲线最优；几何与评分冲突不自动加力 |
| Mean集中或很小 | 同一A/B、总贡献和分群基准 | 保留真实正负贡献，不添Best/胜率/固定分群门槛；没有身份就保持未知 |
| 提议旧数组或对照组合 | 当前同波、公开历史、提议/已选/已执行身份 | 重复须未解问题；匹配臂被舍弃时承认未隔离；新数组不足合同数量时如实说明 |
| 下一步预测被反证 | 同一实际动作的Mean、交付与结构层 | 降低该条件方向优先级；换背景再试须说明改变条件，不能同时说停止又无解释地延续 |
| 临近预算末端 | 剩余可执行轮次和结果能否影响决策 | 权衡边际Mean和信息价值，不强制安全重放；零轮只归档 |

技能没有靶点、教师排名、槽位、原子特征或最优幅度表。规则逻辑经身份替换、集中收益/多数微胜但Mean下降、有效性转化、裁剪掩盖动作、几何和评分冲突、正负括号、动作修复及零预算反例人工核查。没有新LLM离线回放；测试验证执行器和审阅门槛，不证明新技能将提高亲和力。

工具接口、科学源码、模型、R0、奖励、类别转移、CRN、采样轮次、token预算及清理全部保持原样。没有新程序化事实工具，不能声称文字规则已消除归因错误。V5必须与相同R0和同预算版本比较固定组及TOP1，并检查行为错误是否减少；写得更清楚不是效果证据。反复开发两位教师有选择偏差，不能推广成跨靶点验证。
