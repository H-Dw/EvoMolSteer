# M2 之后各分支：均值、有效结构最高分与高分尾部审计

日期：2026-10-17。只读取本地已有结果，未运行新生成、LLM API 或 affinity head。这里的 checkpoint 指代码、奖励程序与推理配置，不指重新训练的 FLOWR 权重。

## 结论

1. 在可配对的时序、旧消融及 Top10 教师研究中，12 个不同数值方向曾在至少一个指标上高于同输入 M2。改善多数是开发样本的点估计，不能统一称为统计确认的提升。
2. 固定 400 池中，Top10 全局 0–0.5 的均值与 Best 都高于 M2；S3 的均值、有效率与应变较好，Best 和高分数量没有同步改善。恒定混合 λ=0.5 在旧批次 6248–6255 曾同时提高三个指标，但合并其所有 2,600 个配对尝试后，三个指标均未超过 M2。
3. 本次可核验的 M2 之后新数值方向中，没有同时超过原始 Steer 的平均 pIC50 7.651480 和有效结构 Best 8.704806。更早的冻结 M2 自身在历史样本里已同时出现更高均值和 Best；后来的 API 链或精简 Skills 再次返回同一 M2，不算新奖励超越。
4. 没有发现新生成分子的合格记录超过历史 M2 Best 8.881638。N/C 固定坐标重标记和 Kekulé 编码诊断产生的较高分不能算新的生成成功。

## 口径与基准

- 均值使用所有尝试的有限终态 head 评分，另报评分覆盖；本表全部评分覆盖为 100%。失败结构不通过过滤从主均值中消失。
- Best 为明确结构资格字段为真的样本最大值；配对 M2/时序/Top10 使用 `valid_connected`。它不代表应变、PB 完整检查或所有药化指标都合格。局部/祖先研究使用较严格的 `qualified_structure`，包含严重碰撞检查，因此另表呈现。
- “长尾富集”统一使用原协议阈值 **pIC50 ≥ 8.258901977539063**，并要求上述结构资格，分母为全部生成尝试。后期原报告的 8.13504886627 阈值不直接搬来混比。
- M2 的历史 3,000、固定 400 和前 200 是不同范围；前 200 包含在固定 400 内。历史汇总与固定池、screen 与 expanded、旧 blend 与 S2 共享记录均不能相加伪造独立样本量。
- 配对记录键 `(batch, slot)` 逐项一致；既有执行审计还验证了相关研究的初始状态签名。跨历史 Steer 的比较不是等在线搜索预算的配对试验。
- 比较容差为 1e-6 pIC50，防止 CSV 显示舍入制造“超过”。分数都是模型预测，未新增实测亲和力证据。

### 策略究竟改了什么

- **S3**：静态冻结教师奖励逐渐过渡至同时钟历史端点预测教师奖励，动态比例 0→0.5→1。混合的是两个标量奖励，不是平均两个构象的坐标。它是预注册数值对照；本轮 Agent 没有选中 S3，不能把数值收益归功于 Agent。
- **恒定 λ=0.5／S2**：在两个奖励之间始终各占一半。旧签名 `ab41341eeb9b` 与新调度签名 `287e3b494ad5` 在共享 200 个输入上的逐分数、SMILES（缺失值规范化后）及结构有效标签完全相同。保留各自执行记录，但不算两次独立发现。旧研究已有固定池 400 结果，可补充单独时序报告只列出 S2 200 筛查的视角。
- **λ=0.25**：同时钟奖励占 25%，静态奖励占 75%。这里改的是教师奖励比例，默认混合温度 τ=0.5 未变；不是温度消融。
- **C2/C3**：修改实际生效的 `pointcloud_delta_A`，分别恒定 0.75 Å、从 1 经 0.75 降至 0.5 Å，改变 pseudo-Huber 对远距离偏差的响应；并非提高整体权重。旧 JSON 的 `robust_delta=2` 是此奖励族不生效的历史元数据，不能当成实际曲率。
- **W1/W3**：改变 RMS 控制器归一化之后的剂量时间分配，分别 [0.35,1,1.65] 与 [1.65,1,0.35]，窗口平均请求预算相同。旧线性衰减分支改 `time_ramp_power=1`，属于另一种不同的剂量干预。
- **Top10**：按历史终态评分选教师，再追溯祖先，奖励实际使用最后学习节点 t=0.49 的端点预测点云。局部方案只匹配 Agent 指定小区域；全局方案匹配整个点云。延迟到 0.1 同时减少十次注入，不能只归因于起始时间。

### 哪些改善值得保留、哪些仍只是信号

- **Top10 全局 0–0.5**：在固定 400 池中同时提高均值与 Best，均值差 +0.038287；多重比较同时区间 [−0.005412, 0.103808] 跨零。应变 p90 0.84141，M2 为 0.86806，整体有效率也较好。适合继续验证，未确认优于 M2。
- **S3**：均值差 +0.031748，普通配对区间 [0.00220, 0.06280]，九候选同时区间 [−0.00694, 0.07517]。应变 p90 0.71498 比 M2 低 17.64%。主要改善分布低端，高分计数仍 3/400，q99 下降。扩大后的 400 包含筛查 200，不能叫独立确认。
- **C3**：均值差 +0.010784，同时区间 [0.00080, 0.02493] 为正，但应变 p90 1.05363，较 M2 高约 21.4%。C2 只提高 0.001422，不能解释为明确的实质改善。
- **Top10 延迟局部**：Best 提高 0.248968，但均值降低 0.193927，应变 p90 1.91131，较 M2 高约 120%。最高分个体不是全面质量改善。
- **尾部**：固定 400 的 Top10 延迟全局从 M2 的 3 个变成 5 个；W3、S1 在 200 中从 1 个变成 2 个。这些计数太少，不能证明稳定富集。旧 λ=0.5 较好批次从 2 个变成 6 个，但其全量 2,600 反而少于配对 M2。

原始区间、能量和结构记录见 [时序方向完整报告](../temporal_direction_comparison_20261013/report.zh-CN.md)、[Top10 完整报告](../m2_terminal_regions_20261014/analysis/report.zh-CN.md)、[旧消融最终状态与结果](../m2_tools_full_drop_ablation_20261012/study_summary.json)。本次不从统计摘要推导具体区域的因果机制。
