# 失败解释与可复用教训

本文依据已保留的筛选结果和第18轮第一组确认撰写，不改变第20轮冻结参数。最终结果以四批200个候选的完整确认报告为准。

## 已有直接证据

第16轮温和模式去偏在筛选面板上比R26提高0.068018 pIC50，两批均为正；第18轮相对R26下降0.029829，两批分别为-0.039580和-0.020078。有效率和能量诊断没有出现相应幅度的崩坏，但这些次级指标不能替代主要亲和力目标。

推理审计显示学习窗口内每步均有非零注入、之后完成原生续推；使用实际FLOWR端点VJP，没有亲和力头梯度、额外生产神经前向或粒子重采样。不能将此次退化简单解释为引导未启动。也不能将化学图变化本身当作质量变差原因，图变化不受推理gate限制。

另一个独立问题已获得负对照支持：第6轮只采用旧先验归一化、没有新学习规则，却重现第4轮约+0.02518的改善；第4轮相对第6轮仅-0.00000285。早期算法收益被数值实现混杂。修复和原版本同时保留，避免将所有差异都归因于科学机制。

## 仍属假设的原因

1. **稀有性和目标收益没有被等同验证。** 冻结候选的先验是`π_k ∝ exp(−d_k/T+βs_k) n_k^(-α)`，本次α=0.5、β=2。在距离和其余条件相同时，1:3模式占用使稀有教师相对权重增加√3，相当于抵消约0.275 pIC50的标签差距。这是公式的确切效果，却不是稀有模式最终亲和力更好的证据。温和去偏可能保留有益路径，也可能偏向低收益模式；第18轮证据支持暂停采用。
2. **筛选面板适应性。** 多个参数在同一两批面板上比较，选择其中最高均值会产生选择偏差。独立确认是检验这类偏差的必要步骤，不可把筛选改善幅度当作可复现收益。
3. **选择器标签缺少原生未来测量。** 教师分数与原始选择器使用同一预测来源，未续推的淘汰分支未来亲和力未知。谱系留存、当前分数和局部几何模式的关联不能自动推出最终结合收益。
4. **坐标优势证据有限。** 整个学习支持上的74项几何群体特征中，原生积分有68项BH显著，期望选择没有显著项。该结果不证明没有有用的局部信号，但不支持把原生趋势或未经校正的低p值写成确定优势区域。

上述机制可能同时存在；当前实验未单独测出它们各自造成退化的比例。不能为第一组确认下降给出确定的单一因果结论。

## 对下一次探索的约束

保持R26为已验证起点。优先取得已有分支原生续推后的目标标签，区分当前选择分数、实际未来收益和未观测结果；这是离线证据补充，不要求在引导每步调用亲和力头。若继续探索模式权重，应使用目标收益与独立支持共同约束，而非仅奖励几何稀有性。

坐标挖掘应加强同批次、相近父状态条件下的局部几何联合比较，保留完整点云兼容性；以独立批次/源家族估计不确定性，避免克隆数量制造显著性。新规则仍需明确的标量、条件坐标导数、动态学习支持及独立确认，失败恢复基线。这里提出的是后续研究方向，本次未实施额外实验或宣称已得到新的优势区域。

实现层面继续要求空机制、等模式占用和单位协方差具有标量及梯度一致性；同时保留先验和后验ESS。微小浮点扰动可改变后续离散采样轨迹，因而实现对照与科学对照都需要保留。
