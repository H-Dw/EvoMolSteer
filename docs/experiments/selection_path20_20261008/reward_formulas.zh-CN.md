# 选择路径奖励的可执行数学定义

本轮保留R26的完整分子教师点云，在每个实际学习节点使用真实FLOWR预测端点 `Y=F_t(X)`。窗口由程序与参考库共同校验；当前实验数据的支持为0–0.5，引导之后原生积分至1。教师、Hungarian对应、局部先验和协方差在当前端点锚处冻结，只有端点坐标参与求导。以下是条件导数，不声称包含离散教师选择或对应重排的导数。

设局部选出的K个教师为`Z_k`、冻结对应为`σ_k`、残差为`r_ki=Y_i−Z_k,σ_k(i)`。R26使用：

`ℓ_k=−HungarianMSE_k/T+β(s_k−mean(s))`，`π=softmax(ℓ)`。

`q_k=mean_i ||r_ki||²`，`ρδ(q)=δ²(√(1+q/δ²)−1)`。

`R=τ log Σ_k π_k exp[−ρδ(q_k)/τ]`。

当前基线K=4、T=4Å²、β=2、τ=0.5、点云δ=1Å。程序中继承的`robust_delta=2`不控制这条点云公式，实际字段为`pointcloud_delta_A`，缺省1。评分仅用于离线教师先验，没有对亲和力头求导。

令`a_k=softmax(logπ_k−C_k/τ)`，则：

`∂R/∂Y_i=−Σ_k a_k r_ki/[N√(1+q_k/δ²)]`。

作用于当前状态的梯度是`g_X=J_Ft(X)^T ∇Y R`，由实际FLOWR前向的自动微分VJP计算。控制器将其归一化到既有predictive-flow RMS比例，继承单原子步长上限与严重口袋碰撞回退；不增加生产神经前向，也不限制化学图变化。紧邻离散采样变化的轨迹可放大极小数值差异，因此归一化实现必须一致。

## 逐项替代机制

质量排序只把`s_k−mean(s)`替换为`(average_rank(s_k)−0.5)/M−0.5`，并保留完整空间模式。没有训练对比编码器。

ESS规则令`π'=(1−ε)π+ε/K`，用确定性二分找到满足`1/Σπ'²≥fK`的最小ε。约束的是教师**先验**，后验`a_k`的ESS可以更低，已分别记录。没有复制或重采样分子。

几何模式规则通过世界坐标Hungarian距离和确定性原型划分得到分组。先验去偏为`ℓ'_k=ℓ_k−α log(n_group(k)/max_group_count)`；相等占用时没有公共常量偏移。代表覆盖和来源批次覆盖分别改变教师索引，保持K与剂量不变。

协方差规则在模式内将教师对齐到原型，按来源批次均衡权重，计算每个对应原子的3×3协方差。收缩、正则化、逆特征值截断和迹归一化得到SPD矩阵`M_ki`。令`A_ki=I+λ(M_ki−I)`：

`q_k=mean_i r_ki^T A_ki r_ki`，`C_k=ρδ(q_k)`。

`∂R/∂Y_i=−Σ_k a_k A_ki r_ki/[N√(1+q_k/δ²)]`。

实际代码将`λr^T(M−I)r`加到原始欧氏误差上，单位度量时与R26逐位一致。每个教师中心和完整点云都保留。该度量允许较宽空间方向，惩罚教师中更稳定方向的偏离；它是待验证的局部几何假设，不能解释为能量势或因果优势区域。权重ESS是教师权重集中度，并不等于独立家族数；独立批次数与克隆限制另行报告。

逐原子稳健误差使用`C_k=mean_i ρδ(||r_ki||²)`，而不是先平均所有原子的平方误差再稳健化。其条件导数是：

`∂R/∂Y_i=−Σ_k a_k r_ki/[N√(1+||r_ki||²/δ²)]`。

第14/15轮仅更换这条损失及其δ，协方差和先验规则没有叠加。

## 证据与解释边界

74项整个学习窗口的群体几何趋势经过批次不确定性和BH校正后，选择项没有显著特征。不能把显著的原生积分趋势改称富集优势。以上规则因此都是受既有教师支持约束的实验假设；是否保留由完整生成后的配对亲和力、构象及应变决定。

Analyst/Designer的字面输入、响应及哈希保存在agents目录。真实模拟发生于初始注册与一次表示澄清；之后的参数探索由确定性工作流顺序编排，不代表每轮重新调用LLM。研究理由、失败原因、程序、版本和评估均保留，失败后恢复R26运行入口和基础Skills。
