# I3、I4、M2 的共同性质与组合试验

2026-10-10。当前证据支持优先组合静态端点空间目标，接触场作为单独的次级试验。新组合模块已实现、完成数学测试，尚未进行新的 FLOWR 生成，不能宣称组合后的 performance 已提高。

## 已观测的性能

以下方案每组 100 次尝试、批次 75/76，每批 50；master seed 42，实际批种子为 `42 + 100003 * batch`。总共 100 个积分步，前 50 步注入坐标梯度，其后完成原生推理。所有指标为相同终态重评分流程的结果。pIC50 是 FLOWR 的预测，非实验测量。应变是收敛的同化学图局部 MMFF94s 松弛能差/重原子数，单位 kcal/mol/重原子。

历史 Steer 1000 个尝试的平均值为 7.65148，高于阈值 8.25890 的有效样本有 37 个。I3/I4/M2 的平均值高于这个历史参考，但三者都仅有 1/100 个阈值以上有效样本；其 P95 分别为 8.10702、8.07132、8.12562，历史 Steer 为 8.23844。不同样本量、不同在线筛选预算的历史比较不成对，尚不能证明平均优势可推广，更不能证明极高亲和力路径发现能力已经超过 Steer。

## 三者实际改变了什么

I3 的 Designer 输出改用原始结合配体点云的端点锚定奖励。实际程序是 `0.5 L - 2 P`，其中 L 为点云匹配后的平滑距离损失，P 为小于 2 Å 的受体排斥。已有轨迹中 P 始终为零，故主要生效的是原始点云锚定。奖励自身不读历史生成结构，然而该轮 Analyst/Designer 输入仍然读了历史统计；删除 elite_geometry 文字也被 Designer 误解成信息不可用。这不是干净的“删一条指引”的因果实验，也不是 Agent 完全零 Steer 输入实验。

I4 同样采用原始结合点云，实际程序是 `L + 0.25 C - 2 P`。C 是无类型的受体距离壳占据场，中心 3.6 Å、宽度 0.6 Å，不是亲和力或相互作用能量。它不含历史轨迹匹配奖励。相比 I3，C 会改变合成梯度方向；其应变略好、平均亲和力低 0.04128。因此加入通用接触偏好并不能自动提升目标亲和力，空间接触数量不能替代有用接触的方向与位置。

M2 是数值控制，不是额外的 Luna Skills 消融。它保留 Steer 选中的教师点云，却将整个窗口使用的教师集合固定为最后学习节点 `t=0.49` 的端点预测点云；这不是保存的真实 `t=1` 终态。M2 与 M1 都设 `teacher_score_beta=0`，只按当前端点预测与教师的空间接近程度选最近四个教师、计算条件先验；教师集合本身仍来源于历史高分选择。M2 相对 M1 的平均提升为 0.16159，两批次提升分别为 0.16156/0.16162。这比直接比较 I3 与 R26 更接近隔离“固定还是动态目标”的数值对照。它不说明评分信息没有用，也不说明不需要历史 Steer。

## 这些结果反映的引导性质

1. **端点目标可以固定，生成路径仍然动态。** 奖励作用于 FLOWR 对当前状态的端点预测 `Y=F_theta(x_t,t)`，通过真实模型的坐标 VJP 得到 `g_t=J_F^T ∇_Y R`。即使目标点云不变，端点预测、最邻近教师、匹配关系和模型 Jacobian 仍会随时间变化。因此固定目标不是固定每一步位移；它有机会让不同的原生路径到达有用的空间区域，无须强制复刻历史路径。
2. **方向连续性有帮助，但不充分。** 排除初始虚拟值后，相邻步梯度余弦均值为 R26 0.64221、M1 0.63401、I3 0.77262、I4 0.77484、M2 0.75259；反向比例分别为 5.35%、5.22%、2.82%、2.57%、3.08%。动态教师会随时刻变化，可能产生目标切换和拉回；该现象与较差性能相关，尚不是单独的因果证明。I4 最连贯却非最高分，说明稳定的错误方向同样无益。
3. **改善主要不是来自更大的实际剂量。** R26/I3/I4/M2 的每步注入 RMS 分别为 0.01480/0.01495/0.01494/0.01481 Å，均使用 eta=0.33、ramp=0。只给整个单项奖励乘正数，在梯度归一化后通常不改变注入方向和剂量；I3 的系数 0.5 不能解释成一半的有效引导强度。接触比例、目标选择和 eta/ramp 才可能实质改变方向或幅度。
4. **不需要总是沿原生流前进。** M2 的梯度与原生预测流平均余弦为 -0.17154，比 R26 的 -0.15862 更负，但其平均亲和力更高。不能据此添加“与 native flow 同向才接受”的质量 gate。允许坐标改变并由原生解码产生不同化学图，现有方案没有化学图相等限制。
5. **平均值改善伴随探索收缩。** I3/M2 的有效唯一化学图分别为 44/47，R26 为 59。I3 对原始模板的终态匹配距离较小，存在“熟悉的结合空间吸引子”解释，而不是已经证明更自由地挖掘了新优势区域。I3 的非优势邻域局部 MMFF 松弛 RMS 约 0.355 Å，R26 约 0.285 Å；该指标是无受体约束的局部松弛，不等于实际口袋适配能量。组合实验必须同时检查高分尾部、唯一高分图和局部应变。

成对槽位比较也显示异质性：I3 比 R26 高分的槽位为 57%，M2 比 M1 为 62%，M2 比 I3 为 58%。M2-I3 的平均差仅 0.00932，不宜宣布稳定优胜。当前只有两个批次，并从多个候选中挑选，存在选择偏差，需要预留批次确认。

## 已实现的组合奖励

组合库包含一个原始结合点云和一次保存的 28 个静态教师点云。对当前端点预测的 detached 副本执行几何 Hungarian 匹配，并从教师库选最近四个。对应关系、邻居集合及距离先验在这次求导中固定；posterior 对端点坐标保持可微。所有原子类型和化学图都不参与匹配。

对每个已匹配点云 T_k，令

\[
q_k(Y)=\frac1N\sum_i\|Y_i-T_{ki}\|^2,\qquad
D_k(Y)=\delta^2\big(\sqrt{1+q_k/\delta^2}-1\big).
\]

设置原始点云先验质量为 rho，四个静态教师的总先验质量为 1-rho；教师内部先验按 detached 匹配均方距离的 `softmax(-q_anchor/4)` 分配。不是按亲和力即时加权。主奖励为

\[
R_{geo}(Y)=\tau\log\sum_k\pi_k\exp[-D_k(Y)/\tau],\qquad
\nabla_Y R_{geo}=-\sum_k p_k(Y)\nabla_Y D_k(Y).
\]

当前 delta=1 Å、tau=0.5，分别准备 rho=0.25、0.5、0.75 的 H25/H50/H75。rho 是**先验质量**，不是原始点云在实际梯度中的百分比；posterior 还取决于当前距离。将不同模式保留为分别的势场，有助于避免直接对教师坐标取均值产生几何折中；较高温度或冲突目标仍可能发生抵消，不保证混合一定更好。

主试验不加入接触奖励，保持与纯锚定/静态教师的清晰对照。另准备一个条件性辅助试验：若 H50 的亲和力先得到改善，再比较

\[
R(Y,t)=R_{geo}(Y)+0.05\,u(t)^2 C(Y),\qquad
u(t)=\operatorname{clip}\left(\frac{t-a}{b-a},0,1\right).
\]

只在晚些阶段逐渐增加少量接触偏好，尝试保留 I4 的应变收益并减少过早抢占空间主方向。该时间规律是待检验的工程假设，**不是已从富集变化率拟合出的规律**。全窗口的主几何梯度仍持续生效，不会只引导几步。a/b 读取实际输入元数据，没有在奖励模块硬编码 0–0.5；此例为 0–0.5，之后原生推理到 1。

注入仍使用既有 FLOWR 坐标 Jacobian 路径、单次共享模型前向、归一化梯度与预测流相对剂量 eta=0.33。不额外调用 affinity head、不对其求导、不做粒子重采样。保留既有几何步长/严重新冲突约束，不添加限制化学图变化的控制。

新诊断记录原始点云 posterior、混合 posterior ESS 以及端点空间的梯度抵消比例 `||sum p_k g_k|| / sum p_k ||g_k||`，另记录加权接触梯度在几何/接触两项范数和中的份额与两项方向余弦。不能只凭接触系数小，就假设它在几何梯度接近零时仍然影响很小。这些指标能识别组合是否退化到单一教师、相互抵消或接触项抢占方向；它们不是经过 FLOWR Jacobian 后的状态空间分解，也不是亲和力指标。当前仅记录，不据此添加接受 gate。

## 顺序测试与判定

保持 I3、M2、R26、无引导四个冻结基线。提议的新筛选批次为 83/84，每方案 100 个；确认批次为 85–90，每方案 300 个。master seed 42，各方案使用同一批次初态。这里只准备协议，尚未启动生成。

1. 已完成数学契约测试，再逐个测试 H25、H50、H75，不同时改 eta、接触、温度或 Skills。
2. 检查实际梯度方向/剂量确实改变，才能解释函数组合是否有效。若退化为某一端点、梯度近零或相互抵消，先分析混合机制，不能仅增大 eta。
3. 主要比较全部尝试平均预测 pIC50，相对 I3/M2 的成对差值；同时记录唯一高分化学图、精英尾部和有效率。应变为次级目标，不能用改善应变来宣称完成亲和力目标。
4. 只在 H50 获得亲和力增益后进行 H50_late_contact 的单模块对照；若其他 rho 更好，应另行冻结其接触对照，不能偷换 H50 的名义。
5. 将入选方案与最强冻结单一基线在未参与选型的确认批次重测，再决定是否提升为基线。筛选失败保留报告与提交，回退至冻结 I3/M2/R26；不覆盖原始 Steer。

不能靠“把 I3、M2 分别生成的一半分子拼在一起”证明更高平均分：固定预算的群体混合，其期望平均值只是两个均值的加权组合，虽可能改善覆盖但没有超过最好均值的保证。这里测试的是同一条生成路径中可微空间势场的组合，其收益和冲突都需要实际验证。

## 实现、验证与存储

实现位置：`src/evomolsteer/generation/static_hybrid_reward.py`；入口通过既有 `generate_dependency_flowr.py` 注册 `endpoint_static_hybrid`。预处理接口是 `scripts/prepare_static_hybrid.py`，接收基准程序、原始结构引用、静态教师引用及输出目录；运行配置保存在 `configs/experiments/static_combo_v1/`。它是本次依据实测结果提出的数值组合，不是新的 Analyst/Designer 模型响应，也没有自动改写默认 Skills。

参考库只保存一次教师点云，不重复存 50 个相同帧。此例输入静态引用为 802,483 bytes，新混合引用为 21,630 bytes（含原始配体与受体点）；省掉的是重复表示，不是删掉失败对照或全部历史信息。完整谱系与原始分析数据继续保留，可由来源 SHA256 回溯。

14 项相关测试通过：匹配后的标量/梯度极限、条件有限差分、坐标刚体/原子排列不变性、padding、动态窗口、模拟共享前向拉回、解析接触梯度诊断与引用契约。`mathematical_audit.json` 进一步使用真实库的九个扰动点云验证：rho=0 与 M2 静态教师奖励相符；rho=1 与单位原始锚定奖励相符。float64 梯度最大误差约 3.5e-18，float32 约 3.7e-9。rho=1 等价于 I3 方向的结论以 I3 排斥项未激活为条件。

这些是数学/接口验证，未验证新奖励在真实 FLOWR 上的生成质量。此前重复/独立确认队列因引用契约问题停止，本地已修复并保留重试规范；远端当前在 SSH banner 握手阶段无法连接，尚未部署重试或启动新组合。没有新的组合平均亲和力可报告。
