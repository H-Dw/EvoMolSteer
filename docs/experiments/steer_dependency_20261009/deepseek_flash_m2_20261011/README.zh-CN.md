本轮将 M2 模块消融从代理 Agent 改为真实 DeepSeek API。Analyst、Designer 和功能审阅均请求 `deepseek-flash`，不设置其他模型回退。原计划的 GPT-5.6 Luna 配置保留为历史规划，实际配置见 activation.json。

后台流程先生成配对 M2 与无引导控制，每个 arm 200 个分子；随后先完成 Analyst 的删除/方向修改，再固定六份 P_struct Analyst 输出测试 Designer。共 25 个指令条件、每条件六条独立调用链；另有两个数值控制。六条链采用两种等义任务表述，各三次。API 不承诺 token 随机性可复现；FLOWR 固定主随机种子 42 和新批次 2000–2003。相同有效奖励共享推理结果，避免将重复调用变成虚假的独立分子样本。

当前启用 P0/P1/P2 筛查。P2 使用预先冻结的全模块 Analyst 池，剂量消融使用固定 M2 奖励形状，避免根据未经独立确认的筛查赢家改变下游输入。最终模块删减、必要性结论与组合确认仍需交叉不确定性及独立确认，后台不会凭均值或“不显著”自动删除模块。

固定接口给出真实点云奖励公式、单位、FLOWR endpoint VJP、学习范围和参数读取行为。每个条件只允许一个有界参数编辑，或保留/延期。G 只改几何，U 只改剂量；窗口从参考元数据读取，结束后继续原生推理至 1。禁止 SMC、affinity head 求导、原子类型控制和化学图相等门控。配对末态评估使用现有本地评估器，包括预测 pIC50、PoseBusters、同图 MMFF 应变及覆盖率。

证据包含全部标量效应、弱效应和反向效应，使用无损列式 JSON 保存一份。没有按 q 值只取优势行。旧候选性能和逐节点原始曲线不进入本轮 Agent，覆盖和拟合摘要保留。各调用的完整实际输入使用内容哈希引用共同输入库；调用回执保留真实服务模型、用量、请求/结果哈希。功能审阅对六条输出进行盲审并核实引用原文，但其打分不等于统计因果或模块必要性。

本机后台进程负责 API 调用、编译、commit/push、接收数据和数学/化学评估；远端只 pull 和运行 FLOWR。每个正式奖励先提交 Git 再远端执行。数据归档经校验、执行审计和本地评估后，删除本轮原始轨迹、运输包和远端本轮种子副本，保留紧凑指标、哈希、调用回执及报告。历史 Steer 数据不在清理目标中。

首次 packet_v0 试调用发现 Designer 把教师个数 k 与 Å 距离核尺度混淆，并将诊断 pair-kernel 误作奖励项；该真实试调用保存在 pilots/，不计入正式结果。正式 evidence.json 加入公式/单位契约后冻结。不能把此类解释错误当成模块正常响应。
