# I3 为什么较优，以及是否应作为新基准

2026-10-09。针对已完成的批次 75/76、主随机种子 42、每组 100 次完整生成进行回溯分析。新增脚本只读取保存的轨迹和指标，没有增加 FLOWR / affinity 推理调用。

## 结论

I3 是当前六组文字指引条件 I0–I5 中平均预测亲和力最高的方案。更准确的归因是：删除一段提示诱导 Designer 从动态 Steer 教师混合奖励转向固定的原始结合构象奖励，后者在这两批上的方向更连贯。不能从这组结果单独判定“多模态优势构象指引有害”，也不能说已把 Steer 的局部优势区域/趋势成功蒸馏为奖励。

建议把其实际算法命名为 `original_bound_pose_endpoint_anchor`，加入并列候选基线，暂不覆盖 R26 默认配置。`baseline_nomination.json` 已登记准确程序和参考文件的 SHA256，没有提交新的推理或改写正在执行的确认协议。

## 已测量性能

所有预测亲和力均为 FLOWR 终点重评分。应变为同一化学图 MMFF94s 局部松弛的能量解除量/重原子，不是结合能。

## 哪个模块真正发生了作用

### A. 提示层：只移除了 elite_geometry 指引

从 Designer 实际请求中移除的是：考虑多模态坐标目标是否比独立平均的特征目标更能保留真实构象，以及避免平均出不受支持的几何。Analyst 的谱系、时序指引和 Designer 的历史增量指引仍然存在；I3 数值证据权限仍为 `full`，full/unweighted/static/structure/pocket 五个函数族均允许选择。

I3 Designer 的解释将移除该提示理解成“信息约束”，于是选择 structure。这个解释超出了实际协议：删除建议没有禁止读取历史教师。这说明提示确实影响了本次函数选择，但也暴露了 Agent 对“删除指引”和“撤销数据权限”的混淆。高分不能证明这一解释正确。今后应在统一执行契约中明确区分两者，而不是把本次误读固化为新 Skills 规则。

### B. 执行层：奖励目标更换是最大的实际改变

R26 对当前预测端点 Y 使用随 t 变化的 Steer 教师点云 T_k(t)。每步先按 detached forecast 做 Hungarian 对应并选最近 4 个教师；先验包含距离项与 beta=2 的已记录分数倾向，然后对多教师鲁棒距离使用 log-sum-exp。它的几何目标、候选教师和混合响应可能随阶段与当前样本改变。

I3 不再使用这些时变教师或教师分数。它使用同一个原始结合配体 T，并让 FLOWR 继续决定原子类型与化学键，没有固定化学图的 gate。当前作用于全部 25 个活跃原子，是全分子空间模板锚定，不是只作用于已挖掘局部 motif 的奖励。

两者都通过真实 FLOWR 端点预测 Jacobian 回传，都使用 eta=.33、ramp=0、相同 0–0.5 窗口，之后无 guidance 生成到 1.0。实测 50 个控制步均注入非零位移，窗口外注入为零。

### C. 0.5 的锚定权重没有导致更弱的引导

I3 的执行函数为 R(Y) = 0.5*L(Y) - 2*P(Y)，接触权重为 0。其中：

q = mean_i ||Y_i - T_pi(i)||²；L(Y) = -(sqrt(1+q)-1)；P(Y) = mean_i sum_j relu(2-d_ij)²。

对应关系 pi 在当前导数中冻结。全部保存的预测状态中 P=0，因此实际梯度只来自 L：

g_t = -0.5 / [N*sqrt(1+q)] * J_FLOWR(x_t)^T (Y-T_pi)。

控制器对每个分子的梯度归一化，正的整体因子会被抵消。实际注入方向相当于 normalized[J_FLOWR^T(T_pi-Y)]，强度由 eta、预测 flow RMS 与时间剂量控制。

独立生成已验证：锚定权重 0.5 的 I3 与此前锚定权重 1 的纯锚定控制，在 0.5 的坐标/原子/键状态、最终记录及 SDF 上完全一致。它们共享相同种子，这证明执行可复现，不构成新随机样本上的统计验证。因此不能把 I3 的收益解释成“降低锚定权重，给周围区域更多自由”。排斥项也未贡献本次亲和力增益，但在其他状态上仍可能发挥作用。

## 轨迹为何支持“稳定目标”解释

|已实现的诊断|R26|I3|M2 静态教师|
|---|---:|---:|---:|
|每控制步平均注入 RMS / Å|0.01480|0.01495|0.01481|
|相邻步梯度平均 cosine，排除首步合成值|0.64221|0.77262|0.75259|
|相邻步梯度 cosine<0 的比例|5.35%|2.82%|3.08%|
|最终生成点云对原始配体的 Hungarian RMS / Å|0.81385|0.62421|未在此表重新计算|

I3 注入幅度只比 R26 大约 1%，而方向连续性明显更好。对原始结合构象的终点距离更小，接触代理略提高（.68884→.69356）。这些是观测支持，不能把接触代理改进直接解释成物理亲和力提高。

FLOWR 的 Y 是最终端点预测，即使在早期 t 也指向最终结构。Steer 每阶段的预测端点差异同时包含预测误差、筛选群体变化和真实模式变化；直接把这种差异当作必须跟踪的时间目标可能增加移动目标的噪声。固定的成熟教师或原始结合构象可以提供更持续的方向。这是合理假设，尚未将各噪声来源逐一因果分离。

M1/M2 提供更有针对性的控制：在 eta=.33、ramp=0、beta=0 的相同混合公式下，把动态教师替换为学习窗口末个节点 t=.49 的固定端点预测教师，均值从 7.58307 升到 7.74466（+0.16159）。两批均提高约 .1616。M2 仍是多模态混合，因此这支持优先排查教师的时变目标，而非全面剔除多模态。

相比之下，仅把 R26 教师的分数倾向去掉，M1 对 R26 只提高 .00363，无法解释 I3 的主要增益。

剂量也有作用：同样的纯锚定方向，eta=.2 的 I2 为 7.61593，eta=.33 的 I3 为 7.73534（+0.11940）。I2 的非零锚定系数同样受归一化抵消，其排斥也未激活。这个对比支持当前锚定方案充分剂量的效果，不意味着继续无限增大剂量一定更好。

## 是否存在代价

I3 的有效独特化学图少于 R26（44 vs 59），说明该模板可能集中生成分布，不能据此声称更自由地探索潜在空间。按每个 canonical SMILES 首次出现的样本去重，预测 pIC50 仍提高（7.43589→7.50978），但提升小于全部尝试的均值提升。

I3 周围原子的局部 MMFF 松弛 RMS 为 .35474 Å，R26 为 .28518 Å，M2 为 .28762 Å。该诊断在无受体参与的同图局部松弛中计算，不等于口袋适配能，但说明应变中位数下降没有自动转化为更小的周围位移。

I3 的最高分为 8.35858，固定精英阈值以上有效样本只有 1/100。历史 Steer 有 37/1000，且预算和样本量不同。当前结果不能证明 I3 已解决“极高亲和力路径发现与保留”，也不能按不同 N 的最大值判定优劣。

M2 对原生 flow 的梯度方向平均更相反，却仍有较高均值。因此不能把“尽量与 native flow 同方向”视作通用质量规则；native 自身未必朝目标最优点移动。相邻步方向稳定性、目标是否有效和注入剂量需要分开评价。

## 基准线决定

适合：把实际 I3 算法作为“原始结合构象锚定”的简单、明确、无需 Steer 坐标的并列候选基准，与 R26 动态教师、M2 静态教师、无引导共同比较。

暂不适合：直接替换默认配置、据此全局删除 elite_geometry Skills，或把 I3 称为已验证的 Steer 知识蒸馏/跨 target 零样本方案。其 Designer 实际仍读取历史统计；算法依赖原始结合配体与相同原子数，并由本目标上的筛查选出。

现有后台的六批确认协议只允许 D3/D4 等不读取 Steer 输入的候选，I3 不在其中。因此即使该确认完成，也不能自动当作 I3 的独立确认。若要正式提升为默认基线，需要另行冻结 I3 与 M2，在同一组未用于选择的批次和等样本量下验证；优先平均预测亲和力，同时要求有效率与应变不出现实质回退，公开尾部、多样性和周围位移。

可复核文件：`quality_summary.json`、`direction_summary.json`、`I3.response.json`、`R26.response.json`、`baseline_nomination.json`。分析入口：`scripts/analyze_guidance_directions.py` 与原有 `scripts/analyze_dependency_reward_response.py`、`scripts/analyze_dependency_study.py`。
