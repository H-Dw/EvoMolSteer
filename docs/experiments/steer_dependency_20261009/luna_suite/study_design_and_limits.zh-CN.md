# GPT6-Luna 历史 Steer 依赖消融：设计与解释边界

本组是应用户要求停止旧模型队列后重新开始的实验。所有新 Analyst / Designer 调用均显式使用 `gpt-6-luna`，采用隔离的空白上下文。旧模型数据仅保留为数值控制的可复核记录，不计入 Luna 指引消融的模型效果。

## 1. 对比定义

固定历史 R26 的 FLOWR 模型权重、100 个积分步、25 个生成原子、主随机种子 42 和执行控制器。第 b 批实际随机种子为 `42 + 100003*b`。筛查使用批次 75、76，每组 100 次生成；独立确认预先声明为批次 77–82，每组 300 次生成。

I0–I5 比较四类来自旧 Skills 的文字指引：谱系与后续存活、时序支持、精英构象的联合几何、父子增量/历史路径匹配。各组保留同一份数值证据，但删除不同指引块。I5 一次删除四类块。D1–D4 进一步降低可用历史信息，分别允许无分数动态教师库、静态教师库、原始结合结构、受体点云。D1/D2 教师由历史选择结果形成，仍包含隐式选择信息。

D3 的 Analyst 输入和奖励程序均不含生成的 Steer 数据。D4 再从奖励和 Agent 输入中移除结合配体模板，但 receptor crop 仍按原始配体位置裁剪，FLOWR 标准输入与原子数也保持原实验配置。D3/D4 可以称为“本次 Agent 输入与奖励不读取 Steer 轨迹”，不能称为完全无目标先验或跨 target 零样本验证。

I0/I5/D3 各做第二次独立的 Luna Analyst→Designer 调用，输入冻结、不提供生成指标。第二次输出出现不同的函数或剂量，说明模型输出存在变异。仅两次调用不足以精确估计模型方差。实际生成结果完全相同的数值程序才允许以等价证书复用测量，不能虚构独立重复。

## 2. Agent / Skills 如何响应

每次 Analyst 请求包含角色指引、允许读取的证据、证据 ID 和结构化输出 schema。Designer 只读取同一条件的证据与其 Analyst 结果，并从明确的可微函数注册表中选择函数族和允许的参数。编译器检查 schema、证据引用、参数适用范围与 SHA256，将真实输出编译为执行配置。没有在 Skills 中加入 VPN、GitHub 或当前目标的特定残基指令。

`agent_input_audit.json` 验证实际请求中删除了相应字句、角色指引确实送达、引用指向存在的输入、输出进入编译器，以及 D3/D4 没有 Steer 统计或教师坐标。`role_model_ledger.json` 与显式模型调用记录核实 26 次 Luna 角色调用。模型设置与 Skills 分离。外部 API 接口保留；若 API 环境指定的模型与实验声明不同，会在网络调用前拒绝执行。

这只能证明指令和选择进入工作流，不能证明某一句话必然造成性能变化。Designer 同时改变了函数族、参数与剂量，I/D 条件名也没有盲化。原 R26 的数值配置得到固定，但本次完整 Agent 输入只保留历史统计表的最强 8 项和最弱 2 项及原始结构几何，没有原先完整的局部坐标库、所有节点曲线和谱系支持。I0 是本次压缩输入的完整指引基线，不是旧 R26 原始长上下文的逐字复现。

## 3. 历史证据与无历史证据分别支持什么

历史证据包括全 0–0.5 窗口的终点对比、局部空间形状、增量效果和后续存活效果。Luna 识别到短尺度 pair kernel 与优势终点正相关、较大尺度关系反向，以及不同局部坐标/协方差分量具有不同方向。它同时指出：部分整体效应与首末变化方向不一致，增量与后续存活项的多重检验结果不足以建立可靠规则。因此没有将相关性当作因果优化规律。

D3/D4 没有生成历史标签，不能开展选择富集、成功失败谱系或轨迹趋势推断。其 Analyst 能提出的方向限于原始结构的配体空间支撑、受体距离壳层、局部接触覆盖及距离排斥等待验证几何假设。这样的输出不等于恢复了 Steer 中的精英 motif，也不能凭原始结构直接声称预测亲和力会提高。

当前是受限函数注册表内的设计实验，不是允许任意 Python 奖励源码的无限制搜索。消融结果反映该工作流与注册表的能力边界，不能证明历史 Steer 数据在所有奖励设计方法中都无用。

## 4. 可执行函数和梯度

以 FLOWR 当前终点预测的世界坐标 Y 为输入，不对 affinity head 求梯度。原始结合配体 T 与受体重原子 P 只作为结构先验。Hungarian 配对由 detached forecast 计算，并在本次导数中冻结。

令 q 为生成点与配体模板的平均平方距离，d_ij 为生成原子到受体点的距离：

- 配体锚定 L(Y) = -(sqrt(1 + q) - 1)。
- 接触 C(Y) = mean_i [1-exp(-sum_j exp(-0.5*((d_ij-3.6)/0.6)^2)/4)]。
- 排斥 P(Y) = mean_i sum_j relu(2.0-d_ij)^2。
- 结构奖励 R(Y) = wL*L(Y) + wC*C(Y) - wP*P(Y)。pocket 函数令 wL=0。

单位为 Å；3.6/0.6/2.0 是通用几何代理超参数，未解释为原子类型依赖的物理能量。接触饱和减少受体点密度导致的无限增益。该函数不是 Vina 能量，也不含本次亲和力推理输出。

完整 R26 则使用按时间变化的高分 Steer 终点教师点云混合，unweighted 去掉混合的分数倾向，static 使用固定教师点云。它们仍读取历史生成结构。

控制器通过真实 FLOWR 坐标终点预测的 Jacobian–vector product 将梯度传回当前状态：g_t = J_FLOWR(x_t)^T * grad_Y R。标准化后的方向乘以 native predictive-flow RMS 与 eta；外部时间剂量 s(t)=(0.1+0.9*clip((t-a)/(b-a),0,1))^power。随后执行原 R26 的单原子位移、累计位移与严重碰撞回溯限制。窗口 a/b 来自配置，当前为 0/0.5，之后继续原生推理到 1.0。

新的推理没有 Steer / SMC、没有复制粒子；实际选择映射始终为 identity。每一步只有一次生产 target forward，另有一次性预检调用单独记录。原 affinity 输出不进入奖励导数，最终预测亲和力统一重评分。没有限制化学图必须保持相同的 gate。

## 5. 为什么权重变动有时完全没有效果

`scalar_weight_response_audit.json` 对两组独立生成发现：0.5 的全部保存状态逐字节一致，最终记录和 SDF 也一致。在这些样本中，接触项为零权重，所有预测状态的排斥项都为零，只剩锚定项梯度。梯度标准化会抵消正的整体倍数，因此 0.5/1/2 的锚定权重可能对应完全相同的注入。这是这些条件下的实测等价，不是声称所有结构、所有参数都等价。

对有接触项的方案，权重比例可改变梯度方向；eta 和 ramp 改变实际注入强度。`reward_response` 同时保存各分项活跃比例、首末观测、实际一阶变化和终点几何汇总，避免只按配置数字解释效果。一阶奖励上升不等于有限步精确奖励上升，更不等于亲和力上升。

## 6. 统计与报告要求

主指标使用全部生成尝试的 FLOWR 预测 pIC50，同时报告有效分子与 PB fast、P95/最大值、固定精英阈值、有效独特化学图，以及已收敛的同一化学图 MMFF94s 局部应变解除量/重原子。MMFF 应变代理不是结合能或实测稳定性。

同批次同 slot 成对比较，按 batch bootstrap 计算不确定性。100 次筛查仅有两个 batch，置信区间只作描述性参考。确认集不参与 Agent 输入或调参；只确认预先允许的 D3/D4/D3 repeat/M3 中筛查均值最好的方案。M3 是 D3 空间函数配以 R26 的 eta=.33、ramp=0，用于拆开“缺少历史数据”和“采用较保守剂量”两种原因，不是一次新的 LLM 设计。

历史 Steer 的 1000 个结果是不成对、不同计算预算的参照。必须区分均值与极高亲和力尾部，也不能用 100/300 与 1000 样本的最大值简单判断算法优劣。最终判断需同时看确认集、质量指标和探索多样性。
