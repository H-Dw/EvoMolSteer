**实验设置、最优候选、教师选择与 S3 函数说明（2026-10-13）**

本次只读取冻结代码、API 记录和终态评分，不运行 LLM 或分子生成。新增统计是对此前“平均质量优先”报告的补充，不事后改写原预注册检验。最高分均指同一 FLOWR head 的终态预测 pIC50，不是实验测量。

**1. 角色链与数值实验是两个层次**

数值实验从冻结 M2 出发，预先注册 W1/W2/W3（剂量时间分配）、S1/S2/S3（固定与同评分时刻教师之间的奖励混合）、C1/C2/C3（几何响应曲率）。温度不变，固定 seed42，候选与对照使用相同索引批次输入。各 200，S3/C2/C3 各扩展到 400；总计 2,400 次新增生成尝试。原 M2 400、无引导 400 和历史 Steer 1,000 复用。

每个样本完成 100 个积分步：评分节点 t=0,0.01,…,0.49 实施坐标 guidance，最后一次更新至状态时刻 0.5；随后不注入 guidance，继续至终态。推理无粒子重采样、无 affinity-head 求导。学习窗口由 metadata 指定。这是本工程本轮的执行设置，不能混同论文所有案例的默认参数。

Agent 实验评估：在相同数据和受限程序目录下，新增科学指引是否改变读取的证据、提出的假设和选中的奖励程序，进而改变生成质量。它不是开放式 Python 奖励创新实验。

一条角色链为：空白上下文 Analyst → 只读 ReAct tools → findings/hypotheses/limitations → Designer 读取交接与继承引用 → 返回 edit/retain/defer → 确定性编译器生成注册奖励。Designer 不读取本轮新生成质量来挑选赢家，也不直接手写运行时 Python。

W/S 各有 00、10、01、11 四条件，C 有 00/11 两条件。00 使用通用 Skills，10 只追加 Analyst 扩展，01 只追加 Designer 扩展，11 两者追加。每条件六条空白上下文角色链，两种等义任务表述各三次，真实 DeepSeek Flash API temperature=0。零温度不代表远程调用绝对确定，也不能把这些输出当作独立分子实验。

六条链按数值程序众数选择；平票优先 M2，否则按程序签名排序，不看生成成绩。相同数值签名直接复用同一批生成结果。

**“60 条链均未选择 S2/S3”必须补充菜单限制：只有 24 条 S 链有资格选它们。**

| S 条件 | 六条链输出 | 条件众数 |
|---|---|---|
| S00 | S1×4、M2×2 | S1 |
| S10 | S1×6 | S1 |
| S01 | S1×5、M2×1 | S1 |
| S11 | S1×6 | S1 |

所以准确计数为 24 次可选机会中，S1 21 次、M2 3 次、S2/S3 各 0 次。其余 36 条 W/C 链的菜单根本没有 S2/S3。不是 60 条分子轨迹未到达 S3，也不是 S3 未生成；S3 已作为预注册数值对照完成 400 个样本。没有实际的 Designer-S3 成功调用可供总结，S3 来自确定性数值对照。

接口交付、引用和编译已通过，但不能据此断言科学决策正确。W/C 部分条件混用 v2/v3 协议，也限制了模块因果归因。

**2. Steer 的算法行为与应用目标**

FLOWR.ROOT 的 importance sampling/SMC 用奖励权重重采样固定数量粒子，从而把计算和后续繁衍机会向高奖励路径倾斜。其形式目标是奖励倾斜后的生成分布，富集是手段；不承诺每次找到全局最大值，也不只用于增加候选数量。[原论文 Methods：Inference-time scaling](https://www.nature.com/articles/s41467-026-74130-9)。

如果应用只需要少数最优秀候选，建议未来前瞻将固定预算下的有效 Top-1、化学图去重后的 Top-5/10、达到高亲和力阈值的独立候选数及其应变/姿态质量作为主要结果；均值和全体有效率保留作分布诊断。仅看均值会偏向“修复较差 seed”，不一定奖励发现新高峰；仅看最高值则容易被样本数和个别异常高分主导。应明确输出预算和在线计算预算，两者不同。

**3. 应变指标究竟是什么**

本工程使用 `terminal_evaluation.energy_relaxation`：固定生成构象的重原子，先加氢并最多 500 次迭代松弛氢，得到 E_pose；保持同一化学图，释放所有原子，进行最多 1,000 次 MMFF94s 局部优化，得到 E_local。两阶段均收敛才统计：

strain_proxy＝(E_pose−E_local)/N_heavy。

它衡量该生成姿态可通过局部几何松弛释放多少内部能量。键长、键角、扭转、离面和分子内非键作用都可能贡献，不能从一个总数分辨具体来源。当前计算不包含受体相互作用，不是结合自由能，也不是相对全局最低能构象的完整应变；一个局部极小的错误构象也可能得到很低的数值。MMFF 的组成和计算接口见 [RDKit 官方文档](https://rdkit.org/docs/source/rdkit.ForceField.rdForceField.html)。结合构象应变与构象复杂性、参考构象估计有关，不能跨方法直接套用阈值：[J. Med. Chem. 原始研究](https://pubs.acs.org/doi/abs/10.1021/acs.jmedchem.2c01744)。

应用价值是辅助排查高分但畸变的姿态、对可比候选排序、定位需要局部重优化的区域，以及检查 guidance 是否以不合理内部几何换取高预测评分。最好联合松弛位移、蛋白碰撞/接触保留和其它评估判断。低应变不自动等于高亲和力、易合成、化学稳定或 ADMET 良好。

本工程的 PB 是 `dock_fast` 结构检查子集，不是完整 PB-valid；高应变样本通过 PB 并不矛盾。不同化学图之间比较内部绝对能量没有直接意义；此处比较各自图内能差，仍需注意力场与构象覆盖限制。

**4. 最优候选的逐分子比较**

以下最高分样本均结构有效、通过 PB dock_fast 且 MMFF 收敛。Top-5 是在这三项条件下，每个 canonical isomeric SMILES 取最高分姿态后选前五的均值；它是候选 shortlist 统计，不是去重产率估计。

| 条件 | N | 最优 batch/slot | 最高 pIC50 | 该分子的应变/重原子 | 去重 Top-5 均值 | 高阈值有效姿态/独立图数 |
|---|---:|---|---:|---:|---:|---:|
| 无引导 | 400 | 6382/43 | 8.57340 | 1.17392 | 8.34588 | 3/3 |
| M2 | 400 | 6379/40 | 8.34576 | 0.38314 | 8.22497 | 3/2 |
| S3 | 400 | 6382/31 | 8.33213 | 0.39922 | 8.17933 | 3/1 |
| C2 | 400 | 6379/40 | 8.34568 | 0.38277 | 8.18484 | 2/1 |
| C3 | 400 | 6379/40 | 8.34570 | 0.38281 | 8.22497 | 3/2 |
| 历史 Steer | 1,000 | 11/30 | 8.70481 | 5.89230 | 8.57406 | 37/23 |

这里高阈值仍为预先冻结的 8.258901977539063。独立图按保存的 canonical isomeric SMILES 去重，不等于骨架或三维模式均不同。

原报告的“有效高尾部”统计的是姿态/生成尝试，不能解读为同样多的不同候选。尤其 S3 的三个高分姿态都属于同一化学图；M2 为两个图，Steer 为 23 个图。全部有效独立图数量：无引导 225、M2 139、S3 131、Steer 401（样本数量不等）。这是引导分布收缩的现象证据，不证明具体模块导致塌缩，也不支持增加化学图锁定 gate。

Steer 的最高分 8.70481 对应应变 5.89230/重原子，25 个重原子约释放 147.31 kcal/mol，需进一步检查姿态。但是 Steer 还有：

| batch/slot | pIC50 | 应变/重原子 | 说明 |
|---|---:|---:|---|
| 4/27 | 8.62589 | 0.63132 | 亲和力高，应变低于 M2 群体 p90 |
| 17/21 | 8.58440 | 0.38923 | 应变接近 M2 最优候选，亲和力明显更高 |

因此不能把 Steer 的高分优势全部解释为高应变假象。17/21 的 batch 也不在原 0–13 的教师发现批次中；后续若扩充教师库，应显式记录发现/评价数据边界。

补充事后诊断：若统一要求应变不超过原 M2 群体 p90＝0.8680609，最佳预测 pIC50 为无引导 8.28885、M2 8.34576、S3 8.33213、C2 8.34568、C3 8.34570、Steer 8.62589。这个相对保护线不是通用物理有效性阈值，没有加入生成过程。

最高值受 N 影响。为检查输出数量影响，从 Steer 20 个完整批次中每次无放回抽 8 批（400 个输出），seed42 重复 5,000 次；最高有效分的中位数为 8.62589，2.5%/97.5% 分位为 [8.34794,8.70481]。97.52% 的这些子面板最大值超过当前 M2/S3 的观测最大值。它仅是现有历史面板的描述性敏感性分析，保留了批内克隆依赖；不是新生成、不是置信区间，也不匹配在线计算开销，不能据此报告因果显著性。

其余 200 样本探索的最佳分及应变也已保存：W1 8.41441/2.68423，W3 8.41794/2.68250，W2 8.23859/0.40644，S1 8.34477/0.44403，S2 8.25075/0.35947，C1 8.34557/0.38301。它们不能与 400/1,000 样本的最高值直接当作等预算排名。

**5. 同时刻教师如何建立和选用，M2 有哪些动态部分**

离线教师来源：`continuous/affinity_geometry.py` 在原 Steer 14 个 donor 批次的每个实际重采样评分节点，用记录的即时目标 head 分数排序。每批选最高分 seed，再取一个端点几何特征略有区别（特征距离 >1e−3）的高分 seed，组成 28 个教师。这个弱去重条件不等于严格构象聚类。

`affinity_endpoint.py` 复用其端点预测坐标。M2 的 `dependency_ablation.py` 把所有时间帧的教师字段替换为最后学习节点 t=0.49 的字段，并把教师分数清零。S3 的 `ablation/evidence.py` 另外提供每个评分时刻的原始教师库。

在线使用：每个 seed 都以本次 FLOWR 的端点预测 yₜ，与所有教师做几何 Hungarian 原子槽匹配，计算匹配均方距离 d²；选距离最近的 K=4 个教师。教师先验为 softmax(−d²/4)，奖励温度 τ=0.5，teacher_score_beta=0。所以“优质”由离线中间评分预选，“当前最适合哪个教师”由在线几何决定；并不是每步调用 affinity head 再选一个最高分教师。

| 内容 | M2 行为 |
|---|---|
| 教师来源 | 固定 28 个 t=0.49 中间端点预测教师，不是一个 t=1 最优分子 |
| 时间调度 | 无显式 ramp，窗口内 dose factor 恒为 1 |
| 近邻教师 | 每 seed、每步重新选择几何最近的 4 个 |
| 原子对应 | 每步重新做 Hungarian，忽略原子类型/化学图匹配限制 |
| 教师先验和奖励责任 | 随当前端点距离变化；先验与离散匹配 detach |
| 空间梯度 | 通过当前真实 FLOWR endpoint Jacobian 回传，因此随状态和时间变化 |
| 位移大小 | 按每 seed 的预测流位移 RMS 标定到比例 0.33，再经过原子/累计位移上限和严重新碰撞回退 |
| 化学图 | 原生生成允许变化，无图相等否决 |

因此 M2 是固定教师库和参数形式下的动态条件控制，不是固定方向、固定向量，也没有动态在线选种/克隆。`geometry_block_weights` 等历史配置字段不能等同于本 pointcloud 分支实际启用的局部区域加权；该分支代价是全体活跃原子的匹配均方距离。

**6. 是否应使用终态极高亲和力祖先**

这更直接对应“少量极高质量候选”目标，值得优先作为独立方向验证，但不等同于 M2，也不保证必胜。即时高分教师回答“此刻评分高的构象是什么”；终态祖先教师回答“最后成功的路径此刻具有何种特征”。未来会优秀的分支早期不一定即时最高，当前策略可能遗漏它。

建议离线用统一终态重评分选择多个独立、高亲和力且姿态合理的终态图/模式，沿 selected_indices 回溯每一评分节点的真实祖先，使用该祖先当时保存的端点预测 X̂₁(t) 作为教师，以保持与端点奖励的表示一致。不能把祖先的含噪 Xₜ 坐标直接当作本函数的终态目标；不能仅按 slot 数字跨时间拼接路径。

极早期多个优秀终态可能共享同一祖先，应合并其几何教师并保存后代身份，不重复放大权重。消亡路径没有观察到未来，不应标为低终态亲和力。保留多个模式和几何适配选择，避免将所有 seed 强拉到一条历史路径。不要先加大 score beta 或强度来掩盖教师表示差异。

已有 `build_terminal_path_credit.py`、`build_terminal_path_library.py` 支持祖先信用和身份教师；应验证原时钟及文件来源后复用。最干净的比较是：冻结 M2；同数量同参数的终态优秀分子祖先在末学习节点的固定教师库；其全窗口身份连贯教师库；最后才测试与 M2 的时序混合。这样区分终态选择、路径身份与时序权重的作用。该方案是研究建议，本次未执行。

**7. S3 的实际函数，不是已存在的 Designer 新设计**

对教师集合 T，在当前点云 y 上，固定本次 Hungarian 对应与最近四个教师，令 qₖ(y) 为匹配均方距离、πₖ 为上述分离梯度的几何先验：

R_T(y)＝τ log Σₖ πₖ exp[−ρδ(qₖ(y))/τ]，ρδ(q)＝δ²(√(1＋q/δ²)−1)。

S3 设置 δ=1 Å、τ=0.5、K=4、几何先验温度 4 Å²，beta=0，均沿用 M2。它不是对两个教师坐标做插值：

Rₜ(y)＝[1−b(t)]R_fixed(y)＋b(t)R_same-clock,t(y)。

b 在归一化观测评分节点位置 0、0.5、1 上取 0、0.5、1，分段 smoothstep。当前实际值为：t=0→0；0.10→0.181897；0.20→0.455592；0.30→0.564280；0.40→0.847156；0.49→1。之后停止 guidance，保留原生后半程。动态参考成员可在节点间更替，所以平滑 b 不保证奖励梯度连续。

对真实 FLOWR 端点预测 yₜ＝X̂₁,θ(Xₜ,t,P)，gₜ＝Jₜᵀ∇ᵧRₜ。合成标量只需一次端点 forward 和一次 VJP；不经过 affinity head 求导。位移 RMS 约为 0.33×RMS[Δt(yₜ−Xₜ)/(1−t)]（同坐标单位、上限/回退前），沿 gₜ 方向，在原生更新后叠加。梯度是步前当前状态的条件导数，不是注入后额外 forward 得到的新 reward。

本轮 Designer 实际上应输出注册 `edit_choice=S3_static_to_observed_control` 加真实假设/曲线引用，编译器展开上述执行表；但 24 条 S 链没有这样输出。因而不能报告“对应 Designer 已发现早期固定教师更好”的事实。若后续让 Designer 基于本轮结果选 S3，应明确标记为结果知情的再设计，并使用新的匹配数据检验，而不是当成本轮盲选成功。
