**四、数值机制与实际执行**

令 FLOWR 对当前状态的端点预测为 yₜ＝X̂₁,θ(Xₜ,t,P)。S3 使用：

Rₜ(yₜ)＝[1−b(t)]R固定(yₜ)＋b(t)R同时刻(yₜ)，b(t)：0→0.5→1。

这里混合的是两个标量奖励，不是把两个教师坐标平均成一个分子。固定教师来自 M2 冻结的学习末节点端点预测库；同时刻教师来自对应评分节点的历史端点预测库。都不是早期含噪当前状态，也不能等同于终态解码后亲和力最优的分子。

空间引导由 gₜ＝J端点(Xₜ)ᵀ∇ᵧRₜ 计算：复用一次真实 FLOWR 端点 forward，对合成奖励做一次 VJP；教师选择和匹配离散步骤 detach。没有通过 affinity head 求梯度。剂量保持 M2 默认，S3 改变的是奖励目标相关性。

C 方向改变 pseudo-Huber 空间尺度 δ，其基本代价为 ρδ(q)＝δ²[√(1＋q/δ²)−1]，q 为平方匹配残差。δ 越小，对远距离偏差的惩罚越稳健，会改变梯度响应及教师责任分配；它不是温度，也不能简单理解为整体引导更弱，因为控制器还做 RMS 标定。

实际 trace 证明 W 调度生效：W1 首/末节点注入与标定 RMS 比为 0.1155/0.5445，W3 相反；W2 两端约 0.1667、中部约 0.4996。各路线窗口平均比例均约 0.33，W 的 cap/碰撞回退比例为 0。相同平均请求预算不等于逐 seed 相同物理位移。W1 下降不能归因于“权重没有执行”，也不支持直接进一步加大后期权重。

一种待检验解释是：早期同评分时刻的历史端点预测噪声或模式偏置较大，固定教师提供较稳定的方向；进入较后阶段后，同时刻教师提供不同的几何覆盖。竞争解释包括教师模式选择、距离分配和两个奖励梯度的抵消差异。现有数据没有分离这些机制，不能把早期 forecast 不可靠当成已证事实，更不能推出模型某个内部模块的因果贡献。

**六、值得继续研究和应用的方向及顺序**

**优先 1：把 S3 作为可选候选，保留 M2 基准；验证 S3、S2 与 M2。**

当前可应用的价值主要是较好的整体质量和较差样本改善，适合优先考虑平均成功率/适配性的候选生成。极高亲和力发现仍应保留历史 Steer 作为参照。S2 是必要对照：如果恒定混合同样好，收益可能来自增加教师模式覆盖，未必需要复杂时序。

下一项单模块研究应固定温度、剂量、曲率与教师集合，只比较固定教师、恒定混合、S3 时序。先冻结方案，再在新增匹配批次验证；原 400 对照可用于当前开发比较，不能重复抽样伪装成新验证。需要新增独立输入时，相应对照也必须匹配新增输入。不要一开始叠加 S3＋C3＋剂量修改，否则无法区分收益来源。

**优先 2：改进 Agent 的方向辨别，而非仅扩充格式约束。**

建议作为新的可选研究指引和审计模块，而不直接覆盖当前基准 Skills：

1. 使用中性方案 ID，对数学上对称的调度提供同等说明；随机化目录顺序。隐藏“主干预/反向 control”措辞，检验选择是否随标签改变。
2. Analyst 输出“哪些观测能区分两个时间方向”的对比证据表：对应时间节点、独立批次支持、端点预测稳定性、候选与教师的匹配残差、模式覆盖和反例。如果曲线只支持存在时间变化，明确记录不能识别调度方向。
3. Designer 对每个可行方案写出不同的可检验预期，不能以“control”名称排除候选；不能从一条非单调区域曲线直接推导全局单调教师权重。有证据不足时允许 retain/defer。
4. 在统一 v3 接口下验证“实际读取→方向判断→程序选择→实际梯度→终态质量”。当前分子结果可以用于开发假设，不能再次作为未见过的验证集。

增加两个奖励在端点空间的梯度夹角、梯度范数、匹配残差与教师责任熵的精简批次/节点汇总，可帮助区分目标冲突和强度问题。端点空间的夹角不等于经过真实 Jacobian 后当前状态空间的夹角；若做后者诊断，应单独计量额外 VJP 开销，不把它无说明地加入每步生产推理。生产阶段继续一次 FLOWR forward、一次合成奖励 VJP。

**优先 3：从“同一时刻的优质几何”走向“通往终态高亲和力的多条连续路径”。**

本轮两套 reference 都是每节点 28 个教师，`label_semantics` 为已移除记录亲和力、采用等评分先验；都没有 `teacher_node_ids`、`teacher_path_ids`。所以当前时变奖励不保证在相邻节点追踪同一条终态优秀谱系，也没有显式依据最终 pIC50 区分路径价值。这是本轮表示的局限，不能说原始 Steer 文件中没有这些信息。

仓库已有工具，可先核对历史失败经验后接入当前流程：

| 能力 | 现有入口 | 下一步要检验的问题 |
|---|---|---|
| 终态结果回溯祖先 | `scripts/build_terminal_path_credit.py` | 中间优势是否连接到最终高亲和力，而非仅高重采样分数 |
| 带节点/路径身份的教师库 | `scripts/build_terminal_path_library.py` | 保持路径身份是否优于每时刻独立选教师 |
| 路径/模式覆盖 | `scripts/analyze_outcome_path_coverage.py` | 极高亲和力模式是否在现有库中缺失或低权重 |
| 有限样本尾部信用收缩 | `scripts/regularize_outcome_tail_credit.py` | 避免少数克隆后代导致过大的路径价值估计 |

这些工具不是本轮新证明有效的算法，也不是首次存在；W/S/C 并未单独验证它们。下一轮首先比较“同教师数、同剂量，只有路径身份/终态标签连接发生改变”，不要把多个变化一起打包。

建议区分终态高亲和力祖先、终态普通有效祖先、选择时被淘汰分支。被淘汰分支的自然延续终态未观察到，不能直接标记为低终态亲和力；可作即时选择的负对照，但其未来标签应为删失。以独立 donor 批次/祖先统计，克隆数另存，避免把同一终态化学图重复计为独立高尾部证据。这里的图去重是统计处理，不限制生成中的化学图变化。

候选奖励可保留多个完整构象模式：Rₜ(y)＝τ log Σₘ πₘ(t) exp[−Dₘ(y,t)/τ]，其中 Dₘ 来自身份连贯的路径教师，πₘ 来自有界、收缩的离线终态信用及当前几何兼容性。保持多个模式，避免所有 seed 强制朝唯一最高分样本移动。先改变教师身份，再改变先验，各做独立对照；τ 保持原默认，不引入温度消融。终态标签仅离线提供，不增加每步 affinity head 调用。

该信用是历史 Steer 条件下观察到的未来结果，不能解释为 native continuation 的成功概率。把优势转移到无重采样推理仍需实际测试。

**优先 4：在已验证教师切换上增加 seed 兼容性，作为独立探索。**

相同 t 下，不同 seed 可能适合不同教师。可以研究 b(Xₜ,t)，用匹配距离、连续端点预测变化、教师责任熵等可计算量，在固定教师与同时刻教师之间平滑分配，而不是仅用统一 b(t)。第一轮宜将权重选择 detach、限制变化范围，并保留原始引导窗口，避免通过权重导数钻规则空子或把不适配 seed 直接筛掉。它是新假设，本轮没有执行或证明有效。

只保存按 batch、时间、残差/兼容性分层的样本数、均值、分位数、失败数和少量可追溯代表路径，必要时保留跨节点配对 ID；不用重新展开全部坐标明细。这样能够区分“谁受益/谁受损”，也符合当前精简存储策略。

**暂缓方向：纯剂量重排，以及直接采用 C3 为默认。**

W1、S1 当前参数组合有明确不利信号，应停止同配置重复；不能据此禁止所有早期适配研究。W2/W3 没有亲和力收益证据，优先级低。C1 无明显增益；C2/C3 的应变尾部代价需要解决后再考虑应用。曲率机制可以作为后续单独研究，暂不与 S3 混用，也不因应变变差引入限制化学图变化的 gate。
