# 时序引导实验执行授权与队列

2026-10-13 用户授权：提交代码、远端拉取并后台执行本轮实验；单个实验失败时跳过，不停止整轮。

本轮以独立运行配置激活前瞻计划中的 W、S、C，顺序执行。计划目录中的零调用清单仅为准备时快照，不作为当前运行状态。新运行状态见 `run_status.json`。

- 本地：真实 DeepSeek Flash API 调用、证据与 Skills 交接、编译、最终质量分析、报告及 commit/push。
- 远端：拉取已提交程序后，仅执行 FLOWR 推理、源文件校验、紧凑终态打包；不进行 Agent 科学分析。
- 每个数值候选先生成 200 个样本，固定 seed 42、原对照的四个 indexed batches。使用相同四批对照进行配对比较。只有满足预登记亲和力保护与次级质量条件者扩展至 400，仅增加剩余四批。
- 初筛保护条件：九候选同时区间下界对 M2 高于 −0.02 pIC50、对无引导高于 0；有效率/PB/收敛能量覆盖不明显下降，应变点估计处于既定质量包络。该规则是保守筛查，不将区间不清楚称为无效；极端尾部仍可能功效不足。
- 每个新数值程序/批次只生成一次；不同 Prompt 输出相同程序时共享结果。M2 恒等输出直接复用，不重新生成 400 M2 或 400 无引导。
- 10 个 Prompt 条件，每条件 6 条独立角色链。失败条件记为 `skipped_error`，不作为 retain 或有效消融结果。后续条件继续；已失败条件重启时也不暗中重试。
- 代码/奖励先提交并 push，经本机 VPN 转发后远端 `pull --ff-only`。所有参数在调用前注册；质量结果不进入 Agent 输入。没有激活组合探索或额外尾部扩样。
- 每次生成完成全部 100 积分步，guidance 仅在学习 metadata 支持内生效，之后完成无引导后缀。生产每步一次模型前向；不使用 SMC、原子类型控制或 affinity-head 梯度。
- 保留远端错误日志、失败 trace、状态和本地结果报告。新生成的测试数组在校验、紧凑打包后从本轮专属目录退役；原始 Steer、冻结对照、checkpoint 和历史结果不在删除范围。
- 公共前置配置错误会记为 `blocked_preflight_or_coordinator`；普通 API/生成/分析条件错误会隔离。此状态不能伪报任务已完成。

后台运行依赖本机保持开机、网络及 VPN 可用。远端已启动的 `nohup` FLOWR 子任务独立于当前聊天界面。
