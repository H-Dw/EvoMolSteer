## 3. 完成 400 个样本后的比较

应变使用收敛 MMFF94s 的局部松弛能差/重原子数，单位 kcal/mol/heavy atom。它是姿态应变代理，不是结合自由能；不收敛及不可计算者另报，不填成零。

有效高尾部阈值预先固定为 pIC50 ≥ 8.258901977539063，分母包含全部尝试。以上所有尝试均有预测评分；结构及能量覆盖继续单独统计。S3 390 个有效结构及收敛能量样本，PB 通过 390；M2 分别为 382、382、381。

### S3 的收益与边界

- 对 M2：均值增加 **+0.03175**。普通 95% 配对 bootstrap 区间 [0.00220,0.06280]；九候选同时区间 **[−0.00694,0.07517]**。通过预登记非劣保护，但没有在多重比较控制下证明平均亲和力明确提升。
- 对无引导：增加 **+0.24142**，同时区间 [0.19294,0.30668]，优势明确。
- 对历史 Steer：均值点估计增加 +0.08502，独立批次区间 **[−0.04858,0.22305]**。历史预算、样本数量及克隆依赖不同，不能宣称显著超过 Steer。
- 对 M2 的应变 p90 点估计降低 **17.64%**，有效率提高 **2 个百分点**。这些是次级指标的描述性改善，未在这里另行建立其显著性。
- S3 的 p95 仅增加 0.00053，p99 反而低 0.05176。有效高尾部仍为 0.75%，历史 Steer 为 3.7%。当前目标中的“极高亲和力路径发现与保留”没有得到改善。

S3 的平均收益主要表现为下尾改善：q01 增加 0.28292、q05 增加 0.09104、q25 增加 0.03690，q50 只增加 0.00415。按同一 batch/slot 配对，239 个 seed 评分上升、161 个下降，配对增量中位数仅 0.00028。以 M2 的最低四分位作事后分层，其对全体均值差贡献 +0.05089，其余样本合计贡献 −0.01914。该分层以基线分数为条件，易受到向均值回归影响；只能说明收益分布，不能证明特定空间区域或因果机制。

这意味着 S3 更像是在改善部分较弱路径及整体适配，而不是找到新的极端高亲和力模式。不能仅依据平均分提高，将其认作长尾问题已经解决。[上尾分位图](upper_tail_quantiles.png)同时展示了 cohort 大小，图为经验分布描述，不是显著性检验。

### 曲率方向

C3 相对 M2 的均值为 +0.01078，同时区间 [0.00080,0.02493]，本开发样本存在很小的改善信号。但 C2、C3 的应变 p90 均恶化约 **21.4%**，超过预登记 10% 包络，400 样本检查均未通过次级质量保护。其应变仍优于这组无引导/历史 Steer；不应将其描述为全面崩坏。

曲率修改改变了端点代价及教师混合响应，剂量保持一致。这种纯几何奖励并没有直接限制最终构象的局部内能。因此亲和力略升而应变上尾变差是可观察的权衡；现有结果不支持把化学图变化本身认作质量下降原因。

## 4. 实际引导是否生效

执行 trace 的逐节点数据证实调度生效，不能只用全窗口均值判断：

| 路线 | 第一个节点实际注入/标定 RMS | 最后一个节点 | 全窗口平均 |
|---|---:|---:|---:|
| M2 恒定 | 约 0.3300 | 约 0.3300 | 约 0.3300 |
| W1 | **0.1155** | **0.5445** | 约 0.3300 |
| W2 | 0.1667 | 0.1667 | 约 0.3300；中部约 0.4996 |
| W3 | **0.5445** | **0.1155** | 约 0.3300 |
| S/C | 约 0.3300 | 约 0.3300 | 约 0.3300 |

这是等请求比例预算的预期结果。W1/W3 的平均相同不代表权重未生效。W 候选记录中 cap 和碰撞回退比例均为 0；累计逐步 RMS 剂量约在 0.735–0.742 Å，彼此接近，但该量不是净位移，也不保证每个 seed 物理剂量相同。W1 降分应首先从时序/目标适配审查，而不是盲目增加权重或认为调度被忽略。

S3 的执行奖励为 `R_t=(1-b(t))*R_static+b(t)*R_observed_forecast(t)`，b 从 0 平滑增加至 1，温度、近邻数和 eta 保持 M2 默认。固定教师为冻结的学习末节点端点预测库；动态教师为当前评分节点的历史端点预测库。两者都不是把早期含噪声当前状态直接当成终态，也不是对教师坐标求平均。

早期固定教师、后期同时刻教师在本次数据中较好；反向 S1 较差。可能的解释是早期历史 forecast 尚不稳定，而后期 forecast 更适合接续局部路径。不过只比较到总体质量和剂量，无法据此证明该解释，更不能识别模型内部模块的因果贡献。需要保留“恒定混合同样有效”“教师模式覆盖或责任分配导致差异”等竞争解释。

## 5. Agent 条件为什么全部被跳过

**不是非法 JSON、不存在的引用编号或 API 模型不符。** 两个角色均成功返回可提取的结构化输出，但在确定性时序程序的科学证据校验环节失败：

`Temporal edit needs an actual Analyst hypothesis and observed temporal evidence`

具体审计结果：

1. 10 个 Analyst 均提出了假设，Designer 均选择 edit；没有任何 Analyst 调用 `get_curve` 或 `get_stage_profile`，实际曲线来源数均为 0。
2. 7 个条件只检索了 `continuous_trends` 的摘要行；**W01、S01、C00 仅读取了 metadata**。趋势摘要包含变化率等信息，但没有实际逐节点曲线，不能替代编译器所要求的证据交付。
3. `temporal_profiles_available=false` 只表示新增样条 profiles 未生成，**不表示 200 条现有曲线不可读取**。部分回复混淆了“没有 profiles”与“没有曲线”，也没有检索以验证这项判断。
4. 原始 Skills、选定扩展、研究合同和 JSON 接口的 SHA 与实际请求 binding 完全一致，说明指引确实交付；不能简单归因于 Skills 未加载。但“读取真实曲线”这个科学功能并未落实。
5. 当前必要条件在 Analyst/Designer 都 finish 后才检查，没有把“必须读取并引用相关曲线”的缺口反馈到 ReAct 的 finish 校验/修复循环。因此每个条件在 chain_00 中断，后五条角色链没有执行。

本轮 Agent 提出的未通过程序包括：W00/W10 选 W3，W01 选 W2，W11 选 W1；所有 S 条件选 S1；两个 C 条件选 C1。它们没有形成有效的六链选择结果，也不能用已经完成的同名数值对照来追认 Agent/Skills 有效。尤其 S3 的较好结果是预注册时间反向对照的数学实验结果，不是本轮 Agent 从数据中有效发现并设计出的奖励。

因此，本轮不能判定某个扩展模块对生成质量有正/负效应，更不能据此删掉模块。

## 6. 后续应优先解决的环节

1. 将读取曲线和绑定假设引用的要求移到 Analyst finish 之前：明确选择 feature、调用 `get_curve`，缺失时在既有有界反馈循环中返回可纠正诊断。不能靠放松校验、自动补充未读引用或把摘要伪装成曲线过关。
2. 区分 `curves_available` 与 `stage_profiles_available`；Designer 必须继承与其实际假设有关的曲线来源，不能只检查“曾经读过任意一条曲线”。
3. 精简 Agent 输入中的重复数值数组，保留注册选项语义与签名；完整执行表由确定性编译器维护。再验证扩展是否改变实际 tools 读取、假设和执行函数。
4. 在新版本调用目录完成各条件六链，旧失败记录保留。若输出仍是这九种程序或 M2，复用本轮及固定对照，不需要重做 2,400 个生成。
5. S3 保留为候选，M2 保留为已验证基准。后续应围绕极高亲和力祖先/教师模式覆盖与连续路径适配继续挖掘；需要失败对照、谱系身份和终态标签连接，不能用连续曲线摘要直接推出最优强度。

本次仅收集、审计和保存分析，没有改写 Skills、奖励或重新派发实验。
