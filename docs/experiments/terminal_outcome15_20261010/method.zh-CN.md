# 最终后代表现回溯的坐标引导实验

本任务的 R11、R26 是历史奖励配置及代码检查点，使用同一份 FLOWR.ROOT v2 权重。学习窗口由输入配置与实际评分事件确定；本实验为评分时钟 `[0, 0.50]`，对应最后一次被筛选的 proposal 状态为 `0.51`。标签来自最终解码，不把特征学习或梯度控制延长到最终时刻。

最终报告用 TO01–TO15 表示本次十五轮实验，与历史 R11/R26 区分。代码中的 `roundNN` 对应 TO编号；例如 `round11_R11_neighbors6.json` 是本轮 TO11，名称中的 R11 表示所用历史基础奖励。

## 标签与计算单位

通过 `selected_indices` 将最终 slot 精确回溯至各评分事件的祖先。保存后代数量、有效后代数量、独立化学图数量、图内平均再图间平均的亲和力、分位数、有效比例和高分后代比例。没有可观测后代的分支是“未来未知”，不填成失败或零分。原始 Steer 的中间即时选择分经数据验证是 `pic50_on`；它仅用于条件匹配与选择诊断。

相同当前状态的复制分支共享几何信息，因此先验证坐标及化学状态相同，再合并其后代集合。R05 只修正已选教师的家族评分先验，教师点选择不变；R06 才将家族平均用于教师排序，改变了 26/714 个批次事件的选择；R07 只替换分支方向。最终采用的家族排序策略避免先选碰巧拥有最好后代的复制分支，再以坐标去重。这也不等于估计一个未筛选祖先自然产生好后代的概率：原始轨迹的后代仍受 Steer 选择影响。

历史标签平均删失比例为 0.9042577，支持量随时刻变化。高分比例以所有观察到的最终 slots 为分母，含无效解码；有效比例另外报告。R05/R06 使用均值，尾部奖励权重为零，工具具有尾部效用能力不等于这些轮次已经启用。

## 数学工具与证据

`terminal_outcome` 在全部窗口内计算批次等权的优势组/普通组差异、p/q 值与连续时间二次拟合及导数。克隆、同一祖先和连续时刻不作为独立实验重复。`outcome_summary` 检查中间高分/最终普通与中间非高分/最终变优的交叉组，报告完整分布。相关性及时间导数不能直接解释为空间力。

可选 `outcome_conditioned_geometry` 在共同祖父、不同直接父分支、即时分相近条件下比较空间占据、受体接触、坐标位移、速度和预测流向；不重复使用匹配对，逐祖先和批次汇总，保存紧凑批次表与趋势，不保存膨胀的逐原子特征缓存。几何接触不是结合能。`outcome_matched_reference` 仅替换有支持的自然分支方向；无支持处精确返回已有教师奖励。`outcome_alias_credit` 用观察到的高分后代比例扩展家族效用；`outcome_path_coverage` 诊断教师家族覆盖了多少最终高亲和力路径，不能把这些路径的最大值直接写入奖励。

R07 实际即时分匹配容差为 0.25，方向标签为最终解码的 exact-copy 家族均值。匹配计算得到 266 对、264 个祖先事件、152/686 个有支持的批次事件。137 个匹配特征均无多重校正显著项（最小 q=0.9753）。方向库仅 101/1169 条教师记录有支持，原始方向 RMS 中位数 0.020329 Å、最大值 0.087401 Å；这是稀疏的观察性方向测试，不是固定 motif 或因果力的发现。

## Agent 与实际执行

Analyst 与 Designer 使用 GPT6-Luna subagent 模拟接口。每次请求携带冻结的 literal Skills、注册工具清单、实际计算 receipt、输入/输出哈希、完成轮次的真实指标以及当前基准配置。Analyst 提交结构化发现与反证；Designer 只能使用注册的奖励函数与一个获准参数变化。程序编译器校验请求、Skills、证据、Analyst 回复、参考库及基准程序之间的哈希绑定。保留可选外部 API 接口，本任务不调用它。

分别验证：指令进入 Agent 输入，数值工具实际执行且输入未变，编译奖励相对父配置产生响应，真实 FLOWR 推理产生非零控制与 VJP 响应。第一阶奖励响应是局部导数诊断，不是第二次前向计算获得的奖励增益，也不是最终亲和力提升证明。

## 奖励与比较

奖励是随评分事件变化的教师坐标多模态混合。基于冻结端点 anchor 建立原子置换匹配及局部教师先验；先验同时考虑几何邻近和最终家族效用。平滑距离代价经 log-sum-exp 汇总，有支持时加入小质量的分支虚拟教师。用真实 FLOWR 预测端点关于当前坐标的 VJP 得到控制方向，再按原生预测流 RMS 标定剂量、限制单步过大位移。化学图允许自然变化，无亲和力头导数、额外生产前向或重采样。

开发阶段固定 seed 42、完整 100 积分步及相同初始状态，比较无引导、R11、R26 与各候选最终质量。开发批次上的自适应增益不能宣称泛化。预留两轮新的独立批次，冻结候选程序、参考库和生成源码，重新运行候选、无引导与两个历史控制。历史 Steer 1000 个输出作为未配对参照，不能宣称相同算力或逐粒子因果比较。先评估预测亲和力，再看有效率、应变与高分尾部。

每轮保留配置、Agent 输入输出、计算与推理响应、逐最终分子指标、批次统计、源码与传输证明。校验报告后才删除本任务上一轮的远端及本地生成载荷；原始 Steer 与模型权重保留。
