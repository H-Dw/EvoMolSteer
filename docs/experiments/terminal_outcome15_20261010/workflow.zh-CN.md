# 最终表现回溯的 Analyst / Designer 工作流

本次以历史 R26 点云奖励和 R11 分支混合奖励为两个起点。原始单目标
Steer 数据与模型 checkpoint 保留；生成固定 seed=42，100 个积分步。
每轮仅部署已提交代码，在前轮报告校验完成后删除本轮专属工作目录的旧生成数据。

## 时间与标签

`score_window` 表示实际选择事件的评分时刻，可由调用者指定。当前为
`[0,0.5]`，包含评分 0.50 的事件。控制终点由该事件的实际 proposal/state
时钟确定，因此本数据得到 `[0,0.51]`。学习坐标不延伸至后半程；最终解码
评分仅用于标签回溯。此后的原生积分、SDE 和离散状态更新继续到 1.0。

`terminal_outcome.outcome_labels` 从最后一个节点沿完整 selected-parent
数组反向追踪到每一个窗口节点。有效最终分子的亲和力先在相同化学图内取均值，
再在图之间等权取均值。另保存后代数、独立化学图数、有效比例、亲和力上四分位数
和超过固定尾部阈值的后代比例。这里的“独立化学图”仅指去重身份，不能当作独立实验。
没有最终后代的分支是删失，不记为零分。最终后代均无效的分支也没有有效亲和力均值。

这些是 Steer 选择条件下实际观测的后代分布，不能声称它们是无选择推理的成功概率。
原先边界对照的 metadata 中“joint head”指一次模型前向中的亲和力预测输出；
本轮使用的原始 `single` 臂及教师数值均为 on-target 评分，并非 on-minus-off 目标。

## 计算工具与角色

1. `mine_terminal_outcomes.py` 读取原始轨迹与共同协议的最终评价，构建回溯标签、
   全窗口批次效应、二次趋势曲线及其变化率、覆盖率和可执行教师库。
   批次为统计重复单位，时间节点和克隆不增加独立样本数。
2. `summarize_outcome_labels.py` 明确对照中间高分/最终普通、中间高分/最终优质、
   中间其他/最终优质三组，同时报告观测后代的数量与分布。
   最终高组必须高于中位数，避免并列值同时进入高组和普通组。三组不是完整分区。
3. `outcome_agent.py` 通过统一的请求/响应契约支持 subagent 与外部 API。
   当前使用 GPT6-Luna subagent。请求包含 literal 角色 Skill、terminal-outcome
   模块、注册工具证据、收据、父程序和本轮允许改变的参数。
   请求、Skill、计算输入输出、Analyst 响应和 Designer 响应均校验 SHA256。
4. Analyst 必须使用最终解码标签解释优势，同时保留删失、效应量及反证。
   Designer 只能据已校验分析选择注册公式，每轮最多改变一条数值轴。
   基础标签替换轮不改变剂量参数，也不启用匹配分支/尾部比例扩展。
5. `audit_outcome_reward_response.py` 检验新指令是否改变冻结 endpoint 上的实际
   奖励梯度。它只验证奖励空间响应；实际模型 Jacobian 和轨迹响应由远端生成
   的 preflight 与逐步 trace 另行验证。
6. `score_outcome_round.py` 在本地评估完整最终分子、预测亲和力和 MMFF 应变，
   校验跨实验初始状态一致、51 个控制步、无重采样、后半程零注入及真正执行的
   配置。保存精简指标、配置、Agent 记录及保留清单；之后才允许清理本轮结构。

## 数学对象

教师是窗口内原始 FLOWR endpoint forecast 点云。即时评分仅作为诊断或匹配条件；
新教师的选择及先验以最终回溯质量为依据。几何匹配不要求固定原子类型或固定化学图。
设原生 forecast 为 `y_theta(x_t,t)`，匹配后的教师为 `Y_m`。冻结原生 forecast
上的对应关系和先验，计算有界曲率的多模态点云奖励：

`R(y,t) = tau * logsumexp_m(log pi_m - cost(y,Y_m)/tau)`，

`log pi_m ∝ -matching_cost_m/T + beta*(final_quality_m - mean_quality) + batch_base_log_weight_m`。

随后以真实 FLOWR endpoint VJP 得到 `dR/dx_t = J_theta^T dR/dy`，按原生预测
流的 RMS 标定剂量。R11 保留有界的 natural-branch virtual modes；其基础替换轮
仍使用原有即时分的分支方向，这个限制必须说明，不能误称已实施最终标签匹配扩展。
富集曲线的 `d(feature)/dt` 是描述变化率，不直接当作坐标梯度。

## 存储和解释边界

只保存回溯标签与 batch/event 汇总 Parquet，不展开大规模逐原子、逐边、逐特征缓存。
小型教师库是推理所需的坐标副本。原始轨迹、计算配置和提交版本用于重建明细。
开发批次 131/132 的自适应筛选结论只能用于探索；最终候选须冻结并在未参与
调参的批次 133–136 上验证。原始 1000 个 Steer 分子的比较是非配对参考。

基础改造完成后才依次探索同祖先/相近即时分的空间、接触及速度对比，以及
后代尾部比例与分布。失败候选保留报告，恢复已验证父程序继续探索。
