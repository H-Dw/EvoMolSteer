# 从Steer谱系学习坐标规则：方法、证据与实验判据

核心目标是提高最终小分子的预测亲和力，同时保留接近Steer的构象合理性与能量稳定性。边界形状相似只是中间判据，不能替代最终分子评价。当前实验不把化学图改变视为失败原因，也不要求保留原图。

## 文献方法如何迁移

[Felsenstein的系统发育比较方法](https://ichthyology.usm.edu/courses/multivariate/Felsenstein_1985.pdf)提醒我们，谱系相关性会破坏独立样本假设。SMC树是复制与筛选的谱系，分支不满足经典布朗演化模型，不能直接套用系统发育独立对比。因此，统计重复单位采用生成批次；下一步收益分析每个父节点只计一次；等根和根内分析诊断祖先频率混杂。复制次数保留为选择结果的权重。

[STREME的motif发现思路](https://pubmed.ncbi.nlm.nih.gov/33760053/)提供前景与背景对比的组织方式。这里的motif是口袋参照系内的空间分布，不是序列片段。前景分别定义为即时选择与边界存活祖先，背景为同一时刻的全部候选；无引导生成另作参照。前景/背景必须分开，不能从高分分子集合单独总结“优势”。

[PLIP的相互作用识别](https://academic.oup.com/nar/article/43/W1/W443/2467865)结合化学属性与几何。我们目前的壳层和原子对距离核缺少供受体、芳香性、荷电与角度等充分条件，因此只称为几何描述量。早期原子类型来自FLOWR的终态预测，尚未成为稳定化学图，不能把早期距离核解释为氢键或局部结合能。

[NSGA-II](https://web.njit.edu/~horacio/Math451H/download/2002-6-2-DEB-NSGA-II.pdf)启发奖励程序之间的非支配比较与回溯。当前实现是小预算的Pareto程序探索，比较亲和力、边界形状、有效率、能量中位数/尾部和周围区域松弛位移；没有实现完整NSGA-II的交叉或拥挤度机制。遗传选择作用于奖励配置，FLOWR生成中的分子没有被再次筛选或重采样。

## 选择窗口与谱系目标

所有范围从轨迹与学习配置读取。当前学习窗口为0–0.5。score_time为评分事件的时间，state_time为积分后的提案状态时间。100步积分中，score=0.49的提案恰在0.5；score=0.5的提案在0.51。边界存活目标只回溯实际state_time不超过学习终点的选择边，并从尺度估计中排除外部提案。它不使用最终1.0结果。

对第k次筛选前的候选i，设D_k(i)为边界种群中源于它的后代数。由最后种群的单位质量向前回溯：

`D_k(i) = sum_{j: selected_k(j)=i} D_{k+1}(j)`。

每个事件总质量必须等于种群规模。归一化D得到保留祖先的经验分布；它不是独立重复数。不同批次仍等权。低祖先有效样本数表示参考退化，不能靠大量克隆制造置信度。

目前保留两种目标：即时选择概率加权，和真实边界后代质量加权。后者接近“哪些早期状态最终留在优势路径上”的回溯描述，但经过低维特征投影与高斯近似后，不是精确的最优控制或Doob变换。它同样不能证明某个空间特征造成亲和力提升。

## 预设数学模块与Agent分工

1. 流式读取压缩轨迹，核对世界坐标系、缩放、真实筛选标志、父子索引与数据哈希。
2. 计算与原子排序无关的局部质心、口袋相对壳层核和原子对距离核。分别保留all、NOS及NOS–C通道；NOS–C距离同时对极性和碳原子的坐标求导。
3. 用同事件背景计算选择差异、边界保留差异和预声明四分位尾部富集；再加入等根、根内、全局姿态/大小/类型计数控制与父节点下一步收益诊断。
4. 在完整窗口拟合连续变化，采用留一批次交叉验证的一标准误规则选择Legendre阶数；有界特征采用sigmoid输出。时间导数用于描述变化率，不是空间引导力。边界效果曲线另外保留批次重采样置信区间与整曲线检验，避免正负效应抵消。
5. Analyst读取紧凑证据、全部检验数量、空结果与谱系退化信息，提出带反证和可证伪条件的区域/阶段假设。Designer选择登记的可微公式及其权重，声明单位、时间支持和谱系目标。
6. 结构化接口检查证据ID、观测量、窗口与来源哈希。编译器输出配置到经过数值导数验证的torch公式，不执行LLM自由产生的Python。
7. 冻结并提交每轮配置，在远端拉取相同commit后仅执行推理与导出；下载后在本地评价并保留报告。校验保留结果后清理生成轨迹和压缩包。

这条路径不训练额外神经代理模型。经验均值/协方差与连续曲线仍属于统计估计，不能称作完全“不拟合”。LLM承担代码与规则设计，不靠阅读原始坐标文本直接猜测三维亲和力。原始轨迹保存为可复算来源，LLM输入是可核对的低维证据。

## 奖励、梯度与强度

直接奖励作用于真实的native proposal坐标。条件性的区域成员权重与预测原子标签在本步固定，下一个FLOWR积分步重新计算。该路径对坐标函数求导，不需要对预测终态求FLOWR Jacobian。若以后使用依赖预测终态的损失，则必须通过真实FLOWR终态预测计算Jacobian；不能用可学习代理或伪Jacobian冒充。

奖励比较同一时刻的标准化质心/壳层/距离核分布，使用多个独立批次的均值与正则协方差。混合分布保留替代模式，避免直接把不同路径平均成一个构象；单独比较pair、shell、joint，检验收益来自哪里。另一种奖励是选择/背景密度对数比的平滑截断。很弱的密度差异不能经单位梯度归一化后得到完整剂量，因此另保留经验差异幅度。

外部剂量与奖励系数分开。剂量参照验证过的线性FLOWR预测流位移，而非起始随机收缩；配合原子步长和累积路径上限。正的连续剂量曲线覆盖学习窗口内各步，结束后完成剩余无guidance的native inference。原子/键通道及其图变化始终自由；距离分布奖励不等于锁图。

## 当前证据如何限制结论

发现阶段14批次、两个预选区域的调整后关联和根内关联，没有建立稳定的亲和力方向。严格边界分析的保留均值与等根偏移均未通过FDR；少数低尾部积分检验通过，但整曲线检验未通过。两类检验问题与检验功效不同，不能把其中一个结果当作因果确认。

已完成的前几轮显示：增加joint引导强度可提高亲和力与中间态相似度，但伴随部分物理代价；pair-only有较好的无引导对照折中；NOS–C的简单替换并未自动解决周围适配。这些是干预结果，尚不能唯一归因于区域作用机制。回溯与替代探索根据这些反证继续进行，直到15轮预算完成。

最后三轮冻结同一发现阶段奖励，不依据验证/留出结果重新调参。评价同时报告全部尝试、有效分子、去重分子的预测值，MMFF收敛覆盖、中位数/90分位及逐批次方向。历史Steer100仅是发现阶段基准，并非随机配对的留出对照。MMFF为孤立配体松弛应变代理，周围位移并不是实测口袋兼容性；预测head与原选择器共享来源。达到这些指标仍不等同于证明真实生物亲和力提升。
