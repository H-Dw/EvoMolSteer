# 空间motif奖励的数学定义与解释边界

本文件记录可复现的奖励推导依据、公式与限制。实际数值以每轮冻结的配置、来源哈希和实际推理配置为准，不用未记录的自然语言推理替代配置。

## 从完整窗口构建选择前景

令第k个真实筛选事件的积分前时间为t_k，提案时间为s_k=t_k+dt。窗口[a,b]从配置读取，控制仅作用于满足t_k>=a、s_k<=b的提案。当前100步实验对应50个有效更新：0→0.01，…，0.49→0.5。0.5→0.51不属于该控制窗口。

即时前景使用事件选择概率；边界前景使用存活到真实b状态的祖先后代质量D_k(i)。后者由实际筛选索引反向求和，事件总质量守恒。复制多次的祖先得到更多经验质量，但不会因此增加独立统计样本量。批次仍等权，根平衡、根内统计和低有效祖先数用于诊断混杂与退化。

对特征f，整窗效应可以写为：

`Delta_f(t) = E_weighted[f(x_t)] - E_background[f(x_t)]`。

在同一事件内比较前景/背景，再跨独立批次估计不确定性。富集分析另外比较预声明的背景四分位尾部概率。原始均值不为零、几何收缩或出现大量克隆，都不能单独证明优势。

整窗函数拟合使用留一批次交叉验证选择低阶Legendre表示：`Delta_f(t)=sum_j c_j P_j(u(t))`。对0–1有界特征使用sigmoid链接。拟合后可计算`d Delta_f/dt`并保留批次重采样区间；它描述随生成阶段的变化，不能直接作为坐标引导力。实际奖励使用精确记录节点的分布参数，不以曲线近似替代它们。

## 可微空间描述量

在固定受体世界坐标系中，每个区域、每个通道保留九个观测量：局部质心三个分量；2/4/6 Å壳层高斯核；1.5/3/5 Å原子对距离高斯核。通道包括all、NOS和NOS–C。NOS–C核同时对极性原子和碳原子的坐标求导；对角自距离不参与配对统计。

区域成员权重根据本步FLOWR预测终态的距离计算，并在本步求导中固定。预测标签同样固定，下一个native积分步再更新。可微变量是本步实际提案坐标，不是预测终态坐标。该条件梯度允许本地结构移动，并不固定化学图。

壳层核没有完整的供受体、角度、芳香性或电荷条件。原子对核也不区分所有化学键类型。因此这些量是几何描述量，不能称作已经验证的氢键、局部结合能或MMFF项。

## 多阶段混合奖励

在同一时间节点，以独立发现批次形成多个模式。令标准化特征为z_t(x)，第m模式的均值与正则协方差为mu_(m,t)、Sigma_(m,t)，维度为d：

`q_(m,t)(x) = (z_t(x)-mu_(m,t))^T Sigma_(m,t)^(-1) (z_t(x)-mu_(m,t)) / d`。

使用平滑稳健代价：

`C(q) = delta^2 * (sqrt(1+q/delta^2)-1)`。

混合奖励为：

`R_t(x) = tau * log[ (1/M) * sum_m exp(-C(q_(m,t)(x))/tau) ]`。

不同时间使用各自经验分布，因此它是覆盖整窗的时变奖励，而不是只在少数时间点开启的一项固定终态损失。混合模式保留替代路径；单一平均坐标会把不同模式混成未观察到的构象。joint/pair/shell视图分别检验完整空间、相对距离和受体壳层贡献。

其坐标梯度由描述量Jacobian给出：

`grad_x q = (2/d) * J_z(x)^T * Sigma^(-1) * (z-mu)`，

`grad_x R = -sum_m responsibility_m * C'(q_m) * grad_x q_m`。

这里J_z属于确定性空间描述函数，torch自动微分并经有限差分核验。因为奖励直接依赖实际提案坐标，本路径不需要FLOWR预测终态的Jacobian。如果奖励改为预测终态上的函数，必须改用真实FLOWR模型的Jacobian；两种路径不能混称。

另一登记方案是平滑选择/背景密度对数比：`R=b*tanh((log p_selected-log p_background)/b)`。弱密度差异另乘有界差异幅度，避免几乎为零的信号经单位梯度归一化后得到完整剂量。这仍是经验描述量密度近似，不能称为精确最优控制。

## 从梯度到实际FLOWR更新

令native提案为x_native_next，线性预测流位移为`d_flow=dt*(xhat_1-x_t)/(1-t)`，则额外坐标更新的尺度参照RMS(d_flow)。剂量曲线为：

`eta(t) = eta0 * (0.1+0.9*u(t))^p`，`u(t)=(t-a)/(b-a)`。

在窗口内该剂量为正；窗口外剂量为零。归一化坐标梯度乘上述尺度及有界残差幅度，再经过单原子步长、累计路径和严重新受体重叠约束。当前冻结R9方案使用eta0=0.05、p=0、tau=0.5、delta=2，单原子步长上限0.025 Å，累计RMS路径上限1.25 Å。

这些约束控制几何扰动，不要求图相同，也没有原子对距离变化的接受否决。native原子、键和电荷转换继续发生，SMC选择、克隆和重采样关闭。窗口结束后完成剩余native积分至1.0，并评价实际终态。

## 为何不能据此宣告优势机制

投影后的低维分布不能唯一确定化学图、键角、扭转、非成键排斥、受体相互作用或最终亲和力。特征值拟合成功也不保证物理稳定。当前统计关联、根内关联及边界整曲线检验未建立稳定的因果方向；多轮开发适配也可能放大偶然收益。

本次最后三轮冻结同一发现方案，检查与配对native相比的亲和力预测、构象、能量尾部与可计算覆盖。历史Steer是发现基准，并非留出配对臂。MMFF是孤立配体应变代理，周边松弛RMS也不是实测口袋兼容性。只有这些限制下的干预结果可据实报告，不能升级为生物亲和力证明。
