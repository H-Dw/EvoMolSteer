# 优势坐标目标与谱系增量：可复核设计

本模块服务于新计数30轮实验。首要指标为全尝试候选的配对终态预测pIC50均值；有效、唯一、最佳与Top5另外报告。能量仅在明确预测收益后作为次级比较。所有结论是模型预测，不能解释为实验结合亲和力改善。

## 为什么小均值不等于没有控制

第6轮有50次非零坐标注入、每步约0.01332 Å。最后一个有标签的控制节点是评分t=.49、随后状态到.50；两批窗口标签增益平均约+.112，但最终均值变化−.00634。个体平均绝对亲和力变化约.382/.467，说明控制发生，而非所有候选保持原样。窗口收益的消失、候选正负抵消与奖励代理错误需要分别排查。该末节点标签不应误称为注入后的新t=.50评分。

第7轮使用完整优势endpoint点云、真实FLOWR坐标VJP和同样eta=.3，最终平均增益+.22929，有效率99%。唯一分子均值增益+.22886；应变中位数下降约11.35%。这支持研究坐标目标的共同构象信息，但仅是自适应发现结果，后续冻结留出验证仍必需。它未超过历史Steer100子集最佳8.34794；子集也不是原实验的完整最高值或等预算配对比较。

整体乘大奖励常数会被方向归一化抵消。实际强度由native_rms_ratio、时间调度及实际限幅决定；字段相对权重改变方向。不能只看配置中的标量权重，应检查注入RMS、累积路径、个体与批次响应。

## 精简数据挖掘

现有74项endpoint几何量包括整体形状、原子对距离和受体landmark邻近统计。完整保留证据，按原窗口50个实际节点统一分析；24项满足稀疏方向支持条件。低阶多项式不符合实际节点，因此保留真实节点函数，禁止使用不通过保真审计的曲线。

新增endpoint_kinematics读取不可变原Steer HDF5，并用上一个节点selected_indices将子代对应到真实父节点。计算的是模型预测终点的特征变化，不是当前原子真实运动速度。高/低评分四分位分别先平均同一父节点的子代，再等权平均父节点；批次才是统计推断单位。全窗率=所有真实边变化量之和/真实总时长。首节点无父边，零占位不进入积分。14个批次的bootstrap区间、p/q与方向一致性独立保存，不建立粒子特征缓存。

V3历史支持只有landmark_00_softmin（q约.0461）。它反映邻近统计关联，不能直接解释为氢键、能量或因果适配机制。其他字段仍保留统计，但不加入受支持历史奖励。

## 受约束奖励

令Y=FLOWR当前forward预测的终点世界坐标，z=Phi(Y)/s，P_k为原Steer优势构象的实际特征向量，v为当前节点批次平均方差。支持字段权重w在四个几何块内归一化；可选salience为真实节点效应绝对值截断到[.1,2]，它不是时间导数的空间梯度。

q_k=sum_j w_j(z_j−P_kj)^2/v_j；rho(q)=delta²(sqrt(1+q/delta²)−1)。原记录评分构成固定先验pi=softmax(beta*(score−mean_score))。

R_attract=tau*logsumexp(log(pi_k)−rho(q_k)/tau)。这是有限上界≤0的吸引目标，下界可趋于负无穷；不能称为双侧有界奖励。保留不同优势原型，不平均点云坐标。它压缩了第7轮完整点云的信息，因此效果必须通过实测比较，不能预设一定更好。

可选历史项：e=z(Y_t)−detach(z(Y_previous))−原数据当前边高分子代平均增量。仅历史支持字段h有非零质量；R_history=−lambda*phase^power*rho(sum_j h_j e_j²/v_j)。首个学习节点禁用历史；下一节点必须对应紧邻的已观测父边。它是软奖励，不限制化学图，不证明能保持未来亲和力。

历史字段的筛选依据是高分−低分差异，匹配目标则是高分绝对平均增量，两者不能混淆。当前唯一支持字段的高分目标在49条边中有22正/27负，其总和约−1.46673，低分约+.94131；首边高分增量虽负，高−低反而为正。它不是全程同方向靠近受体的规则；需要实际逐节点检验，并保留失败对照。

R=R_attract+R_history，通过真实FLOWR J_endpoint(x_t)^T grad_Y R求输入坐标梯度。模型参数冻结，self-conditioning、历史、原型与对应关系detach；affinity head不参与标量和求导。生产过程无新增目标/head forward。梯度在原生积分更新后注入，因此记录的响应为旧状态的一阶估计，而非重新推理的注入后奖励。

## 实验与接口

- scripts/mine_endpoint_kinematics.py：reference/dataset/campaign/output输入输出接口；只保留均值节点增量、全窗效应、父节点支持与来源SHA。
- scripts/prepare_persistent_agent.py与verify_persistent_agent.py：冻结精确Skill/输入/两套prior，审计实际Agent的亲和力选择、窗口收益消失诊断、允许字段与公式，再编译注册程序。哈希本身不是行为响应证据。
- scripts/resume_affinity_campaign.py --persistent-profile：先本地测试与commit/VPN push，远端精确pull、校验上轮报告后清理旧生成，再推理导出，本地分析。保护原Steer与checkpoint。

第9轮匹配eta=.3/history0；第11轮首次history>0并重新做完整native/zero/guidance三臂。history0有4次一次性有限差分forward；history>0须启动与内部各4次，共8次，恢复RNG并冻结历史。fixture测试不能替代真实FLOWR/GPU审计。

后续注册对照分别检验完整点云剂量/对应先验、受支持历史强度、区域权重与salience。退步后保留全局最佳程序。第26轮冻结发现期赢家，第27–30轮使用新批次检查，不能根据留出结果重新调参。报告保存字面Agent响应、公式、证据、假设、干预理由与失败分母，不保存私有思维过程。
