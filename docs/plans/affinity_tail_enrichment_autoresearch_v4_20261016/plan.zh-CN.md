## 1. 研究主张与优先级

下一阶段建议围绕**经统一终态评分确认的多条成功路径，学习可提高终态高分概率的局部坐标变化，再把这些变化编译成有实际剂量响应的 guidance**。

同时推进两个首要目标：

1. 提高结构合格分子的最高预测 pIC50，达到或超过历史 Steer 最优候选 `F_b011_s030` 的原生分数 **8.7048063278**。
2. 提高同类高分分子的单位生成产率、绝对数量及独立化学解数量。不能用更多尝试得到的一个极值代替富集改善。

当前最值得优先利用的历史成果是：**冻结 M2 已经产生过一个有效、PB fast 通过的 8.8816376 分子**；近期 v3 的 8.6994 则没有在新初态池复现同等级发现。因此，v4 应同时从 M2 的已成功终态和局部控制分支取材，不宜只沿最近一个开发池赢家继续调参。

平均分作为分布诊断和退化监测项；应变和结构质量为次级目标。若高分产率真实提高而均值小幅下降，应保留该 Pareto 分支并明确代价。亲和力几乎不变、只有应变改善的方案，不登记为完成首要目标。

本计划的核心可检验问题是：

> 给定一个真实生成状态，某个局部空间模式及相应坐标干预，是否提高其完整原生后缀产生高预测亲和力、结构合格分子的概率？这种收益能否在新的初态中重复？

### 2.3 冻结 M2 的准确含义

本计划的 M2 指数值签名 `c62e296818e05c479dc68bee5d34f24ef0871cab3bc3e6204f442a9b6dfe40cd`，配置为 [D2_without_trajectory_static.json](../../../configs/experiments/steer_dependency_v1/D2_without_trajectory_static.json)。

其主要行为是：在整个学习窗口使用固定的历史端点预测教师库，按当前端点预测的几何距离选最近四个教师；教师评分系数为 0；使用稳健点云距离的 log-sum-exp 奖励；真实 FLOWR 端点 VJP；相对原生预测更新的 RMS 剂量为 0.33。该固定库来自最后学习节点的预测端点，不是全体教师的真实 t=1 结构。

这里的 **0.5 是 mixture_temperature**，几何教师先验尺度为 4 Å²，实际点云 delta 为 1 Å。**该冻结 M2 没有 temporal_teacher_blend。** 后续实验中名为时间教师混合 0.5 的程序是另一数值签名 `ab41341...`。源配置中的 `robust_delta=2` 也不能覆盖实际执行 delta=1 的事实。

M2 的全点云只作为受保护的历史基线。v4 新奖励使用严格局部支持；M2 的成功经验主要通过稳定端点势、多模式、可验证对应和实际剂量迁移。不能将“局部化 M2”仍称为原样 M2。

## 3. 首先建立可信的预测亲和力比较

### 3.1 已证实的评分风险

R02 与参考 R15 的同槽位最佳分子，规范化化学图相同、坐标 RMS 差约 **0.021916 Å**；等价 Kekulé 单/双键编码有 6 条无向边差异。真实 head 的 2×2 评分分解表明：原始 +0.109274 的分差中，键表示平均贡献 **+0.120423**，坐标平均贡献 **−0.011149**。

交换表示得到的 **8.710514** 不是新生成分子，不计作完成目标。也不能因此禁止不同化学图：需要统一的是**同一分子的等价表示**，不同合法化学图始终允许。

现有汇总器 `ablation/collection.py::quality` 的 `max_pic50` 对全部尝试取最大值，而 `elite_valid_count` 才加有效性条件。例如某些历史高最大值来自无效分子。v4 必须同时输出 `max_all_scored`、`max_basic_qualified`、`max_PB_qualified` 及对应 sample ID，不能靠列名推断资格。上文 M2 8.8816 已单独核对有效性，其他历史极值也按同样方式复核。

### 3.2 两条评分轨道

保留两条可追溯轨道：

1. **S_raw**：准确复用原生评分对象、坐标、原子、键、电荷、自条件、pocket、batch shape 与评分时刻。保留与原论文/历史 benchmark 对接的 8.704806 目标。
2. **S_std**：对同一微态、立体化学与物理结构，使用冻结版本的合法规范 Kekulé 表示统一重评分。不得通过选取最高分编码优化结果。可额外计算最多四种确定性等价表示的均值、范围与排名稳定性，作为敏感性诊断。

先用少数原始输入重建并确认分数，再处理所有参与富集比较的旧结构。只审计最高分子无法估计总体产率，也可能遗漏原始分数低、标准化后高的样本。

具体要求：

- 对原始 Steer、M2、无引导及候选采用同一规则。规范编码必须通过真实模型词表和化学等价检查；不能把未支持的芳香类别直接写入模型。
- 保持对应坐标与所有图数组一致；变更原子顺序另测置换响应。形式电荷、质子化和互变异构不是任意可合并的编码差异。
- 原始分数与结构永不覆盖。每个新分数附 `scorer_hash`、模型、表示、微态、批量上下文和数据来源。
- 原输入数组已退休、只有 SDF 的旧样本，不能冒称原生评分逐值重建；先在确有原输入的焦点上验证接口，再对可恢复结构做统一 S_std。保留旧 S_raw，逐项报告原生重建和标准化覆盖，缺失不补造。
- `S_std` 下重新确定原 Steer 的实际最高者和高分阈值；规范化后原最高者可能改变。规范化目标不能继续硬写成 8.704806。
- 规范化实验失败时，先保存原始比较和表示区间，明确限制；不能宣布已经获得表示稳健的亲和力提升。

这一步仅涉及已有终态的 head 推理，不对 head 求导，也不增加生成过程中每步的 affinity 推理。其 GPU 时间和前向次数单独计入成本。

## 4. 主指标、富集定义和推进标准

### 4.1 主指标

令 N 为所有实际尝试，包括解码失败、不可评分和结构无效者；Q 为预先声明的结构资格；s 为指定评分轨道。

\[
Y_H=\frac{1}{N}\sum_i\mathbf1(Q_i)\mathbf1(s_i\geq\tau_H),\qquad
Y_*=\frac{1}{N}\sum_i\mathbf1(Q_i)\mathbf1(s_i\geq T_*).
\]

\[
U_H=\frac1N\sum_i\mathbf1(Q_i)(s_i-\tau_H)_+.
\]

同时保存：合格最高分、top-k 均值、分位数、高分独立规范图数、骨架/局部作用模式数、高分来源 root/批次数。Q_basic 与 Q_basic∩Q_PB 分别报告。不可评分样本的命中为零，分数保持缺失；全尝试均值同时列出评分覆盖，不伪造缺失分数。

原生轨道冻结 `tau_H=8.258901977539063`；较低的 `tau_P=8.135048866271973` 只作先导效用和与旧 v3 对接。`T_raw=8.704806327819824`；另把经审计 M2 8.8816 的分数作为延伸参照。标准化轨道的阈值须从相同的历史发现集/规则重建，禁止根据新候选成绩选择阈值。

**U_H 不能单独承担富集目标。** 一个幸运极值可能抬高 U_H，却几乎不增加高分数量；应与 Y_H、Y_* 和去重后高分数量共同判定。

### 4.2 分阶段目标

| 等级 | 需要的证据 | 可以宣称什么 |
| --- | --- | --- |
| 功能生效 | 指令交付、实际算子/梯度或位移发生预期变化 | 模块确实实施 |
| 局部机制成立 | 配对干预改变指定 observable，且完整后缀的收益方向有支持 | 局部假设获初步支持 |
| 富集改善 | 未用于设计的配对初态中 Y_H 优于 M2/无引导，区间支持；高分独立来源增加 | 单位尝试富集改善 |
| 极值发现 | 结构合格的新终态超过 T_raw，并在 S_std 下也超过统一的 Steer 最高参照 | 发现更高的稳健预测高分解 |
| 综合目标 | 富集与极值两项均达成，质量代价可接受 | 当前研究目标得到支持 |

建议的中期工程目标为先让 Y_H 相对匹配 M2 提高至少 1 个百分点，再争取达到/超过历史 Steer 的 3.7%。它们是**待冻结的实用目标**，不是当前已实现效果；3.7% 对应旧 Q_basic 和原生轨道，统一 PB/编码后的参照另行计算。

均值相对 M2 的 −0.02 pIC50、PB/有效率 −2 个百分点、应变 p90 +10% 可作为沿用旧研究的预警尺度。它们不是已证明适合 v4 的自然常数，也不自动否决已确认的高尾部收益。若需要放宽，须在看确认结果前登记并报告代价。

### 4.3 统计与等预算

- 主要不确定性以 batch/root 分组，保留配对初态。时间点、同胞克隆、同一个终态的不同编码和 Agent 链不是独立生成重复。
- 开发池用于选型，确认池冻结后不再调参。已经反复观察的 400 对照和 batch 0 可以做回归池，不能充当新的未见确认。
- 最高分按相同 N 报告，并画固定 N 的发现/富集曲线；同时记录模型前向、VJP、终态评分和总 GPU 时间。
- 历史 Steer 仍为非配对、在线预算更多且部分被用于知识构建的参照。不能把相同终态数称为等计算量、独立泛化胜负。
- 罕见事件不能靠宽区间判无效。示意：若独立单次成功率为 0.1%，1,000 次至少一次命中约为 63.2%；集群依赖会改变该估计。缺少极高分复现不自动等于方向无效。
- 固定总预算下，将若干算法结果拼在一起不会保证超过最高单算法的期望均值。模式档案用于改善条件决策和覆盖，收益须重新验证。
- 正式比较采用事前冻结的主要对比、批次配对区间与多重比较控制；稀疏事件另列各批原始命中及合适的计数区间。少数批次的 bootstrap 不能制造可靠性。

## 5. 从失败记录提出新的可检验假设

| 假设 | 已有依据与缺口 | 首个区分实验 | 否证结果 |
| --- | --- | --- | --- |
| H1：遗漏的成功模式限制尾部覆盖 | M2 有 8.8816 的不同极性基团解；局部研究主要围绕 F_b011_s030 | 固定支持数、算子、表示和剂量，比较单教师与加入经审计 M2 成功模式的局部库 | 新模式几乎未被采用，或采用后终态收益不增 |

| H5：硬路由与模式切换损害可达解 | v3 最近/记忆/响应路由均未获尾部收益；M2 本身为软混合 | 在同一局部库上比较固定配额、硬选与经验证的软后验，温度固定 | 无抵消/切换问题仍无收益，说明模式库或局部价值信号不足 |
| H6：离散布局需要空间/角色联合目标 | N/C 换位影响固定输入 head；形成 N、校准梯度均不充分 | 先保持几何方向，再仅加入有证据的局部角色/类别平衡场 | 形成和保持均改善但 S_std 不增，放弃该角色目标 |
| H7：原生后缀破坏了窗口内优势 | 窗口目标改善与终态质量脱节；当前 VJP 不含整个随机后缀 | 逐项跟踪窗口末端→积分终点→final correction 的同一局部关系 | 关系保留而分数无收益，问题转向假设/评分而不是保持 |

已有失败不能直接支持泛化结论：v3 的静态三模式、最近路由、几何 VJP 响应路由都不是 M2 的局部软混合；旧统计协方差不是未来终态分布的条件协方差；小点云失败也未配齐所有同大小对照。

还应区分“已实现”和“已被选择运行”：v3 的类别质量平衡开关没有被选中测试，不能登记为失败；static_hybrid 的旧报告只确认了数学实现与离线测试，没有提供新组合的生成收益。重启这些候选前先核对后续实际回执，避免重复未核实的成功或失败叙述。

## 6. 数据挖掘：终态成功模式与完整窗口的坐标选择效应

### 6.1 成功库的来源与分层

优先汇集四类已存在数据：原始 Steer、冻结 M2、高分动态对比分支、局部 R15/R02 等。每条记录至少关联：

`sample_id / campaign_id / commit / numerical_program_id / initial_sha / batch / slot / root / native_protocol / raw_score / standardized_score / quality / structure_ref / trajectory_ref / clocks / vocabulary`。

终态标签分为：高分且合格、高分但结构有代价、低分且合格、结构失败、终态未观测。最后一类不等同于低亲和力。先对单个成功候选与真实可比对照分析，再按局部空间/化学角色划分多个模式。

复制谱系中共享的祖先只存一次。保留“终态产率”和“独立成功来源”两种统计：Steer 的克隆确实属于产出，但不能把共享祖先当独立机制重复。

对 M2 8.8816，先检查是否保留可恢复状态和完整原生输入。若只剩终态结构，可以先将其用于终态局部模式库；在找回或精确回放前，不伪造其低 t 祖先。

### 6.2 优先新增/完善的特征

几何为主线，元素和化学角色用来解释或区分几何关系。特征限定在候选局部区域及必要邻居，避免再次形成无节制的宽表。

| 特征组 | 具体可计算量 | 新增价值 |
| --- | --- | --- |
| 口袋参考系局部布局 | 局部质心、方向轴、带符号位移、平面法向、对口袋站点的投影/距离 | 区分整体移动、局部调整与相同距离下不同朝向 |
| 基团间协同 | 杂芳环 N 邻域、羰基/酰胺/酸区的相对距离和取向；附着点与邻域形状 | 检验联合空间模式，避免只奖励单点靠近或总 N 数 |
| 对称与对应稳定性 | 图同构/公共子结构映射、等价氧、环对称、assignment 切换与 margin | 避免把编号变化和等价键式当成新物理优势 |
| 优势的有符号变化 | 成功祖先相对对照的位移、特征增量、选择效应及其导数 | 区分“像成功样本”与“正朝有益方向移动” |
| 生成流的局部响应 | 原生预测位移、实际含噪位移、受控方向、局部雅可比响应、控制后差异 | 区分奖励有效、可控、形成和终态收益四件事 |
| 后缀保持 | 窗口末端、积分末端、最终预测的局部关系/角色；同槽位与重新匹配分别统计 | 定位优势形成后在哪里丢失 |
| 化学条件的空间场 | 可靠的 N/C、N/O 或角色分通道局部质量、方向邻域、类别精确率/召回率 | 避免多数 C 主导总匹配率；不冒充相互作用能量 |
| 局部兼容性诊断 | 未直接控制邻域的拥挤、连接几何、局部松弛与口袋距离 | 检查优势区域是否以周围代价换取；默认不把全体邻域加入奖励 |

当前缺少角度/微态支持的接触只称几何代理。不能把近邻距离直接解释为氢键、盐桥或结合自由能。N 元素概率也不是可靠受体概率。

M2 高分酰胺区与 R02 酸区的比较先做统一表示和公共子结构定位，再提出方向假设。允许这些结构属于不同化学图，禁止同图 gate。

### 6.3 将选择效应与生成演变分开

对一个 B 粒子事件，特征为 phi_i，繁殖概率为 w_i，实际后代数为 n_i：

\[
\Delta_{sel}^{expected}=\sum_i(w_i-1/B)\phi_i,\quad
\Delta_{sel}^{realized}=\sum_i(n_i/B-1/B)\phi_i.
\]

\[
\Delta_{sampling\ noise}=\Delta_{sel}^{realized}-\Delta_{sel}^{expected}.
\]

再独立计算继续生成后的特征变化，保留复制映射。按正确多项分布采样时，噪声项的条件期望为零；不能要求实际选择长期大于期望才叫“优势”。

上述统计反映原 Steer 选择了什么。只有将其与真实终态收益、配对干预相联系，才可讨论它是否值得迁移到新 guidance。按原中间 head 排出的正例，只能用于描述原算法选择压力，不能作为成功真值。

### 6.4 全窗口拟合与变化率

- 沿用完整学习窗口 W=[a,b]。当前数据 W=[0,0.5]；不再把 [0,.1)、[.1,.2) 等作为独立富集分析单位。
- 以真实 `state_time`、`score_time`、`prediction_time` 区分当前、proposal、端点。t=0.5 的评分可能对应 t=0.51 proposal；窗口外状态不能混入窗口内目标。
- 对每个模式/局部 observable 拟合 `mu_success(t)`、`mu_control(t)`、差异 `d(t)`、选择效应及其导数；低阶多项式或受限平滑样条按 batch/root 留出选择复杂度。
- 保存全窗口效应、残差、有效支持、置信区间、导数及全窗口净变化。特征多时保留 BH-q 和效应量，但 q 小不自动授权奖励。
- 与全球质心/形状、同 root、近似骨架或相近初态的对照分开，检查局部增量信息。PCA 仅作紧凑描述与冗余诊断，主成分不自动等于优势方向。
- 描述曲线的 d/dt 不是坐标空间梯度。实际奖励须写成当前状态的可微函数，再通过其真实依赖求导。

## 7. 小量真实续生成：把“有用方向”变成可测对象

### 7.1 恢复状态的前置验证

坐标文件不一定是完整生成状态。恢复接口须包含原子/键/电荷、已有自条件预测、mask、口袋变换、时刻、原生噪声设置、RNG 和必要缓存。

先用无干预恢复与未中断运行比较，确认同一已知原生轨迹能重建；若旧 H5 缺少状态，则从已保存初态和冻结协议回放前缀，或新建可恢复前缀。不得将不完整坐标续推当作原生状态恢复。

保持 B=50。B24→B50 已被证实会改变后续随机数消费；只固定 seed=42 和部分初始坐标不能保证路径相同。不同干预臂共享同批状态与同一随机流，显式记录发生分歧后的随机调用一致性。

### 7.2 首个小实验

先在一个完整 B50、一个窗口内诊断时刻、一个后缀随机流上，执行三臂：无干预、+epsilon*d、−epsilon*d。d 由局部几何假设产生；三臂全部继续至 t=1，关闭后续 SMC，只在终态统一打分。

这实际消耗 **150 条后缀轨迹**，即使只分析其中少量焦点 seed，也必须把同批其他槽位计入成本。例如剩余 70 个积分步，其前向积分规模约为 105 条完整 100 步轨迹，另计前缀与终态评分成本。这个换算不等同于精确 GPU 时间。

有信号后才增加其他 batch、随机流和第二个诊断时刻。具体时刻从窗口配置与可恢复状态读取；在少数时刻做机制干预，不等于把全窗口统计切成时间箱。

### 7.3 获取什么知识

记录局部 observable 的改变、终态 S_raw/S_std、资格、后缀保持与成对收益。低事件率时先用连续终态分数和较低阈值效用辅助辨别；不能用它们冒充极高阈值成功率。

把“状态本来就好”与“这个干预使它变好”分开：同时估计原生后缀潜力和相对原生的干预收益。单次成功不能标定一个起点的概率。

所有未完整续推的灭绝分支仍为未知。原 Steer 仅保留下来的终态含选择偏差，不能单独识别所有未选路径的潜力；少量真实反事实续生成用于补足这一缺口。

## 8. 从未来收益到局部奖励：理论依据与实现边界

### 8.1 理想对象

把完整生成状态记为 S_t，设高分且合格事件为 A，则自然目标是有限时间成功概率

\[
h_t(s)=\Pr(S_1\in A\mid S_t=s,\text{给定的后续策略}).
\]

对带正终态权重 w(S_1) 的离散 Markov 后缀，理想路径重加权转移满足

\[
K_t^*(s,ds')=K_t(s,ds')\frac{h_{t+\Delta t}(s')}{h_t(s)},\quad
h_t(s)=\mathbb E[w(S_1)\mid S_t=s].
\]

这说明有效的早期偏好应包含未来结果信息。多教师几何相似度、当前 head 分数和单步可控性都只是候选代理。实际 FLOWR 含随机坐标、自条件与离散状态；把连续 guidance 写成简单的 `grad log h` 不会自动复现上式。

成功概率的思路可参考 [Towards a Theory of Transition Paths](https://web.math.princeton.edu/~weinan/pdf%20files/theory%20transition.pdf)；本项目是非平稳生成进度下的有限终态事件，不把它等同于平衡分子动力学的 committor。[On the Guidance of Flow Matching](https://arxiv.org/abs/2502.02150) 区分一般流引导与常见局部梯度近似，并讨论条件分布/协方差信息；这里借鉴其“端点单点近似有局限”的问题设置，不宣称已实现其精确算法。

### 8.2 第一优先：局部多成功模式势

对模式 m，在时钟/表示一致的被控局部 observable O_t 上建立可微误差 L_m，保留 M2 的软混合思想：

\[
R_{bank}=\tau\log\sum_m\pi_m\exp[-L_m(O_t)/\tau].
\]

每个模式保留独立目标，不先平均坐标。v3 当前适配器显式拒绝 soft 路由，必须新增通过导数验证的局部 soft adapter；不能只在 Skills 写“软选择”却运行原硬路由。

先固定 M2 的数值温度，单独比较教师来源/局部化。若先验 pi_m 依赖当前状态但停止梯度，明确这是条件路由导数；若要声称完整混合势梯度，必须将该依赖纳入求导。top-k/对应切换点另作非光滑检查。

所有非零项、模式的直接支持并集必须满足已声明的局部上限。不能用多个“局部模式”合起来暗含全点云约束。模型 VJP 对未直接选中原子可能有间接影响，需记录，不能承诺它们严格不动。

首个 soft adapter 先为每个 seed 建立共有的局部槽位/角色掩膜，再在该掩膜内完成各教师的对应；不能让每个模式各自从全分子匹配 K 个点，最后并集覆盖全部原子。掩膜可以随状态更新，但其来源、切换和导数约定必须可核对；不通过冻结化学图来维持掩膜。

### 8.3 第二优先：真实终态正负对照的局部场

用明确的局部 feature map phi(x,t) 与多个独立成功/实际低分对照建立小维度、对称和表示一致的几何场。可先使用共享协方差的显式对数密度比：

\[
R_{contrast}=(\mu_+-\mu_-)^\top\Sigma^{-1}
\left(\phi-\frac{\mu_++\mu_-}{2}\right).
\]

均值、尺度随完整 W 拟合，独立 root/batch 加权；只有样本支持足够才启用。该函数起初只是关联代理。其优于旧单路径/背景场的关键是**多个真实终态标签、正确对照、局部联合关系和干预检验**，不能仅换函数名称。

若要使用经验未来收益，先用固定样本表与显式局部核计算

\[
\widehat V(\phi,t)=\frac{\sum_j\omega_j(\phi,t)U_j}{\sum_j\omega_j(\phi,t)}.
\]

U_j 来自完整后缀，另建配对干预收益表；不增加训练神经网络。小样本时仅称局部经验估计，保留 ESS、留一 root 校验与支持域。不能用 LLM 文字置信度替代概率或在无支持区外推。若估计不能区分已观测收益，回退至已测局部几何方案，暂不激活“未来价值”项。

### 8.4 第三优先：实际剂量、阶段表示与局部协同

1. 对当前态使用真实当前坐标导数；对端点 Y_theta(x_t,t) 使用真实模型 VJP；桥接项同时保留直接坐标和模型导数。教师必须与 observable 时刻/表示相容。
2. 首先比较固定终态/晚期预测模式与同刻教师模式，不把低 t 噪声祖先逐点当作通用真值。v3 已失败的同刻、前瞻策略只能在新证据明确改变时重新开启。
3. 只对奖励乘正 w(t) 常被 RMS 归一化抵消。调度应作用在归一化后的实际请求位移：

\[
\Delta x^{guide}_{i,t}=D_{i,t}\frac{g_{i,t}}{\operatorname{RMS}(g_{i,t})+g_0(t)},\quad
D_{i,t}=\rho_i(t,\text{已测状态})\operatorname{RMS}(\Delta x^{native,pred}_{i,t}).
\]

   `g0=0` 对应当前单位 RMS 近似；正 g0 是待检验的幅度响应控制器，须按父程序真实梯度尺度标定。近零梯度不应被放大到完整步长。先匹配总请求预算，再比较额外总量。
4. 记录实际注入、上限裁剪、接受/回退、相邻方向、梯度各项占比、native 方向与后缀结果。native 反向并非自动错误；不加入同向接受 gate。
5. 元素/角色项只在几何假设与形成证据支持时增加。使用已有生成 head 的局部软通道，比较类别平衡、概率停止梯度与坐标 VJP；不能把更大的 typed 梯度当作已形成 N/C 布局。
6. 在当前坐标控制主线不编辑离散 logits/转移率，不禁止原生化学图变化，不对 affinity head 求导，不增加每步额外 affinity 推理。

### 9.3 接口和编排

- 保留真实 DeepSeek API / `deepseek-flash`，默认调用温度保持原值 0；不新增温度消融，不回到 subagent 模拟。
- 采用现有有限工具循环：请求工具→确定性结果→source-bound 引用→Analyst 结构化交接→Designer 受约束选择→确定性编译。
- 下一接口增加可枚举的“成功模式、区域、曲线、后缀干预、有效参数”目录。实际工具失败与未请求区分，禁止从表未交付推断方法无用。
- 输出新增字段先版本化 schema，再提供示例与提取器；引用校验覆盖 findings、hypotheses、反证和设计交接。不得用宽松吞字段、填充伪造引用来绕过契约。
- Designer 的最终返回可保持选项 ID 和交接哈希等最小字段。算子、导数、参数前后值由编译器产生，避免自由文字与执行函数分离。
- 分析阶段允许在有限工具目录中生成有来源的新 region/observable 提案；编译及数值验证成功后才进入动作目录。若目录只有一个合法选项，如实记录有限选择，不称 Agent 自主发现。
- 先确认指令→工具结果→字段→函数→控制响应有变化，再讨论性能。六条角色链生成同一数值程序时，只计算一次分子结果，记录“本次 Agent 输出未改变执行函数”。
- 新 Skills 保持通用，不写目标残基/槽位、固定时间段、主机/代理/凭证。具体 CK2 案例和有效数字放入证据包与实验配置。
- LLM 与确定性选择器的独立作用在同一证据、同一动作、同一生成预算下比较。模型可读解释并不是性能贡献的证据。

本节是待实现改动，本次未改写当前的 [Analyst](../../../skills/ancestral-mode-analyst/SKILL.md) 或 [Designer](../../../skills/ancestral-mode-designer/SKILL.md)。

### 10.1 先执行哪一小段

建议首个执行包止于 **E00–E09**，优先顺序为：评分可信 → 找回 M2 成功解 → 真实局部对照 → 功能验证 → 小量后缀干预。某一步无支持便不继续扩大生成。

E02 四臂各 200、E06–E08 各 200、E05 至多 50 后缀、E09 首次 150 后缀，若全部需要新计算，则约为 **1,600 次终态完成**；其中后缀不足 100 步，实际积分规模另算。严格可复用结果会减少新增量。已有终态重评分和 API 费用不隐藏在“0 新生成”中。

后面的 E10–E16 是条件性研究项；E17/E18 是确认预算。当前没有设置自动运行 20/35/更多轮的任务。后续执行配置需明确有效数值实验上限、总尝试上限、API 请求上限与 GPU 时间预算；达到任一上限即保存报告并停止。

### 10.2 罕见尾部的预算策略

50 个样本适合验证接口和明显退化；200 个适合初筛；400 个用于初次配对确认；最终用固定 B50 增加批次数达到 1,000。若极高阈值事件仍太少，应给出未解决区间，再按预先冻结方案考虑扩展至每臂 3,000，而不是继续在同一个 B50 上挑最高分。

先用已有 batch 级命中变异估算所需样本和检验功效。不能承诺每臂 400 一定能区分 0.5% 与 1.5% 的罕见产率，更不能因 0 次命中就证明潜力为零。

## 11. 失败、回滚与父版本选择

同时维护三个指针：

- `reference_M2`：冻结数值基线，任何探索都不覆盖。
- `validated_incumbent`：通过独立确认的方案；当前没有依据把 R02 的开发极值提升为该指针。
- `tail_research_frontier`：有可解释高分案例、仍待验证的多个分支，可包含 M2 新成功模式、R15 局部桥接和 R02 端点分支。

连续两项数值探索若在同池主要尾部指标下降，且没有新的机制区分收益，停止该分支，恢复其已确认父程序/Skills/配置。保留失败 commit、精简结果和原因。回滚不恢复已知的 schema、引用或数学错误。

下列情况分别处理：

| 现象 | 后续动作 |
| --- | --- |
| Agent 文本改变、有效程序相同 | 复用结果；记录数值瓶颈；不作新的分子性能归因 |
| 参数改变、归一化后控制不变 | 修复有效参数定义/剂量接口，先不扩大生成 |
| 控制改变、局部模式未形成 | 检查表示、对应、可控性、剂量和目标可达性 |
| 形成但后缀丢失 | 定位原生后缀/最终校正变化；在学习窗口内优化保持策略，不偷偷延长控制范围 |
| 形成且保持、亲和力不增 | 下调该科学假设；检查输入特征和评分，不一律增权 |
| S_raw 增而 S_std 不增 | 登记表示敏感收益，不升级为稳健坐标优势 |
| 同池有效、新池不稳定 | 保存为局部发现；扩大独立来源或改条件规则，不称随机执行失效 |
| 接口/恢复执行失败 | 修复或跳过任务；不能解释成被消融科学模块必不可少 |

单个高分分子可保留为新教师来源，但不能反向污染其所属确认池后，再称同一池为确认。新终态加入教师后须产生新版本及新验证划分。

## 13. 存储与复现

- 原始 Steer、checkpoint、固定控制库和历史报告受保护；新实验只清理自己拥有且已验证本地归档的临时数据。
- 索引引用原压缩轨迹；共享祖先、固定教师和完整状态只存一份。保存原始原生精度；不能为压缩而悄悄降低坐标/类别概率精度。
- 默认只提取当前研究需用的一种或明确必要的状态表示；并行分片验证合并后清理；不默认保存逐边×全特征、逐节点投影和冗长工具观察副本。
- 常用批次/模式统计使用 float64、无压缩 Parquet；保留效应、变化率、区间、p/q、样本支持和失败。坐标、图、完整恢复状态单独紧凑保存，按需加载。
- 逐步诊断保存实际剂量、匹配/路由与少量局部 observable 的汇总；仅焦点案例保存必要的完整小数组，不把每次 API 交付重复展开大表。
- 高分候选除结构外，保留可回放初态/前缀依赖、程序、模型/原生版本、评分输入、资格和来源哈希。只有终态 SDF 不足以复现生成成功路径。
- 每个有效探索：本地完成代码/配置/Skills 修改及相关验证 → commit/push → 远端拉取并核对提交 → 清理已归档旧临时结果 → 执行推理 → 本地分析 → 记录推进/回滚。
- 每轮保留简洁的 `hypothesis → evidence → executable delta → expected response → observed result → decision` 记录，不保存或要求模型内部思维链。该记录足以审计奖励函数来源和复现实验。

## 14. 借鉴的方法与本项目的采用边界

| 方法来源 | 借鉴内容 | 采用边界 |
| --- | --- | --- |
| [Transition paths / committor](https://web.math.princeton.edu/~weinan/pdf%20files/theory%20transition.pdf) | 用未来成功事件解释有潜力的状态 | 本项目为有限生成时域，完整状态含离散变量；不直接套用平衡动力学结论 |
| [On the Guidance of Flow Matching](https://arxiv.org/abs/2502.02150) | 区分一般流引导、条件终态信息和局部梯度近似 | 保留真实模型导数；条件协方差/未来价值需本地估计和验证，不直接宣称精确采样 |
| [Feynman–Kac steering](https://arxiv.org/abs/2501.06848) | 中间势应反映未来终态奖励；粒子相互作用带来的搜索视角 | 作为解释原 Steer 的参考；v4 主生成不引入 SMC 或繁殖 |
| [MAP-Elites](https://arxiv.org/abs/1504.04909) | 分开维护多个高质量模式档案，防止全局排名淹没稀有成功解 | 只借鉴终态档案与探索预算，不在生成中执行遗传复制；档案本身不保证富集提升 |
| [Value Gradient Guidance for Flow Matching Alignment](https://vggflow25.github.io/) | 区分未来价值的控制信息与即时端点奖励 | 其训练 value/flow 模型的算法不属于本计划主线；不复制其训练需求或性能数字 |

以上是有文献依据的设计启发。具体工具、核函数、阈值、分组统计与序贯队列是本项目待检验的实现选择，没有外部论文可以替代当前 CK2 的性能验证。

## 15. 首批交付和完成判定

首批应交付：统一评分与候选资格表、可回溯的检查点注册表、含 M2 高分解的多成功模式库、全窗口局部几何/选择效应与导数、真实状态恢复核验、首个配对局部干预结果，以及 Analyst/Designer 功能响应记录。

之后只有在局部方向对终态结果有支持时，才扩大到多模式、时间调度和化学角色的组合。最终报告同时回答：最高分是否提高、高分是否更多、是否来自独立解、是否在新初态成立、是否对等价编码稳健、结构/能量代价怎样、用了多少计算。

若没有模块在严格对照中提高高分产率，应保留冻结 M2 和失败证据，明确未来价值代理尚不足；不靠继续复制历史最高分、扩大生成数或更换比较口径宣布成功。
