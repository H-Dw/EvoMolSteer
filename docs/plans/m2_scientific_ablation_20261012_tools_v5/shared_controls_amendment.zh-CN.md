# 剩余实验的固定对照与数值去重修订

本修订依据 2026-10-12 的用户要求，仅改变未完成实验的样本复用策略。原始 protocol、activation、已完成比较和 Agent 指引均保留，不重新解释旧比较。

固定对照为已完成生成与本地评分的 `DSF_c62e296818e0_b6376_controls_indexed_batch`：批次 6376–6383，每批 50 个尝试，两臂各 400 个。选择依据为终态结构仍完整保留，未根据亲和力或应变选择样本库。更早批次的结构已被旧清理策略删除，只有评分仍在，故不将其假称为完整结构对照。

1. 永久保存这组 M2 与无引导的终态 SDF、包含失败样本终态张量与解码记录的已验证压缩包、全部 800 次尝试的评分、应变及失败原因。
2. 剩余筛查、形状选择、剂量选择、最终比较和最终上下文复核统一使用上述八个批次。主随机种子 42、按批次索引生成随机流、每批 50 个、100 个积分步、模型及积分配置均不变。
3. 每个执行函数按照去除描述性元数据并补齐默认值后的数值签名去重。M2 直接使用固定对照；新签名只生成一次 400 个候选，不再生成无引导或 M2 对照。
4. 候选必须匹配对照的每批初始状态哈希，保留全部批次/slot。缺失样本、评分或哈希不匹配时报错，不通过过滤失败样本补足 400。
5. 完整条件与删除条件的六条角色链均为 M2 时，直接复用，并写入“本次 Agent 输出未改变执行函数”。这说明本次角色调用未改变数值程序，不能据此声称相关科学方法无用。
6. 学习证据、模块删除条件、真实 DeepSeek flash 调用、默认温度、奖励族和主次指标均不修改；继续保留既定的执行失败跳过策略。

该样本库属于反复使用的开发比较集。重复引用不增加样本量，不将六条相同程序的角色链算作 2,400 个独立分子。剩余所谓“确认”及最终复核均标注为共享样本比较，不再宣称独立留出验证；置信区间是对这组 RNG 批次和角色输出的条件性估计。

小型清单与修订契约保存在 `docs/experiments/m2_tools_full_drop_ablation_20261012/shared_control_bank/manifest.json` 和同级 `shared_control_policy.json`，用 SHA256 绑定原协议、固定样本与生成实现。完整结构数据位于本地忽略目录 `data/control_banks/m2_tools_full_drop_ablation_20261012/DSF_c62e296818e0_b6376_controls_indexed_batch`，不进入 Git。远端保留该库的终态 SDF。

实现入口为 `scripts/freeze_ablation_control_bank.py`，复用与校验模块为 `src/evomolsteer/ablation/shared_controls.py`。样本或生成实现发生变化时停止复用，要求显式建立新实验，不能静默重算对照。
