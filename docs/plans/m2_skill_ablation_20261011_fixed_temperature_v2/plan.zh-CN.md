# M2 Skills 消融计划：固定默认温度 v2

状态：**仅修订计划与执行接口，不启动新实验。** 本版继承原计划的 46 行条件矩阵、八个研究模块、评价标准和先 Analyst 后 Designer 的顺序；使用用户指定的真实 DeepSeek API / `deepseek-flash`。

原计划和原始调用、生成、失败记录保留在原路径。旧计划不被覆盖，本文件是后续实验的修订入口。计划版本必须写入激活文件和调用记录，禁止从旧队列无标记续跑。

## 1. 本次修改的边界

|项目|v2 要求|
|---|---|
|教师混合温度 `mixture_temperature`|固定为冻结 M2 的默认 **0.5**|
|教师距离先验温度 `teacher_endpoint_temperature_A2`|固定为冻结 M2 的默认 **4.0 Å²**|
|温度候选、温度扫描、温度删除/替代条件|不设置、不提交、不用于选择新基准|
|温度在 Skills 中的地位|移出可调研究指引，作为所有条件共享的不可变契约；具体值只在外部配置与证据包中提供|
|已有温度 0.25 结果|保留历史审计身份，不算 v2 消融，不作为 v2 的基准、选定 G 形状或模块效果|
|数值模型、教师库及 M2|保持原文件与校验值；不是重新训练 checkpoint|

这里固定两种奖励温度，以免把同一类混合效应通过先验温度重新引入。LLM API 的解码参数不作为本实验的研究变量，所有角色条件采用相同接口策略。

温度原本是 Designer 可输出的旋钮，并不是原矩阵中的独立任务行。因此 **46 行仍为 46 行**；删除的是设计空间中的温度变化及 D2 中的温度选择指引，不删除 D2 整个模块，也不增加新条件。

## 2. 固定基准与共同契约

数值 F0 使用 `configs/experiments/steer_dependency_v1/D2_without_trajectory_static.json`，教师引用使用同目录 `static.json.gz`。两者的原校验值保存在 `protocol.json`，每次激活与运行前验证。

所有研究条件沿用：真实 FLOWR 端点 Jacobian 的 VJP、冻结对应关系、100 个积分步、随机数主种子 42、亲和力优先评价。学习与控制支持从引用元数据动态读取；支持结束后继续无 guidance 推理到终态。禁止 SMC、affinity-head 梯度、额外生产模型前向、原子类型控制和化学图相等 gate。

Analyst 的统计单位、标签含义、选择与终态重评分的区别保持一致。全窗口坐标差异、富集与趋势证据及失败对照不因指引被删除而从输入中移除。固定温度是执行限制，不是待证明必要的 Skills 模块；任意模块删除或合理替代都不能改变它。

## 3. 结构化研究模块

|Analyst 模块|功能|应在输出中验证的后果|
|---|---|---|
|A1 选择对比|找出优势与失败对照的坐标差异|正确 cohort、标签、方向及真实证据引用|
|A2 可靠性与反证|让证据强弱影响假设排序|区间、跨批支持、q 值和反例实际改变优先级|
|A3 空间分配|区分整体优势与局部优势|区域来源、相对全局变化的增量信息及周围自由度|
|A4 可操作假设|把描述变成可测试的设计信息|可改变的坐标 observable、尺度、预期响应、否证条件|

|Designer 模块|功能|应在输出及运行中验证的后果|
|---|---|---|
|D1 证据到奖励项|把 Analyst 假设映射到实际奖励|假设、公式、生效项及预期坐标响应对应|
|D2 几何响应尺度|按证据考虑距离响应、曲率、教师邻域或区域强调|允许的参数有来源，实际响应范围或梯度方向变化；不调温度|
|D3 实际剂量|考虑真实位移与覆盖|强度或调度改变实际注入；不把奖励整体倍数当剂量|
|D4 基准与反例|决定修改、保留或暂缓|反例影响决策并形成具体失败条件|

正常指引、删除和合理竞争方向由 `module_registry.json` 给出，功能评分由 `response_rubric.json` 给出。D2 的替代仍是采用注册表缺省几何策略；正常和替代均遵守同一温度契约。其他七个模块原文保持不变。

## 4. 可调设计空间

G 通道固定剂量、教师来源、教师评分权重及两种温度。每条 Designer 输出最多选择一项原子性几何修改：

- 教师邻居数 2、4、8；这是教师数量，不能当作分子内部距离壳层宽度。
- 实际 pointcloud 曲率 0.5、1、2 Å。
- 有真实区域证据绑定的软区域强调配方，保留正的周围区域权重；配方尺度在角色调用前冻结。

不新增接触能量、原子类型项或轨迹速度项，不允许通过修改教师数据间接改变固定温度。不把 intramolecular pair-kernel 富集统计直接解释成教师混合梯度的因果机制。

U 通道固定**经 G 阶段选定且有凭据的奖励形状**及同样的温度，只允许一次 eta 或 ramp 修改，网格沿用原计划。不能提前把 M2 当作已选定 G 的替代品；如果 M2 经比较被正式选中，才可按该选择凭据使用。

编译器从冻结 M2 文件读取固定参数，在构造候选前后核验。温度提案即使数值恰好等于默认，也不算合法“修改”；应保留基准。非法输出保留为接口失败，不能被静默改成温度候选或成功调用。

## 5. 执行顺序和阶段关卡

### P0：建立同模型、同接口基线

保留 F0_M2、N0_native、P_current、P_dependency、P_clean、P_flat、P_struct。后三种研究文本与数据交付方式遵守原计划；平铺与结构化使用相同研究文字，仅改变组织方式。

每个角色条件采用六条独立角色链、两种等义任务表述，各三次无共享聊天历史的 API 调用。Analyst 和 Designer 使用同一模型。格式接口版本在 v2 中统一；旧版未完成链和隔离格式探针不能补作 v2 的六条新角色链。

原共同分子控制结果只有在程序、模型、参考、积分、初态、随机数及评价定义均匹配时才可明确复用；它们不变成新的独立生成样本。

### P1：先 Analyst 删除和替代

固定 Designer 提示词及 G 接口。执行 A_full_G、A_empty_G 和 A1–A4 的逐项 drop/alternative。完整对照行保留，不隐式丢弃。先核查实际交付与目标功能，再比较实际程序、坐标响应和最终性能。

筛查后必须做功能与统计审查，逐步精简并重新检查留下来的模块，形成选定 A*。不能把一次最高分输出当作选定 Analyst，也不能在 P1 前固定 P_struct 输出池充当 A*。

初始执行器只允许 P0/P1 筛查。P1 后停止在选择关卡；阶段尚未实现或选择凭据缺失时应报告等待状态，不自动推进。

### P2：再 Designer 删除和替代

选定 A* 后，生成并冻结六份没有生成评估结果的 Analyst 输出，以来源、内容校验值及条件身份绑定输入池。全部 Designer 条件读取同一六份输出。

G 通道保留 D_full_G、D_empty_G 和 D1、D2、D4 的逐项 drop/alternative，固定剂量与温度。经审查选定 G 形状后，U 通道执行 D_full_U、D_drop_D3、D_alt_D3，固定形状与温度。

保留 `U_scalar_noop`：奖励乘正标量后核验实际归一化力及完整轨迹等价。已有单元检查是前置验证，不能代替该条件的运行凭据。

P2 未获得正确 A* 冻结池不得调用；U 未获得正确 G 选择凭据不得调用。禁止自动回退到 P_struct 或 M2 后声称遵守原阶段设计。

### P3：组合与最终必要性

条件性执行 J_final 及剩余模块的删除、替代。原矩阵中的 17 行条件性复核全部保留，只有前置选择与确认完成才激活。对最终上下文的冗余、交互和必要性作独立复核；不直接继承早期完整版本的结论。

## 6. 评价与保留规则

每个模块贯穿检查：指令交付 → 对应分析功能 → Analyst/Designer 交接 → 生效奖励 → 真实引导变化 → 最终质量。温度全部固定，因此观察到的模块作用不能来自温度扫描。

主指标仍是全部生成尝试的最终预测 pIC50，并报告评分覆盖及失败。应变中位数/P90、PB、有效率、固定阈值高分尾部及唯一化学图分别报告。历史 Steer 只作为采样预算不同的非配对参考。

每个不同生效程序初筛 200，首次确认 400；批次索引与样本量在未查看新结果时冻结，种子规则沿用原协议。数值等价的程序复用生成，不能伪装成独立分子实验。

原统计规则继续适用：角色链与生成批次分块的配对比较，阶段内多重比较校正，确认前冻结同时区间方法。亲和力必要性要求最终上下文中 keep−drop 和 keep−alternative 的区间下界均超过 0.05 pIC50；次级必要性要求亲和力等价且两种干预均明确恶化应变超过 10%。宽区间或不显著不等于无效。

如果没有研究模块通过，允许保留最小角色接口与冻结 M2。不会为了证明 Skills 有益而加入温度调参。
