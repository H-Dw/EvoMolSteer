**FLOWR 局部坐标引导：auto-research 代码优化与顺序探索计划**

版本：v1，2026-10-15。状态：规划完成，尚未执行本计划的新实验。

本计划用于后续 auto-research agent 的任务输入。它规定研究方向、代码改动边界、证据标准和迭代流程；不预设某个新奖励一定有效，不自动授予新的计算轮数。上一轮 20 轮已经完成，不能因读取本文件而重新启动或追加第 21 轮。执行时使用用户最新授权的预算、约束和模型设置。

**一、任务目标和必须保留的边界**

核心目标：在完整 FLOWR 从头生成后，提高最终预测结合亲和力，并保持与对应无引导和历史 Steer 相近的构象合理性、能量稳定性。亲和力为主要优化目标；应变及结构指标用于识别副作用。局部模仿损失、N/C 命中率、半程相似度和 LLM 文字质量都不是最终成功标准。

生成控制以坐标为主要干预通道。若额外修改类别预测，必须登记为独立的混合控制分支，不能把其收益记作纯坐标 guidance 收益。

执行约束：

- 使用真实 FLOWR 生成器的当前状态梯度；不对 affinity head 求梯度，不增加逐生成步的 affinity head 推理。终态评分及预先登记的小量离线对照单独计入成本。
- 不使用原始 SMC/重采样，不重新引入限制化学图变化、冻结全图或强制全分子 N 数量的 gate。化学图变化本身不是失败理由。
- 保持局部点云支持，可以是非连续区域；禁止把全部点云偷偷加入奖励。直接受损失约束的上下文点也计入支持大小。
- 学习窗口和控制窗口动态配置并核验。本研究当前学习窗口为 [0,0.5]；控制起点可以在该窗口内变化，控制终点不得越界，之后无额外 guidance 地完成至 t=1。
- 选择相关的富集、差异和趋势分析覆盖整个实际选择窗口，不恢复 [0,.1)、[.1,.2) 等独立分箱检验。终态标签用于回溯成功，后半程数据用于保持诊断，不能冒充选择窗口中的筛选证据。
- 主随机种子沿用 42。匹配输入依靠初态内容、样本身份、随机流及生成配置的实际记录，不能仅凭 seed 相同声称完全配对。
- 原始 Steer、冻结对照、最佳奖励、代码历史和失败记录保留。清理对象只限已核验、已提取证据的派生实验数据。
- 保留真实 LLM API 接口；当前 Analyst/Designer 为 DeepSeek `deepseek-flash`，沿用已用默认温度。默认不开展温度或模型消融，不自动替换为 subagent。
- 不训练新的 affinity 预测网络或神经奖励拟合器。允许确定性统计、几何计算及预先说明的低复杂度趋势函数拟合；拟合仅为证据摘要，不宣称其具有新靶点泛化性。

通用 Skills 放科学任务、证据规则和角色职责；目标残基、候选编号、固定时间、主机及网络部署信息放数据/配置/运行文档。

**P0：配置真实生效与可复现身份**

修改位置：`src/evomolsteer/nc_guidance/{search,workflow,mining,reward}.py`、`src/evomolsteer/final_guidance/{native,evidence}.py`。建议新增独立的配置/运行身份模块，避免在轮次 if 分支里分散赋值。

必须完成：

1. 编译唯一 `resolved_config.json`。每个数值字段记录 declared、resolved、单位、来源、消费者和 runtime readback。别名明确归一化；兼容历史配置应使用有版本迁移器，不把无效旧字段当作已生效。
2. 修复被覆盖的 assignment_type_cost；让起点列表、指标、回滚次数、点数等由配置控制。把没有消费者的 hard_negative_count、region_sizes 等移除或实现，不保留虚假入口。
3. 统一 teacher_time、learning_window、guidance_window、实际 teacher 状态时间；修复 base_config 遮蔽 master 时间的路径。引入时钟、单位、表示、词表、原子槽位和局部支持断言。
4. 明确读取实际模型的原子/电荷/键词表；取消未核验的芳香 bond=4 等隐式索引假设。
5. 显式保存类别噪声、SDE、噪声调度、solver、积分网格、sc_recycle_steps、corr_iters、final_corr_pred、末端评分协议。记录原生代码和 adapter 内容哈希，而不只保存 CLI 原始值。
6. 数值缓存身份覆盖：教师与局部支持、函数/参数、窗口、checkpoint、实际数值代码、原生积分器、初态及样本序列、seed/随机流、dtype/关键计算配置。评分与结构评价使用单独版本身份。不得仅以 batch/n/奖励 JSON 判断等价。
7. 已存在 round 配置应是不可变快照；输入发生变化应产生新 round ID。禁止修改 master 后静默使用旧 round 配置而声称执行新设置。

验收：采用两个非当前靶点的合成配置和当前历史配置做解析/编译检查；使用非 .5 时间和非 100 步验证动态性。不能依靠再次碰巧设置 .5 来证明动态接口有效。编译、执行计划、实际回读应一致；这些测试不需完整生成。

默认保存每步、每批的紧凑统计：

用少量固定输入回放已冻结程序验证日志无干预。若同一软硬件条件不能逐位一致，先复测原程序的自然数值波动并说明误差来源；不得为通过测试放宽到掩盖行为变化。诊断回放计入生成成本，但不作为新奖励成功或独立验证。

计量定义：形成率是在控制末端满足目标的比例；保留率是在末端已满足目标的样本中，后续仍满足的比例；无末端成功时保留率为 NA，不填 0。分别报告元素、联合布局、可判定化学角色和局部空间关系。中间离散标签不等于已成立的有效化学结构。

富集/差异分析：在可比较的候选、布局或谱系层面定义正负群体，报告效应、区间、覆盖和反例；同胞克隆与同骨架重复应聚类/配对处理。先定义完整检验族，随后校正；少量布局是有限输入集合，不是独立实验重复。

趋势分析：对整个学习窗口建连续描述，先试线性、低阶多项式或低自由度样条，比较留出谱系/批次拟合误差及稳定性；保存系数、适用区间、导数及不确定性，不用高阶曲线硬拟合噪声。全窗口曲线可有时间变化率，不拆成多个区间分别宣称显著。时间导数不等于坐标梯度。

证据包必须给出：观测事实、条件关联、固定输入干预、待验证生成假设四种类型。明确证据局限：布局得分高不等于有真实续生成路径；供体代理高不等于氢键能；O 场具有解释力不等于移动 O 必然增益。

**P3：重构 Analyst/Designer 的真实决策与交接**

Analyst 的任务是提出并区分局部假设；Designer 的任务是在其假设边界内提出可执行控制。二者不能靠长篇说明弥补接口缺失。

Analyst 允许调用登记的只读工具，形成有限轮的“提出问题→调用工具→读取结果→修正假设”循环。工具参数经过 schema 验证，结果带证据 ID、内容哈希和精确行引用。工具调用数与上下文预算显式配置，不无限循环。不能调用任意 shell；需要新分析能力时返回 capability_gap，由代码修改流程实现、测试和登记后再调用。

Analyst 交付至少包括：

- hypothesis_id、候选/布局来源、真实或反事实属性、对照定义。
- 正式证据引用、支持与反证、科学不确定性；重要数值由工具附带，不凭语言重算。
- typed targets、必需几何上下文、可选背景及保持自由的区域；局部区域由可审计规则构建，登记后编译。
- 目标可观测量及预期方向，学习/控制时钟，形成与保持的分别预测。
- 需要验证的一项干预、否证条件、缺失数据及下一项最小工具查询。

Designer 交付至少包括：

- 精确引用 Analyst hypothesis_id、证据版本和支持集；不能另换教师、增添点或改写角色目标。
- 选择注册奖励族，提出有来源的参数及边界；明确每个参数控制方向、剂量、曲率、对应关系还是原生动力学。
- 区分 coordinate VJP 与额外 logit 操作；数学定义、单位、窗口和动态调度完整。
- 指出每项预期执行变化及验收量，必要时返回 defer/capability_gap。

只把数据、局部支持和合法边界设为契约常量，不把全部数值设计结果预先写入 `const`。提案通过确定性校验后再冻结为该轮执行契约。角色 schema 不承诺实现其未获得的自由；每次记录允许区域数、可变参数数和实选值。

提示词仅放本轮相关的紧凑证据摘要、可检索索引和按同一 patch/窗口/奖励签名归组的历史。唯一候选的冻结确认可直接复用已批准决定，或标记为 confirmation，不宣称自主区域发现。

比较 Skills 版本时固定模型、温度、thinking 设置、输出预算及输入证据；按预算安排重复角色调用，避免把单次回答波动归因为某条指令。记录服务端实际返回的模型标识，temperature=0 不等于 API 输出绝对确定。

Skills/workflow 改动的验收链：实际文本/hash送达→输出中出现目标分析功能→Designer 使用该信息→编译算子变化→真实控制变化→终态效果。若解释变化而算子未变，登记下游瓶颈；若已数值等价，复用推理，不伪造新分子实验。用两份可区分、真实的证据案例检验功能响应；移除关键证据的诊断输入也可使用，但不得伪造科学测量。功能响应不等于性能收益。

首先固定同一局部假设、初态与原生动力学。每个子实验只改一项；下列数值是可配置的起始探索建议，不是已验证最优值，也不应写入通用 Skills。

|分支|单一变化|比较与停止依据|
|---|---|---|
|P4-D 实际剂量|以历史 rho=.33 为中心，先测试约半倍/两倍|看实际位移、裁剪和响应；若施加量不变，先找隐藏归一化/上限；不可继续盲目放大|
|P4-W 方向份额|固定实际剂量，仅改类型/几何份额|测真实夹角、形成率和几何副作用；不能把份额改变叫作总剂量增加|
|P4-M 匹配|在已测空间尺度下加入可解释的角色代价或稳定对应机制|先核实对应切换是否下降，再看布局/终态；不以固定整图实现稳定|
|P4-T 时间调度|在同一学习窗口内改变单个起点或连续 ramp|报告实际更新数和积分剂量；区分“时机效应”与“总剂量效应”|
|P4-C 形状|把无效的聚合 δ 调参替换为可响应的逐点稳健误差或局部方向函数|先做导数/响应探针；只对有增量方向变化的函数生成|
|P4-L 混合类别控制|仅在单独登记分支分级调整 logit strength/cap|不能只测试强度8；测当前状态和未经倾斜概率、下一步自条件响应；与纯坐标结果分列|

默认先检查日志提示的主要瓶颈，不强制跑完整网格。若方向/形状改动无实际响应，查接口/归一化；若控制改变但 N/C 不形成，查坐标可控性、对应关系、角色兼容；若形成后丢失，进入 P5；若能稳定形成但终态亲和力下降，优先回到 P2 修改假设。

不要使用“全权重同乘”或当前聚合 pseudo-Huber δ 变化充当强度实验。新增函数需在固定对应、远离不连续点处通过有限差分/自动微分一致性检查；Hungarian 切换点应单独作为非光滑边界记录。

**P5：原生保持与终态预测诊断**

从 P1 的同一次轨迹先比较控制末端、积分终点 current、final predicted，尽量避免不必要的重复生成。评分 current 时沿用明确的同一终态评分协议，作为诊断输出，不偷偷将其替换为正式输出。

|顺序|实验|约束|
|---|---|---|
|1|定位积分后半程和最终预测各自造成的变化|先观察原配置；保存紧凑实际状态及对应|
|2|固定奖励，仅改变类别噪声参数|需要同类别噪声的无引导对照；保留原噪声参照；不固定标签|
|3|固定奖励，单独研究合法数值积分分辨率/概率处理|先说明是否改变积分近似或采样过程；同时保存概率截断频率|
|4|单独比较 final_corr_pred 的输出策略|标记为生成协议改变；不与旧协议结果混作同一条件|
|5|日志确有需要时，再单独研究坐标随机项/漂移定标|不能把参数 .2 当固定 Å 噪声；避免同时改类别与坐标过程|

类别转移中的 14% 条件离开概率是已知机制风险，不是已证明的全部失败原因。降低噪声不是锁定化学图，也不保证亲和力提高；必须同时测生成质量和探索多样性。积分器的数值合法性处理不得被包装成禁止化学图变化的 gate。

若改变步数或原生算法，匹配新条件的无引导对照需要重新计算；若只改评分器，可复用结构并统一重评分。原始 Steer 保持历史参照，不修改其数据或将其视为新动力学下的匹配对照。

**P6：证据支持后的局部奖励探索**

优先顺序由实际诊断决定，以下都是候选假设，不是待全部堆叠的奖励项：

1. 联合局部交换：保留目的 N 与补偿 C 的联合关系，并说明其邻接/空间条件；不用独立边际差冒充各原子能量。
2. 局部化学角色与坐标兼容：对具体局部角色采用软概率、邻接和方向描述，同时保持其它区域可适配。避免只奖励 generic N。
3. 周围 N/O 距离场与空间分配：作为候选的兼容性信息，寻找有单候选对照支持的少量位置；不把所有极性原子都纳入损失。
4. 多个局部教师模式：使用多个有真实终态支持的局部路径，保留模式身份与条件；避免坐标平均产生不存在的中间构象。混合方式单独测试。
5. 时间相容的局部目标：从整个选择窗口的真实轨迹拟合低复杂度目标变化，函数参数、导数和范围可审计；不能将反事实终态标签冒充其真实早期路径。
6. 原生保持支持：优先选择控制结束后仍受原生模型支持的局部状态。可用已有或少量登记续生成反馈检验，但不在每一步调用 affinity head，也不把 LLM 自信度当存活概率。

每次只加一个有独立证据的新组件，与删除该组件的匹配对照比较。若性能下降且控制确实形成目标，应回退该组件并重审证据；不要不断叠加惩罚项来保护原假设。

**四、每轮 auto-research 的固定工作流**

1. 读取最新授权预算、活动最佳数值配置、失败档案及当前阻塞阶段。预算不明时可做离线审计与方案准备，不默认启动新的 GPU/LLM 批次。
2. 选择一个问题，写出假设、单一自变量、固定项、预期执行变化、判定指标、失败后备选解释。
3. 先运行已有离线工具；不足时本地补充独立模块及必要测试。接口故障或缓存失配修复后，重试同一科学条件，不将其计为新成功假设。
4. 发起真实 Analyst 调用并验证证据；Designer 基于其输出提出程序。用确定性程序校验引用、支持、参数、单位与时间，编译并冻结。
5. 比较执行签名及响应探针。数值等价则复用结果并写明“本次 Agent 输出未改变执行函数”；不重复生成。
6. 本地 commit、经既定本机网络入口 push；远端 pull 后运行指定 commit 的调用接口。记录实际源码身份，不允许远端手改科学代码形成未登记分支。
7. 检查旧派生结果是否已同步、提取报告及可复核证据，随后按精确清单清理远端对应实验目录。保护原 Steer、checkpoint、最佳记录与共享数据。
8. 先少量功能性生成，再按预算扩大筛查；完整生成到终态。接口/窗口/实际控制不符合声明时，标为执行失败，先修复，不报告科学效应。
9. 本地分析：指令响应→函数变化→控制变化→形成→保持→最终亲和力与副作用。保存支持结论及相反证据。
10. 决定 retain_candidate、promote、rollback、reuse、defer 或 inconclusive；写入状态与下一问题。只对有独立确认的结果更新正式基线。

角色说明和决策记录保存可复核的证据摘要、备选方案、选择依据、参数来源与预期结果；不要求保存模型隐藏思维过程。

**五、样本、评价与基线更新规则**

样本量必须写入预算清单。建议功能诊断先用少量固定样本；性能筛查可沿用24个输入，随后在未用于调参的独立初态池以50个或预算允许的更多样本确认。24/50只是资源分级建议，不能保证统计功效，也不能自动把后续扩大到400或1000。

“未用于本轮调参的初态”不等于“未参与历史 Steer 教师挖掘的独立分子数据”。分别记录初态是否用于调参、其历史终态是否进入教师/特征选择，以及靶点是否相同；只声称实际实现的独立性层级。

比较层次：

- 相同初态、样本编号、原生协议及评分版本的无引导对照：衡量净控制收益。
- 相同条件下的冻结历史 R13：衡量新组件是否改善当前起点。
- 原始 Steer：保留总体分布与上尾参照。样本量/谱系不同则明确标记，最大值不能直接解释成公平方法排名。

随机数管理：同 seed 不保证不同批大小、不同采样分支或不同 RNG 调用次序下的随机噪声一致。优先按 sample/step/channel 管理可复现随机流；未实现时，严格固定同一比较中的批大小和调用协议，并报告可确认的配对层级。扩大样本量不能自动当成一组独立新样本。

指标至少包括：全部尝试的最终评分覆盖、可评分均值、上尾/Top-k、高分成功率、最大值；全部尝试的有效率、当前结构合格率、失败类型；应变及能量覆盖/收敛状态；局部形成率、保持率和几何响应。无评分失败不得悄悄丢弃，覆盖下降时不能仅比较成功子集均值。结构合理性可增加更完整检查，但须对可复用基线统一重评，并记录新旧口径。

统计单位是生成尝试/匹配输入及其谱系或批次，不能把原子、步数、克隆或合法布局当成独立样本扩充显著性。保留配对效果及不确定区间；参数搜索后的区间标记为探索性。单次最高值只用于候选发现，不能单独决定更换基线。

执行前配置并冻结：主指标、实际意义阈值、允许均值波动、结构/应变副作用边界、区间方法与确认样本。阈值应来自任务要求和基线波动，不把历史最高值的 .01 容差机械套用到所有统计量。预算不足以区分时，状态为 inconclusive，不填“等价”或“无效”。

基线更新要求：代码与窗口核验通过；目标功能确实实现；主指标达到预登记提升要求；独立确认未显示不可接受的均值/覆盖回退；次级质量接近基线或改善。若只改善上尾而均值下降，作为单独策略候选报告，不宣称总体全面改进。

连续两轮达到预登记的“明确下降”定义时，恢复活动最佳数值配置，并回到失败所属阶段分析。失败实验和正确性修复保留；回滚必须真实影响后续 parent program，不能只写 rollback.json 然后继续沿用失败合同。相同根因重复失败时更换检验假设，不消耗预算重复调同一无效参数。

**七、存储、实现组织和交付物**

保留现有规范：按计算角度拆分模块，IO 和 schema 共用；数据默认输出紧凑汇总、小型 Parquet 和 JSON，保持既定精度。高重复标签表使用合适类型，避免展开成巨大逐原子/逐边 CSV。全过程只保存必要标量与少数关键状态，不默认保存完整生成轨迹或完整 Jacobian。

统计计算可读取完整原始证据，LLM 只读取摘要和工具返回。程序不通过删除失败对照压缩数据；明细可重建的前提是原始源、配置、代码和谱系都保留。每轮报告产物大小与源清单。

建议新 campaign 的每轮目录包含 `proposal`、`calls`、`compiled`、`execution_manifest`、`analysis`、`decision` 等职责明确的文件；大结构位于忽略的数据目录，Git 保存源码、配置、紧凑结果和决策记录。生成结构已下载且摘要/校验完成后，再清理远端冗余副本；涉及历史原始数据不在自动清理清单内。

每个阶段交付：代码 commit；对应功能性验证；真实执行/工具调用证据；已知限制；下一项可区分实验。不要因完成代码就宣称分子质量改善，也不要因一次预测高分就跳过接口核查与独立确认。

**八、可直接交给 auto-research agent 的启动指令**

> 读取本计划和最新用户约束，先确认已经完成的历史工作与尚未授权的新计算预算。从当前未通过的最早阶段开始，优先复用冻结证据。每次只选择一个可区分问题，在本地完成可审计代码、配置与必要测试。Analyst 必须基于真实局部证据提出假设，Designer 必须绑定该假设并说明参数如何影响实际控制。先证明本轮改动改变了预期功能或执行量，再解释性能；函数数值等价时复用结果。需要推理时遵循本地提交推送、远端拉取指定代码、清理已归档派生数据、再运行的流程。对形成失败、后续丢失、终态亲和力下降和执行错误分别处理；保持局部支持、动态窗口、无 SMC、无 affinity 梯度及正常化学图自由度。保存证据、反例、结果和决策摘要；遵守预算与回滚规则，最终仅在匹配对照和独立确认支持时更新最佳基线。
