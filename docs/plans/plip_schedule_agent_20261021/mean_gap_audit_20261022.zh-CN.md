## 3. 引导路径、幅度和有效作用

`flowr.py`明确调用`_generate_selective(..., apply_guidance=False)`；这个参数关闭的是原生SMC重采样。
梯度引导由另一个路径执行：`Control.forward`计算Endpoint局部奖励对当前坐标的梯度，
原生积分器更新后，`Control.after`叠加指导位移。这个标志不表示关闭梯度引导。
历史PLIP梯度实验同样关闭SMC，因此两者机制一致。

当前R0按用户确定的四区间运行，10–90含端点共81个更新使用0.5，0–9和91–99使用0。
历史固定幅度/暖启动实验覆盖全100步，两者不是同一个调度。
轨迹中的实际lambda、时间标签和位移已核对；存在非零指导，未发现未执行引导或坐标单位重复缩放。
此前实际保存状态的梯度有限差分、单位换算、RNG隔离和11个入口恢复验收也通过。

下列统计覆盖Top1 R0全部五批，每个区间按分子、时间步等权。位移比为整分子指导位移范数/原生更新位移范数。

只有26–50区间的1/2500个分子步发生裁剪，其他引导区间没有裁剪；0.025 Å上限不是大多数轨迹受限的原因。
当前幅度范围0–1、每轮通常±0.1，故局部调度变化未必能把这样的小扰动变为显著的整体质量提升。
不应未经试验便断言放大lambda有效，更不能在冻结的V1中直接修改奖励、归一化或范围。

## 4. 为什么与Steer差距明显

1. Top1虽有两个PLIP互作指纹，但均关联同一个配体重原子（native index 9），核心覆盖率仅1/10。
   一跳上下文包含原子7、9；当前C奖励只约束核心坐标，没有教师原子类型、键、电荷或直接亲和力梯度。
   因此“接近一个高亲和力分子的某个空间点”不等价于“恢复该分子的高亲和力”。
2. 原Steer在生成中按预测亲和力重采样，会改变候选群体的组成；当前流程从全部原始起点分别进行局部几何引导，
   不在链之间复制高分粒子或删除低分起点。逐链TOP1也只在本链历史中择优。
3. 分布支持上述解释：历史Unguided有63/100个结果pIC50<4，Steer只有1/100；
   当前R0仍有60/100。pIC50>=6的数量分别为15、69、14。
4. 当前R0有86/100个槽位的canonical SMILES与历史Unguided相同，说明大部分化学构型未改变；
   这里只作描述性对应，不能声称跨环境相同噪声路径的因果配对。

这些证据提示局部奖励的表达能力和可产生的实际扰动是当前瓶颈，但并未单独识别两者的因果贡献。
R0/R2的Mean相近不是足以认定代码错误的依据，也不是足以认定该科学目标可达的依据。

## 5. 处置与后续解释

本次不改动冻结V1：目前没有证据要求修复采样代码或替换输入。继续保留低分链、失败记录和既定10轮预算。
后续全量复盘应优先看低分链的亲和力响应、局部误差、类型/结构改变、实际位移以及高低分链各自的改善；
结合Top2/Top3模板覆盖差异判断单靠四段幅度调节的能力边界。不能仅凭逐链TOP1的单调增加宣称生成分布改善。

若最终固定轮次Mean仍停留在Unguided附近，应据实判定“当前局部坐标奖励+有限幅度调度尚不能恢复Steer的Mean优势”。
更换局部特征、奖励或幅度范围属于另一个科学协议，需要单独版本化，不能包装为当前V1的软件修复。
