# M2/S3 证据溯源与终态优秀路径教师对照方案

日期：2026-10-13。状态：本地只读审计与前瞻设计；没有调用 LLM API、启动生成或更换活动 Skills。本文件的“建议”均不是已完成结果。来源版本为 4ee832be。

## 1. 已核实的事实与需要纠正的归因

M2 是冻结的静态教师数值程序，不是一次新的 Analyst 输出，也不是另一套 FLOWR 权重。其文件是 `configs/experiments/steer_dependency_v1/D2_without_trajectory_static.json`。旧协议明确列出“M2 static teacher matched R26”；Luna 阶段复用 M1/M2 不变的数值推理。M2 的 native_rms_ratio 为 0.33。

旧 `luna_suite/D2_without_trajectory/Analyst.response.json` 确实存在，但不能等同于 M2 专属分析。该 Analyst 读取原始结合配体/受体的结构描述：25 个重原子、协方差特征值约 0.111/5.696/9.303 Å²、几何接触、308 个受体重原子的裁剪环境。它明确说没有生成状态、亲和力标签、存活或时序证据，不能开展这些分析。对应 Designer 选择 static、剂量 0.2；这与冻结 M2 的 0.33 不同。

S3 是 W/S/C 研究中预先注册的数值方向：固定教师奖励逐渐过渡至同时刻教师奖励。它实际完成 400 次生成，但没有专属的 S3 Analyst/Designer 调用。不能称其为“LLM 从中间态自主发现 S3 并成功生成”。

另一方面，W/S/C 的真实 `deepseek-flash` API 调用确实存在：10 个条件各六条完整角色链，共 60 对 Analyst/Designer；120 是最终角色输出数，不是 HTTP 请求总数。只有 24 条 S 路线可以选择 S2/S3；21 条选择 S1、3 条保留 M2，S2/S3 均为零。数值对照与 Agent 策略选择是两个不同实验层。

### 两个真实输出例子

| 调用 | Analyst 实际分析 | 下游决策 |
|---|---|---|
| S00/chain_00 | landmark_00_soft_mass：全窗对比 z≈0.639，首/末变化率≈9.27/−10.00，4 次符号变化；曲线早负、中部正、晚负；三次多项式拟合拒绝，relative_node_RMSE≈0.286。提出考察时变对比，不支持单一恒定方向。 | Designer defer，执行 M2；它认为这些信息不能确定三种混合调度的方向。 |
| S10/chain_00 | landmark_00_local_dx：全窗对比 z≈−0.18，首/末变化率≈−17.5/+8.1，6 次符号变化、9 个 strong_sign_conflicts；拟合拒绝，relative_node_RMSE≈0.78。提出考察 S1 与恒定混合对照。 | Designer 选择 S1；没有选择 S3。 |

两份输出中的值描述的是预计算的区域对比曲线，不是原子物理速度或已确立的坐标优化方向。原回答把不同量纲/归一化口径的均值与变化率直接比较大小，不能作为“整体效应小、变化率大”的科学证据。S10 Designer 还称 S1 是唯一平滑的阶段干预，但 S3 也平滑；该方向选择没有被所引曲线充分支持。

重新统计最新完整链：全部 60 条中，34 条读取 1 条曲线、6 条读取 2 条、1 条读取 3 条、1 条读取 4 条、18 条读取 8 条；S 路线 24 条中，21 条读取 1 条、3 条读取 2 条。这不是分析全部 200 个局部特征后发现优秀路径。当前接口验证证据存在及交接，但未充分验证“证据足以识别目标区域、阶段与可执行奖励”。

因此：已有真实的中间节点摘要阅读与解释；尚未充分实现真实谱系上的优势区域发现、终态效用归因和特征级奖励构造。问题是证据供给、工具使用深度和下游设计自由度，不是 LLM API 原理上无法执行该任务。

## 2. 为什么只有 14 批，为什么只有 28 个静态教师

`configs/default.json` 把原 20 个 Steer 批次划为：发现 0–13、验证 14–16、保留 17–19。挖掘函数 `continuous/affinity_geometry.py:mine` 与 `affinity_endpoint.py:mine_endpoint` 默认 `range(14)`，冻结教师库沿用这一划分。14 不是 FLOWR 的限制，也不是历史 Steer 只生成了 14 批。

每批原来有 50 个槽位；14×50=700 个槽位，不是 700 条独立完整谱系。每个选择节点，每批按记录的即时 head 分数降序选两个教师：首先最高分，再取端点几何特征距离超过 1e-3 的下一个。该阈值作用于混合单位的特征向量，仅为近重复排除，不能解释为两个独立构象盆地或两个独立根谱系。

于是每节点为 14×2=28 个教师。`dependency_ablation.py:prepare` 的 static 分支把所有 frame 的 `teacher_*` 字段替换为最后学习 frame 的内容，再将 teacher_scores 清零。28 个教师被重复存入每个 frame，是为了移除时间变化的教师信息，并沿用旧加载格式；不是克隆 28 个正在生成的粒子，也不是发现了 28 条最优独立路径。

现有发现/验证/保留名字不能自动恢复独立性。早在 `ck2_terminal_seed42_20261005/round_05.design.json` 已记录 14–19 的部分聚合统计被查看。将全部 20 批用于新教师是可行的开发数据扩展，但应另建版本；不能改写冻结 M2，也不能把原 1000 个 Steer 结果当成完全未见的外部验证。

## 3. 严格区分状态、端点预测与标签

令当前噪声状态为 X_t，FLOWR 端点预测为 Y_t=Fθ(X_t,t,P)，完整推理并解码后构象为 X_1^decoded。

| 对象 | 含义 | M2 是否使用 |
|---|---|---|
| X_0.49 | t=0.49 的实际当前状态，仍可能含噪 | 否，未作为教师坐标 |
| Y_0.49 | 在 t=0.49 进行 forward 得到的端点坐标预测 | 是，固定教师坐标 |
| X_1^decoded | 完成后续推理、解码得到的真实终态构象 | 否 |
| s_0.49^joint | .49 时联合 forward 记录的亲和力 head 标签 | 建库时用于选教师；运行时已清零、β=0 |
| s_t^joint | 各中间评分节点的即时 head 标签 | M2 不逐时刻据此重选教师 |
| s_1^rescore | 解码终态用统一评估流程重评分的预测亲和力 | 不参与 M2 建库 |

上述 joint 标签不能称为对 Y_t 坐标独立重新评分的亲和力。模型内部联合预测与对最终解码分子重评分也不可混称。

本次学习节点是 score_time=0…0.49，因为要求其原生 proposal state_time≤窗口末端 0.5。动态窗口由元数据给出。原轨迹曾记录 score_time=.50 的额外选择事件，对应 proposal≈.51；它不进入本次坐标学习窗口，但终态回溯必须使用其真实索引，不能截断掉后再假定 slot 不变。

M2 虽是固定教师库，控制方向仍随 seed 和时间变化：当前预测 Y_t 与教师做 Hungarian 几何匹配，选最近四个，以几何距离形成条件先验，再经真实 FLOWR VJP 回传。其 β=0 移除了显式分数加权，不等于教师没有历史高分选择偏置。

S3 为 R_t=(1-b(t))R_static(Y_t)+b(t)R_same-clock(Y_t)，b 平滑从 0 到 1。动态库每个节点分别按 s_t^joint 选取教师，没有终态优秀路径的固定身份，不能称为同一批分子沿时间演进的轨迹。

## 4. 真实谱系与多条优秀路径

已存在可复用模块：`continuous/path_graph.py`、`elite_path_credit.py`、`terminal_path_library.py`。后者已保存 teacher_node_ids/teacher_path_ids 并合并共享祖先，但当前 choose_paths 仅按每批终态有效高分、SMILES 去重、最多两条选取；尚未保证根谱系或几何路径的多样性。M2/S3 的旧教师库没有这些身份字段，不能靠列表位置补造。

### 索引定义与必须执行的校验

P[j,d]=selected_indices[j,d] 表示第 j 次转移后子槽位 d 来自该次转移前的源槽位。对最终槽位 q：

    ancestor[T,q] = q
    ancestor[j,q] = P[j, ancestor[j+1,q]]    # j 从 T−1 倒序至 0

几何边分为两类：CURRENT(j,i)→PROPOSAL(j,i) 的原生积分边；PROPOSAL(j,P[j,d])→CURRENT(j+1,d) 的选择复制边。Y_j 应读取预测数组 [j,ancestor[j,q]]，不是 [j,q]，也不是 [j,ancestor[j+1,q]]。

需要验证：索引范围；非选择节点为 identity；offspring_count 等于 bincount；根编号随 P 传播；current_coords[j+1,d] 精确等于 proposal_coords[j,P[j,d]]；终态 SDF/评分行通过保存的输出映射对应最终 slot；坐标单位、受体坐标框架和 mask 一致。终态解码失败也须保留原始 slot，不能用过滤后行号替代。谱系回溯用完整保存的转移，学习特征仅取配置窗口。

### 建议的离线选择算法

1. 对 donor 批次解码终态统一评分，保留全部失败原因。按终态预测亲和力设预注册优秀候选门槛；结构有效是可读构象的前提，应变单独报告，不用事后调能量阈值挑赢家。
2. 从全部终态反向追溯真实 ancestor、root 和分叉事件，记录每条候选路径的完整节点索引。不同 slot 不等于不同路径。
3. 在达到优秀门槛的候选中先去除同构象克隆，再按终态空间模式和整条路径空间距离去重。SMILES 去重不足以确认路径独立；同一图的不同姿态是否保留应由预注册模式定义决定。
4. 在质量门槛内，以最高分候选起始，再贪心选取与已选路径最远者。设置每批、每根及每模式的容量；不足时报告实际数量，不复制教师凑足 28，也不无记录放宽标准。
5. 路径距离可用全部实际学习节点上、固定受体坐标框架中的 Hungarian 匹配端点 RMS 的时间积分。不能对每个分子再独立旋转对齐来消除其相对口袋位置。阈值在开发数据冻结后执行。
6. 区分“不同根”“不同分叉路径”“不同终态模式”；真正的统计重复单位仍为批次。来自一个共享祖先的后代不能当作独立证据。

建议路径表示：唯一节点表保存坐标 locator；路径表保存 terminal_id、root_id、mode_id、terminal_score；path_nodes 保存 path_id→node_id 的稀疏映射。共享祖先仅保存一份坐标，保留其 path_ids 列表。教师权重先按批、根、选中的非重复路径分配，再在共享节点合并其质量；不能按原始克隆数增加权重。所有新比较臂使用同一组路径质量权重，另报共享节点数和有效教师数。未观察到终态的灭绝节点为缺失 future label，不能给零分冒充失败终态。

## 5. 推荐的两阶段数值对照

“t=1 构象”“t=.49 构象”是几何来源；“每时刻评分”是标签/选样规则。这两类因素应分开。以下 t*=最后学习 score_time，从 metadata 取得，当前为 .49。

先冻结同一组终态优秀路径 P*、同一 donor 面板及路径权重。保持 M2 的 reward family、η=.33、K=4、τ=.5、几何先验温度 4 Å²、β=0、曲率默认值、FLOWR checkpoint 和积分器。只替换教师来源。原生图变化继续开放，不增加在线 affinity forward 或 SMC。

| 臂 | 教师身份如何选 | 引导时教师坐标 | 主要用途 |
|---|---|---|---|
| B0：冻结 M2 | t* 即时分数，每批两个 | 固定 Y_t* | 直接复用已有 400 |
| B1：终态构象 | 同一 P*，终态高分路径 | 固定 X_1^decoded | 终态几何目标 |
| B2：末节点预测 | 同一 P* | 祖先的固定 Y_t* | B1−B2 分离最终构象与末节点预测 |
| B3：祖先预测轨迹 | 同一 P* | 真正祖先的 Y_t，逐节点变化 | B3−B2 检查同一路径的时间信息 |
| B4：即时分数教师 | 各 t 按原规则 s_t^joint 重选 | 每节点的 Y_t | 保留 M2 建库规则，仅去掉 static 复制 |
| B5：冻结 S3 | 原静态与逐节点教师库 | 原 S3 混合 | 直接复用已有 400 |

B1/B2/B3 是最干净的坐标时间对照。B2−B0 同时改变了教师选择标签、终态可解码筛选及路径集合，必须按“终态优秀路径策略整体效果”解释。B4−B0 比较动态即时精英库与静态即时精英库；B3−B4 还涉及终态路径约束/多样性，不能仅归因于一个评分时间。

如需要比较实际 X_t* 而非 Y_t*，必须另列状态空间实验。用 endpoint 奖励直接匹配含噪 X_t* 会混合表示尺度；其结果不能等同于末节点端点预测对照。

随后再比较评分时钟：固定 B3 的几何、路径 ID 和基础权重，以同一个预注册 β>0 比较终态重评分、末学习节点 joint 标签、逐节点 joint 标签三种先验；B3 的 β=0 为无分数权重控制。这一步才能解释“相同几何条件下，哪个评分时钟更有用”。不改变温度。早期若多个路径共享节点，joint 标签相同；保持共同合并规则，不制造不存在的评分差异。所用标签全部离线读取，不新增生产阶段 affinity 调用。

不能直接改用 `PathValueReward`：其公式是效用对比而非 M2 的教师吸引，在 β=0 时可能为零。那将是奖励族的另一个实验，不能混入上述教师对照。

### M2 数学形式保持不变

对匹配后的教师 T_k，q_k=mean_i ||Y_i−T_ki||²，ρδ(q)=δ²(sqrt(1+q/δ²)−1)。

    R(Y,t) = τ log Σ_k π_k exp(−ρδ(q_k)/τ)
    π_k ∝ w_k exp(−d_k²/Tgeo + β s_k)
    g_t = (∂Fθ(X_t,t,P)/∂X_t)^T ∇_Y R

教师选择、匹配、π 为本次梯度的 detached 条件；g_t 再进入同一 M2 的 RMS 剂量标定与位移控制。B1/B2/B3 的差别是 T_k(t)，不是梯度定义。新路径权重 w_k 与旧 M2 可能不同，因此它们之间的严格单因素比较是 B1/B2/B3，而非所有新臂相对于 B0。

## 6. 真正的 Analyst→Designer 科学链路应如何验收

数值对照用于判断教师策略；API 层另用于检验 Agent 能否从证据做出有用决策，二者分开归因。

Analyst 应可调用：真实谱系审计、终态信用覆盖、共同祖先坍缩检查、局部坐标富集、控制当前分数后的终态效用对比、全窗经验趋势与可靠性、真实父子增量、失败/反例查询。复用确定性统计工具；不让 LLM 心算三维坐标差或补写缺失标签。

以已观察到终态的普通路径为终态优秀祖先的主要比较群。即时未选中节点只用于即时选择对比；没有后代的节点不提供反事实最终亲和力。按父代/根依赖处理权重，再以批次推断；分数、存活与终态效用分别命名。只有一个共同祖先的阶段，应报告无可识别的优秀/普通差异。

工具先给覆盖全部特征的紧凑统计目录及支持数，再让 Analyst 查看排序前列、异号、不稳定和空效应曲线；选择预算由配置控制。不能“读任意一条曲线并写两条假设”就认定完成空间分析。每个假设需要有 feature/region、表示、评分时钟、对比组、范围、效应/区间、真实 curve/node 引用，以及可证伪的坐标 observable 和目标来源。稳定性未通过时允许无结论，不强制制造规则。

Designer 应能把上述假设映射到注册的区域坐标 observable、离线经验目标曲线与教师路径模式，而不只是 S1/S2/S3 三选一。相对富集 z 不是绝对坐标目标；绝对目标必须从被引节点的原单位观测提取。先校验可微性、几何响应方向和实际注入，再评估亲和力；时间导数不能直接当作空间梯度。

功能通过须贯穿：实际 API 输入与工具调用→足够的证据覆盖→假设来源→Designer 生效参数→编译签名→生成 trace→最终指标。使用中性策略编号并允许 defer，避免“main/control”命名引导选择。保留原 API 模型与默认温度；原始回复、token/结束原因、工具结果、修复及拒绝均可追溯。若保留 M2，标签写明最终执行 M2，不称作候选策略生成结果。

## 7. 样本、性能指标与完成边界

先复用既有 M2/无引导各 400、S3 400、Steer 1000；B1–B4 每个独特有效程序先用相同 6376–6383 批次、seed42、每批 50，共 400，初始输入 hash 必须相同。该面板已经多次查看，只能作为开发比较。最终方案冻结后需要新的未参与选择批次；400 并不保证高尾部检验功效，应按独立批次方差及预注册最小效应另做预算。

主要报告全部尝试最终预测 pIC50 均值及相对 M2/无引导的配对批次区间；针对优秀路径目的，另预注册有效高亲和力产率、不同图/姿态模式的高分数量、top-k、p95/p99、最好且构象合理的样本。应变、PB、有效率、评分/能量缺失单列。对多个新臂控制多重比较。原 Steer 为不成对且计算预算不同的参照；不能只比最大值，也不能把共享教师/后代当独立重复。

只有数值改变的新程序重新生成。控制窗口动态读取，当前 50 次注入后继续原生推理至 1。输出重点是紧凑路径索引、统计、终态评分及实际控制摘要；不保存展开的所有特征副本。新组失败独立记录，禁止静默切回 M2 并继续使用候选名称。

本次只保存上述审计与方案；未实现新的多路径选择器、未构建 B1–B4 教师库、未运行对应生成，不能报告其优于 M2 或 Steer。
