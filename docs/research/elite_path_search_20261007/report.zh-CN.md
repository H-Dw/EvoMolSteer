# 从Steer先验中识别、保留极高预测亲和力路径

日期：2026-10-07。审计代码基线：daf1b6b46c424f46fb182b4c32101b1d311ba728。

建议将当前的“逐时刻高分坐标近邻吸引”扩展为“终态高分潜势、连续分支信息和多模式先验”。最优先补充的不是更多Skills文字，而是能够回答以下问题的计算证据：某个中间态是否通向有效的高亲和力终态？它与哪些已知优势路径属于相同的坐标模式？怎样改变局部坐标有助于进入这些路径，怎样减少干预以保留已经有潜力的路径？

本文是针对当前任务的文献检索、代码与原始谱系审计，以及算法设计。文献结论、当前实测结果和拟议算法分别标明。没有修改现行奖励、Skills或推理程序，没有启动新的远端生成实验。新增的audit_snapshot.py只做读取与小型统计，不调用模型。

## 1. 当前结果表明需要改变什么

现有冻结GG500的终态预测pIC50均值为7.6015，相对配对无引导7.4288提高0.1727；完整Steer1000的均值为7.6515。有效且预测pIC50≥8.2的输出分别为3/500与63/1000，涉及2与32种化学图。GG与Steer输出数量、初始状态和计算预算不同，Steer还有复制相关，不能把这些数字解释为方法的公平因果胜负。但它们说明当前GG主要改善分布主体，极高分尾部仍值得重点研究。[完整比较及定义](../../experiments/guidance_vs_steer_20261007/report.zh-CN.md)

当前的分数是同一FLOWR head的预测值，不是实测结合亲和力。Steer最高预测8.7048的构象应变代理明显偏高；另一个非donor候选预测8.5844、应变代理0.3892 kcal/mol/重原子，同时通过既有dock_fast检查。目标应是增加有效高分路径的发现，而不是让奖励追逐任何高分极值。应变仍作为次级评价，避免压过亲和力。

配对结果中，无引导终态最高的25个输入有18个在GG下下降。这是依据已经观察到的无引导结果所作的事后分组，包含选择与回归均值问题，不能证明可以提前识别这25条路径。它提出了一个值得检验的机制假设：持续的近邻点云吸引可能改善一般路径，却将部分潜在高分路径拉回常见teacher模式。

## 2. 代码与数据中的具体信息缺口

### 2.1 奖励库保存了点云，但没有保存路径连接

现行R26使用endpoint_pointcloud、真实FLOWR endpoint VJP、最近4个teacher和native RMS比例0.33。现行库来自batch 0–13；每个实际学习节点保留28个teacher，时刻为0.00、0.01……0.49，配置窗口为[0,0.5]。每帧只有time、high/low/variance统计、teacher_endpoint_A、teacher_scores和teacher_batches等字段，缺少teacher_slots与父子节点ID。

因此当前库不能说明两个相邻时刻的teacher是否来自同一分支。推理中的最近4个teacher按每个时刻重新选择，未使用路径前缀或分支转移信息。这允许奖励目标在时刻之间跳到不相关的分支。仅有均值曲线或若干高分点云，不足以构成高分路径。

teacher_scores是原在线joint-forward head输出：首帧teacher范围约8.261–8.750，末学习帧约8.235–9.347。这些数字属于对应生成时刻的latent预测，不等于这些teacher坐标在最终解码后重新评分的亲和力。尤其不能把中间9.347解释成发现了终态9.347的候选。

相关实现：src/evomolsteer/continuous/affinity_endpoint.py、src/evomolsteer/generation/endpoint_reward.py和src/evomolsteer/generation/affinity_geometry_reward.py。

### 2.2 当步权重健康，不代表谱系仍然丰富

本次读取原始单目标20批、每批50个粒子的root_slot、selected_indices与selection_probability，验证全部20批父子映射一致。以下是完整20批的均值，取几个时刻展示连续窗口的变化，不是重新划分分析子区间。

|score时刻|当时仍存在的初始祖先数|按初始祖先占比计算的ESS|当步选择概率ESS|
|---|---:|---:|---:|
|0.00|50.00|50.00|47.15|
|0.10|5.95|3.38|48.53|
|0.25|2.00|1.40|47.32|
|0.49|1.15|1.07|47.88|

祖先ESS定义为1/Σf_root²，其中f_root是当时粒子中各初始祖先所占比例；选择概率ESS为1/Σp_i²。它们回答不同的问题。后者接近50不能弥补前者接近1的历史损失。

不能将谱系损失全部归因于尖锐评分权重：均匀多项式重采样也会丢掉祖先。N个等权候选重复抽取N次后，期望被保留的不同候选数为N[1−(1−1/N)^N]；N=50时约31.79。反复复制会累积随机漂变。此处只是机制解释，尚未用消融量化漂变、评分与后续随机生成各自的贡献。祖先数也不等于坐标或化学模式数，同一祖先的后代仍可能分化，故还需要直接计算几何模式覆盖。

原有terminal_lineage_v4的700个batch-node中，349个不足3个有终态后代的祖先，531个不足6个。此处的“有终态后代的祖先数”是在每个时刻向后看，不能与上表“初始祖先覆盖”混为一谈。复制后代数不能直接成为独立样本量。

[可复算审计](audit_snapshot.py)与[结果、校验值和字段定义](audit_snapshot.json)已保存。

### 2.3 已有终态回溯还不是所需的终态高分潜势

已有terminal_lineage_v4按step99的preselection latent head计算平均后代分数，并比较有后代/灭绝分支。它明确将灭绝分支的未来分数记为未知。这是正确的缺失处理，但尚不是“有效且极高终态rescore”的尾部分析。

过去R17/R19/R24等实验已经尝试终态survivor先验，没有取代现行R26。因此不能把“加入终态后代信息”本身当作新颖且必然有效的方案。这里建议新增的内容是：真实终态rescore与有效性、极高分尾部而非平均survivor、完整父子连接、多路径模式覆盖，以及未来续跑策略的明确标记。

现有main1000_w050续跑对照在step10/30/50各32个终态，共96个，源节点均属于joint；重启阶段为pre_integration_scored_state_with_fresh_future_noise。它们不能直接作为当前single目标的无Steer续跑概率标定数据，也不能当作与原轨迹共享未来随机噪声的配对反事实。

### 2.4 时钟与后续策略必须记录

原始Steer在score time 0–0.5含端点执行51次选择，最后选择的是native更新后约0.51的proposal；现行GG库只有score time 0–0.49，对应控制至0.5。不能把原始Steer后代标签当作从X_0.5开始完全无Steer续跑的标签。

研究特征仍限于动态指定的学习窗口。t=1坐标与评分可以作为结果标签，不要求对0.5以后的坐标做富集分析或施加引导。需要保存score_time、current状态时刻、proposal状态时刻、representation、restart_phase和future_policy，避免把不同量误接到同一节点。

## 4. 建议先构建可以搜索的稀疏路径图

### 4.1 保留节点身份与两类边

节点最少包括source SHA、batch、node/slot ID、初始root、时刻、representation、结构引用、在线评分和终态标签状态。teacher提取时必须同时保存原始slot及父子连接。现行点云库不能唯一逆推slot，尤其是多个完全相同的复制点云，不能事后凭坐标猜测唯一谱系。

每一步分成两类边：

- native边：current X_t[i] → proposal X_(t+Δt)[i]，反映模型的生成变化。
- copy/selection边：proposal X_(t+Δt)[i] → next current X_(t+Δt)[child]，由selected_indices映射，表示复制或淘汰。

同一步重复拷贝相同结构不产生新的坐标优化。将这两类边混合计算“变化率”，会把选择频数误认为几何变化，也会把克隆当作独立样本。

对任一坐标特征φ，群体均值存在可核对的分解：

\[
\bar\phi_{t+\Delta}-\bar\phi_t
=\underbrace{(\bar\phi_{\rm proposal}-\bar\phi_t)}_{\text{native生成变化}}
+\underbrace{(\bar\phi_{\rm selected\ proposal}-\bar\phi_{\rm proposal})}_{\text{选择富集}}.
\]

左侧与右侧使用相同批次、粒子范围和表示。该恒等式用于区分变化来源，不证明某个几何特征导致亲和力提高。

### 4.2 使用终态尾部结果，而不是仅使用生存

将目标事件定义为E={终态有效且预测S_1≥τ}。τ从discovery数据的预先约定尾部分位或外部目标指定，之后冻结；现有报告8.2只是诊断阈值，不应写进通用Skills。建议同时分析多个预先确定的尾部分位，以避免阈值偶然性，但不在验证集上挑最有利阈值。

节点应分别保存：后代是否可观测、可观测高分后代数、不同终态/几何模式数、实际终态分数分布、独立家族支持和物理质量标记。终态有效但非elite是已知负对照；被剪掉且未续跑的分支是未知。两者不能合并。

应变较高的高分路径仍保留证据与风险标签，可以在“合理质量的高分路径”和“高分但物理代理异常路径”中分别分析；不应让简单加权总分使affinity首要目标退化为能量最小化。终态化学图仅用于审计和去重；不据此禁止生成化学图变化。

反向计算高分后代信息时，同时标记future_policy。由现有Steer后代得到的是observed Steer-future utility，不是native-future成功概率。消除复制的伪独立性也不能凭空恢复未观测失败分支的结果。

### 4.3 为不同优势模式分配先验存储空间

借鉴MAP-Elites，先对三维路径的低维描述进行归档，而不是建立255维网格。可用全窗口平滑轨迹系数、占据变化和区域间几何关系组成描述，再用确定性的低维投影/聚类划分模式。每个模式保留多个不同家族的高分代表及已知非elite对照。稀有模式得到明确席位，复制次数不能增加它在奖励库中的份额。

不建议把所有elite坐标平均成一个目标：该平均可能处于没有真实优势样本支持的中间区域。保留完整模式或其局部协方差，并记录不同模式之间真实观察到的连接；没有观察到的连接只能作为待验证假设。

离线库能够改善已有高分路径的覆盖，但不能保证发现库中从未出现的新高分模式。“新路径发现”需要native轨迹或有针对性的续跑补充证据，不能只在固定档案上搜索后宣布发现了新的化学解。

## 5. 适合Agent理解的坐标特征与连续趋势

计算仍以三维坐标为主，均置于固定受体坐标系。不要对每个配体独立旋转/平移对齐而消除其在口袋中的位姿差异。原子编号不是跨图保守区域，必要时用柔性点云匹配或区域密度。

优先候选包括：

- 在数据支持的受体/空间landmark周围的平滑原子占据率、局部质心和协方差，描述某区域逐步集中、伸展或离开。
- 区域之间的距离、方向和相对形状，捕捉“核心接近目标位置，同时外围朝哪个方向适配”的协同关系。
- native坐标/特征速度、路径切向和曲率，区别真实生成运动与筛选导致的群体组成变化。
- 相同score时刻的elite祖先与已知非elite祖先差异，以及被反事实续跑证实有潜力的未选分支差异。
- 特征变化与未来尾部结果的关联、首次分歧位置、跨批次方向一致性和不确定性；原子类型/键可作条件与审计信息，主要guidance仍作用于坐标。

例如，空间区域的连续占据特征可写为：

\[
\rho_r(X)=N^{-1}\sum_i\exp[-\|x_i-c_r\|^2/(2a_r^2)].
\]

c_r、a_r应来自目标输入/数据支持，而不是在Skills中硬编码某分子残基。必要时使用mask和归一化，避免原子数直接支配密度。坐标速度只有在native对应关系合理时使用；预测endpoint的变化另称forecast change，不能称为物理动力学速度。

对全学习窗口统一拟合高分与非elite之间的差异D_r(t)，例如D_r(t)=Σ_k b_rk B_k(t)，用低自由度正则化样条，交叉验证平滑度，同时保存D_r、dD_r/dt和置信带。时间knots由真实采样时刻与复杂度选择确定，不重新硬分0–0.1等区间，也不强制全程单调。

检验单位优先为独立批次；重复轨迹与root家族的相关性需要保留。相邻50个节点不是50个独立重复。同一时刻的elite对照有助于去除共同的去噪/生成趋势，但不能解决所有选择偏差。可报告窗口积分效应、端点变化、峰值/转向位置和家族覆盖；对大量特征作多重比较控制，避免逐节点挖显著点再解释为规律。

这里的拟合用于构建可复核的函数，不需要额外训练神经网络。它仍属于统计函数估计。LLM可以选择特征、提出数学形式、写代码和解释证据，但不能凭阅读三维坐标就获得经过标定的概率或可靠梯度。

## 6. 由路径搜索形成低成本可微奖励的两个层次

### 6.1 第一层：有策略标签的未来价值，不冒充概率

首先可以从原始Steer路径建立尾部结果归档和连续路径tube，将现有近邻点云奖励改为多模式、终态标签驱动的几何函数。这一层可马上用现有数据开展离线分析，但输出应称“Steer-future潜势/相对证据”，没有native反事实标定前不称无Steer成功概率。

保留前缀一致性：对于多个路径模式，保存π_t(mode)的软分布，使用路径图的相邻时刻连接与当前坐标匹配更新，而不是每一步独立只选最近4个teacher。它不需要实际复制/淘汰粒子，也不把化学图锁在某分支；重叠模式中允许平滑转换。未观察到的模式转换不能赋予确定的高未来价值。

高潜势tube内应允许guidance减弱；不要继续把已经有优势的路径强拉到某个精确teacher原子坐标。这不是依据当前亲和力评分设置硬gate，而是根据离线学习的区域支持与不确定性控制干预程度。

### 6.2 第二层：native续跑潜势与Analog Markov递推

更接近最终目标的定义是：

\[
h_t(s)=P(E\mid S_t=s,\text{未来按native策略生成}).
\]

s的完整状态包括坐标、离散状态、时刻、受体和必要的模型self-conditioning信息。只用坐标投影是近似，不能默认已经满足Markov条件。生成时间是算法时间，这个h是有限生成期限的目标事件潜势，不是蛋白/配体物理反应速率的committor。

借鉴Analog Markov方法，用同一生成时刻的近邻状态及其native后继建立稀疏P_t。复制边不作为native转移，offspring_count不能替代转移概率。然后反向递推：

\[
q_1=\mathbf 1_E,\qquad q_t=P_t q_{t+\Delta t}.
\]

如果只构建学习窗口内的图，窗口末端q需要由相同重启阶段的native续跑到t=1标定，之后在窗口内向后递推。不能把Steer继续筛选后的后代频率直接填成q。已有native单步proposal提供条件运动信息，但被剪掉区域缺少多步结果；邻域拼接是否可靠取决于状态覆盖与信息充分性，应通过保留批次和native续跑验证。[Analog Markov研究](https://npg.copernicus.org/articles/30/195/2023/)

不建议直接在每次FLOWR推理里做MCTS：昂贵的rollout和affinity评分会改变当前预算与实验协议。已存档有向无环图上的反向动态规划先解决“已有路径如何选”。若需要额外采集信息，可在离线阶段用类似UCB的高价值/高不确定性标准挑少量分支做native续跑；必须含匹配的已选/未选对照及部分随机抽样，避免所有标定数据均来自预先挑中的好路径。该建议是信息采集设计，不是已经实施或已经证明有效的MCTS算法。

### 6.3 用显式核函数接入现有FLOWR坐标梯度

不训练新的网络，也可以将节点/模式价值平滑延拓为可微函数。一个可实现的候选为：

\[
K_j(z,t)=\exp[-d(z,\mu_j(t))^2/(2\ell_t^2)],
\]
\[
\widehat h_t(z)=
\frac{\alpha h_0+\sum_j w_j K_j(z,t)q_j(t)}
{\alpha+\sum_j w_j K_j(z,t)},\qquad
R_t=\log[\varepsilon+(1-\varepsilon)\widehat h_t(z)].
\]

其中z为坐标计算的平滑特征，μ_j(t)是不同路径模式的连续中心，q_j是相应未来价值，w_j同时限制批次/家族重复贡献，可加入缓存的软路径前缀先验；α与h_0提供数据稀疏时的背景，ℓ_t控制邻域尺度。取q_j∈[0,1]、w_j≥0、α>0、ℓ_t>0、h_0∈(0,1)、ε∈(0,1)，未知q不作为零值加入。前缀先验作为当前步的缓存条件，不能假装对整个历史进行了反向传播。若q来自Steer档案，该函数仍只是归一化潜势；若要将其解释为native概率，需要native标签与校准。超参数必须在discovery内确定，不对测试终态追调。

该形式保留多模式；若邻域内q都已很高，梯度可以减弱，帮助保留既有优势。远离所有有证据的模式时函数趋于h_0，避免无限远程吸引。硬top-k截断、Hungarian切换等会造成分段变化；新函数应优先用平滑区域特征或可微软匹配，并测试临界点行为。不能只因公式包含log/exp就宣称全程序处处可微。

若z=φ(ŷ_θ(X_t,t))来自FLOWR预测endpoint，则候选控制为：

\[
u_t=\eta(t)
\left[\frac{\partial\hat Y_\theta}{\partial X_t}\right]^\top
\nabla_{\hat Y_\theta}R_t(\phi(\hat Y_\theta)).
\]

继续使用真实FLOWR endpoint VJP，自动微分也要包含φ。若函数从current或proposal坐标学习，则接口与导数路径应匹配该表示，不能把它套到endpoint上而省略语义差异。η(t)由动态学习窗口、标签可信度和native步长校准确定；窗口以外控制严格为零，然后native续跑至1。梯度与时间变化率不是同一个量：dD/dt提供变化规律，不能直接当作∇_X R。

这不需要affinity head梯度或额外每步affinity推理，但仍有真实FLOWR VJP及几何计算成本。一般flow guidance依赖条件终态分布和路径假设；上述核潜势加VJP是需要实验验证的近似控制，不是对FLOWR精确的Doob变换，也没有复制TDS的渐近正确性。[一般flow guidance及协方差近似](https://arxiv.org/html/2502.02150)

若进一步使用经验路径切向来设计控制，要先检查它是否已由native flow实现，避免把同一运动叠加两次。任意经验方向场也不必能写成某个标量奖励的梯度；需要标量构造或可积性检验，不应把所有“优势方向”直接命名为reward gradient。

## 7. Analyst和Designer应该得到的关键信息

建议给Agent结构化路径证据卡，而不是整个坐标dump或只有全局p/q值。每张卡至少提供：

|信息|用途|
|---|---|
|模式与路径ID、父子连接、native/copy边类型、时钟、输入SHA|确保解释真实连续路径并能回查原结构|
|终态rescore分布、高分尾部、有效性、应变标记、future_policy|区别未来高分、生存、在线高分及物理代理异常|
|独立批次/家族数、克隆数、未知后代比例、置信区间|防止复制频数和幸存者偏差主导解释|
|区域占据、方向、形状的全窗口曲线与导数、elite对照差异|提出在哪个区域、何时、沿何方向调整|
|首次分歧、同胞/近邻对照、跨家族一致性、反事实结果|区别共享趋势与分支相关变化，列出相反证据|
|模式覆盖、可观察转移、近邻支持和外推距离|判断继续控制、保留已有路径还是不确定|

Analyst输出：受证据支持的路径模式、可拟合坐标函数、关键分歧/转向、独立证据量、替代解释及缺失标签。它不宣称仅相关的区域是因果binding hotspot。

Designer输出：所使用的证据ID、标量潜势公式、模式间组合方式、支持范围、导数路径、强度/时间规则及可执行注册程序。它需要能选用新的path/kernel family，否则再修改Skills，输出仍可能回到同一R26模板。

当前注册端只有endpoint_landmark、endpoint_direction和endpoint_pointcloud等已支持族。拟议的新路径潜势需要增加schema、编译器和运行时实现；不是在prompt里描述一个函数就已经完成接入。之前Skills精简未改变冻结奖励的有效执行签名，也提示必须区分“Agent解释改变”和“实际奖励改变”。

建议未来实现的独立模块接口，以下名称为计划而非本次新增实现：

- continuous/path_graph.py：trajectory + metadata → sparse nodes/edges + 时钟/复制一致性审计。
- continuous/elite_path_credit.py：图 + final rescore/质量 + policy → 终态尾部信用、未知标签与家族支持。
- continuous/path_archive.py：全窗口坐标模式 → 模式覆盖、不同家族elite/对照索引。
- continuous/path_geometry.py：稀疏路径 + 原结构引用 → 区域几何曲线、native/selection分解、趋势拟合。
- continuous/path_potential.py：已标记未来策略的标签/转移 → 非神经网络潜势、校准与不确定性。
- generation/path_reward.py：冻结潜势 → 与representation匹配的可微奖励和FLOWR VJP控制。

保持Skills短而通用：阅读证据、区分标签与策略、考虑不同模式、提出有支持的坐标规则、承认未知并验证可执行性。不要把当前靶点残基、固定时段或环境设置写进Skills。

## 8. 精简存储和工作流验证

结构仍使用已有可重建轨迹存储，不重新展开三种表示。node/edge用整数索引和结构引用，统一来源表存SHA及元数据；native/copy边为稀疏连接。只为注册的特征保留全窗口统计、曲线系数、置信带及少量可定位的代表路径。原始float32坐标不人为提高到双精度存两份，统计与拟合保留float64；批次表沿用无压缩Parquet策略。逐原子/逐边完整明细设为可重建诊断，不默认归档。

路径身份、失败/未知状态和不同模式覆盖是新信息，不能为了节省空间删掉。无需重新保存所有particle×time×feature展开表，也不能只留阶段汇总而丢失回查来源。

在修改Skills后，先进行工作流响应测试：

1. 保持各帧坐标/评分集合不变，只打乱父子连接；应改变路径连贯性结论及相应可执行潜势，不能输出完全相同的路径规则。
2. 将终态标签置为未知；Analyst应撤回native概率/终态elite断言，Designer不应凭空生成确定高分规则。
3. 增加完全相同的克隆；独立证据量和模式席位不应成倍增加。
4. 提供高价值但变化率接近零的路径；Agent不应仅因“没有提升”而丢弃。
5. 随机置换终态标签或提供相反证据；应削弱规则，并能在冻结证据集上记录响应。

这些检查分别验证数据、Agent判断和实际执行程序，而不是只检查prompt是否出现某个词。新family还需数值梯度/有限差分、时间支持、坐标系与无额外head调用检查。

## 9. 推荐的验证顺序

第一步先完成现有档案的路径/终态尾部重建。只使用当前discovery批次建立库，在其内部按批次/家族交叉验证；已被反复查看或调参的历史集合只能称回顾性评估。真正的最终验证需要未用于设计的初始样本。

建议分离下面几项增量，以判定性能改善来自哪里：

|对照|变化|要回答的问题|
|---|---|---|
|冻结R26|无改动|现有GG基线|
|终态elite模式库|改变标签与覆盖，保持原近邻奖励|原teacher是否遗漏极高分路径|
|加入路径前缀/连续模式信息|保留父子关系与软路径先验|逐时刻teacher切换是否损害潜力|
|加入native标定的核潜势|有限续跑标签、稀疏递推与平滑函数|未来价值是否比静态点云吸引更接近目标|

每项均与同初始状态无guidance、无Steer续跑配对；guidance仅在动态学习窗口内生效，再native生成至1。Steer比较需要相同输出数和明确计算预算，同时继续保留原始Steer。没有新实验结果前，不承诺上表任一项有效。

主要指标是有效终态高分命中率、固定输出数量的高分分位/最佳值、不同高分模式、相对配对native的亲和力变化；同时报告全部生成尝试为分母，避免过滤坏结构后只剩漂亮均值。不同图数用于结果多样性审计，不作为图变化控制gate。

高分尾部只有少量事件，统计应按批次/独立家族保留相关性，并报置信区间和真实样本量。用多个独立批次检验，不能用一两个极值证明算法胜出。潜势若称概率，还需native续跑的排序、Brier/校准与覆盖检查。应变、dock_fast、周围区域松弛指标继续作为次级质量和风险评价。

最值得优先检验的假设是：在不增加每步affinity head评分、保持化学图自由变化的前提下，终态尾部标签、多模式覆盖和路径连贯性能够保留现有GG对主体分布的收益，同时减少对高潜力路径的不必要牵引，从而提高有效高分尾部的发现率。
