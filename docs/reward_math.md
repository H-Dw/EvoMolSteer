# 解析奖励与生成器接口

设固定原子类别和掩码下的配体坐标为 X，残基 r 的受体重原子坐标为 P_r。距离特征定义为

\[
f_r(X)=-\tau\left[\log\sum_{i\in M,j\in P_r}\exp(-\|x_i-p_j\|/\tau)-\log(|M||P_r|)\right].
\]

全部有效槽位或 N/O/S 槽位构成 M。M 为空时停止该奖励求值，不能把缺失映射到数值 0。计算坐标为 Å；在当前数据中 τ=0.25 Å。

经验窗口 [l_k,u_k]、尺度 s_k 和阶段 [a_k,b_k] 由可引用证据确定。定义

\[
g_k(t)=\mathbf{1}_{[a_k,b_k]}(t)\sigma((t-a_k)/h_k)\sigma((b_k-t)/h_k),\qquad
q_k(f)=\operatorname{softplus}_{10}((l_k-f)/s_k)^2+\operatorname{softplus}_{10}((f-u_k)/s_k)^2,
\]

\[
R(X,t)=-\sum_k w_k g_k(t)q_k(f_k(X)),\qquad
\operatorname{softplus}_{10}(z)=\log(1+\exp(10z))/10.
\]

沿 ∇R 做上升。它是固定解析函数，没有额外拟合网络。梯度需要固定分子类别；硬 argmax 的类别切换不可微，本实现不假装能优化元素或键类型。不同区域的项可能冲突，初始只使用少量低权重假说。

v2 的 t 为评分时间，各项的阶段必须属于观测到的选择窗口。指示函数按左闭右开解释，仅选择窗口的最后端点包含。边界比较沿用分箱的六位小数舍入，平滑门仍使用原始时间；名义区间外奖励及坐标梯度为零。对时间的硬截断不影响固定 t 时关于坐标的可微性。经验区间来自选择概率加权候选分布，不再来自终态成功后代。

设 \(\alpha_{ij}=\exp(-d_{ij}/\tau)/\sum_{i',j'}\exp(-d_{i'j'}/\tau)\)，则固定掩码时

\[
\frac{\partial f_r}{\partial x_i}=\sum_j\alpha_{ij}\frac{x_i-p_j}{\|x_i-p_j\|},\qquad
\nabla_X R=-\sum_k w_k g_k(t)q_k'(f_k)\nabla_X f_k.
\]

实现对零距离加了极小的数值保护。LLM 不需要直接从坐标文本猜测每个原子的梯度：它选择可测区域、时间窗及经验目标，固定运行时从真实几何计算方向。低于窗口时该距离项倾向增大距离，高于窗口时倾向减小距离；多个项的合成方向仍可能冲突，不能将单项方向解释成已经验证的分子优化路径。

若未来生成器给出预测终点 \(\hat X_1=F_\theta(X_t,t)\)，理论梯度链为

\[
\nabla_{X_t}R(F_\theta(X_t,t),t)
=J_{F_\theta}(X_t,t)^\top\nabla_{\hat X_1}R.
\]

从模型坐标到世界坐标的尺度也必须进入链式求导。该公式不是已经完成的实时接入：还需处理原实现的 no_grad/inference 模式、自条件缓存、连续/离散头以及 SDE 求解器的单位和步幅。只对保存终点求导不能自动得到这个 Jacobian。

部署前最小实验应固定初始先验、未来随机噪声、生成预算和终态评分协议，对比无控制、原重采样、解析梯度以及随机/反向规则。区域消融、阶段消融、已修复特征保留、化学有效率、PoseBusters、双目标及多样性均要分别报告。当前反事实副本并未使用共同未来噪声，不能替代这项验证。
