# 选择窗口专用算法与解释边界

本版本只研究：在实际执行 Steer sampling 的时间段内，选择权重偏好哪些区域特征、这种偏好如何随时间改变、随机重采样如何实现或偏离这种偏好。它不估计终态成功率，也不从后期轨迹寻找控制规则。

## 1. 范围与表示

从每个 NPZ 或经验证的无损 HDF5 轨迹的 `resampled` 读取实际选择步。当前分析要求选择组在相同时间表下匹配；时间表不同的实验应分开处理。背景组只取对应评分步，并保留 `resampled=False`，不会误作“全选中”的阳性组。

本实验为 51 次选择，评分时间 0–0.5（含端点）。最后 proposal 的时间约为 0.51，但它是评分 t=0.5 的选择对象。仅在评分事件上分箱，五个展示阶段分别有 10、10、10、10、11 个事件；最后箱含 t=0.5。

保留两个测量表示：预测终点用于理解模型偏好，proposal 用于理解实际复制的几何分布。PCA、阈值、统计、目标原型、证据包均受同一范围约束。规则接口拒绝旧全程证据。

## 2. 先做事件内比较

记单次事件有 B 个候选，几何特征为 φ_i，选择概率为 p_i，实际子代数为 n_i。

期望选择位移为：

\[
\Delta_{expected}=\sum_i p_i\phi_i-\frac1B\sum_i\phi_i.
\]

实际复制位移与随机偏差为：

\[
\Delta_{realized}=\sum_i\frac{n_i}{B}\phi_i-\frac1B\sum_i\phi_i,
\qquad \epsilon=\Delta_{realized}-\Delta_{expected}.
\]

因此，一个几何极端候选偶然被复制多次，不会自动成为“稳定选择偏好”。当特征完整时，还计算该几何均值在多项式抽样下的理论标准差；详细值随可选的事件明细保存。

on/off 两个分量分别按 `weight_on`、`weight_off` 计算。joint 的期望权重为两种归一化权重的等权混合；分量显示目标之间的一致或冲突，不能把联合选择解释为两个目标必然同时改善。

默认要求一个特征覆盖至少 80% 的候选及概率质量。部分缺失时，统计是对有效候选条件化后的分布，覆盖率和保留质量参与每次计算，并可随事件明细保存。compact 保留有效事件数、批次支持和诊断计数。不能把缺失几何当作零距离。完整特征的复制方差才使用精确多项式公式。

## 3. 富集与差异

富集阈值是 discovery 无重采样组**同一评分步、同一表示**的第 75 百分位。这样候选几何随时间漂移不会因不同时间组成产生虚假富集。阈值在 discovery 拟合后冻结。

保存高特征集合的期望概率质量相对均匀分布的增量、实际复制质量增量，以及选中/淘汰的 log-OR；后者使用 0.5 伪计数，只是随机实现的辅助描述。

差异先在单次事件内比较选中和淘汰候选，再计算同一直接父节点内部的同胞差异。不同时间的粒子不直接混为两大组。相同 endpoint 的克隆可能有不同抽样结果，因此同胞零差异必须保留。

## 4. 变化率、统计和算力优化

三种变化率分开计算；阶段推断始终保存，逐事件/逐边明细按输出策略保存：

1. 选择位移除以本次积分 dt：单位生成时间上的选择作用。
2. 相邻事件/阶段的选择效应差除以实际参与比较的评分时间差：偏好形成或减弱的速度。
3. 真实父子边的几何差除以该表示的实际几何时间差：路径上的特征演变。只连接窗口内节点，不按相邻行号配对。

每个批次阶段内对有效事件等权平均，再对独立批次推断。各特征的阶段时间由其实际有效事件计算，不使用包含无关帧的整箱时间。相邻比较不跨缺失阶段或缺失步骤。

检验采用批次符号翻转（≤12 批枚举，否则固定种子随机化）和批次 bootstrap。共享抽样矩阵按样本量缓存，并按多特征矩阵分块计算，避免每个特征重新生成同一批随机设计。固定批次排序确保输入行顺序不影响结果。少于 4 个独立批次只输出描述结果。

BH 的检验族预先限定为每个结果文件内部的“表示 × 策略 × 比较”，在该族内同时校正特征和阶段。可选的逐事件表保留完整描述值；LLM 阶段证据使用校正结果，并按需从候选缓存重建目标特征的事件曲线，不把高频帧当作新增独立重复。

## 5. PCA 与规则原型

PCA 的填补值、尺度和坐标轴仅使用 discovery 无重采样组的匹配选择窗口，不读取后期状态或留出集。所有选择组使用冻结轴，分别计算期望/实际选择质心位移。PCA 载荷是相关变异方向，不能单独确定奖励方向。

规则原型采用有效候选的选择概率加权 IQR：批次之间等权、每批有效事件等权、事件内按 p_i 加权。重复克隆的相同值先合并概率质量，避免分行方式改变分位数。另提供均匀权重的参考 IQR，以及支持批次数、事件数和根数量。

这类原型描述选择偏好，不使用最终成功后代，不声称是几何最优区间。若加权与均匀分布几乎一致，规则的方向性依据就很弱。Analyst 必须保留随机偏差、同胞对照及表示间分歧。

## 6. 移除与保留

主流程和命令行已移除 terminal、counterfactual、成功后代关联、全程策略差异及后期阶段。当前特征表也不包含这些标签；scope 校验会拒绝带结局字段的输入。

原始归档和旧分析结果作为历史证据保留；它们不被当前代码作为规则输入。新无损结构输入包可供当前提取器读取，旧 HDF5 全程特征包不能绕过 scope 校验。输出精简不删除任何特征、非显著结果、同胞零效应或选择对照；其验证与存储边界见 `selection_storage_integration_20261004.md`。

Analyst/Designer schema 升级为 2.0。每个规则都必须有相同特征、表示、阶段的证据。Designer 仅编译预测终点规则，并复制实际评分窗口。奖励阶段门在区间外严格截断；坐标上保持可微，时间作为外部控制量。该接口准备了后续规则试验的输入，没有证明无重采样生成的最终收益。
