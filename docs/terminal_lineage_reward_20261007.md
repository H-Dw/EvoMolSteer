# 终端谱系信用与坐标奖励：正式 v4

当前30轮从本次请求重新计数。最终解码分子的预测 CK2 亲和力是主目标；能量是次级检查。本文记录可复核的输入、决策、公式和限制，不记录私有思维过程。

## 为什么新增该分析

即时评分奖励可以真实改变坐标，却在后续无引导生成与最终重评分后失去平均收益。例如R6学习窗口结束附近平均增益约0.112 pIC50，最终为−0.006；R9约0.071→−0.041。该结果不能等同于“梯度没有生效”。完整坐标点云R7最终平均增益0.229，为已测全局亲和力基线。

此前坐标目标主要按节点的即时联合潜变量 head 分数选择。新增终端谱系信用，以既有后代记录给早期坐标目标补充一个结局标签，不增加网络推理或拟合额外模型。

## 谱系与缺失

`selected_indices[j, child]`把j+1节点的槽位映射到j节点父槽位。末个已评分节点99从identity开始，依次应用98到0的映射，不应用99行的selection。每个节点统计有多少可观测后代，以及这些后代99行既有联合潜变量head分数的均值。灭绝分支的未来亲和力是缺失，保存NaN而不是0。

原始14批各100步、50槽位。原Steer记录实际包括score=.50到state=.51的一次选择。它参与未来结局标签回溯，但不参与严格state≤.5的坐标特征学习。该学习支持为score0… .49的50个更新；窗口从参考数据动态取得。99行score=.99，state=1，其联合潜变量head分数仍不是解码最终分子的独立重评分。

14批在t0的最终存活祖先中位数仅1；700批次节点中349处少于3祖先，531处少于6。不能强行做完整窗口的终端信用高低分对照。200维局部Gaussian质量、均值及协方差的存活／灭绝描述，先在当前父节点内平均再按批等权；剩余初始根依赖仍存在。两个全窗measure共400项联合BH检验均未达到q<.05（最小q约.12043）。这些是探索性存活关联，不能叫显著亲和力优势区域。

## 老师点云和奖励

正式库使用完整受体坐标系中的祖先endpoint预测，每批最多2个，与R7真实canonical库的上限一致。R7每节点28老师；新库随节点从17增至28。早期根收缩是限制，不补造老师。按终端信用排序；固定框架Hungarian RMS≤0.001Å只排除近复制，不保证分离的构象盆地。

每批老师数为m_b时，老师基础log质量为−log(m_b)，使基础质量按批再按祖先等权。离线信用和nearest-K约束随后改变条件prior，不能声称每个生成样本的条件prior仍严格等批。

沿用R7的可微点云公式：在固定endpoint anchor上进行Hungarian匹配，取最近K个完整点云。条件logit为`base_log_weight − anchor_cost/temperature + beta*(credit−mean_credit)`。坐标均方残差q对应平滑代价`rho=delta²*(sqrt(1+q/delta²)−1)`，奖励为`tau*logsumexp(log(pi)−rho/tau)`。匹配、prior及anchor固定，对实际FLOWR预测坐标求导，再经真实FLOWR坐标VJP回到当前状态。

首轮新库比较R17保持eta=.3、K4、beta2、温度4Å²、tau=.5、delta1Å、时间ramp0。它是整个坐标目标库修订，包含存活资格、信用、基础权重及近复制规则，不能将收益单独归因为信用。R19只移除条件logit信用权重，老师仍按信用选择。R24试eta=.18。其余注册探索保留当前全局亲和力赢家，27–30冻结后使用新批次验证，不再调参。

没有原子类型奖励、亲和力head求导、在线额外head／model forward、SMC或化学图接受gate。引导覆盖所有动态支持节点，之后继续原生积分至1。每次首次引用新库必须通过一次真实FLOWR有限差分及完整100步零权重／无引导一致性；CPU检查不能代替GPU测量。

## 来源与存储

正式`terminal_lineage_v4/`有三张无压缩Parquet，约2.93MB，保存700批次节点的摘要、完整统计及缺失覆盖。坐标库约2.17MB；逐候选展开缓存不保存。函数采用观察节点均值的分段线性表示，并保存变化率，避免外推。原始Steer仍受保护。

v1–v3是未激活的预备版本；正式v4来源SHA与运行时配置副本逐字节绑定。参考中继承的`teacher_library`字段是父库来源元数据，不是新祖先点云的内容SHA；新库使用顶层完整文件SHA、reference_variant和terminal_metadata校验。即时标签的high/low统计仍作为父参考来源保留，但运行时限制该库只能用于endpoint_pointcloud，不能作为终端特征对比奖励。

实际Agent完整读取Skill、input与prompt，保留literal JSON、简洁理由和hash。行为测试要求数字响应，且拒绝hash正确但将灭绝填0、混淆最终评分、补造信用分层、错误容量／基础权重或额外head的响应。独立审查覆盖当前代码、数据与编译后的设计，然后本地提交／VPN推送、远端精确pull、清理旧可再生成结构、推理、导出、本地分析与保留报告。
