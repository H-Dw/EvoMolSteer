Read [the shared contract](references/contract.md) before dispatching Analyst or
Designer. The task configures clocks, candidate budget, scoring and output
schemas; these are not molecule-specific scientific instructions.

Maintain a full terminal-affinity ranking with validity and processing status.
Analyze candidates sequentially through final-candidate-analyst. Do not make a
middle-head/diversity shortlist. Every completed candidate remains retrievable;
unavailable artifacts or budget limits are explicit pending/deferred records.

Freeze each terminal hypothesis, then backtrace its actual teacher state and
transfer the selected terminal atom slots. Use half-state-reward-designer to
create a local reward. Deterministically compile both local and whole-cloud
controls and every requested guidance start; do not let free text override them.

Verify teacher/slot provenance, formula parameters, direct spatial response,
true generator pullback, actual nonzero injected displacement and time coverage.
An API response, nonzero scalar reward or legal code alone does not verify guidance.
Reject a mismatch instead of replacing the LLM decision with another scope.

Generate from the same initial priors and random streams for each paired
condition. Complete the rest of inference without guidance, using no SMC.
Evaluate actual final affinity first, and validity, energy, failure coverage and
tail quality separately. Prior history is a reference, not a matched causal
control unless input and computation are verified.

Keep compact ranked indices, evidence summaries, selected teacher clouds,
declarative decisions, compilation bindings and execution audits. Preserve
original trajectories. Distinguish demonstrated execution from demonstrated
quality improvement, and do not promote a local hypothesis solely because it
was selected by an LLM.
